CHAPTER 10 / 14

难度如何量化

约 3 分钟·数据快照 2026-09-21设计阶段 Q0
先掌握这三件事
  • 难度属于某个实例加上完整评测条件，不属于论文名称。
  • 十维人工矢量是设计注记；经验难度需要固定 agent panel。
  • 全模型失败时，先排除不可解任务和错误评分器。

难度的单位是 instance 加上完整评测 contract。同一条毛巾、同一目标，在不同手部能力、观测、controller、示范量和时间限制下，难度会改变。不兼容或不可解的配置应标为不适用／无效，不能当作高难题。

设计难度：十维矢量

维度 0 的锚点 2 的锚点 4 的锚点
H 依赖长度 一个独立 primitive 数个因果依赖步骤 长分支、多个持续承诺
C 组合／因果 直接对应 选择／排序已知子目标 新组合、多约束与依赖
O 观测／记忆 相关状态现在可见 遮挡或短历史 隐藏状态需长／跨 session 历史
P 接触／精度 不需接触 中等容差的稳定接触 窄容差、动态、柔顺或密集接触
D 形变 刚体状态 中等材料形变 重大形状／拓扑、自遮挡、混合材料
B 机体协调 单末端、固定底座 双末端或底座与手臂协调 全身／多末端强耦合
G 泛化差异 匹配训练分布 held-out instances／scenes 新类别、组合、材料或机体组合
U 不确定性 目标／合法动作已知 多种可能解释 需观测／询问的目标与结果不确定性
R 恢复需求 没有注入扰动 一个可恢复扰动 多个相互影响的失败与重规划
S 社会协调 单独运行 共享时序／轮流 意图相关协作与变动对方行为

每维 0–4，中间值 1／3 由相邻锚点判定。需保留完整矢量，unknown 不填 0，并由独立标注者检查一致性。以下等权公式只是旧报告中的透明设计摘要：

D_design = 2.5 × (H + C + O + P + D + B + G + U + R + S)

它不是公认难度标准，不能拿来排列 168 篇论文，也不能跨 QA 和实体操作比较。专门的高精度任务可能很难，却因没有社交／记忆需求而总分低。旧报告的十个假设评分例子保留在附录 H，没有套到 180 个情境上。

经验难度：固定 agent panel 后再估

D_empirical(t) = 100 × [1 − Σ_m w_m × P(success | m,t,contract)]
Σ_m w_m = 1

需要相同模块、兼容 contract、固定方法群、多次实验和不确定性区间。这只是该 panel 下的相对难度；换模型群就可能改变。少数共享 checkpoint／controller 的系统也不是大量独立方法。

保留 method×task 的结果矩阵，先检查是否存在足够的成功／失败差异，再考虑 IRT 或多维／阶层模型：

P(success | m,t) = logistic[a_t × (ability_m − difficulty_t)]

需要检查识别性、数据量、residual dependence、模型家族敏感性与 held-out-agent 预测；fit 成功不等于量尺有效。更新题库时保留 anchor items，但重新验证版本影响。tinyBenchmarks 是相邻领域的方法启发，Rliable 提供 agent 评测的统计方法参考；都不自动证明这套机器人难度量尺有效。P159 P160

难度、诊断力和重要性分开

全模型都失败，可能是难，也可能是不可解、label 错或 adapter 坏。先用专家、oracle 与判分器审核排调试题。全模型都成功的题仍可重要，但对当前排序的鉴别力有限。

视频长度、子目标数、对象数、A/B/C 实作阶段都不能直接取代实测难度。EgoSchema 的时间证据观点提醒我们：应测「必须看多少历史」，不只是「视频有几分钟」。P028
