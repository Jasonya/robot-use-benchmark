先看代号：G是计数粒度，T是评测模块。

例如G2是任务规格、G4是一个测例；T3是预测、T5是实际运行。这些是本计划的整理编号，数字不代表难度，也不要求依T1→T8顺序运行。

家族按语义需求整理，例如「打开—存入—关闭」、「依历史取物」、「指定折法」、「工具操作」、「共同支承」、「数字查找—实体完成」。这 48 个是本计划的 authored grouping，跨工作 canonical mapping 尚未完成。

附录 A 完整列出每个家族的子目标图、证据、近失败、扰动、物理需求和 A/B symbolic template；附录 B 完整列出 180 个情境的初态、A/B 目标与专属验收。它们是设计规格，不是已写好的环境或可运行 predicates。

观测、机体与学习设置是不同轴

O1–O8 是可重叠的来源 presets：文字／语音、头戴视频、胸前／身体摄影机、外部／多视角、剪辑 VLOG、模拟 robot 示范、多 session 历史、非人类第一视角诊断。头戴片段也可能是剪辑 VLOG；不能把这两种标签当互斥来源。

正式 metadata 分开记录 agent origin、camera mount、view pairing、temporal packaging、language、history 和 sensors。EgoBody 研究从头戴设备观察人体，不能只凭名称把它当成胸前摄影机数据。非人类视角可测域移与 egomotion，但不能增加 robot 实体操作覆盖。P019 P025

R1–R6 分别是固定单臂、固定双臂、固定灵巧双臂、移动单臂、移动双臂、全身／人形的候选能力配置，不是已选定六台机器人。L0–L4 分别是 frozen、offline adaptation、few-shot、online adaptation、continual learning；这些参数更新设置与 T2 的推理时记忆分开。

34 个能力、12 个变化轴、8 个来源 preset、独立观测轴、6 个 profile 与 5 种 learning regimes 全部定义在附录 E。

材料模型分为 rigid、cloth、rope、granular、fluid、soft_solid。Articulation 是对象结构，不能当成材料；137 个 rigid 蓝图中包含 2 个信息情境，真正 T5 候选为 135。

目前仍以刚体为主。4 个 fluid 情境集中在 1 个运行家族，不能叫做完整流体操作覆盖。绳索、切割、人体／布料、动态支承和世界模型的验证仍有限。场景换名字不会自动增加接触机制或物理能力。

接触覆盖不等于消毒；机械搅动不等于化学均匀；设备状态机不等于真实热学或洗净效果。若只验证逻辑程序或模拟代理量，就按实际内容命名与分榜。

A／B／C 是提出的实作分组：A 93 个偏原型优先；B 64 个需要柔性物、特殊接触或交互；C 23 个涉及更专项的物理／拓扑／复合需求。它们不是已量测的难度级别。

附录 E 的场域×能力矩阵分开「家族本身需求」、「可额外产生的 probes」与联集。所有 verified cells 仍为 0；C33／C34 等观测能力主要由额外 24 个 Ego 题型支持，不能灌入操作成功率。
