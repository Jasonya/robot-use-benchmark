EgoZero: Robot Learning from Smart Glasses

返回逐篇总表内核内容已核读 方法／综述参考原作 ↗

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

EgoZero公开Aria示范前处理和Franka点轨迹控制；提供的Franka底层done固定False，不能直接把现有success日志当自动任务成功评测。

版本与身份

固定51dc1c6；公开code偏数据处理/实机部署，硬件另依Franka-Teach。未向MPS提交数据或运行机器人。

领域
方法／综述参考，未另作来源用途归纳。
环境
人类Aria录像与Franka/iPhone RGB-D实机部署，需ArUco/相机/robotframe的标定；手持示范场景不等于已可重播机器人环境。
任务
由人类点／手部轨迹学习操作；原README按指定手消失来分demo，用另一手reset，这是搜集协定而非任务语义。
题数与数据
每demo保存original.mp4、palm/wrist/index/thumb/grasp/pose.npy、fingers_keypoints及first_frame_g2w；人工标记对象点／triangulation另存。Frankafeatures为pos3+quat4+gripper1；底层声明action_dim=7却按pos/quat/gripper切片，须核对wrapper实际编码。
评估方式
eval.sh选eval_point_track、10queries/10history与temporal_agg；日志平均goal_achieved。所读Franka step总回done=False，wrapper把done设为goal_achieved，因此此路径未提供task-specific自动成功checker。实机操作展示与论文实验评分需另保留人工／任务规则。
