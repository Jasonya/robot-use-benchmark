领域
装配与生产作业、穿戴交互与动作界面
环境
脱机AssemblyHands/Assembly101玩具组装、Ego-Exo4D活动与EgoMe正确模仿配对视频；AssemblyHands/Ego-Exo4D有同步多视角，EgoMe-pose的Ego/Exo配对可能不同步。CALVIN ABC→D是另行teacher-to-policy蒸馏的robot下游实验。
任务
VL-EHPF在t时刻输入1–10步Ego影格、语言instruction与同段手姿，输出t+1至t+10的42×3座标（两手各21点）及42点validity。论文DERM把涵盖观测与未来的配对Exo视频当训练监督，从Ego输入重建Exo表征，再交GLMM；推论公式只含Ego/语言/pose，不能把实际未来Exo影格加入test条件。它预测人体pose，不直接输出robot动作。
题数与数据
论文报AssemblyHands衍生episode train/val/test=6,120/355/355，Ego-Exo4D=10,869/1,540/1,540，EgoMe-pose=6,067/1,344/2,648；这是episode数，不是10-frame forecast windows、joint数或实际可下载case数。AssemblyHands/EgoMe-pose为15FPS、Ego-Exo4D为30FPS，RGB resize224×224，10步预测因此有不同时间长度。AssemblyHands保留每手>10个valid joints且root有效的frame，world→Ego camera并依共用frame ID连Assembly101文字；随机Exo view配对，从原val随机切50%作test。Ego-Exo4D须Aria去畸变、world→camera及joint-order映射，文字window为atomic timestamp前0.5秒至后1秒且每frame pose有效，也将原val随机半分作test。EgoMe-pose以InterHand相对姿态+RootNet root-depth转绝对座标，剔除false imitation、hand confidence<0.6或有效frame比例≤95%的episode；异步Exo以片段相对位置线性对齐。上述随机seed、episode/frame清单、joint permutation、标注档schema均无公开reader可核。
评估方式
仅论文§4.1.2：MPJPE比较root-aligned predicted/GT关节的Euclidean距离；MPJVE比较关节位移，论文单位写mm，没有可核程序证明另除Δt，不能改记mm/s。这与EMPIRE的absolute-camera MPJPE不同。虽模型预测validity，实际scorer使用GT或pred mask、两手/root是否计入、分母是有效joint-frame或先逐episode平均、位移是否包含最后观测点及缺失邻接frame处理均待程序确认，不能用10×42固定分母填空。CALVIN表列连续完成1–5任务比例、Avg.L.与Avg.R.，采ABC训练→D测试及Exo2EgoPose teacher蒸馏GR-1类student；本版无robot action adapter、trial manifest或具体success checker可读，不能把手姿误差换成robot成功率。

怎么接入我们的benchmark

可重用

重用已确认paper/repo身份、三个衍生数据集的母来源、42点/10步/validity任务契约及论文明列的split/采样条件；repo仅提供发布状态证据。

需要转换

case以母数据版本+衍生episode+query frame+split+FPS识别；保存world/camera/root-aligned三层座标、两手joint-order与validity。另记train-only Exo监督、同步/相对时间线性对齐、原val→新val/test关系；CALVIN蒸馏独立为下游reuse关系，metric保留pose与robot两类原生单位。

仍需补齐

程序与EgoMe-pose benchmark尚未发布；缺前处理、reader、精确split/seed、有效case manifest、MPJPE/MPJVE具体分母与root/mask约定、weights及CALVIN蒸馏/运行成功判定。不能运行或声称本轮重现论文分数。
