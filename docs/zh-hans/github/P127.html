BridgeData V2: A Dataset for Robot Learning at Scale

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

BridgeData V2提供raw/自订TFRecord/RLDS多种表示。预设训练action会被改写成到达状态差分，gripper还会使用后续状态重新标记，不能只改文件扩展名。

版本与身份

固定bc60a35，README清楚区分raw demos与scripted zip及多种表示。此repo是训练/部署方法实作，不能把其所有分支范例当Bridge添加benchmark。

领域
居家整理与清洁、餐饮与烹饪、衣物与洗护
环境
WidowX在多种桌面/厨房环境的搜集与部署；raw示范和scripted数据、经转换的TFRecord/RLDS共用来源episode。
任务
goal-image或language条件的操作；各算法/目标重标与视角不是新的物理任务。CALVIN/SuSIE子目录为其他实验来源，需另标parent。
题数与数据
自订TFRecord每example一trajectory，含observations与next_observations的image/state、actions、terminals/truncates和可选language。relabel_actions用next_proprio[:6]-current_proprio[:6]，gripper阈值>.95/<.05再回填中间值；chunk补首obs/末action，goal与language另采样。
评估方式
部署从checkpoint还原action_mean/std；采样后可加noise、sticky-gripper状态机与屏蔽部分姿态自由度，再送WidowX。这些是控制协定。所读eval程序提供rollout，没有通用任务成功predicate；原作实机成功标记需另建protocol。

怎么接入我们的benchmark

可重用

父episode、多格式映射、原生7D action/重标规则、goal和语言条件。

需要转换

保存raw_action与training_action的转换/normalization版本；补值mask、来源时间、goal采样一起记入case；评测固定action execution horizon及gripper/DOF后处理。

仍需补齐

raw→NumPy→TFRecord/RLDS全量ID映射、相机/场景metadata、测试split与成功rubric、与OXE子数据去重、原生部署验证。
