P035 · EgoVLPv2

EgoVLPv2: Egocentric Video-Language Pre-training with Fusion in the Backbone

返回逐篇总表内核内容已核读 方法／综述参考原作 ↗

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

EgoVLPv2 是跨模态预训练方法与既有 benchmark 的适配实作，保持 related_reference 身份；没有把其下载特征和下游结果当作新环境或新题库。

版本与身份

root README 指明基于 EgoVLP 的特定提交，不能与 P034 的当前固定快照视为完全相同程序。EgoTaskQA 的数据仍属 P032/LEMMA 衍生范围。

领域
方法／综述参考，未另作来源用途归纳。
环境
沿用 EgoClip/Ego4D、EPIC-100、Charades-Ego、EgoTaskQA、QFVS 等父来源；此方法不独立定义一组新生活场景。
任务
预训练与 video-text fusion，于 EgoMCQ、retrieval、动作、NLQ/MQ、QA／summarization 进行迁移。任务清单引用原 benchmark，模型比较本身不增加 canonical tasks。
题数与数据
EgoTaskQA 子目录明确沿原作者预处理，formatted_*_qas_encode.json 的 interval 加 .mp4 定位加工视频，question/answer_encode 和 reasoning_type 保留；tokenizer 以30 token 为上限截断，frame 预算由配置定义。NLQ 保留 clip_uid/annotation_uid/query_idx/predicted_times。
评估方式
核读 NLQ 原生时间 overlap/top-K 阈值 recall，分母为传入预测且只列 evaluated/GT。QA validate 在分布式 allgather 后 argmax 对 answer 索引，另计 reasoning tag 正确率；直接 all_acc 公式写成 correct/B*world_size，需检查分母与 tag 报表的一致性，不直接采用此摘要作新结果。
