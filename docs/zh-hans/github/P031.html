EgoPlan-Bench2: A Benchmark for Multimodal Large Language Model Planning in Real-World Scenarios

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

EgoPlan-Bench2 比第一版加入明确 domain/scenario 字段并扩充人类生活用途；已核读完整 eval.py，确认其测量仍是视频下一步四选一。

版本与身份

与 P030 的 EPIC/Ego4D 双父库不同，本版文件只指 Ego4D；题目集合、父视频与候选需核对后才能算净添加量。

领域
居家整理与清洁、餐饮与烹饪、工艺与修缮、零售与购物、实验室操作、个人照护、交通移动与车辆维修、农业与园艺、休闲与运动
环境
Ego4D v1_288p 视频，原文案 4 major domains／24 scenarios 是生活用途分类，不是 24 个物理 layout。sample_id 的 UUID 前缀连到父视频，另有 task_start_frame。
任务
依整段进度及当前观测推下一动作。四候选与 task_goal 构成题目；CoT／GroundingDINO 是可选方法处理，不能当多一批评测任务。
题数与数据
sample_id、domain、scenario、task_goal、choice_a–d、golden_choice_idx、answer、task_start_frame、current_observation_frame、task_progress_metadata。eval 从 start 到 current 逐 frame 截视频（含末 frame），或用 linspace 抽预设8张给 image model。
评估方式
extract_characters_regex 取回复第一个大写 A–D，空字符串算错，再与 golden_choice_idx 比较累积 accuracy；保存 raw model_response 与 extracted_answer。parser 的部分 prefix 字符串因少逗号被相接，且非严格字边界匹配，需保存此原始版本。

怎么接入我们的benchmark

可重用

来源 domain/scenario、完整观测区间、四候选与推论／解析／分数纪录。

需要转换

沿用父 Ego4D ancestry，添加 source-local domain/scenario 映射；case 留 sample_id/观测范围。image-8frame、video、CoT 分成 evaluator configuration，不把方法条件算成新任务；选项及字符串一致性可在 intake 检查。

仍需补齐

未取得完整 HF 题库／视频或运行。需将所有来源 domain/scenario 逐项映射本计划用途，不能只抄 4/24。输出采 append 且每次 count 重设，重跑需 session ID 与去重；已存在的视觉缓存需绑定 source/sampling hash。
