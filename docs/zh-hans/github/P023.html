My View is the Best View: Procedure Learning from Egocentric Videos

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

EgoProceL 是程序学习数据与 CnC 方法的共同发布；它明确重用 CMU-MMAC、EGTEA、MECCANO、EPIC-Tent 并加入电脑组拆。已核读数据源、PC Assembly loader 和主评分调用。

版本与身份

download README 明列旧 OneDrive 过期与新 Google Drive，并说父库只有部分视频被使用；以新程序标注清单作 subset 证据。PC_Assembly.py 开头注解仍写 MECCANO，但类别及配置实际为 PC_Assembly。

领域
餐饮与烹饪、工艺与修缮、装配与生产作业、农业与园艺
环境
烹饪、玩具／电脑组拆、帐篷搭建等人类程序视频；parent dataset→category→video 需要保留。16 个原生 task 是程序活动，不是 16 个独立房间或全部录制环境。
任务
由同一程序多段视频学习 key-step 与次序，包含缺步、重复步和背景。重用父数据的视频被加上程序标注，不可和父库相加当全新视频。
题数与数据
CSV 与原视频同名，三栏为 step 起始秒、结束秒、step 名；子集按来源／category 分目录。PC_Assembly loader 配对视频与标注、抽 HDF5 frames/labels；train/val/test 分支尚为 NotImplemented，真正公开路径是 mode=all。
评估方式
procedure_learning→gen_print_results→compute_align_MoF_UoI，以 GT/pred frame overlap 做 Hungarian cluster-label assignment，再计 MoF/IoU/precision；per_keystep 模式排除无 GT 类别并平均。另有 procl_eval 函数实作补上未配对类别的 P/R/F1，但不是本主入口调用，二者不混用。GT 用于事后 cluster 对齐不代表模型已输出语义标签。

怎么接入我们的benchmark

可重用

父数据重用清单、原生秒制 step CSV、PC 组装新来源与聚类评分。

需要转换

source→parent video→新 annotation 建 ancestry；task 记来源内 category，case 是指定多视频集合／采样与合法 GT 使用范围。cluster ID 保存 Hungarian assignment 作评分证据；K、背景、per_keystep 与全体聚合明列。

仍需补齐

尚未取得视频／标注、产生 HDF5 或运行。需要逐子集对应原视频及相同 frame 采样；不能自行发明 train/test split 或把 mode=all 的结果标为未见环境泛化。
