Follow-Bench: A Unified Motion Planning Benchmark for Socially-Aware Robot Person Following

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

正确的Follow-Bench是MedlarTea的机器人跟随规划库；社交距离、搜索、无碰撞分开记录，不能混同另一个LLM指令遵循同名benchmark。

版本与身份

原2025paper有2026-05v4；此repo5月创建，site仍有旧6planner与paper8planner叙述差异。ir-sim/RDA-planner为上游组件，不能当独立新benchmark。

官方project页的Benchmark Code按钮仍为空href；另以完整题名、来源owner自述Hanjing YE（原第一作者）与mobile navigation/person-following身分核对MedlarTea/follow-bench。

领域
协助、交接与陪伴、个人照护、公共场馆与服务、包装、仓储与物流
环境
内含ir-sim模拟器与socialRPF规划器；走廊、交叉口、门口、杂物场地及动态人群。人数、宽度、障碍、跟随距离和随机初态是场景设置。
任务
跟随特定人的后方或侧方、失去视线后搜索；README每设置100 seeds是原规划，不表示本次已有100次新结果。seed改人物／布局时是新instance，policy-only重跑另计trial。
题数与数据
env_basic_info.json存step_time、robot/target半径；object_info.json实际按JSONL逐行读count、target_visible、robot/target/obstacles/humans。robot位置为索引1:3，速度4:6，碰撞旗标6，需保留schema与单位。
评估方式
无碰撞与搜索成功分开；连续失踪>max_search_steps才search失败。可见率分母max_steps，路径按差分，zone时间按step_time累加。avg_velocity直接mean速度分量，并非速度模长；private-zone计算扣target_radius，与人群半径异质情况须核对。

怎么接入我们的benchmark

可重用

布局/人群/目标轨迹配置、原log与多项距离/舒适度/搜索metrics。

需要转换

case记target identity、follow位置/距离、seed、max_steps与step_time；evaluator保留碰撞与搜索各分母，不把单一无碰撞当完成全部任务。

仍需补齐
