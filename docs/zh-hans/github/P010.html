EPIC-KITCHENS-100 需保留五项挑战各自的数据与评测约定；本次核读总标注、叙述工具及 C1 动作辨识实际指针，没有把其他挑战概括成已集成。

版本与身份

固定提交的说明列出 P01_109、P27_103 预抽帧错误；原始视频与标注不受影响，数据取得时必须保存修正版本。narrator 是工具，并非额外 benchmark。EPIC-55 many-shot P/R 不等于本版 tail 指针。

领域
居家整理与清洁、餐饮与烹饪
环境
沿用部分 EPIC-55 厨房视频并添加拍摄；PXX_YY 与 PXX_1YY 的视频来源不同，不能把两版视频量相加当作独立场景。
任务
包含动作辨识、弱监督辨识、动作预测、无监督领域适应、视频文字检索。verb、noun、action 类别与检索句子各有原生 ID，挑战种类不等于独立任务数。
题数与数据
train／validation／test_timestamps CSV 以 narration_id 对齐片段；narration_timestamp、start/stop_timestamp、frame 边界各自保存。anticipation 使用动作前 5 秒观测并留 1 秒间隔；UDA 的 source/target 与 retrieval 的 sentence 表另列。C1 预测含 verb_output[N,97]、noun_output[N,300] 及 narration_id。
评估方式
C1 utils/metrics.py 计算全部样本 verb／noun／action top-1/top-5，以及 unseen participants、tail verbs／nouns／actions 的对应 top-1 子集；布尔遮罩决定分母。其他四项挑战需各自取得 evaluator，不可沿用 C1 得分。
