P250 · EgoMAN

Flowing from Reasoning to Motion: Learning 3D Hand Trajectory Prediction from Egocentric Human Interaction Videos

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

EgoMAN 将人类 6DoF 手部轨迹和推理 QA 配对，适合加入语意→预测的共同目录；官方明确表示 processed dataset 与 model weights 不发布。已核数据创建、loader、trajectory／waypoint 评分链，不能把 repo 可读当成 219K 轨迹或 3M QA 已可下载评测。

版本与身份

固定官方 commit；README 提到新 DINOv3／Qwen3-VL 等依赖，不能假设与 paper checkpoints 完全相同。raw metrics 的 closest_pred 选 minADE，summary 则用 ADE+ROT 系数，两种 best index 必须分清；已有 processed.pkl 时会跳过重算，需用来源／evaluator hash 隔离。

领域
居家整理与清洁、餐饮与烹饪、交通移动与车辆维修、穿戴交互与动作界面
环境
人体交互视频的 EgoExo4D／Nymeria 衍生数据，HOT3D 作 OOD。camera-relative 手腕轨迹与人体视角推理不是机器人 actuator 命令；需保留原数据 take/sequence 关系。
任务
语意／空间／时间／阶段 QA 与 3D 双手 6DoF trajectory prediction。approach/contact/end stage、任务文字和两种输出共用 interaction clip；不把 3M QA 与 219K 轨迹相加成独立情境。
题数与数据
README 报告 219K 轨迹／3M structured QA，processed dataset 及权重不公开。原生 meters、10 Hz、position+xyzw；模型以每手 position3+rotation6 的 18D 表达、past 5 frames，未来 tensor 最多 50 slots、−1000 sentinel。视频／tracking timestamp ns/us、reference camera transform、stage annotation 及自动 QA provenance 必须同存。品质筛选要求接触／结束可见且非平凡动作，会影响难度分布。
评估方式
trajectory：ADE/FDE 公尺、DTW按 warping path length 范式、ROT度。GT有效 mask 为每 frame 任一座标非−1000，未逐手遮罩；空 GT 回零值且少 best_idx 栏，正式入口需拒收此情况。summary 的 best-of-K 选 ADE+0.001×ROT 最小同一条候选，再报四项，与单纯 minADE／各指针各取最小不同。waypoint 取各方法 key 交集，>2 点以 GT 选最佳成对候选；--shift 仅对非 EgoMAN/GT 方法向 GT／最近轨迹点移最多 0.06m，各栏忽略 NaN 后平均。这是带 oracle／容忍补偿的协定，不能当实际物理接触成功率。

怎么接入我们的benchmark

可重用

可重用 trajectory／QA／stage 关联结构、来源追踪、创建标注的方法和四种几何误差定义；code 与 data 授权及发布范围各自保存。

需要转换

case 固定 parent clip、标注者／模型与生成版本、起讫与合法过去输入、meters／xyzw／rot6d、validity mask。将 raw single prediction、oracle best-of-K、shifted waypoint 分开报表；所有 expected cases 的遗漏／失败另报 coverage。评测 loader 禁止训练式坏样本换下一笔。

仍需补齐

未发布 processed dataset／模型权重，所以本案未取得这 219K／3M 样本，也未跑推论或 GPT 标注。QA correctness evaluator 与完整基线资产不在本次 trajectory 核读范围；新任务需要独立取得合法数据并完成标注／评分验证。
