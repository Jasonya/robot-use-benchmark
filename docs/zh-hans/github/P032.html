P032 · EgoTaskQA

EgoTaskQA: Understanding Human Tasks in Egocentric Videos

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

EgoTaskQA 可用于「从程序标注产生可追溯问题」的流程。已核读 generation 说明、direct/indirect 切分、LEMMA loader，以及实际答案索引 accuracy。

版本与身份

已核读一种 baseline 的评分路径；其他 HCRN/HGA/PSAC/VisualBERT 的输入及聚合不据此推定完全相同。direct 名称不表示该 split 只含 direct 问题，原程序实际对 all_qas 分配。

领域
居家整理与清洁、餐饮与烹饪、社交与沟通
环境
沿用 LEMMA 人类活动视频与世界状态标注；interval 里的 video_name/fpv/start/end 是观测区间，不是新的场景资产。
任务
world state+template/program 产生 query/localize/counterfactual 等问答，再作答案分布平衡。reasoning_type 可重复附在同一题上，各类分母不互斥。能生成更多问句不等于增加同样数量的程序或环境。
题数与数据
raw parsed.json 与 templates 产出 direct/indirect/merged/balanced QA；maskX 表示对象屏蔽数。baseline 的 tagged QA 有 interval、question、answer_encode、reasoning_type、各词／字编码；vid_intervals 对 feature video_id，HDF5 预设取20 frames。interval=[start,end)，图像文件名为1-based，feature indices 为0-based。
评估方式
所核读 LSTM baseline 对 logits argmax 与 answer_encode 完全比较，validate 先算各 batch accuracy 再平均；另依多个 reasoning tags 计 true/total。test loader shuffle=True/drop_last=True，故不是保证所有 test 题都进分母。direct split 依答案平衡比例3:1:1；indirect 将 direct 题与特定 query/iterate_until 程序留 train，其余 indirect 一分为二。

怎么接入我们的benchmark

可重用

可追溯 world state／program／template、答案分布平衡、direct/indirect split 与原生 QA schema。

需要转换

task/规则保留 program 和生成版本；case 保留父视频+fpv+半开 frame 区间、maskX、template、answer vocabulary/hash。题数按唯一 QA ID 计，视频／模板／reasoning tags 另算；原 split 按问题分，不自动宣称 video-disjoint。

仍需补齐

尚未取得世界状态／视频／特征或运行生成与评分。需确认稳定 ID、完整 split 档及字段，而非重跑未固定 seed 的 split.py；评估 all-cases adapter 与原 drop_last 结果需各自标版本。
