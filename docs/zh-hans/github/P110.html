核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

AHA公开failure生成及失败问答评测；Yes/No脚本把正确率称为F1，LLM fuzzy评分则会略过无有效裁判输出的题。共同报表需要保留实际公式与分母。

版本与身份

固定ICLR2025公开码；README依赖PerAct RLBench并含fork更新，不将其视为与所有RLBench版本相同。只核对生成来源及评分内核，未生成数据或调用裁判。

领域
居家整理与清洁
环境
RLBench/FailGen产生的机器人失败片段，另重用REFLECT等test来源；示例是时间格状拼图，不是额外可操控场景。
任务
判断子任务成功与解释失败原因；下游恢复应用另有运行protocol，问答分数本身不等于恢复成功。
题数与数据
GT JSON含字符串id、image和human/gpt conversations；Yes/No预测为JSONL整数question_id与text。样本格图包含时间顺序与未来空白格说明；source video/frame范围需追回父数据。
评估方式
Yes/No程序取逗点前小写答案，(yes正确+no正确)/indx_num为accuracy而非标准F1；预设indx_num不能当全数据实数。fuzzy用claude-3-haiku-20240307，解析correct/partially/incorrect→1/.5/0，按列序配对且只对有效裁判分数平均；须保存ID、invalid count和裁判回执。
