StillFast: An End-to-End Approach for Short-Term Object Interaction Anticipation

返回逐篇总表内核内容已核读 方法／综述参考原作 ↗

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

StillFast在Ego4D STA上预测下一个交互对象、动作与接触时间；官方测试提交和本机validation必须分开记录。

版本与身份

本机Overall mAP有更多诊断组合，不等于官方只报的STA字段；静态核读还发现add的空字典分支有不可达的内层len(preds)>0条件，集成前须核对空输出对分母的影响。

领域
方法／综述参考，未另作来源用途归纳。
环境
Ego4D视频的观测影格及短历史片段，无交互模拟环境。
任务
共同预测box、noun、verb、time_to_contact；四种STA指针组合不是四份独立素材。
题数与数据
annotation以uid、video_id、frame和objects索引；objects含box／noun_category_id／verb_category_id／time_to_contact。训练标签有noun+1与依ROI版本决定的verb offset，输出JSON再还原。
评估方式
实际validation调用OverallMeanAveragePrecision(top_k=5)：IoU严格大于0.5、TTC误差不超过0.25；依GT数折免(K−1)×GT个高分false positives。正式成绩依README指定的Ego4D evaluator／隐藏test。
