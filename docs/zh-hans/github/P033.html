EgoLife: Towards Egocentric Life Assistant

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

EgoLife、EgoIT、EgoGPT、EgoRAG 是数据／训练集／模型／方法的不同角色。已核读 EgoRAG 的 QA schema、记忆查找、证据与精确选项评分。

版本与身份

主 README 中早期 arXiv-on-hold 等消息仍保留，身份以实际论文标题／arXiv ID 为准。EgoGPT 文件对其他 EgoSchema/EgoPlan/EgoThink 的结果是外部测试，不算 EgoLife 原生题目。

领域
居家整理与清洁、餐饮与烹饪、休闲与运动、社交与沟通
环境
六位参与者一周的真实生活观测，包含 Aria、外部相机与 mmWave；本次内核程序处理人物/日期/视频的记忆串行，不代表所有传感 modality 都已进入每道题。
任务
长期记忆、人物／事件／习惯等 QA，以 query_time 和过去证据答四选一。EgoIT-99K 是九个既有 ego 数据的 instruction tuning 混合，不是添加 99K EgoLife 测试题。
题数与数据
QA 有 ID、query_time 的 DAY/time 字符串、type、need_audio/need_name、question、choice_a–d、answer、target_time、keywords、reason。caption DB 以 date/start/end/video_path/text 建记忆片段；parse_query 实际使用 keywords。时间为来源自订8位编码，需保留原字符串再创建经核验的时间换算。
评估方式
calculate_accuracy 只对已进 answers 的 model_option 与 metadata.answer strip 后精确比较；query_all/main 遇例外 continue，故漏题可能不进分母。get_answer 遇 API 字符串 error 会随机选 A–D；须另列失败 fallback。主入口 extract_evidence 实际 modality=text，EgoGPT 是可换的 caption/视觉模型，不能把此设置报成每题直接看视频。

怎么接入我们的benchmark

可重用

人物／日期／query time、题目与证据 schema、记忆数据库与四选一评分。

需要转换

case 保留本人、query timestamp、合法 past cutoff、是否提供 keywords，以及 target_time/reason 的 GT 身份。cache/DB 对应 caption model/version、视频范围与读取记录；完整预定题清单与已答题清单并列，漏题、随机回退、解析失败分开。

仍需补齐

尚未下载完整一周视频、EgoIT、创建 DB 或调用模型。需核验每层摘要／retrieval/filter 的时间截止与 evidence 完整性，并固定 keyword 可用条件；不同人物和同时摄影不能直接计成独立环境。
