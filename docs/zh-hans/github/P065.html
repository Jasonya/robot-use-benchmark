P065 · CALVIN

CALVIN: A Benchmark for Language-Conditioned Policy Learning for Long-Horizon Robot Manipulation Tasks

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

CALVIN 要一起固定 benchmark 主仓库与 calvin_env 子模块。数据是按时间步保存的多传感器／动作／状态，评测则是连续指令链；不能把训练窗口当成正式评测题。

版本与身份

mees/calvin在fa03f01…的Git tree明确pin calvin_env到1431a46…，与calvin_env目前main 797142c…不同。要重现CALVIN就使用gitlink，不直接替换成依赖仓库的最新main。

领域
居家整理与清洁、通用对象与机动作业
环境
A–D场景与机体／传感配置由calvin_env提供；D_eval是评测设置，不能直接另算独立layout。
任务
task函数以start_info/end_info变化定义；语言可对应相同原生task。正式long-horizon评测是从同一初态连续运行指令，失败就停止prefix。
题数与数据
每步NumPy字典包含rgb/depth/tactile、actions、rel_actions、robot_obs、scene_obs；语言档另外保存ann/task/embedding及起讫索引。scene_obs是评分/状态数据，README明示原作不供政策使用。
评估方式
rollout用原作task oracle比对起终info；evaluate_sequence保持环境状态延续，子任务失败即回传成功prefix长度。count_success计至少完成1至5项的比例。

怎么接入我们的benchmark

可重用

NPZ字段、语言片段、场景定义、固定串行／初态和task oracle。

需要转换

保留7维absolute与relative两种动作的区别、世界座标和50/20缩放；训练窗口、指令链case、子任务运行各自识别。依协定分开政策输入和评分状态。

仍需补齐

完整素材闭合、共同跨来源任务对齐及本库协定下的运行验证。
