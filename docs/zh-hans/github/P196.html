Deform360: A Massive Multi-view Visuotactile Dataset for Deformable World Models

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

Deform360有明确多视角/触觉对齐与annotation contract，可直接作数据层参考；README明示world-model训练、baseline和checkpoint未公开。

版本与身份

固定d8522a4；所读公开库定位access/preprocessing/annotation/alignment，未把能生成annotation推论为已发布world-model baseline。

领域
衣物与洗护
环境
BRICS capture dome真实柔性物交互；原作198对象/13类、1980交互，41同步RGB相机及4组16×32触觉sensor。13对象类别不是13生活domain，41views不是41episodes。
任务
柔性物世界模型/多视触觉研究数据；dataset utility提供对齐和annotations，不等同机器人物理任务registry或已发布的world-model benchmark runner。
题数与数据
原作215.7h、约23.3Mframes须保留其跨视角统计口径。episode/<camera>/undistorted.mp4与K/c2w、aligned timestamps、provenance hash；预设检查相机frame/timeline一致。H5键data：mask bool/uint8二值、depth uint16毫米且0无效、velocity m/s；不可像RGB除255。
评估方式
这些检查验证数据形状/时间/校准一致性，不是world-model或robot成功分数。触觉nearest配对保留match/accepted/duplicate信息，未接受格补0须连valid mask使用；用于预测task时另外限制query以前的可见数据。
原作数字：保留论文的单位与页码

怎么接入我们的benchmark

可重用

明确图像/姿态/深度/速度/触觉契约、common timeline与output hash校验，可复用到标准化来源层。

需要转换

source/episode是主lineage，camera/frame/sensor作子记录；保存微秒时间、c2w方向、单位、invalid值与alignment政策，case另绑定真正预测目标和scorer。

仍需补齐

完整数据/annotations取得、interaction/对象split、world-model评测协定/程序与checkpoint、从感知数据创建物理可运行task的验证。
