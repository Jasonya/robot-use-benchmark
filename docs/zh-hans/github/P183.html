领域
装配与生产作业
环境
以下为论文规格，尚无repo实作可验证：Isaac Lab2.2.1／Isaac Sim4.5，另声称验证5.1。DLO有PhysX D6刚性segment chain及FEM deformable两种表示，对齐task／connector界面而非声称材料参数等价。模拟支持UR5、Franka、Trossen Stationary AI；实体validation用UR5+Robotiq2F-85、腕部与侧视RGB、3D打印Ethernet接头／task board。实体腕部force/torque sensor读值未用于policy，只需在sim匹配其几何offset。
任务
三个family为connector insertion、clip routing、channel seating。论文注册五种connector geometry，其中cylinder/cuboid/Ethernet/DisplayPort进入所报实验，USB-A为额外asset；不能把五个connector全当已评测tasks。clip difficulty最多3个clips；channel由5 segments组成，可为直线或每joint最多±20°弯曲。family、variant、fixture数、reset variation与episode均不同单位，无公开registry可确认精确全部task count。
题数与数据
论文称scripted、RL rollout、sim teleoperation、real UR5四种来源共用LeRobot-compatible schema。UR5 state/action各7D（6 joint+gripper），双RGB与instruction同步；这是论文语义，未取得实际feature keys、parquet/video path、dataset revision或reader。IL/VLA比较使用同一1,000条scripted insertion trajectories，非全benchmark总case数。RL另用42D privileged observation与Cartesian delta pose+gripper action，clip到[-1,1]再乘0.01；不与joint-space dataset action直接合并。原生physics dt=1/120 s、decimation=2、control=60 Hz，其他实体数据时间约定需待公开。
评估方式
只有paper-defined protocol：insertion分SRreach（夹持plug进入socket周边2 cm）及SRinsert（tip就座），不得以reach代替insert；3 mm是Ethernet测试clearance，不是插入成功阈值。clip需seated于clips；channel需超过80%线长在channel内，尚无公开离散化／checker细节。RL报3 seeds的mean±std，8秒horizon；IL/VLA附录F用4 seeds×16 rollouts=64/checkpoint、800 simulator steps，不可与8秒／60 Hz budget预设等同。checkpoint以相同evaluation rollouts的reach success取前三，并非held-out validation选模；insert来自同checkpoint、未另优化。公开tree无可运行scorer，不能声称已核对这些条件的程序实作。
