P177 · H2RBench（human transfer）

H2RBench: A Real-to-Sim Benchmark for Evaluating Human-to-Robot Transfer

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

H2RBench提供基于PolaRiS的6个Gym场景注册与human-to-robot transfer评测。此版rubric按曾完成的子条件累积，与末态全部同时完成有差异。

版本与身份

固定5082e75。README arXiv仍TODO且clone示例为旧DavidZ2851/polaris；官方h2rbench.github.io连此库并列精确2609.24778，身分相符。与P151视频生成H2R-Bench保持不同source。

领域
装配与生产作业、通用对象与机动作业
环境
Isaac Lab与PolaRiS真实场景重建/3D Gaussian splat；固定registry6个Gym ID为放红杯、叠积木、套环、挂杯、玩具入盒、叠碗。authoring scene.json与runtime scene.usda/渲染资产不是同一种环境描述。
任务
6个原生task setup有Rubric前置依赖；新case须保存human/robot数据转移的训练条件与实际goal，不能把完整PolaRiS父资产库当本篇全部已评任务。
题数与数据
initial_conditions.json含instruction/poses；task_config.yaml有object_randomization/waypoints。当前randomize以poses[0]为底再取range，未逐条使用所有原始pose；旋转入参xyzw、输出wxyz。policy推论入口送obs+language，human示范训练/配对数据另需manifest，不能从此eval入口推定已有video prompting。
评估方式
每criterion曾达成即latched，progress=ever_reached/total，成功为全数曾达成；空criteria会success=True但progress0，应拒作合法case。放置看XY投影覆盖与finger条件；插入有速度稳定/XY/Z检查，其closure计数须确认跨episode重置。续跑先生成ic后快转RNG，第一个恢复episode仍用旧ic，需修正或保存实际初态。视频固定15fps不是控制clock证据。

怎么接入我们的benchmark

可重用

6环境注册、scene/initial_conditions/task_config界面、可追溯predicate与依赖进度。

需要转换

case绑定source episode、重建/碰撞/渲染资产版本与座标系；记实际初态、human训练子集和固定budget；保持ever-success与同时末态成功分项。

仍需补齐

human/robot完整配对数据、资产和training split、续跑初态一致性、stateful predicate reset、非空rubric/全部终态有效性及跨机体基线。
