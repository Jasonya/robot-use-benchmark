NavVerse: Benchmarking Indoor-to-Outdoor Embodied Navigation in Continuous Robot Simulation

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

NavVerse提供室内、室外与连接场景的连续导航；原程序的成功距离是参考路径近似值，collision指针是卡住代理量，不等同接触传感。

版本与身份

原PDF p1连umich-curly.github.io/NavVerse-Benchmark，与此同名组织库和题名相符；本次固定2026-09后更新之commit，非宣称逐项重现7月版本。

领域
公共场馆与服务
环境
作者报100室内＋50室外＋50连接场景，来源USD/navmesh/scene_scale/collider设置另存。这是作者release声明，尚非本库已取得200个资产。
任务
ObjNav/VLN/PlaceNav三种条件导航；原episode_target_type分obj/place，instruction_type分target/vln，避免把同一终点的两种指令视为新场景。
题数与数据
VLNEpisode含scene_id/scene_type/episode_id/path/scale/navmesh_preset、goals(instance/type/location/radius/reference_path)、start_position/start_rotation；episode_label=scene_id+episode_id。JSON读取错误会continue，导入应另列遗漏。
评估方式
距离取当前点到各reference_path点的直距＋后续路径长，再扣目标半径；成功需STOP且距离<1.6。SPL由该初始距离与实走长计。collision以有移动指令但pose变化<0.015判断，collision_rate平均此代理信号，非直接物理碰撞次数；保留原名与操作定义。

怎么接入我们的benchmark

可重用

场景与episode schema、split manifests、语言/目标条件和native measures。

需要转换

environment固定场景包hash+navmesh/collider；case存scene_episode+目标/指令/机体/控制模式；metric存实际距离近似、STOP及卡住判定而非仅缩写。

仍需补齐

10,000作者报episode的全量取得／ID完整性、各机体控制与场景有效性、物理contact及近似指针对照。
