P004 · CrossTask

Cross-task weakly supervised learning from instructional videos

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

CrossTask 的核心是从教学视频定位有顺序的步骤。18 个 primary tasks 有时段标注；65 个 related tasks 用于跨任务学习，不能全部当成同样有答案的评测题。

版本与身份

公开程序的版本已固定；README 的外部下载与旧依赖尚未作完整可运行重现。

领域
餐饮与烹饪、工艺与修缮、交通移动与车辆维修
环境
教学视频来源；没有交互场景清单。
任务
原生人类活动包含有序 step descriptions；primary 与 related 任务资格需保留。
题数与数据
tasks 档、task/video/URL CSV、每视频特征 NumPy、叙述限制 CSV 及逐步时间标注。read_assignment 对 start floor、end ceil 并使用半开时段。
评估方式
train.py 的 eval 以 DP 产生步骤指派；get_recalls 按有 GT 的步骤计匹配，再以 task 平均。这是步骤定位召回，不是整个程序的物理完成率。
