EgoThink: Evaluating First-Person Perspective Thinking Capability of Vision-Language Models

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

EgoThink 是单图像第一人称思考问答。已核读数据样本、推论输出、实际裁判 prompt 选择与分数聚合；程序沿用 FastChat 格式，但原生分数不是其通用 1–10 分。

版本与身份

README 列 VidEgoThink 为另一篇后续工作；不能因同 repo 宣传链接就把其视频题目计入 EgoThink。现行预设裁判为 gpt-4o，原论文使用的模型／prompt 必须另依对应版本钉选。

领域
居家整理与清洁、餐饮与烹饪、工艺与修缮
环境
来自人类第一人称图像；样本 source_dataset=ego4d，image_path 为本地图片。能力目录不等于生活场域或新实体环境；原视频时间／地点需另外补来源映射。
任务
六类能力目录 Activity、Forecast、Localization、Object、Planning、Reasoning，下含 12 份 annotations.json。导航／协助题是文字规划问答，未要求机器人运行。
题数与数据
样本含 source_dataset、image_path、question、answer；eval.py 用 image_path[0] 的文件名定位图像，依目录顺序重新给 question_id，输出 question/model_answer/reference_answer JSONL。assistance/navigation token 预算300，其他30，需保留差异。
评估方式
gen_judgment.py 实际采 judges[math] 的 single-math-v2 prompt：只看问题、参考与模型文字、不看图片，给 0/.5/1；common.py 解析 [[rating]]，最多尝试3次，失败=-1。show_result.py 排除 -1 后平均，去重被注解；应额外报有效率和重复题，不能将保留样本平均当全题 accuracy。
原作数字：保留论文的单位与页码

怎么接入我们的benchmark

可重用

十二能力题集结构、单图像 QA schema、原参考答案与具体 0/.5/1 裁判流程。

需要转换

case 用 source+能力目录+原始 row/hash 建稳定 ID，保存生成 question_id 映射；记录图片、token budget、reference、judge model/version/prompt、原 judgment、解析重试与缺失。各能力分项，与 physical navigation evaluator 分开。

仍需补齐

未运行模型／付费裁判。仅读 Activity 第一笔数据样本，未逐题查图片与标签；需确认各子集来源 video/time、去重与盲测切分。API 模型版本与裁判可靠性需另外验证。
