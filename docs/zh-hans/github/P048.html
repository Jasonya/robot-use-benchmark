EGO-TOPO: Environment Affordances from Egocentric Video

返回逐篇总表内核内容已核读 方法／综述参考原作 ↗

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

EGO-TOPO把视频中的活动区域建成图，再用于动作预测；图节点不是已重建且可操作的房屋场景。

版本与身份

EPIC/EGTEA数据与其后AntGPT等工作重用，不能将图或模型论文各自的数据量相加。

领域
方法／综述参考，未另作来源用途归纳。
环境
EPIC55与EGTEA视频、推断的活动区域及访问图；保存video来源与时间关系。
任务
拓扑活动图与长期动作预测，是既有数据上的方法／表示，不添加独立数据集。
题数与数据
每视频graph.pth、locnet特征与配对分数；epic_utils用video、start/end frame、labels及图历史选出指定frame的图。
评估方式
metrics.py提供top-k accuracy、逐类平均top-k recall与TTA；图建构品质和动作预测分数需分项。

怎么接入我们的benchmark

可重用

父视频ID、图／visit时间、特征引用与动作评测。

需要转换

图存context衍生资源，保留产生器和source hash；用观测截止点取图历史，不把完整未来图自动暴露给模型。

仍需补齐

原片与预计算特征、建图窗口/切分核对及evaluator接线。
