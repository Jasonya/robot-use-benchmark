RoboCasa: Large-Scale Simulation of Everyday Tasks for Generalist Robots

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

2024 RoboCasa 的数据界面可由官方 v0.2 tag 核读：25项 single-stage 数据注册、5项 multi-stage 数据注册、HDF5 重播与具体几何 checker。这些数据入口不是论文100项任务的完整清单；现行 main 已转为 RoboCasa365。

版本与身份

v0.2固定756598a5be52e052339bb2d957426e39015c2afb；目前main固定456174f62b89b8fca99eaaf33949c29fec9cfc2a，属P071。不可把v0.2的0-based layout/style、PnPCounterToCab、HDF5 env_args与365的1-based ID、PickPlaceCounterToCabinet、LeRobot格式按名称直接合并。旧版仍要求robosuite master并留有旧controller入口，需要额外锁定兼容版本。

对应 arXiv:2406.02523v1（2024-06-04）及八位作者的 RSS 2024 论文。v0.2 README 直接列此题名／作者并连原论文；v0.2 是同一作品的后续维护版，未宣称其commit就是投稿时程序。

领域
居家整理与清洁、餐饮与烹饪
环境
原论文10个floor plans×12个styles＝120种厨房组合；v0.2 scene_registry 的layout ID为0–9、style为0–11，分别解到YAML。fixtures包括柜子、台面、家电；一个layout的材质变化不另算平面配置。
任务
论文100项＝25 atomic＋75 composite。已读PnPCounterToCab把对象从台面放入柜内；get_ep_meta.lang插入抽样对象名称，_get_obj_cfgs给name/obj_groups/graspable/placement及两个干扰物。数据registry的5个composite入口只涵盖ArrangeVegetables、MicrowaveThawing、RestockPantry、PreSoakPan、PrepareCoffee，不能据此说其余任务不存在。
题数与数据
registry以human_path、mg_path、horizon及download_links连接v0.1数据；human_raw读demo.hdf5，human_im／mg_im分别挑选带图像／生成材质的文件，NavigateKitchen没有mg_path。HDF5 data.attrs.env_args提供env_name/type/env_kwargs；data/demo_N内含states、actions或actions_abs、obs/<camera>_image，attrs含model_file与ep_meta。ep_meta、XML、资产与初态需一起还原，frame index、控制频率与视频抽帧分开记。
评估方式
已闭合run_random_rollouts→PnPCounterToCab._check_success→obj_inside_of AND gripper_obj_far。前者检查对象8个bbox角点对fixture内部3轴的投影，后者要求eef与对象中心距离>0.25公尺。obj_inside_of的0.05加在未范式轴矢量的内积上，不能直接标为5公分容许误差。create_eval_env固定(1,1)/(2,2)/(4,4)/(6,9)/(7,10)，obj_instance_split=B。论文每task50 trials；这里main只是3回合×100步随机动作示例，不是正式BC-Transformer评测预算。

怎么接入我们的benchmark

可重用

layout/style YAML引用、原生task class、对象抽样与语言模板、v0.1 HDF5数据源、task checker。

需要转换

source固定论文v1与程序v0.2；environment分layout/style/asset；task保留PnP等原生ID；case记对象split、场景pair、初态与控制设置；evaluator分开bool成功、step horizon及trial数。raw、rendered、MimicGen数据保留派生关系。

仍需补齐

完整75 composite与已公开数据入口的逐项对应、原始2024程序／robosuite精确版本、正式policy runner设置与50 trials seed清单，以及HDF5／资产闭合验证。
