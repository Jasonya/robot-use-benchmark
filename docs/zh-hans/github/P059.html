P059 · EMAG

EMAG: Ego-motion Aware and Generalizable 2D Hand Forecasting from Egocentric Videos

返回逐篇总表内核内容已核读 方法／综述参考原作 ↗

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

EMAG 是重用 Ego4D／EPIC-Kitchens-55 的双手位置预测方法。已读数据与 ADE/FDE 计算程序，但公开设置、读取器与 trainer 的字段／时间维度不一致；不可标成可直接运行的跨数据集评测。

版本与身份

固定 0386bd9de2bd2ec3504e5b645a095c46e9a565ca（2025-03-25），与 2024 论文区分。loader 传 ego_feat，trainer 却读 egos_input；loader 保留五时点且没有裁切，test_step reshape 明定四时点；两份设置皆未定义 trainer 初始化所读的 model_config.loss。论文称 homography，文件路径／变量称 fundamental/fmat，未取得矩阵资产前不能宣称两者等价。非截断 tree 未列 EPIC 专用 loader 或前处理发布。

README 自称 ECCVW 2024 官方实作，列 Hatano、Hachiuma、Saito，与 arXiv:2405.20030 论文及其指定作者页一致；作者页 Code 连至 masashi-hatano/EMAG。论文也引用 SORT、hoi-forecast、EGO4D/forecasting 作为相关工具／比较方法，不能把它们替代成本论文的实作。

领域
方法／综述参考，未另作来源用途归纳。
环境
论文在 EPIC-Kitchens-55 厨房视频及 Ego4D 多种人类活动上做同数据集／跨数据集预测；数据属人类第一视角图像，没有机器人可运行动作界面。已读程序入口使用 Ego4D schema，EPIC 另有设置但没有独立 loader／转换脚本。
任务
论文 §4.2 用八张 4 FPS 观测，预测未来一秒四时点的左右手 2D 位置，并以未来 ego-motion 为辅助训练目标。跨数据集的方向（EPIC→Ego4D 或反向）及 train/val 必须各自保留；活动类别分析不是添加机器人任务。
题数与数据
读 annotations/fho_hands_{mode}.json 的 /clips/*/{video_uid,clip_uid,frames}，由 frames/*/{pre_45,pre_30,pre_15,pre_frame,contact_frame}/boxes 的 left_hand/right_hand 创建 [2,5,2] 座标与 [2,5] mask；以来源 w/h 范式。排除设置 delete 清单、pre_45.clip_frame≤interval×8 或全零 mask。输入 image_frame/{clip_uid}/{frame:06d}.png、optical_flow/{clip_uid}/npy/*.npy、fundamental/{clip_uid}/*.npy，另读 hand-objects/interval={interval}/{clip_uid}/{pre45}.pkl 的 bboxes_obj/bboxes_hand/attention_mask。回传 frames、flows、bboxes、ego_feat、future_hands、future_egos、hands_mask、egos_mask 与影格 h/w；八个观测索引终于 pre45-interval。影格步长不能直接当秒；pickle 与图像均未下载／反串行化。
评估方式
论文 §4.3 定义图像高度256 px尺度的 ADE（所有未来时点、左右手）与 FDE（末时点、左右手）。实作 test_step 固定四时点、套 hands_mask，scaling_original 按 meta 中的来源 w/h 还原像素；calculate_L2_loss 排除 GT=(0,0)，分别累积左右手所有有效时点与第四时点的 L2 距离，test_epoch_end 只输出四个分手平均。没有此处的左右手合并报表，也没有保证来源 PNG 高度为256的转换步骤；原始分辨率不同会改变分数。

怎么接入我们的benchmark

可重用

原生 clip_uid、观测锚点、标注时点与有效性 mask，左右手／对象框引用及分手位移算法。

需要转换

case 以父数据集版本+split+clip_uid+锚点定位；保留 2D x/y、来源影格尺寸与秒／帧对照，明列四步 horizon、两手缺失规则与图像高度256的评分尺度。跨数据集保留训练来源与评测来源，不合并其原生 case。

仍需补齐

须补齐图像、flow、手物框与 ego-motion 前处理来源／版本及 EPIC 格式转换；修复 ego_feat/egos_input key、五标注时点对四输出时点的契约与缺少的 model_config.loss 设置，确认两手合并、分辨率及遮罩后才可运行验证。
