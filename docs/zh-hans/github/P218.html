How You Move Tells What You'll Do: Trajectory-Conditioned Egocentric Prediction

版本与身份

固定 repo commit 85afac4ae7a800fc104a4499c349b09979c34941 的完整树只有 README.md；未将作者网页算成模型程序。论文附录称 atomic/Keystep 等使用 validation takes，但结果表称 test split，需保留原文标示差异并取得 manifest 才能对齐。Aria pose 与 RGB估计 PI3 的 oracle 条件也不可混同。

论文题名 How You Move Tells What You’ll Do: Trajectory-Conditioned Egocentric Prediction，作者 Sejoon Jun、Hai Nguyen-Truong、Luigi Seminara、Lorenzo Torresani。PDF 连到 farsightlab.github.io/TrajPilot，页面题名、作者与 arXiv ID 一致；farsightlab/TrajPilot 与该项目共用命名空间，但公开 README 只有名称，项目页未提供可核验的方法程序链接。排除搜索中的 mimozing3003/TrajPilot-AI-Autonomous-Driving-Research-Platform：它描述自动驾驶，与本篇论文不符。

领域
方法／综述参考，未另作来源用途归纳。
环境
脱机人类第一人称视频：Ego-Exo4D atomic／Keystep、Ego4D GoalStep、EgoPER，另做 EPIC-KITCHENS-100 anticipation 与 Ego-Exo4D 篮球投篮结果分类。相机运动是观测／条件信号，并非可直接运行的机器人控制。
任务
分开记录提供 start+goal 的程序规划、移除 goal 的未来动作预测，以及 made／missed 二分类。规划 horizon H=3–8 是动作串行长度；8,472 个 atomic 文字标签、1,165 类 closed collapse、375 个 Keystep 标签、310 个 GoalStep 标签和57个 EgoPER 标签均为各自词汇表，不能加总成任务数。Scorer 使用训练集候选未来轨迹，Oracle 使用实际未来轨迹，两者信息条件分开。
题数与数据
论文附录 A.1：atomic 为 take-disjoint 的140,413 train segments／2,237 takes 与11,425 validation segments／312 takes；连续 segment 形成 H=3–8 windows，但未提供公开 window manifests。每段16张 RGB，384×384，V-JEPA 池化为1664维特征；atomic 区间以相邻时间戳中点决定，其余以标注区间中点与边界采样。Aria 或 PI3 相机姿态对齐视频时间并转成相对 [Δx,Δy,Δz,Δrx,Δry,Δrz]，旋转为 rotation vector；实际 tensor schema、尺度／单位与插值实作未公开。篮球子集294 train／74 test events、42／10 takes，test 为37 made+37 missed；模型仅看平均1秒的出手前片段，16张采样自30 fps来源视频。
评估方式
没有具体 metric/scorer 程序可读。论文区分 middle-step R@1/5 与 full-sequence R@1/5，MSeq/FSeq 为整段全对比例；Full 包含观测端点，Future 不含 observed Start。Closed-vocabulary 另报 Mid/Full mAcc、exact-sequence SR、mIoU、Levenshtein，实际 macro/micro、重复标签与跨 horizon 权重须等程序确认。EK100 的 verb/noun/action 为 mean-class Recall@5，另列 instance accuracy；篮球 accuracy 分母为74个事件，balanced accuracy 为两类 recall 平均，各类 recall 分母37。模型内部 Scorer 的候选排序／fallback 不是 benchmark 成功判定，不能取代 evaluator。

怎么接入我们的benchmark

可重用

重用论文所界定的来源数据集、take 层级 split、原生动作词汇与规划／anticipation／outcome 任务分类；repo 仅可重用身份与版本证据。

需要转换

source 连回各母数据集；case 以 take_id+segment/window+H+split+词汇版本识别，保存 start/goal 可见性与 No-Traj／Scorer／Oracle。camera_pose 另存来源 Aria/PI3、时间轴与相对6DoF格式；evaluation 分列 step retrieval、sequence exact match、class recall、event accuracy及其分母。

仍需补齐

公开 reader、window／label-bank manifests、轨迹采样与单位、实际 scorer/gating 和全部 metric 实作；尚不能核验论文指针或形成可运行套件。
