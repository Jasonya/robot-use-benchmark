Vision and Intention Boost Large Language Model in Long-Term Action Anticipation；Congqi Cao、Lanshu Hu、Yating Yu、Yanning Zhang，Northwestern Polytechnical University。固定arXiv:2505.01713v1（2025-05-03）；ICVL在本篇指Intention-Conditioned Vision-Language，不是同缩写的其他数据库或实验室。AntGPT、PALM及候选帐号的STDD／Open-MeDe／Cue-R1均非本篇code。

领域
方法／综述参考，未另作来源用途归纳。
环境
Ego4D人类第一人称日常环境，及EPIC-KITCHENS-55／EGTEA Gaze+的厨房活动视频；都是脱机视频预测。意图是VLM从已观测影格推断的文字，并非添加人工意图真值集，也没有robot场景／控制界面。
任务
ICVL先辨识历史verb–noun labels，再从按时间顺序抽取的观测影格逐步推断intention；每次VLM输入包含先前生成的intention context，以最后结果作最终意图。ICAF以意图embedding为query、视觉embedding为key/value，再与文字prompt合并预测未来串行。Ego4D目标是noun／verb／action串行；EK-55与EGTEA明定为剩余视频中会出现的verb集合，不能把两者共用一个sequence evaluator。
题数与数据
§3：segment Si对应Ai=(vi,ni)；每段均匀取k影格形成visual embeddings，总数T=Nseg×k，意图另取Nfrm影格；k/Nfrm的数值、FPS、实际annotation key及split manifest未提供可核reader。历史action recognition用CLIP ViT-L/14与Transformer加两个MLP heads；ICAF的visual encoder为BLIP2-OPT-2.7B，意图VLM原文明写「LLaMA 3.2-9B」，text encoder及预测LLM为LLaMA 3-8B，精确模型ID／revision仍待设置档核实。例子只从training pool取observed labels与future labels；先对视觉及文字embedding的L2距离各自min–max范式，再用α加权，距离较小为较相似。α实际值、零距离范围／ties处理未核到。§4.4虽说7例最佳，最终结果明确采3个例子。Ego4D的243小时／3472 clips、117 verbs／521 nouns以及EK-55的125／352与EGTEA的19／51词汇量皆为原作母库描述，非ICVL已核case数。
评估方式
§4.1的Ego4D：Nseg=8、Z=20、K=5，对noun／verb／action分别报minimum Damerau–Levenshtein ED。完整距离实作、范式分母、三项是否各自取min及生成错误处理未核到。Ego4D只称standard splits，Table1未明列具体版本／评测split ID。EK-55与EGTEA则沿EGO-TOPO设置：观测首P%=25/50/75%，预测其余部分的verbs only，于validation报multi-label mAP All/Freq/Rare；未取得串行转verb分数、频率分组与AP聚合程序。3个ICL例子、5条生成候选、8个观测segments及20步预测是不同预算，均非题数。

怎么接入我们的benchmark

可重用

可重用observed video→辨识labels／生成intention→ICAF→LLM的数据流、training-only例子来源、距离融合规则、3-shot例子预算与原生Ego4D ED／EK-EGTEA verb-mAP规格。没有已核ICVL模型实作或evaluator可接线。

需要转换

source保留arXiv v1及母数据集依存；domain/environment限定脱机人类视频。task分有序verb–noun forecasting与无序verb presence。case应保存观测窗口、原生labels、生成意图、visual/text表示引用、3个training example IDs与5条预测；intention标为model_generated，训练例子的future labels与test GT隔离。evaluator分开保存ED与All/Freq/Rare mAP，母库clips、frames及词汇不展开成虚构案例。

仍需补齐

官方ICVL repo／commit、精确模型型号与版本、影格／segment reader、数据／类别与split IDs、example pool及去重隔离规则、prompt/输出parser、ED与verb-mAP scorer。需确认原文LLaMA 3.2-9B型号、α及frame抽样值；不能借用AntGPT、PALM或STDD的程序视为ICVL已实作。
