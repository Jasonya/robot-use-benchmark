P058 · EgoPAT3Dv2

EgoPAT3Dv2: Predicting 3D Action Target from 2D Egocentric Vision for Human-Robot Interaction

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

EgoPAT3Dv2 的作者 repo 同时保留原版与扩充版读取器；可追到逐帧 3D 目标误差与进度分箱，但 HDF5 版本、手部特征错写及评分汇整差异须先处理。

版本与身份

固定 a24b3a5a2453931de69a17dfc7116057dc849136（2024-03-19）。configs/README.md 在 manifest 中是空档；README 测试命令未带程序所需 model_epoch/checkpoint。test_DDP 后处理固定 4K 内参，v>=2160 分支错改 u，且 x1/y1 使用前轮 z；重现前须确认保留原行为或另列修正版。论文 §IV-A 说扩充分配 9+2 新场景，§V-B 又说添加12场景，不能以文字自行决定总场景数。

README 的完整标题、十一位作者与论文 arXiv:2403.05046v1 一致；论文指定的 ai4ce 项目页直接连本 repo 与 Hugging Face 数据。这是 ICRA 2024 EgoPAT3Dv2 的实作及 EgoPAT3D 扩充数据入口，原版 D1 与扩充版 D2 有重用关系，不能加总当作两份互斥数据集。

领域
协助、交接与陪伴、穿戴交互与动作界面
环境
头盔安装 Azure Kinect 的人类对象操作视频。论文 §VI 的 UR10e 避让／朝预测点移动是另行展示；已读 repo 提供预测数据与模型测试，没有该展示的机器人任务成功评分器。
任务
在线以 X1:t 预测同一段操作最终 3D 手部目标；目标必须转到当前影格相机座标，并非未来全身动作或机器人控制。T1/T2 指原版／扩充训练来源，D1/D2 指测试数据版本，seen/unseen 指场景是否在训练出现。论文报告可用 clips 由 4129 增为 9579；本轮未下载资产核算此数。
题数与数据
原版 HDF5 用 /{annotrain|annovalidate|annotest}/{scene}/{video} 与 /sequences/{scene}/{video}/{color,transformation/odometry}；扩充版将 /color/{scene}/{video}/{frame} 与 annotation、/transformation/{scene}/{video}/{frame} 分置两档。annotation 每列前三值为三个边界，3:6／6:9 为两段目标 xyz；原版要求 z>0.1，扩充版 z>0。长度=end-start、RGB 读 start+1…end，累乘 odometry 后以逆矩阵转换目标，单位公尺。RGB resize 224×224；training 直接排除长度>25 的 clips，测试以最长段补零并回传真实长度。handLM 为 21×2、hand 为 landmark 5 的 x/y；两 RGB 读取器的 handLM 奇数栏实际也写 lm.x，不能当成正确的 x/y 特征。
评估方式
test_DDP.py 依模型／epoch、scene、video 输出 start-end.txt（逗号分隔 xyz）与 start-end_gt.txt。eval.py 算每帧 ||pred-gt||2，以 i/(L-1) 落入十个宽 0.1、两端皆包含的区间；先在 clip 内平均，再平均同 recording 的 clips，最后等权平均 recordings，×100 得 cm；Overall 使用 linspace(2,1,10) 加权。边界影格可能进入相邻两箱，短 clips 可出现空箱。论文 §IV-B 写按影格等分十阶段、余数给较早阶段，并报三个 seed 平均；目前入口不自动做三 seed 汇整。eval.py 的 --mode 是 store_true，仅用于输出命名，真正 split 由 test_DDP 的设置决定。

怎么接入我们的benchmark

可重用

scene/video/clip 边界、逐帧目标与 odometry 引用、D1/D2 及 seen/unseen 分派、欧氏误差实作。

需要转换

case 保存 dataset_version+split+scene+video+start/end，附实际影格索引、公尺相机座标、有效长度与手部缺失遮罩；evaluator 明列进度分箱、recording 平均、Overall 时间权重与 seed。原版／扩充版以来源重用关系相连。

仍需补齐

需取得并固定 Hugging Face HDF5 版本／场景清单，核对修正版标注与影格采样时间；修正或隔离 handLM 的 x/x 特征、补足 checkpoint/model_epoch 参数与私人路径，再验证评分分箱及后处理。
