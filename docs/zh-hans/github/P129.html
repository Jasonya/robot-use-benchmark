P129 · RH20T

RH20T: A Comprehensive Robotic Dataset for Learning Diverse Skills in One-Shot

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

RH20T API能按时间对齐多相机、TCP和力矩，但不同机体有不同前处理；tactile原始数据可加载，按时间查找界面仍是占位。

版本与身份

固定aa31244 API版；README列出的界面和实作范围分开。未下载大数据或进行online机器人投影运行。

领域
居家整理与清洁、装配与生产作业、通用对象与机动作业
环境
多机器人配置与相机串行的实拍操作场景；scene folder是数据record脉络，机体/摄影机数不能当独立环境数。
任务
多样操作示范与多模态学习数据；此库主要提供loader/visualizer/online preprocessor，任务目标与评测协定需连原文／来源metadata。
题数与数据
时间查找以毫秒，图像选最近low-frequency timestamp，TCP/FT/关节/夹爪值另线性插值。TCP7D四元数、FT6D；Kuka位置除1000，Franka/UR5姿态及不同gripper各有processor；标定和raw/zeroed FT不能混用。
评估方式
没有从此数据API取得通用task成功scorer。get_tactile(timestamp)与detect_outlier仍NotImplemented，高频gripper getter也未实作；不能由tactile.npy存在推定整套评测界面可用。

怎么接入我们的benchmark

可重用

配置ID、相机serial、raw/aligned数据、毫秒时间与机体/相机转换参数。

需要转换

source/native scene与实际workspace分开；case保存各模态原始时间/插值方式/数据缺失、TCP encoding、FT零偏和gripper单位；sensor trace不是直接可运行action。

仍需补齐

全量metadata/素材、任务goal及split、四元数插值有效性、tactile/高频gripper接线与原生评测判分。
