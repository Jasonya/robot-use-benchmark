P086 · DeformableRavens

Learning to Rearrange Deformable Cables, Fabrics, and Bags with Goal-Conditioned Transporter Networks

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

已核读模拟主仓库与实体 cable 实验补充仓库。12 个添加柔性物任务共用 Task.reward 分支，但 cloth coverage、袋口凸包、袋子搬运与真机 mask IoU 是不同指针；bag-items 的 task.done 只要求正分，不能直接当论文完整成功。

版本与身份

两仓库均固定 2023-06-11 commit；模拟 README 的 metric 概述仍只写 pose/zone，实际添加分支更多。原生状态／示范及 PyBullet、Franka 控制均未运行。

模拟 README 明示 ICRA 2021 完整题名及作者、继承 google-research/ravens，并直接链接 gctn_physical；后者 README 反向指向模拟仓库。论文 arXiv:2012.03385v4 含后加真机章节，不能把 2023 真机程序视为 2020 初稿内容。

领域
衣物与洗护、包装、仓储与物流
环境
模拟为 PyBullet UR5 桌面与三台 RGB-D camera，z 轴向上；柔性 cloth/bag 需 deformable world，environment 注解要求至少 480 Hz，CLI 预设却是 240，必须保留实验命令设置。真机另为 Franka Panda＋手部 Azure Kinect、foam 工作面及校正转换。
任务
添加 5 cable、3 cloth、4 bag，共 12；全 registry 另含原 Ravens 任务与 insertion-goal。cloth-flat 等程序名称对应论文 fabric-*；bag-items-easy/hard 对应 bag-items-1/2。cable-ring-notarget 只是无可见标线，load.py 未将它列为 goal-image conditioned 任务。bag-items 以打开、插入、搬运三 stage 及各 stage primitive 参数组成。
题数与数据
Dataset 将 color/depth/action/info 存成各目录相同的 {episode:06d}-{length}.pkl；RGB uint8 为 T×3×480×640×3，depth float32 为 T×3×480×640。最后一笔另存 last_color/last_depth/last_info，不在 action 长度内；goal 预设取同回合最后状态，也可抽未来时间。action 有 camera_config、primitive、params.pose0/pose1；info 保存 object_id→(position,rotation,dimensions) 及 extras。真机 trial_info 的 img_dict/eval_metrics 应比 act_dict/gctn_dict 多一笔，旧 trial 有缺尾；depth 原始毫米、mask 160×320，需保留 crop 与相机外参。人类示范取像不是 robot rollout。
评估方式
模拟 reward 回传当步 delta，extras.total_rewards 保留当前值。cable-target 检查每珠到任一目标 XY 距离 <3.5×radius、全数合格才 done；ring 面积除 πr² 达0.75，bag-alone-open 达0.70。cloth-flat 以目标交集/目标面积达0.85，另记 IoU；cloth-cover 要 cube 在 segmentation 不可见且距四角中心≤0.25。bag-items 在 stage3 以物体入 zone 比例与袋口珠入 zone 比例各占0.5，done 只要求 total_rewards>0；训练 main.py 另过滤不完整示范，测试 load.py 仅排除 t=0 或 exit_gracefully，不能沿用示范过滤作 test success。bag-color-goal 以目标物可见像素位于目标袋口凸包的比例≥0.95，先要求可见袋口珠比例>0.33；不是完整3D containment。load.py 每2000 iteration 评测一次，共10 snapshots，各20个有效回合，seed 从10000开始，保留重抽计数与 final_info；论文第5页对3训练runs的60个指针先平均再取10 snapshots最大值，bag-color-goal仅1 run。真机 evaluate_masks 算交集/联集，另有交集/min(mask面积)；论文成功为10动作内 IoU>0.25，程序只存连续值、README 使用手动退出，尚无完整自动成功汇总。

怎么接入我们的benchmark

可重用

添加 task subclasses、metric 分支、RGB-D／goal 配对、seed 与 snapshot 的结果 pickle，以及真机 mask evaluator。

需要转换

source 分两个 commit；environment 分 UR5 模拟与 Panda 真机；task 保存 paper_name↔code_name 与 Ravens 继承；case 绑 seed／goal episode／初态；evaluator 分 delta、raw score、task.done、termination_reason 及 paper-success。t=0 为取像而非操作，所以 max_steps=21/11/3 等不能直接作动作数；有效 cable 通常20、cloth-flat10、cloth-cover2次，bag依子类8或9次。

仍需补齐

数据／goal 资产清单与每次重抽 seed；论文 bag-items 完整成功的结果汇总对接；10-snapshot 选择与独立测试分割；真机10-goal清单、手动停止纪录、完整校正和缺尾 trial 处理。
