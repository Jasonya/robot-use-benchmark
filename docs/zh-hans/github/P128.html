核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

RoboNet原生loader会检查数据hash，统一T个图像/状态与T−1个action；不同机体维度可补零、截短或推估autograsp，必须保留转换来源。

版本与身份

固定d83eee2的2019来源实作；RoboNet另被OXE重发为RLDS，需保留同一父episode关系。未运行TF模型或原数据loader。

领域
通用对象与机动作业
环境
多机器人HDF5 interaction sequences，metadata带robot/ncam/维度/长度/文件hash。任务环境或对象配置不能由机体名与record数推定。
任务
动作条件视频预测、逆动态／视觉控制及标注点预测；frame、subsequence、同episode多camera皆不是添加语义任务。
题数与数据
env/state、policy/actions、camera图像及可选bbox_annotations；loader以min(state_T,img_T,action_T+1)决定可用T，action取T−1。Mismatch模式可PAD_ZERO/CLEAVE，autograsp根据后一state及边界推估添加控制维。
评估方式
标注variant预设拆non-annotated train/val/test并另列annotated robots；指定train_ex_per_source时另走分支，须固定split规则。metrics提供分布像素距离和normalize到1的PSNR/MSE等，值受resize/camera/horizon影响，不是物理task完成率。

怎么接入我们的benchmark

可重用

内容hash、原robot/相机/维度、T/T−1对齐、标注模式与视觉metrics。

需要转换

case记parent HDF5、选取camera/起始frame/context/horizon、原维度和补零/截断/autograsp推估；像素误差附图像分辨率，原标注缺失与零placeholder分开。

仍需补齐

数据资产与完整metadata、场景/语义目标映射、原train/test与annotated子集隔离、视觉控制真实成功协定及跨来源去重。
