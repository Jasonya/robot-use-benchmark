EgoCast: Forecasting Egocentric Human Pose in the Wild

返回逐篇总表内核内容已核读 方法／综述参考原作 ↗

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

EgoCast 的预设分支与 forecasting 分支是两个不同版本。已追到预测分支的 loader→test_fcast→report；目前 pred_input=True 路径会改写回传 gt，不能直接把这个快照视为可重现论文 ground-truth 评测。

版本与身份

default commit 1db0c6e 与 forecasting commit 6ba9eec7 各自锁定。README 的视频下载范例重复 annotation 命令；需依父数据工具取得真正图像。此处只报静态可查的路径差异，不声称论文结果有误。

领域
方法／综述参考，未另作来源用途归纳。
环境
EgoExo4D 与 Aria Digital Twin 的人体姿态预测，没有新机器人环境。已深入核读的 forecast 路径为 EgoExo4D；ADT loader 虽存在，本次未声称完整核对其 forecast evaluator。
任务
先估当前全身姿态，再由历史头部轨迹与估计姿态预测未来。论文比较 0.5／1／2／3／4／5 秒 horizons；default repo 的姿态估计、forecast branch 的预测与 oracle-GT pose input 必须分条件。
题数与数据
EgoExo4D take_uid、camera_pose、body annotation、17-joint skeleton、visible flags、time index、cached prediction route。forecast train config window_size=80、future_frames=15，test config 为 30；文件名与 dataroot 中的 fps 字样不足以证明实际 sampling frequency。test loader 排除 take_name 含 bouldering，且为 prediction input 使用外部 camera 档绝对路径。
评估方式
test_fcast 滑窗产生多个预测，skeletal MPJPE 乘 visibility 后除 (error!=0) 计数，真正零误差也被排除；速度沿相邻窗口轴相减并乘 10，aria 分支乘 30，不能直接视为同一 future-time 速度。外层每 take 等权平均，跳过 enumerated index 17/62。更关键的是 pred_input=True 时 skeletons_window 被 cached prediction 覆盖，且同变量作输入及回传 gt，feed_data→test_fcast 沿用；需修复／核实独立 GT 才能发布结果。论文的跨 horizon AUC 不在本次读到的 caller 中实作。

怎么接入我们的benchmark

可重用

可重用 current-estimation→forecast 的任务分解、take／frame 对照、17-joint schema；固定两个 branch commits 与父数据版本。

需要转换

以 task 记录 forecasting 目标，case 指明 estimated-pose 或 GT-pose 条件、history／horizon／sampling、visibility 和独立 GT 资产。将 default／forecast revision 分开；修订 gt、mask、velocity 或 index exclusions 时添加 evaluator version 与原生对照。

仍需补齐

未下载完整 EgoExo／ADT、cached predictions 或 checkpoint，未运行模型。当前源代码有上述评分链缺口与本机路径依赖，尚不能认为可直接重现 paper horizon curve。
