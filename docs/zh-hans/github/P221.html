P221 · STAformer++

Integrating Affordances and Attention models for Short-Term Object Interaction Anticipation

返回逐篇总表实作尚未确认 方法／综述参考原作 ↗

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

P221精确论文连到作者AFFttention库，但pinned版本停在2024年；已实读旧版STA reader与metric，尚无法把它核定为2026 STAformer++的完整实作。入口虽引用DETR，但必要模块不在完整树中，且新版Swin-T/EgoVideo/DETR配置未对上。

版本与身份

固定commit 1a1253fa2bde09ef1de4894f3bf872c1fbf270de，日期2024-07-15；2026论文§4是明确架构延伸。完整tree未truncated，因此缺失的DETR/hand模块不是缓存挑档漏抓。README要求依StillFast配置，程序仍import stillfast但目录叫stillfast_code，另有硬编码本机/省略号路径；只能主张已读具体旧版程序段，不能主张新版可重现。

论文为 Integrating Affordances and Attention models for Short-Term Object Interaction Anticipation，Lorenzo Mur-Labadia等，arXiv:2602.14837v1；P221-discovery保留PDF第1、9页指向lmur98/AFFttention的超链接。这是2024 AFF-ttention的延伸，作者与repo关联已确认；未确认的是2026新版方法与公开程序版本的一致性。

领域
方法／综述参考，未另作来源用途归纳。
环境
脱机Ego4D STA v1/v2及由EPIC-KITCHENS active-object tracks/action segments衍生的STA视频标注。environment affordance为历史视频相似场域的noun/verb先验，并非交互模拟器或新机器人场景。
任务
每query输出(box,noun,verb,TTC,score)，另利用environment affordance及interaction hotspot调整预测。论文添加STAformer++的Swin-T、EgoVideo、DETR与learned affordance integration，不能只因同一repo有字样就视为已公开可运行；旧版配置是Dino2D_with_EgoVLP、ROI_HEADS.VERSION=aff。论文EPIC-STA的33,804 train／7,055 val是衍生标注instances，104 noun／51 verb是taxonomy，不是添加robot tasks。
题数与数据
Ego4D reader依TRAIN/VAL/TEST_LISTS读info.video_metadata及annotations；每例uid、video_id、frame、objects[*].box/noun_category_id/verb_category_id/time_to_contact。v2配置指向v2数据，但活跃读取仍用video_id、video_uid行被注解，需明确版本适配。fast clip以frame-arange(N×stride)[::-1]取历史，负索引夹到0；配置N=16、stride=1，不能未读metadata就假设FPS。noun+1，非v1 ROI verb+1；writer再减回。AFF档以v_id/frame寻找AFF_N_top3、AFF_V_top3，找不到用全1先验。EPIC pkl为eid、video_id、timestamp、objects内平行arrays；合并noun群组、剔除含others的整例及指定verb后重编ID。EPIC框被乘(1920,1080,1920,1080)，影格int(timestamp×30+1)，16张含当前影格、最低1；AFF却以round(timestamp×30)+2查找，两个frame convention不可混同。test分支直接读val_annotations.pkl，不能列成独立test split。
评估方式
STATask.validation_epoch_end先以uid建dict（重复UID会覆写），再调用OverallMeanAveragePrecision(top_k=5)，输出8个class-agnostic AP及4个按noun平均的mAP。匹配为+1像素面积IoU>0.5、TTC误差≤0.25秒及各项noun/verb条件，按score贪婪一对一配GT；每query、每metric忽略前4×GT对象数个FP。recall分母是已加入GT中的相应类别对象数；AP为VOC precision-envelope积分×100，mAP预设仅平均有GT的noun，不按noun-verb joint class平均。需保留程序缺陷：add的空preds={}分支再次判断len(preds)>0，因而不加入GT；空array字典与真正空字典行为不同，不能宣称未检测案例分母已安全处理。Ego4D _load_annotations对无objects例还会造出[0,0,100,100]及零标签dummy target，不能拿test-unannotated当validation真值。

怎么接入我们的benchmark

可重用

可重用已核读的旧版Ego4D/EPIC reader规格、noun/verb offset、affordance sidecar schema与原生AP/mAP定义，标成AFF-ttention 2024 lineage；论文2026方法另存版本关系。

需要转换

保留source→Ego4D/EPIC衍生标注关系；case使用版本+split+uid/eid，区分原annotation、清理后有效case与taxonomy。显式映射EPIC normalized xyxy→1920×1080像素、timestamp→影格及独立AFF lookup frame；保留noun合并/剔除表、background offset、FP-budget及AP vs noun-macro mAP。

仍需补齐

新版STAformer++正确revision与Swin-T/EgoVideo/DETR/learned-affordance完整实作；pinned tree缺少入口导入的detr_criterion.py、detr_backbone.py、detr_transformer.py、detr_matcher.py及ego4d_sta_hands_still_video.py，DETR_head也未在入口定义。另缺正式annotation/sidecar资产与portable路径、v1/v2字段适配、EPIC双frame偏移核验及空预测/无GT的计分测例。
