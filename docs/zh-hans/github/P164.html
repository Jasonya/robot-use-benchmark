The Imitator Game: Benchmarking Robot Imitative Ability Beyond Action Prediction

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

The Imitator Game提供人类视频→robot模仿的配对数据、分级场景与模拟评估。任务完成、轨迹相似及盲测偏好是三种不同证据。

版本与身份

固定d6d16ec；README对应2608.22301。所读为共用DP评测链与两个具体task版本，未宣称整个ManiSkill内含任务或全部基线已验证。

领域
居家整理与清洁、餐饮与烹饪、包装、仓储与物流、零售与购物、实验室操作、医疗与手术支持
环境
ManiSkill/SAPIEN双Panda imitator scene，人类demonstrator另有视频。pinned tree中L0/L1/L2/L3各50个config，合计200个task-level设置；不能未去重就宣称200个独立语义任务。
任务
以示范模仿操作，可用video-only、language-only或两者。task透过human/robot/sim ID mapping关联，L-level与input mode保留case设置；盲测arena另有human preference协定。
题数与数据
LeRobot metadata/parquet/video对齐timestamp秒与episode；MANO姿态是同episode特征，不是另一数据集。is_right=-1表示缺侦测、数值补0需mask。评测按task随机抽human episode与video frame；原始action范例双臂8+8=16D，应固定reference IDs与normalizer。
评估方式
例子成功为两对象几何中心在各篮XY bounds及Z上界，is_robot_static另外输出但未加入success。TSS=1/(1+DTW/path_length)，直接对action矢量L2，尺度/单位会影响分数；success轨迹截到首次成功，fail截GT长度；ss<2走fail分支需核验。eval status=success代表流程完成，物理完成另看success_once/at_end。GT seed=None且batch任一truncated就重置群组，需要固定抽样/同步假设。

怎么接入我们的benchmark

可重用

人类/robot/sim mapping、native level configs、LeRobot schema、完成与TSS的独立指针。

需要转换

case固定human示范及frame IDs、sim资产/初态、level/input mode、双臂action spec；reference trajectory与方法输出分隔，success/TSS/human preference分栏报告。

仍需补齐

所有task checker覆盖、完整IG10K资产取得、case固定种子、action尺度/TSS可比性、同步batch条件与盲测评审一致性。
