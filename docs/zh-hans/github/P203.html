领域
居家整理与清洁
环境
重用 Ego4D Episodic Memory VQA、EgoLife、EgoTempo、Multi-Hop EgoQA 与 HD-EPIC 的人类第一人称视频；没有添加可运行机器人环境。父来源、视频、参与者与重写 QA 关系必须保留。
任务
7 个 primary memory dimensions：detail、spatial、temporal、event、social、causal、prospective；每题另可有 secondary tags。7 个 recall regimes 是同题的时间条件：0 秒、0–5 秒、5–30 秒、30–180 秒、180–1,800 秒、1,800–28,800 秒、超过 28,800 秒，不应计成额外语义 task。
题数与数据
论文流程 2,634 candidates → 2,335 人工核对 → 2,250 final base questions，再依 AVW 展成 8,528 question–recall evaluations。每题概念上关联来源视频、四选一题／正解、evidence moment、primary／secondary labels、AVW 与 recall timestamp；目前没有公开 annotation 档可验证这些概念的实际 JSON keys、时间原点、split 或 loader。Appendix A.6 以秒为 delay 单位，Instant=0，其余依 regime 截取高斯分布采样，只接受落在该题 AVW 的时间，ultra-long 用 TTL；不是每题固定乘 7。
评估方式
论文 §3.4 定义四选一 accuracy = 正确推论数／适用 question–recall 推论数，完整实验分母 8,528；语义类别与 recall regime 用各自子集分母，不能用 2,250 代替。串流只准使用 recall time 前画面，建记忆时不可先知 query，亦不可无限保存原影格再重读；需记 memory budget 与平均每 frame 处理时间。Appendix A.7 描述 ingestion／QA 分离并要求回复选项 index；实际 parser、skip／error 计数、记忆限制与 timing scorer 未公开，论文协定不可记成程序已核。

怎么接入我们的benchmark

可重用

可保留官方网站／paper 的题型、AVW 定义、因果观测限制、原生统计及子题扩充关系；网站程序仅作 discovery 证据。

需要转换

source 记 v2、website repo commit 与五父来源；task 记 primary dimension、secondary tags；case 分成 base QA 与带 recall timestamp／AVW／regime 的条件化评测纪录，保留群聚 parent ID。evaluator 分开记整体／类别／regime accuracy、实际有效推论分母、memory／frame budget 及时间成本。

仍需补齐

公开 annotations／split／source manifest、AVW 与 recall 抽样清单／seed、数据 reader、串流 memory manager、答案解析与 concrete scorer。尚无可核实的 executable release；不能把网站部署程序当评测。
