EPIC-KITCHENS VISOR Benchmark: VIdeo Segmentations and Object Relations

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

VISOR 是 EPIC-KITCHENS 视频上的分割与对象关系标注。五个仓库分别承担 VOS、HOS、来源追溯、可视化与抽帧工作，不能算成五批独立环境。

版本与身份

VISOR-FrameExtraction 要求先修正插值并列出 P02_01、P03_14；新版名词表追加左右手／手套，仍保留旧 hand/glove 类别。VOS 不是未修改的 DAVIS 评分：末影格被纳入。

领域
居家整理与清洁、餐饮与烹饪
环境
EPIC-100 的厨房视频子集；video、subsequence、image 各是不同层级。VISOR 重新抽帧，需 frame_mapping.json 才能对回 EPIC。
任务
VOS 在给定首影格对象遮罩后追踪分割；HOS 判断手侧、接触与手对象组合；WDTCF 用查找对象遮罩追溯来源对象与证据影格。这些为视觉理解，不是机器人完成操作。
题数与数据
每视频 JSON 的 video_annotations 含 image.name/video/subsequence 及 mask id/name/class_id/segments/exhaustive/in_contact_object/on_which_hand。dense type=0 为插值、type=1 为端点 GT，不可同当人工标注。VOS 转成 DAVIS 的 JPEGImages、Annotations、ImageSets 与对象色码映射。
评估方式
VOS 实作排除首影格但保留末影格，以逐对象 J（IoU）与 F（边界 F-measure）评分；空 union 的 J=1。HOS 将手侧／接触转类别、遮罩转 RLE，交给 COCO evaluator。WDTCF 必须 query 类别、证据影格字符串吻合，source 类别才可计分，另算 query/source mask IoU；错类别或错影格会归零，非单纯来源分类正确率。
