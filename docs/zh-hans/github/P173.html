LabDex: A Hierarchical Benchmark for Dexterous Manipulation in Laboratories

返回逐篇总表文件／网站 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

LabDex的GitHub目前是展示网站，Code标Coming Soon；作者链接的HF dataset card已核对，但还没有可核验的task evaluator实作。

版本与身份

固定3d1c43b网站与2608.18618一致；2026-10-11已读serandt/LabDex公开card。Code仍Coming Soon，未把网站或8000+声明当已集成case。

领域
实验室操作
环境
实体与模拟共用Franka Research3+XHand，三个相机视角、20+laboratory assets；同场景多视角不增加环境数。
任务
原文概观为30+Atomic、10+Compositional、1Long-Horizon workflow；实验表实际比较26atomic instances、7种操作类别。整体collection、已报评估subset及family是不同层次。
题数与数据
HF card声明8000+demo和1M+trajectory steps，包含同步多视角RGB、proprio、action、hierarchical annotations；card未给详细键名/文件布局，本次没有下载demo。50为每task评估trial数，非demo总量。
评估方式
原文成功要求末stage后状态在目标容差内连续2秒；atomic报SR，composite/workflow另报各atomic成功及每rollout平均完成数。必须取得容差、stage/时间checker才可运行。

怎么接入我们的benchmark

可重用

三层task结构、原生demo/trajectory量、2秒稳定成功协定与作者dataset入口。

需要转换

environment保留robot/相机/asset版本；task创建atomic→composite→workflow关系，不重加共享subtask；case记phase/容差/稳定时间和split。

仍需补齐

正式code、可解析episode manifest、确切action/clock schema、容差与每task成功规则、真实/模拟数据分割。
