领域
方法／综述参考，未另作来源用途归纳。
环境
脱机人类第一人称视频，Ego4D-v2 LTA及EPIC-Kitchens-55／EGTEA Gaze+；stage1读full-frame与hand-object区域的预抽特征。不存在可供policy rollout的交互环境。
任务
stage1是verb/noun action recognition，stage2产生think/intention/answer文字与未来verb-noun串行。Ego4D论文协定观测8个action segments、预测5条各20个action的串行；8不是8张frame。EK55/EGTEA则预测视频前25/50/75%之后会出现的verb集合，报All/Freq/Rare mAP，不是同一ED题型。
题数与数据
ActionDataset按train.json／val.json／fho_lta_test_unannotated.json的clips分组clip_uid，再依action_idx排序；长clip切window_size=8、stride=1重叠窗口，短clip逐action成例。每action读split/<clip_uid>_<action_idx>.pt两路特征，标签verb_label/noun_label；缺feature会使不完整窗口被舍弃。main配置input_dim=1408、117 verb／521 noun，collate再摊平窗口，因此同action可能重复计数。reader未提供原影格时间/fps/feature采样manifest；test就算is_test=True仍会在getitem读mask feature。stage2依外部ms-swift chat JSONL，messages assistant含<answer>与<intention>，images提供路径；cal_ED把images[0]父目录当clip_uid，GT同ID会覆写。pred JSONL用clip_uid、res_list；没有公开的完整stage1→chat/prediction转换与split资产。
评估方式
stage1 train/validate是分类正确action occurrences除以flattened有效标签数×100；main的co-occurrence validation在各top5 verb/noun组合中挑raw_cooccurrence>0且概率乘积最大的pair。prior缺档时只由train创建，但重叠窗口会重复action。cal_ED以逗号分动作、第一个词为verb，其余为noun；保留大小写，不做taxonomy ID校验。具体DP允许插入/删除/替换及相邻交换（受限交换递归，未证明与官方Damerau实作等价）。对每条res_list候选截至GT长度L，分别取最小action/verb/noun距离，三项可来自不同候选，再各除L、最后按处理到的prediction records平均。候选数不强制5、L不强制20；缺GT的prediction被跳过，完全缺prediction的GT不进分母，重复prediction ID可重复计数，L=0给0，空res_list会使min失败。reward不是此ED：只接受两个英文字token的pair并lowercase，至少20对才开gate，内容分数分母固定20；intention为MiniLM cosine经β=0.8、γ=40 sigmoid映射，R=gate×(0.85内容+0.05意图+0.05语言+0.05格式)，shell再以0.9此R+0.1外部soft_overlong组合。意图reward不是意图分类accuracy；EK55/EGTEA的All/Freq/Rare mAP scorer未在此版本公开。

可重用
