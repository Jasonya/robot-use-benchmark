COIN: A Large-scale Dataset for Comprehensive Instructional Video Analysis

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

COIN 将标注、下载与评测拆成不同仓库。要先读 annotations 的 domain/task/step 与视频 JSON，再读 code 的时段定位／逐影格分割评测。 2026-10-11 补读 annotation-tool 的实际导出与时段生成。

版本与身份

12 domains／180 tasks 是作者的活动分类，并非本库21类用途或180个已去重的机器人任务。 annotation-tool 为独立固定提交，CSV 标注工作档不能视为已发布的 database JSON；sample 的 0.5 秒间隔不能推为所有视频 fps。

领域
居家整理与清洁、餐饮与烹饪、工艺与修缮、个人照护、交通移动与车辆维修、休闲与运动
环境
视频观测脉络；原作生活用途不是交互场景 ID。
任务
原生 domain/task/step 分类与人类程序活动；定位、分割是信息评测题型，不能等同机器人工作规格。
题数与数据
ActivityNet 风格 database JSON、YouTube ID、视频 URL、步骤 label/segment 及 taxonomy。README 范例的 class 与下载器的 recipe_type 字段需对实际版本检查。 补读：annotation-tool 读 URLID/URL、TagID/Tag、URLID/Frame/Time 三表，导出 instruction_时间.txt 的 CSV 八栏 URLID,URL,TagID,Tag,Start,End,Time,State。输出 Time 为 times（确认保存次数），有别于 frame.txt 的抽帧秒数；Start/End 为时段秒数。影格模式依 newSpace 分开不连续区段，视频模式先以 toFixed(0) 保存整秒文字。导出只保留有 URLID/TagID 的 tagInfo 列，不含没有标注的视频。
评估方式
定位结果包含 action_id、start、end、confidence、video_name；evaluate.number_label 需设为相符的原生标签空间。分割另报逐影格 accuracy；各自保留分母。 补读工具的 State=0/1/2 分别是未标注／已标注／删除；checked 是另存于浏览器的布尔值，八栏导出没有带出。这些是标注流程状态，并非 AP/F1、GT 品质或独立复核指针。

怎么接入我们的benchmark

可重用

活动／步骤 ID、视频血缘、原生时段及 AP/F1 等判分程序。 可另重用工具输入字典、逐视频 tagInfo 与导出字段。

需要转换

活动放 human_activity_definition；视频与时间标注放 context/annotation；定位与分割 case 分开创建，保留秒与影格换算。 工具 URLID/URL → 来源视频引用，TagID/Tag → 工具版本内标签，Start/End → 原生秒区段；Time/State 放标注流程 metadata。需明确创建这些本地 ID 与已发布 COIN JSON/taxonomy 的映射。

仍需补齐

视频有效取得、完整 split 清单、字段别名核对及本库信息题型的 evaluator 接线。 工具读写采直接逗号／换行切分，未处理引号包覆的逗号；仍需导出往返、整秒精度、缺列及 checked 遗失验证。此补读未取得视频或运行浏览器工具。
