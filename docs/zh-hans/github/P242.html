P242 · NAOGAT

Leveraging Next-Active Objects for Context-Aware Anticipation in Egocentric Videos

返回逐篇总表实作尚未确认 方法／综述参考原作 ↗

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

已核NAOGAT原作、WACV刊载页及作者现行project：GitHub仍标示Soon，EK-100添加NAO框标注须向作者索取。可收录论文层级的STA方法与标注衍生关系，尚无可固定commit并核读的官方reader／evaluator。

版本与身份

2023年arXiv摘要承诺接受后提供code；2026-10-11读到同篇project仍为GitHub(Soon)，有Code标题但没有方法链接。project文末误标WACV 2023，刊载年份以CVF 2024为准；本笔技术内容仅按已固定arXiv v3核读，未声称和会议PDF逐段一致。探索用/wacv24短网址返回404，其后由作者about找到可用现行project；这不是GitHub repo不可用或全球无code的证明。本轮小型HTML读取除该404外均200，未遇429／rate-limited403；未联系作者或读取内嵌视频。

精确题名为Leveraging Next-Active Objects for Context-Aware Anticipation in Egocentric Videos；Sanket Thakur、Cigdem Beyan、Pietro Morerio、Vittorio Murino、Alessio Del Bue。核读缓存arXiv:2308.08303v3（2023-10-05）；CVF确认WACV 2024、pp.8657–8666。作者about以略不同的Short-Term题名连回同一arXiv及本project。ANACTO、GANOv2是另篇方法；网站模板richzhang/webpage-template亦非NAOGAT程序。

领域
方法／综述参考，未另作来源用途归纳。
环境
Ego4D人类第一人称日常活动及EPIC-KITCHENS-100厨房视频，皆为脱机观测。STA假设下一交互对象在最后观测影格可见；EK-100原有action anticipation并不保证此条件。未提供可reset的robot场景或动作控制界面。
任务
输入截至T的RGB串行，预测下一active object的noun类别n、最后观测影格中的bounding box b、未来动作verb v及距接触的δ秒。NAO定位与动作／TTC联合预测属一个STA问题的不同输出，不是四套机器人任务。EK-100实验仍须和Ego4D STA分开记录。
题数与数据
§3–4.2：16影格、4 FPS；训练resize高度248–280 pixels并crop224。Faster R-CNN侦测输入为每对象4个框座标加confidence，固定Q笔不足时padding；Q/Nq的实际值、座标顺序／范式与串行化key未能由reader核实。Ego4D forecasting部分称逾1000视频、STA标注30 FPS；EK-100母库97 verbs／300 nouns／约90K action segments皆非本篇有效case数。附录§7的EK-100框由GT noun匹配侦测器结果产生，失败再用hand-object ROI及top-3 noun候选；noun仍沿用EK标签，不是新人工重标整库。12.5% training、6% Unseen及约22% Tail的NAO缺失分别有不同分母；附录另把22%称validation中的「Test Set」，需原始ID核对。现行project只提供索取标注的联系方式，没有已取得的annotation档、split manifest或loader。
评估方式
仅核到paper protocol：§4.3以noun／verb top-1判对、box IoU≥0.5及|TTC误差|≤0.25秒；联合条件须全部满足。Table1列8种b/n/v/δ组合的AP，但正文概述称4组，应保留各字段而非并成单一成功率。候选预算、AP积分／macro平均、confidence合成及漏标样本处理没有scorer可核，不能径套另一篇Ego4D的Top-5实作。EK-100 Table2分Unseen/Tail/Overall及action/verb/noun；§4.3仅援引先前方法的metric，未在本版明列其Top-k／类别平均细节。§4.4剔除无NAO的tail clips后所得分数属另一次过滤评测，不能覆盖原validation分母。

怎么接入我们的benchmark

可重用

可重用原作身份、Ego4D STA／EK-100衍生框标注关系、四项预测输出、16frame/4FPS输入及论文明列的IoU与TTC门槛；尚无已核可运行reader或scorer。

需要转换

source保留arXiv v3及WACV 2024关系；domain/environment限定人类视频脉络，task以STA定义建档。未来case须带video/segment身份、最后观测影格、原生box参照、noun/verb taxonomy、δ秒及缺失NAO原因；Ego4D、EK原split及过滤子集分开。evaluator保存各AP组合与尚待核实的EK metric，不把母库frames/segments或模型queries当case数。

仍需补齐

作者可确认的官方方法repo／commit、EK衍生框文件及授权、精确split与NAO缺失ID、座标／时间转换reader、分类与AP evaluator。需厘清附录Test Set／正文Tail Set及EK metric细节；ANACTO或GANOv2程序不可代填。
