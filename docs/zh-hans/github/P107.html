THE COLOSSEUM: A Benchmark for Evaluating Generalization for Robotic Manipulation

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

Colosseum在20个RLBench任务上加入扰动；变体产生、示范seed及RVT评测在不同文件／仓库。RVT所称success rate来自100倍缩放的成功reward。

版本与身份

scene程序用函数参数数量兼容upstream/PerAct RLBench；安装可成功不代表两版本物理／评分完全一致。RVT repo沿用RVT README，身份由Colosseum官方README明确链接确认。

领域
居家整理与清洁、通用对象与机动作业
环境
RLBench/PyRep/CoppeliaSim TTM场景；scene加载自定义TTM并在episode／step套变体。原README20任务×14因素不可直接当280独立场景／新语义任务。
任务
源任务＋对象/桌面/背景/相机/光照/物理参数等扰动。例CloseBox只有1原生task variation、4句说明，成功登记JointCondition(box_joint,2.6)，依固定RLBench版本判。
题数与数据
factor含variation/name/enabled/targets及参数；demo保存NumPy random state，可依指定demo index恢复。正式示范在外部tar，未取得，实例必须带variant配置与资产版本。
评估方式
官方链接RVT runner以指定demo初态评测，例预设25episodes和25控制步，使用规划式末端姿态＋离散gripper。wrapper将原task reward>=1的成功缩放100；IK/path/invalid-action错误给0并终止。CSV success rate取eval_envs/return，需保留0–100尺度与实际完成／缺题数。

怎么接入我们的benchmark

可重用

20task定义、factor schema、TTM/示范seed、原生成功条件与RVT评测入口。

需要转换

task连RLBench父任务，case固定factor值/激活时间/初态/控制预算；evaluator保存成功布尔、100倍报分和错误分母，重复来源不增语义任务。

仍需补齐

RLBench/PyRep/fork精确依赖闭合、所有factor资产与demo取得、YARR聚合环节和同预算原生跑通。
