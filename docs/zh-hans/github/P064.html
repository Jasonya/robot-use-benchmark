LIBERO: Benchmarking Knowledge Transfer for Lifelong Robot Learning

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

LIBERO最清楚的入口是benchmark注册表：每个Task把语言、BDDL、init-state档与示范路径连起来。成功判定要沿wrapper找到实际problem子类；base class的False是占位。

版本与身份

不能只读bddl_base_domain._check_success就断言没有判分器；必须追TASK_MAPPING到实际problem子类。

领域
居家整理与清洁
环境
problem类型、MuJoCo场景与对象资产由BDDL和wrapper连接；suite或task数不能直接当layout数。
任务
Task含name/language/problem/problem_folder/bddl_file/init_states_file。原作100-task集合拆成90/10；程序有五个suite清单但不可重算同一组任务。
题数与数据
HDF5示范含多视角RGB/可选depth、proprioception、action/state/reward/done；另存模型XML和初态。评测需固定.pruned_init等来源。
评估方式
具体problem子类以parsed goal predicates合取检查成功；evaluation脚本固定步数和checkpoint，保存loss与success_rate两种不同指针。
原作数字：保留论文的单位与页码

怎么接入我们的benchmark

可重用

Task注册、BDDL及init states、HDF5示范和具体problem evaluator。

需要转换

保持task、scene/assets、initial state、case protocol分离；将原生goal program与predicate实作一起引用，HDF5映到typed episode数据。

仍需补齐

跨来源等价判定、素材闭合、controller/相机一致性与本库case验证。
