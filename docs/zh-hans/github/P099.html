HomeRobot: Open-Vocabulary Mobile Manipulation

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

HomeRobot的OVMM流程分找物、抓物、找容器、放置；真正overall成功还要求零robot-scene碰撞。已沿官方submodule读到实际放置与稳定性checker。

版本与身份

home-robot tree把Habitat-Lab钉在b727ca9f7123101aaedb737ca9ccc1b153525dd9；本次直接读此版checker，没有用现行HabitatHEAD代替。README另指定home-robot-ovmm-challenge-2024 tag，与本main快照分开。

领域
居家整理与清洁
环境
真实Stretch与Habitat模拟分开；模拟依赖HSSD ovmm资产、对象、Stretch模型和episode配置。相同HSSD屋子被多任务重用需按父资产键去重。
任务
将指定类别对象从起始容器搬到目标容器；四阶段是同一长程任务进度，不自动算4道独立题。原生episode允许多个candidate对象／容器。
题数与数据
OVMMEpisode记object_category/start_recep_category/goal_recep_category及candidate goal集合。wrapper读head_rgb/depth、GPS/compass/joint及task goal；depth由[0,1]映射min/max并特判边值；相机座标模式与GT semantic开关必须记入protocol。
评估方式
原子放置量测检查对象与合法容器接触、排除地板与过深穿透，父checker再检查放开、末端回rest距离及可选的稳定步数。阶段success具有历史累积性；metrics_utils的overall_success=END.ovmm_place_success且robot_scene_colls==0，partial=(找物+抓物+找容器+overall)/4。缺失字段在聚合时被略过，须额外保存完整预期episode与缺值数。
