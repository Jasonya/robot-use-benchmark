ALFRED: A Benchmark for Interpreting Grounded Instructions for Everyday Tasks

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

ALFRED把家务类型、具体场景／对象／轨迹和语言repeat分开；成功取决于终态条件，与每步API成功、reward和示范长度加权分数不同。

版本与身份

主程序同时保留原论文与后续model links；不把所有外部model repo当新benchmark。ALFWorld是同系环境的不同界面，需显式重用关系。

领域
居家整理与清洁、餐饮与烹饪
环境
AI2-THOR室内场景与对象状态；原生目录tuple包含scene_num，具体轨迹还需原始初态与版本。现行README仍指THOR2.1.0数据／文件。
任务
评测器分7种家务类型：直接放置、清洁后放置、加热后放置、冷却后放置、放两物、持物照灯、透过可移容器放置。对象／场景／语言repeat是下层条件，不与7种直接混算。
题数与数据
traj task_id/task_type、pddl_params、plan.high_pddl/low_actions、turk_annotations.anns[repeat_idx].task_desc；模型输出离散action与交互mask。原生trial名称不等于本库policy重跑trial。
评估方式
EvalTask从视觉和语言rollout，STOP／max_steps／max_fails可终止，再取get_goal_satisfied与条件满足数。例：照灯要求持有目标且灯可见并打开。GC全局累加条件分母，PLW按原示范low_actions长度加权，非导航图最短距离SPL。t=0的除法及被exception跳过的题需adapter明确处理。

怎么接入我们的benchmark

可重用

7种native task类别、PDDL参数、初态／低层操作与终态条件、language repeats。

需要转换

原task_id/scene/repeat_idx拆为source instance与case键，留示范／语言父子关系；原生SR/GC/PLW分开记录，失败和未产出题也入分母清单。

仍需补齐

完整THOR初态重播、资产版本、split与合法模型信息、missing/error题处理和原生/共同协定对照。
