核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

rliable可为已有的多run、多task结果加上分布与不确定性；它不定义robot任务，也不能让不同原生metric自动变可比。

版本与身份

固定3ccd9f4；API标示archived。这是来源实作核读，未安装套件或宣称CI已计算。

领域
方法／综述参考，未另作来源用途归纳。
环境
方法评估库，不添加环境；原展示使用Atari/ALE/DM Control/Procgen。robot使用时仍保留原environment/source lineage。
任务
对既有task结果作聚合、bootstrap与performance profile，不是添加task registry或case dataset。
题数与数据
输入每个algorithm的num_runs×num_tasks(×其他维度)矩阵，需固定同一task列顺序、metric尺度与missing值策略。不能把不同分布的未知/不适用填0。
评估方式
mean先按task平均再总平均；median是task均值的中位数；IQM将所有run×task分数flatten后trim25%；optimality gap=gamma−mean(min(score,gamma))。bootstrap预设只重抽run，task_bootstrap才同时抽task；概率提升按task算Mann–Whitney再平均。不同方法同case配对与共享source的相依性需另设计。

怎么接入我们的benchmark

可重用

原生公式、CI与performance profiles、固定task集合/未知task母体两种推论区分。

需要转换

先对同协定同单位结果创建可比score矩阵；保存run/case/scene群组与分层权重，再报per-domain及整体CI。公式不直接混合SR、距离与LPIPS。

仍需补齐

真实policy结果矩阵、不同来源群聚重抽样策略、缺失结果规则、范式依据；所读update_indices使用全域np.random，重现时需验证RNG设置。
