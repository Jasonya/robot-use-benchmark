HandsOnVLM: Vision-Language Models for Hand-Object Interaction Prediction

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

HandsOnVLM公开了EPIC手轨迹与reasoning数据界面；核读发现评分变量命名和实际函数不一致，必须保留程序版本并先校核。

版本与身份

静态核读另见inference正常回传3项而evaluate_epic_kitchen_traj以2项接收；尚未运行，不能宣称此commit可直接跑通或原文数值有相同问题。

领域
餐饮与烹饪、穿戴交互与动作界面
环境
EPIC-KITCHENS第一人称视频与人类手轨迹；reasoning子集由有对应提问的影格筛选。
任务
一般或文字条件的双手未来2D轨迹预测；预设评估入口是ek100 validation，非所有父数据的统一测试。
题数与数据
dataset提供future_hands[2,5,2]、future_valid[2]、contact_point、image_abs_paths及prompt；评分移除首点后用双手×4个未来点。reasoning用valid_index筛子集，图像张量的重复不增加题数。
评估方式
traj_eval含ADE/FDE与四步加权WDE、位置及手的有效遮罩；但evaluate_traj_stochastic把compute_fde存为ade、compute_ade存为fde，最后回传均值而非已算出的min。推论包装还跳过无效生成，需另报覆盖率。

怎么接入我们的benchmark

可重用

需要转换

case保留提问、原始影格ID、2D范式座标、4步时间点与valid masks；metric保存实际函数、候选数及失败输出处理，不直接信任打印名称。
