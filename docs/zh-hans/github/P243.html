FactCheck: Feasibility-aware Long-term Action Anticipation with Multi-agent Collaboration

返回逐篇总表实作尚未确认 方法／综述参考原作 ↗

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

已核FactCheck原作的Observe–Plan–Verify流程、数据与mAP设置，并找到通信作者列出的同篇IET Software论文；该条目仅连Paper，尚无confirmed官方方法repo。本文的Verifier是LLM推理模块，报告的mAP是未来类别集合评测，不能当成实体可行性验证或机器人成功率。

FactCheck: Feasibility-aware Long-term Action Anticipation with Multi-agent Collaboration；Rui Cao、Jiannong Cao、Bo Yuan、Zhiyuan Wen、Mingjin Zhang。固定核读arXiv:2606.14778v1（2026-06-10）；首页的Journal 2023与DOI xxx/xxxx是模板内容。通信作者Zhiyuan Wen的publications页列同五位作者及IET Software 2026、DOI 10.1049/sfw2/7118691。此FactCheck是动作预测方法，非同名新闻／文字事实查核项目。

领域
方法／综述参考，未另作来源用途归纳。
环境
脱机EPIC-KITCHENS-55与EGTEA Gaze+人类第一人称厨房活动。Observer由已观测片段的辨识结果重建对象状态，并非从robot simulator取得真实状态。§5.4的长程操作及人机协作属未来应用构想，没有本篇实体robot评测环境。
任务
§3以M个action segments构成视频、N=floor(αM)个历史片段预测Z=floor(βM)个未来verb–noun动作；α为25/50/75%，β≤1−α。Observer产生历史动作、意图／环境摘要及图；Planner生成有序草稿；Verifier依Object Availability、Affordance Validity、State Consistency修正。三个agent是推理角色，不是三台robot，也不是三个独立benchmark。§5.1.1实际评测取剩余视频中的动作类别集合，须保留「串行生成、集合计分」差异。
题数与数据
§4.1与§5.1.3：每action segment均匀抽4影格，以冻结CLIP-ViT-L/14-336px加训练分类head辨识verb/noun；抽样是每片段4张，非4 FPS。History Action Abstract是一句生成文字。图的noun node保存Attr(n)=(v,t_start,t_end)，edge weight计历史转移频率；时间单位未明列。Table3提供示意JSON的nodes[].id/state/history及edges[].src/tgt/w；§5.1.3另称图串行化为JSONL，未取得真正文件或parser，不能将示例当已验证schema。Planner用Qwen2.5-3B/7B-Instruct与QLoRA；摘要及Verifier用grok-4-1-fast-reasoning，Verifier prompt含3个人工few-shot范例。母库的EK-55 39.6K segments／125 verbs／352 nouns及EGTEA 86 videos／10,325 action instances／19 verbs／53 nouns，不是本篇测试case数。精确split ID、完整提示与范例、生成输出及数据reader均缺。
评估方式
§5.1.1按α=25/50/75%的观测比例，对剩余(1−α)部分的未来类别做mAP-All／mAP-Freq／mAP-Rare；Freq/Rare沿EGO-TOPO分组，这里未提供类别表或频率门槛。未核到实际sequence→class score转换、重复动作处理、AP积分／空positive类别及各α平均方式。没有独立的物理可行性真值、constraint violation rate或robot rollout；Table3是定性修正案例，不能作scorer。§5.1.1称沿用train/test split，§5.2.1却将EK-55结果称validation；§3的floor与79动作案例「50%=40个observed」亦不一致，须以原始case生成器厘清。

怎么接入我们的benchmark

需要转换

source保留arXiv v1及作者页所列journal关系；domain/environment归人类视频预测。task同时保存有序生成目标与无序集合计分。case应保留video/segment、α/β、observed recognized labels、生成摘要／图、draft与refined outputs，并与GT分离；evaluator记类别与频率分组、提示／模型版本及采样预算。图中的状态为推断记忆，不升格成已确认的实体世界状态。

仍需补齐
