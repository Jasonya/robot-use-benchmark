OpenEQA: Embodied Question Answering in the Era of Foundation Models

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

OpenEQA 的 question/answer/history 格式和文字裁判已可具体追溯；本次核读一笔原始 QA、历史取得方式、两种 prompt 与完整评分脚本。

版本与身份

data README prose 写 simulator2.5，但实际安装命令是 habitat-sim0.2.5；以明确套件版本和历史版本为准。RGB直接下载被作者标为第三方hosting，官方来源身份与实际分发者需分栏。

领域
居家整理与清洁、办公与教育
环境
episode histories 来自 HM3D 与 ScanNet；HM3D 用 Habitat 重播 agent states，ScanNet 从原扫描数据抽取。episode_history 路径连回 scene/source；RGB、depth、pose 是同历史不同观测，不添加场景。
任务
开放词汇环境问答，可讨论 episodic memory 和 active exploration；此核读 evaluator 判文字答案，没有证明某 agent 已完成探索或操作。
题数与数据
open-eqa-v0.json 例含 question_id、question、answer、category、episode_history，可另有 extra_answers。HM3D 版本为 hm3d-v0/场景路径，数据文件提供 RGB-only 或 RGB-D+intrinsics+pose；原 scan/agent state 与 extraction 版本要随 case 保存。
评估方式
llm_match 预设 gpt-4-1106-preview/seed1234/temperature.2/max_tokens32，以原参考与可选 extra_answers 判1–5；parse Your mark 后整数。evaluate-predictions 先核 ID/数量、截掉最后句点后的尾文、逐题缓存，再将clip(score,1,5)线性映成0–100平均。prediction=None 回0后映为0；force 只对提供的 result 遍历，dry-run 只取前5，均不能报全量分数。

怎么接入我们的benchmark

可重用

稳定 question_id、scene/history 路径、参考答案与替代答案、原始 judge prompt／范式。

需要转换

environment 保存父 HM3D/ScanNet scene 和 extraction release；case 绑 question_id/history/modalities/观测 budget。evaluator 固定裁判版本、prompt hash、预处理、cached score 来源；完整数据／结果 ID 一对一，force/dry-run 和缺题另标。

仍需补齐

尚未取得 histories、运行 simulator／baseline／付费裁判。只读 QA /0 schema 范例，未逐题验证全库；若更换模型或 prediction，旧 metrics 缓存需按输入hash区分，并另外验证裁判与人工一致性。
