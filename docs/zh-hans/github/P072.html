VLABench: A Large-Scale Benchmark for Language-Conditioned Robotics Manipulation with Long-Horizon Reasoning Tasks

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

VLABench 有交互VLA评测与脱机VLM技能串行评测两条不同链。已追到select_fruit的容器几何、progress实作、HDF5 writer/reader及DSL匹配；metric.py的pass不代表全库没有评分器，但现行总分与CLI确有静态缺陷。

版本与身份

VLM get_final_score虽声明0.4/0.4/0.1/0.1，实际total_score只加前两项，因此完美匹配上限80；get_final_score_dict调用get_result_save_path时漏eval_dim。evaluate_vlm.py引用未声明的task_list_json/save_dir。交互Evaluator捕捉episode例外后不加入task_infos，均值分母会缩小；必须另列请求、完成、失败及错误数。README的旧CLI拼字/参数也不等于现行parser。这些是静态检查结果，未运行上游。

固定论文为arXiv:2412.18194v1（2024-12-24），README引用相同题名与11位作者。固定程序cf588fe60c0c7282174fe979f5913170cfe69017（2025-11-11）已有2025评测轨道与数据更新，不能视作2024预览版的原封快照。

领域
居家整理与清洁、餐饮与烹饪、办公与教育、实验室操作、休闲与运动
环境
MuJoCo/dm_control依scene、components、robot及MJCF资产组装；select_fruit_series具体使用studyroom_0与table。观测依模型的ncam迭代，不能把样例四视角当所有任务固定相机数。物理步、NUM_SUBSTEPS=100与policy步数分开；视频10 fps不是通用控制频率。
任务
论文100项（60 primitive＋40 composite）；原生task、config_manager与condition以注册名连接。select_fruit的seen类别为apple/banana/orange/pear，unseen为peach/lemon/kiwi/mango；contain检查对象worldbody位置点落在Plate的平面范围及预设0–0.1公尺上方，不检查整个对象bbox或稳定接触。PourCondition只比较top/bottom site高度，是姿态代理，不代表液体流动。
题数与数据
HDF5为data/<时间名>/observation、meta_info、trajectory、instruction；observation可含rgb uint8、depth/q_state/q_velocity/q_acceleration/ee_state及点云float32。meta_info保存entities、target_entity、episode_config字符串；writer略过segmentation、instrinsic、extrinsic等字段，点云补零且未另存有效点数。trajectory为8维xyz/Euler/两指gripper；脚本只从xyz减robot_position，不能宣称已做含旋转的完整座标转换。VLM题目则是task/exampleN/input的input.png/input_mask.png/instruction.txt与output/operation_sequence.json，GT为skill_sequence[{name,params}]。
评估方式
交互链：Evaluator→load_env→dm_control终止→ConditionSet→ContainCondition→Plate/FlatContainer.contain；success取timestep.last。未提供episode_config时用42+i seeds；预设最多200个policy步，可由task_config覆盖。当前API分别平均success、intention、progress；intention是历史最小eef距离<0.1公尺，primitive progress将当前已满足condition与曾抓握target计数合并，没有实作论文0.2/0.8加权PS。脱机VLM链用技能/参数多重集合recall、技能参数联合recall及DAG节点匹配百分比；这些0–100分数不能转称物理成功率。
原作数字：保留论文的单位与页码

怎么接入我们的benchmark

可重用

原生task/config/condition、确定性episode_config、HDF5与DSL case结构、分开的物理checker及图匹配metric。

需要转换

同一source保留交互与脱机两种case/evaluator；映射name/params/target_entity_name/target_container_name时保存图依赖模式、few-shot、CoT及信息可见性。保留8维Euler waypoint、9维joint＋gripper控制与观测四元数各自语义，不依维度误并。

仍需补齐

大型track JSON与外部vlm_evaluation_v1.0的完整case清单尚未取得，不能填全库episode数；仍需修正CLI/metric、固定model与dm_control版本、资产闭合，以及逐task验证进度支持。
