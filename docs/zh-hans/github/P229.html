P229 · UniEgoMotion

UniEgoMotion: A Unified Model for Egocentric Motion Reconstruction, Forecasting, and Generation

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

UniEgoMotion 把重建、生成和预测放在同一人体动作框架；它的 EE4D-Motion 是 EgoExo4D 的处理版本。已核对切窗／split、可见信息 mask、3D 评分与地面接触代理量，不能把三种设置当成三批独立原始数据。

版本与身份

本次固定官方 commit，三种 task 共用 EE4D-Motion。论文／README 的数据量为来源报告量，不是本案已取得题数；时间窗口和 eval 抽样不可省略。

领域
餐饮与烹饪、休闲与运动、音乐与表演、穿戴交互与动作界面
环境
EgoExo4D 多用途人类活动的 Aria 视频、轨迹与拟合 SMPL-X 身体；没有添加可运行机器人环境。EE4D-Motion 使用父数据 take／train-val 关系。
任务
原生三种 model task：recon 全观测重建；gen 仅第一影格可见；fore 可见 window 前 1/4（典型 20/80 帧）。这些是观测协定差异，不能直接增加三倍独立情境。
题数与数据
DATASET.md：原始 4,792 takes、约 208 小时，筛选为 train 2,032／val 560 takes、约 110 小时。segment key 的 start/end 使用 30 Hz 原始 index、含末端；motion 为 10 Hz。dataset 每 20 motion frames 建窗，正式 evaluation 再用每第十个 validation sample。SMPL-X 是拟合结果，需保留失败／屏蔽筛选及父 take ID。
评估方式
评分含全身／body 前 22 joints／hand 25:55 的 MPJPE 与 PA-MPJPE、head／trajectory 误差、足滑、穿地、腾空与接地距离。rotation error 是 R差的 Frobenius norm，非角度。接触指针各有 4 cm／8 cm 等阈值；足滑按串行长度归一且乘 1000，不是成功率。compute_3d_metrics 遍历 GT key，评整段和每 20 帧；pred trajectory=None 时以 GT trajectory 替代，此条件下 trajectory 误差不能证明模型预测能力。

怎么接入我们的benchmark

可重用

重用 take lineage、SMPL-X／Aria 对照、明确 mask 与 evaluator 各原生字段。；保留 reconstruction／generation／forecast 的条件差异，不混合 rank。

需要转换

canonical case 固定 take、start/end、30→10 Hz 对照、valid frames、观测 mask 和 train-only normalization revision。；把 supplied-GT trajectory 与 predicted trajectory 设为不同 evaluation condition；报分时明示。；全段与分段 metrics 分开；若另评纯未来区间，添加 evaluator 版本并保留原生成绩。

仍需补齐

未下载受原始数据／SMPL-X 授权约束的完整资产，未跑模型。；语义生成评分与模型内部 diffusion 未在本次列出的 3D reader 范围内完整审核。
