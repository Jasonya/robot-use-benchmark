TACO: Benchmarking Generalizable Bimanual Tool-ACtion-Object Understanding

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

TACO的公开库主要是人体手–工具–对象数据加载和投影工具。pre-release与V1的串行、triplet和视角数不同，必须分版计数。

版本与身份

固定b385ac1；CVPR2024原作2401.08399，README后续更新到V1与额外工具。未将可视化成功当作理解或机器人操作成功。 已补核TLabel be7121d0的文件、schema与quality入口，限后加工具角色；未运行adapter／export或宣称TACO数量因此增加。

领域
餐饮与烹饪、居家整理与清洁、穿戴交互与动作界面
环境
真实双手工具操作，多视角RGB与ego RGB-D。pre-release为8个allocentric views，V1为12个，且共用206object models；不同view或release不当成独立物理场景。
任务
〈tool,action,object〉triplet理解与generalization：pre-release244sequences/137triplets，V1 2317sequences/151triplets。triplet是原生语义组合，sequence是观测样本，不自行当151种可运行robot目标。
题数与数据
按triplet/sequence组织RGB-D、Hand_Poses、Object_Poses及Camera_Parameters；MANO48Dpose+10Dshape+translation，输出778vertices/21joints。hand模型结果除1000、object_cm.obj乘0.01后进同m座标；camera extrinsics明示world_to_camera。缺shape helper会补0beta，需标missing/default。 额外工具TLabel的固定README／schema已补读：它另有schema_version、sensor_info、capabilities、episodes，以及14个触觉语义字段；这不表示原TACO已有这些触觉信号。TLabel的L1–L4描述信息完整程度，非本benchmark的任务难度。
评估方式
所读是loader与可视化，不是完整原作benchmark grader；frame数与pose数不符会跳过。需要原作task split/metric才可做辨识/轨迹/交互评测。后加TLabel workflow只是工具支持，不能据此把原作RGB-D清单宣称添加实测触觉模态。 TLabel的QualityScorer以一致性30%、平滑25%、完整性25%、覆盖20%合成数据品质分数；不是对GT量测准确率、机器人成功率或校准后的难度。data_quality另可用户自述；schema预设confidence=1.0也不能当已验证的可信度。
