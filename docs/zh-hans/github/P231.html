P231 · MADiff

MADiff: Motion-Aware Mamba Diffusion Models for Hand Trajectory Prediction on Egocentric Videos

返回逐篇总表内核内容已核读 方法／综述参考原作 ↗

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

MADiff 是重用多个既有 Ego 数据集的手轨迹方法。已读到的官方版本提供 H2O／EgoPAT3D 两个 backend，并附 ACT 条件输入教学；论文五个数据集的覆盖、目前程序入口与添加机器人教学分开登记。

版本与身份

目前 README 为 T-PAMI 2025、引用同一 arXiv；版本添加 H2O／EgoPAT3D backend 与 ACT 教学。已读原生程序与论文范围不相同，必须按版本列出。 补查MMTwin README：它对应2504.07375，CABH列三种人类操作任务，CABH专用模型仍待发布；EgoPAT3D配套程序已在P222核读。这是相关延伸，不改写MADiff本篇的任务或可运行范围。

领域
方法／综述参考，未另作来源用途归纳。
环境
父数据 EK55、EK100、EGTEA Gaze+、EgoPAT3D-DT、H2O-PT；目前公开入口主要为后两个。EgoPAT3D loader 有 11 个已见 scene IDs 与 novel 13／14／15；ID 是父数据场景，不能当 MADiff 新建环境。
任务
同一手部轨迹 forecasting 方法在不同数据与观测配置测试。现行两个 backend 设置 target=2d、observation ratio=0.6；H2O max_frames=64，EgoPAT3D=40。ACT 教学将 forecast 作额外 token，没有提供一套新的正式 robot benchmark 题单／判分器。
题数与数据
原生数据与权重需外部下载，来源依赖 USST 预处理。读取 native filename、scene/recording split、有效帧数、trajectory／GLIP／motion features；论文五数据集的 train/test 样本表不能算为五批全新原始视频。
评估方式
实际 H2O／EgoPAT3D eval loop 对纯未来区间逐串行计 normalized-image ADE 与末点 FDE，并非档内未用 helper 的 weighted error。H2O 每题 1 次抽样、gap=999；EgoPAT3D gap=333。test_novel 虽有 loader，traineval 对 tuple 取 [0]，预设入口只评 test。H2O rank 档只汇整 ADE、文件名需隔离运行以免读到旧档。

怎么接入我们的benchmark

可重用

重用父数据 split、scene IDs、有效长度、座标转换与实际调用的 ADE／FDE。；ACT forecast-token 教学可作 human-to-robot 界面参考，与正式测题清单分开。

需要转换

case 包含 dataset revision、backend、filename、60% boundary、max_frames、normalization 与 feature revision。；novel test 建独立入口和完整 expected-case manifest；抽样次数、diffusion gap 各自固定。；把论文五数据集与目前两 backend／MMTwin 3D 延伸保留版本关系，不合并报为新环境。

仍需补齐

未跑模型、未取得特征／checkpoint；没有重现论文数字。；机器人教学缺可下载任务／示范／evaluator；MMTwin本次仅补读README；其EgoPAT3D程序核读见P222，不把CABH待发布模型当成已可用。
