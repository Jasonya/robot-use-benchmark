Robobench: A Comprehensive Evaluation Benchmark for Multimodal Large Language Models as Embodied Brain

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

RoboBench 的钉选版本已分 MCQ 与 Planning，并提供原生粒度表。本次核读 loader、MCQ、Q1–Q3 planning 的核心规则，以及 point/IoU 辅助 evaluator；不把模型裁判等同物理运行。

版本与身份

README已是ECCV2026 release，不能无版本注记地替换2025 arXiv表。IoU文件开头提mAP，但实际回传平均IoU／pass rates，没有AP排序积分；点／IoU工具存在也不代表32 manifest全都使用它们。

领域
居家整理与清洁
环境
图像／视频中的机器人或人类操作观测；unique_id 中的 images 路径定位样本。cross-embodiment/object/view/attribute 是泛化条件，5 dimensions 是能力分类，不是5种生活用途。
任务
2026 release README 列5 dimensions、14 groups、25 tasks、32 subtask manifests、6,092 QA，MCQ=1,895、Planning=4,197；这是版本化原作者规模，非本次数据集成实数。Q1 多步计划、Q2 下一步、Q3 状态估计会共用同一来源图像。
题数与数据
system_prompt.json 和 dimension/subtask/questions.json；question 有 unique_id、task_type、image_urls、robotic_type、question/options，转 request_id/prompt。Q1–Q3 suffix 在找图时去除；Q1另读 dag.json 的 id→gt_dag，navigation 无同样 DAG。human 在 prompt 被转成 single-arm，原始 embodiment 不能因此覆写。
评估方式
MCQ 取 answer tag／清除 think 后比A–D集合，不明确输出可用另设裁判范式。Q1模型看首图、GT nodes/DAG、预测计划，给 node correctness与task completion各0–10后平均映0–100；空 critical-state集合依prompt直接Completion=10。Q2 skill/object/parameter三项平均，前两任一0则parameter=0；Q3 yes/no精确比。Q1/Q2解析失败排除均分但overall按原count加权；point/IoU亦只用有效解析作分母，需附valid率。

怎么接入我们的benchmark

可重用

原生32 manifest层级、题目/skill/DAG/prompt格式与逐项判分证据。

需要转换

source 固定 release+commit，task 保留原25/32映射，不把 Q1/Q2/Q3 或新视角当新环境；case 保留 raw_question/来源图/embodiment/DAG及观测预算。evaluator 分MCQ、Q1/Q2/Q3和point/IoU等可选工具，native分数、parse_failures与分母同存。

仍需补齐

未取得完整HF数据／DAG或运行模型裁判。需查 empty-goal cases、裁判一致性、skill语义与可用资产；MLLM imagined rollout 不能宣称物理稳定性／真实任务成功。trajectory evaluator 未在本次核读范围。
