Open X-Embodiment: Robotic Learning Datasets and RT-X Models

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

Open X-Embodiment提供共用RLDS容器与数据读取示例；相同tensor形状并不自动统一不同机体动作的物理意义，父数据集也不能重复计数。

版本与身份

固定9eeb68b；README的3Hz/单workspace RGB是RT-1-X模型界面，不代表所有OXE数据的原采样率和可见模态。Notebook source cells与输出分开核读。

领域
居家整理与清洁、餐饮与烹饪、通用对象与机动作业
环境
聚合多来源、多机体的robot episodes，包括Bridge、RoboNet等；每个子数据原有场景和授权/版本，OXE不是额外一份完全独立的环境数据。
任务
主要是跨机体训练数据与RT-X方法；不能把数据集数、机体数、skill labels和实际评测题数互换。
题数与数据
RLDS episode含steps，notebook以TFDS builder从固定dataset/version读取。Kuka示例拼world_vector/rotation_delta/gripper_closedness_action，Mutex直接取action；图像resize128。另一例保留is_first/is_last/is_terminal且只对齐图像，并未对齐所有action语义。
评估方式
仓库读取／混合示例和RT-1-X inference不是覆盖全部子数据的通用成功checker。README指出7个控制变量可能是absolute/delta/velocity；相等TensorSpec只是形状检查。tf.data.repeat重复采样不增加独立数据；train[:10]也是示例subset。
