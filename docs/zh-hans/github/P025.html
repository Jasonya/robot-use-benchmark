EgoPet: Egomotion and Interaction Data from an Animal's Perspective

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

EgoPet 分成动物交互 VIP、动物移动 LP，以及四足机器人数据上的 VPP。已核读三项定义与实际评测，不能把动物视频或 latent 回归直接算成机器人完成任务。

版本与身份

主 README 的会议年份文字不可单独作书目依据，身份由标题／作者／项目互连确认；LP 文案的 40 点／4 秒和命令的 num_pose_prediction=120/fps/pps 需依实际 pose_skip 映射，不能只抄旗标数字。

领域
宠物照护与动物活动
环境
VIP/LP 是动物第一人称视频；VPP 另用四足机器人在 office/park/beach 的录制与日夜／地面移转。视频来源、robot episode 与实体地点分层。
任务
VIP 判断是否交互与 17 种交互对象；LP 预测尺度模糊的未来相对轨迹；VPP 从图像预测 proprioception-derived latent，在 -1.5、-.8、0、.8、1.5 秒条件分项比较。
题数与数据
VIP CSV 含 animal、ds_type、video_id、segment_id、start/end_time、interacting_object、video_path；LP 另存 DPVO stride 和 TUM trajectory。LP loader 用 training_set/validation_set、cat/dog、有效文件过滤，test 最长截到 50 秒；sample index 不等于完整来源总量。
评估方式
VIP interaction 使用 sigmoid/accuracy/BinaryAUROC；object top-1/top-3 与 macro AUROC 仅在 GT 有交互样本算。LP 以方向范式增量预测，重建时乘回 GT 增量尺度，再用 evo align=True/correct_scale=True 的 ATE/RPE RMSE；不是无尺度辅助的导航成功率。VPP validation 用 MSE，loader 设 drop_last=True，分布式补齐可能重复样本；百分比形式打印的 loss 不表示 accuracy。
