P055 · FUTR

Future Transformer for Long-term Action Anticipation

返回逐篇总表内核内容已核读 方法／综述参考原作 ↗

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

FUTR重用Breakfast与50Salads，预测动作类别及持续比例；观测／预测百分比和frame级MoC是原生协定的一部分。

版本与身份

FUTR是方法repo，父数据与EGO-TOPO／其他预测方法可能重用；样本窗口与原片不能重复相加。

领域
方法／综述参考，未另作来源用途归纳。
环境
既有长视频及预计算视觉特征，无新可操作场景。
任务
从过去视频预测后续动作分段；一支视频的多个观测比例是不同评测设置，不是不同语义任务。
题数与数据
groundTruth逐影格标签、features/*.npy及mapping.txt；dataset返回features、past_label、trans_future_target、trans_future_dur，保留sample_rate、NONE、pad_idx及n_query截断。
评估方式
predict.py将预测类别／duration展开到未来影格，再按观测与预测比例截取；eval_file累积每类正误影格，最后对有GT的类别平均得到MoC，非全影格micro accuracy。

怎么接入我们的benchmark

可重用

来源视频／split、逐影格GT、类别字典与MoC计算。

需要转换

case保留来源视频长度、obs_fraction、pred_fraction、特征步长及label mapping；duration比例要连同视频长度保存，不改写成固定秒数。

仍需补齐
