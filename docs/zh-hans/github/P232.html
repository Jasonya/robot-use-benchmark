P232 · Diff-IP2D

Diff-IP2D: Diffusion-Based Hand-Object Interaction Prediction on Egocentric Videos

返回逐篇总表内核内容已核读 方法／综述参考原作 ↗

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

Diff-IP2D 重用 OCT／EPIC 的轨迹与接触标注，但实际轨迹入口评的是 WDE／FDE。逐段追到 runtime caller 后，已把它和 repo 内沿用但未在该路径调用的 OCT evaluator 分开；不能只看文件名就判断评估方式。

版本与身份

原生程序 import 了 evaluate_traj_stochastic，但所读实际轨迹路径使用 compute_wde／compute_fde；OCT wrapper 的名称对调不能直接套到此主结果。固定版本的来源差异均保留。

领域
方法／综述参考，未另作来源用途归纳。
环境
来源视频与人工评测 labels 重用 EPIC-KITCHENS／OCT；论文也包含其他 Ego 数据实验，README 的当前完整部署仅 EK100，EK55／EG 发布仍列待补。
任务
未来 2D 双手 waypoint 与 object affordance/contact hotspot；典型 10 个过去 token→4 future 点。改 diffusion 架构不是添加语义任务，沿用 label 要连回 OCT 父来源。
题数与数据
features／bbox／有效性、uid／raw frame 与 homography 均有原生字段。training loader 会加 future features，evaluation loader 不加；manual-merged annotations 不等同 OCT 原始 annotation folder。各外部文件与 checkpoint 要固定 hash／split，不能只记 repo commit。
评估方式
主循环将预测转 numpy 后调用 compute_wde：4 未来点权重 0.25／0.5／0.75／1.0，求和未除以权重总和；FDE 为末点，normalized image 单位。tensor 分支反而为普通平均，但不是此路径。输出先按 batch 的有效手平均，再跨抽样／batch／rank 平均，与全数据有效手池化不同。heatmap SIM/AUC-J/NSS 沿用 OCT，仍需按 uid 配对、NaN 分母明示；原始 metrics rank equal-average 也要保留。

怎么接入我们的benchmark

可重用

重用 OCT lineage、native labels／split、真正在主循环调用的 WDE／FDE 与热图 evaluator。；保留 full／fast diffusion 与 sample_times，不能将 10 次抽样当 10 道题。

需要转换

source 同时记 paper version、code commit、data archive hash；canonical case 禁止 training-only future features 出现在评测输入。；原生 WDE、FDE、heatmap 各列公式和有效分母；若改为 sample-weighted global mean，需添加 evaluator 版本。；以父 participant/video/time 去重；EPIC55/100、OCT／Diff-IP2D 保留 overlap 关系。

仍需补齐

未下载 weights／features 或运行，README checkpoint links 与其他数据部署仍需逐一取得。；已有函数不等于已有完整测试任务，case metadata 与 raw video 权限尚未集成。
