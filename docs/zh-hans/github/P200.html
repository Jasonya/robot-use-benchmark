SABER: A Scalable Action-Based Embodied Dataset for Real-World VLA Adaptation

版本与身份

2026-10-11原项目路径转向DreamVu首页；research页仍列精确2605.09613与DreamVu/SABER-10K，但公开HF raw请求401。401只表示本次未取得，未推定资源不存在或尝试绕过访问限制。

领域
包装、仓储与物流、零售与购物
环境
多个真实grocery store；头戴GoPro配固定ALIA360°六个同步视角，拍摄时没有robot。相机数/视角数不能当商店或环境数。
任务
零售补货、取放商品、货架不同高度、篮车/冷藏柜与走道活动；原文主张domain-specific VLA adaptation，尚无已取得的固定任务/评测case清单。
题数与数据
原文约100小时双流拍摄；Stream1为25K约10秒ego episodes的LAPA latent tokens，Stream2为18.6K ego episodes的人类21点hand pose/修正后retarget，Stream3由exo SMPL转UnitreeG1。三stream来自相同拍摄，不相加当独立物理episodes；手动修正的human pose与retarget不是原生robot控制纪录。
评估方式
原文包含VLA适配实验及人工annotation QC；尚无取得的评估code/episode verdict，不能重现其提升倍数，也不能把人工QC比例当任务成功率。
