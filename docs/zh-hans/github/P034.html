Egocentric Video-Language Pretraining

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

EgoVLP 同时提供 EgoClip 预训练与 EgoMCQ 开发评测；本次核读 EgoMCQ 格式、chunk loader 和实际 accuracy。其他 Ego4D／EPIC／Charades 评测保留父来源。

版本与身份

EgoMCQ 被用来选预训练 checkpoint，应标 development set，不自动当独立最后测试。EgoVLPv2 为后续方法，新闻链接不代表本 repo 已包含其添加结果与全部程序。

领域
居家整理与清洁、工艺与修缮
环境
视频来自 Ego4D；600 秒 chunk 是保存切块，不是物理环境。intra/inter-video 指候选来自同／异视频的难度条件，不等于生活用途。
任务
EgoMCQ 给文字查找，从五个视频候选找正解；与从视频选文字答案的 QA 方向不同。EgoClip 数百万 narration clips 是训练单位，不能当 EgoMCQ 测试题或新动作任务。
题数与数据
EgoClip TSV 含 clip_idx/video_uid/narration_source/narration_ind/narration_time/clip_start/end/clip_text/tag_verb/tag_noun；MCQ JSON 有 query/choices/answer/types。loader 依 clip 秒数取可能跨两个600秒文件的 frames，返回 video/text/text_ops/correct/type。val 与 test 都读同一 egomcq.json。
评估方式
egomcq_accuracy_metrics 在各 type 内 argmax 对 label 算 accuracy。重要不一致：loader 注解写 1=inter、2=intra，但 metric 将排序后 type 配给 Intra-video、Inter-video；需对原 JSON 定义后判断，不能直接抄标题。eval config 4frames/224px/loading=lax，失败会以黑图补，应另计数据读取失败。

怎么接入我们的benchmark

可重用

原生五候选 query/choice metadata、来源切块映射、pretraining 与 development 分界。

需要转换

case 保留 EgoMCQ ID、候选顺序及各父 video/time；source 分 EgoClip/EgoMCQ/下游父 benchmark，tag 字典作原生训练词汇。evaluator 保存 type 数值与已核定名称、4frame 预算、缺档回退，不能把同 JSON 的 val/test 加成两套题。

仍需补齐

尚未取得 egoclip/egomcq 全量 metadata、视频或运行。需解决 type 名称矛盾、有效样本清单与跨来源视频去重；下游 NLQ/MQ/PNR/OSCC 完整 adapters 仍另按父协定验证。
