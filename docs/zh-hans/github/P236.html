P236 · ActFusion

ActFusion: a Unified Diffusion Model for Action Segmentation and Anticipation

返回逐篇总表内核内容已核读 方法／综述参考原作 ↗

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

已核 ActFusion 的 feature/label loader、full_len 遮罩推论、TAS scorer 与 LTA MoC。固定 release 的预设 LTA 仍使用完整视频长度；不可标成论文 ActFusion† 的未知未来长度协定。训练亦用 test split 分数选 best checkpoint，需保留模型选择条件。

版本与身份

固定 00ba6c1df0ac30cfcb90110278dd3616a589ced4。release 的 50 Salads epochs=7001、n_mask=10，Breakfast batch_size=16、feature layers=[7,8,9]；论文表 S5／§5.2 有 5000 epochs、50 Salads mask=25、Breakfast batch_size=4 等差异，不能把公开 JSON 称作逐项相同的论文设置。README 的 default_configs.py 实际位于 src/default_configs.py。本次未运行任何上游模型或训练。

arXiv:2412.04353v1（2024-12-05），Dayoung Gong、Suha Kwak、Minsu Cho，NeurIPS 2024。官方作者帐号 gongda0e 的 README 明列相同 arXiv、题名、作者与会议；搜索中更早同名 magrogovich/ActFusion 不采用。PDF 提及 FUTR 和 DiffAct 是比较方法／重用程序，不能拿它们当 ActFusion release。此 repo 创建及固定 commit 为 2025-07-08，晚于论文。

领域
方法／综述参考，未另作来源用途归纳。
环境
离线程序活动视频；Breakfast 与 50 Salads 是第三人称烹饪来源，GTEA 是第一人称烹饪来源，不能全部标 Ego 或机器人环境。程序以预先提取 I3D 特征为输入，不提供物理控制或 robot success。
任务
同一模型做 temporal action segmentation（TAS，完整观测）及 dense long-term anticipation（LTA，部分观测）；论文 TAS 用 50 Salads/Breakfast/GTEA，LTA 用前两者。原生 action 数从外部 mapping.txt 的列数取得，event_list 的行序编码与 read_mapping_dict 的首栏数字必须一致；这次未取得该数据报，未冒称固定程序类别数。论文 50 Salads 的 50 videos/17 fine-grained labels、Breakfast 的 1712 videos/48 labels、GTEA 的 28 videos/11 labels是原作统计，不能直接当本次加载的有效 case 数。
题数与数据
datasets/{dataset}/features/{video}.npy、groundTruth/{video}.txt（一行一个 frame label）、mapping.txt（ID 名称）、splits/{train,test}.split{split}.bundle。reader 接受二／三维 features，swapaxes 后为 augmentation×T×F，assert T 与 GT/boundary 长度一致；未知 label=-100。事件边界在 label 改变点及前一格置1，再可 Gaussian smoothing。sample_rate=8（50 Salads）或1（Breakfast），temporal_aug 对各 offset::rate 建样本，但 dataset 长度仍是 video 数；回复用 nearest interpolation 与首末值填充。时间原生为 annotation frame index，无可靠 fps/秒转换资产随 repo；2048 是输入 feature 维度。paper 指 5/4/4 folds，程序每次只读指定 --split，没有自动跨 fold 聚合；完整数据报及有效长度未下载。
评估方式
预设 decoder-agg：LTA α=0.2/0.3，full_len=feature[0]时间长度，observed_len=round(α×full_len)，切掉未来视觉特征后仍把 full_len 传给 ddim_sample 追加 mask tokens；这是已知全长设置。各 temporal offset 概率平均，median filter（50 Salads=30、Breakfast=15 个采样位置）、argmax，回复至 GT 全长。LTA 对 β=0.1/0.2/0.3/0.5，以 [int(αT):int((α+β)T)] 的原始 frame 范围计各 GT 类别 n_T/n_F，先跨 videos 累加，再对有 GT frame 的类平均 n_T/(n_T+n_F)×100；不是 frame micro accuracy，也不是 best-of-K。TAS Acc=所有评测 frame 正确数/总 frame；Edit=每视频压缩连续同标签后的 (1-Levenshtein/max(segment_count))×100 再视频平均；F1@10/25/50 以同类 segment IoU 门槛一对一配对，跨视频累积 TP/FP/FN 后计 F1。只排除字面 background，不能预设所有 SIL/action_start 类被排除。LTA 同时回传的 Acc/Edit/F1 是 observed prefix 上的分段分数，不能标成 future MoC。sampling seed=video_idx，25 sampling steps／1000 diffusion steps；offset 不是添加试验数。

怎么接入我们的benchmark

可重用

bundle/video key、mapping、逐格 labels/features 对齐、TAS 具体 Edit/F1 与 LTA class-count scorer。

需要转换

source 保存 paper version/commit 及 MS-TCN feature来源；domain/environment 依数据集视角分开；task 分 TAS 和 LTA，case=(dataset revision,fold,video,α,β,length_protocol)，frames/segments/augmentation 不互相加总。另记 F、feature_stride、offset、original_frame_index、round/int 边界、median 窗、seed、DDIM budget；evaluator 区分 frame micro、video-mean Edit、pooled segment F1、class macro MoC。

仍需补齐

需固定完整 mapping/split/feature bytes与原始 fps，检验 mapping 行序=数字 ID、未知 -100、背景与末 segment end 的边界（实作最终 end=i，非 i+1）。论文 §5.4 的 ActFusion† 用 r=4×observed length，此 release 的 CLI/config/已核 sampler 未提供该协定；须添加明确 adapter/取得对应作者版本。train 在 test_test_dataset 上计 TAS 五项平均与八格 LTA MoC 平均选 best／combined 模型，须改为独立 validation 或如实标注。TAS及不同 α 共写同一 prediction/{video}.txt，导入须另用 protocol key 防覆写。GTEA 无随附设置与数据；不能只凭 main.py 的分支宣称已接通。
