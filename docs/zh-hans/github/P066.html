ManiSkill: Generalizable Manipulation Skill Benchmark with Large-Scale Demonstrations

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

2021原作应读haosulab/ManiSkill-Legacy，不能用现在ManiSkill3的main代替。其四种基本任务会依PartNet模型与目标link产生更多环境ID，这些不是全部新的工作种类。

版本与身份

来源版本固定为Legacy commit58964d08…；与ManiSkill2 v0.5.3和ManiSkill3分别保存，不混用数量及API。

领域
居家整理与清洁
环境
SAPIEN场景绑定PartNet-Mobility模型；model/link ID与level控制资产及初态变化。
任务
OpenCabinetDoor、OpenCabinetDrawer、PushChair、MoveBucket四种原生基本任务，再衍生模型／link设置。
题数与数据
观测可为点云／RGBD／状态；示范及资产外部取得，模型分割与初态在YAML／level设置。读取时需保留观测模式和模型身份。
评估方式
具体task先产生条件旗标，base_env要求连续保持0.5秒；Evaluator依episode终止时eval_info计比例，不能以某一帧接近目标替代。
