tinyBenchmarks: evaluating LLMs with fewer examples

返回逐篇总表内核内容已核读 方法／综述参考原作 ↗

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

tinyBenchmarks提供用少量anchor题推估原benchmark分数的IRT工具；对本计划是抽样与难度校准参考，100题不是所有robot领域适用的固定答案。

版本与身份

工具固定e9a8b10，原实验库c9df154；package缺pickle时连mutable main下载，正式adapter需把数值资产另行固定hash。未运行模型/IRT或pickle。

领域
方法／综述参考，未另作来源用途归纳。
环境
原研究为LLM评估题库，没有robot物理环境；MMLU、AlpacaEval等是父benchmark。
任务
评估任务是以少数已跑题估计完整benchmark/model表现。100为每个tiny dataset的anchor数，非100个新语义task；模型family外推与题目抽样需分开切分。
题数与数据
package读seen_examples、examples_weights、A/B、optimal_lambdas与scenario/subscenario positions；y_input为按anchor顺序的response矢量。原实验data包含models与各benchmark结果矩阵，以model row拆IID/non-IID。未下载或反串行化pickle。
评估方式
以sigmoid(sum(a×theta−b))拟合能力，IRT加权anchor、pIRT混合观测与未测预测、gpIRT再混合；不是补出真正运行结果。README说公开小集从5seed选test平均最佳版本，因此新robot设计应另留独立validation/test model families，不能直接保证相同误差。

怎么接入我们的benchmark

可重用

anchor/index/权重、模型response矩阵、IRT估计流程与分布外评估概念。

需要转换

先取得本benchmark多policy×case的实测response，再按来源/场域/任务分层；calibration、anchor selection与最终model test分开，预估分数明标estimate并附误差。

仍需补齐

robot response矩阵、跨policy/embodiment外推验证、难度参数稳定性与估计CI；不能用目前metadata假造IRT难度。
