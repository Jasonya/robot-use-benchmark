EgoMonth: A Month-Level Egocentric Video Benchmark for Long-Term Spatiotemporal Memory

返回逐篇总表文件／网站 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

susu801/EgoMonth 的 README 与网站对应同名论文的 301 小时／738 clips／1,443 QA／14 题型，但 pinned 完整 tree 只有静态页面与图片。文件声称存在的 scripts/ 与评测程序均不在此 commit；尚不能视为已公开可运行 benchmark。

版本与身份

程序来源固定 81143141d98b4511ff1adcae9a5ccf3a9f0f9606（2026-09-22），PDF 为 2608.13113v1。非截断 tree 的 15 个 entries 中没有 scripts/、.py 或数据 JSON；README/index.html 的存在声明与此版本实物不一致。未尝试用别人的同名仓库填补。

核对 arXiv:2608.13113v1 首页题名、作者及正文。候选仓库完整题名、统计与题型一致，足以确认内容所指论文；但 pinned PDF 未连到该仓库，README/index.html 仅署名 EgoMonth Team，未提供作者名单或 arXiv 反向链接，因此 susu801 的作者官方身分仍未独立证实。

领域
居家整理与清洁、餐饮与烹饪、办公与教育、零售与购物、交通移动与车辆维修、休闲与运动
环境
人类日常第一人称录像，20 名参与者各跨 20–120 天、室内外与不同设备；论文有学习工作、交通、饮食、购物、休闲、家务六种活动分类，没有可运行 scene registry 或实体场所去重总数。
任务
保留 Table 1 的 14 QA 类型：Habit Inference、Personality Inference；Detail Retrieval、Spatial Relation、Self-localization、Temporal Ordering、Event Time、Object Location；Procedure Planning、Event Counting、Object Counting、Route Reasoning、Cross-view Spatial Reasoning、Direction Judgement。三组分别是 Schema Consolidation、Episodic Indexing、Cascading Reasoning；它们是视频记忆／推理题型，非机器人动作任务。
题数与数据
已读到的 schema 仅是 README 文件示例：JSON list，每笔 video_path 为一至多个相对视频路径，question、四个 options、correct_options 字母与 task_type；文件称以 CONFIG["video_root"] 接路径，但没有可核对的 loader。论文报 738 clips、18,072 分钟与 1,443 人工四选一题；这些是论文统计，未取得 QA manifest，不能宣称已清点实际 release。跨日参与者／session ID、时间戳格式、每类实际题数与 split 档均未见。
评估方式
论文 §4.1 与 README 定义 micro Acc = 全部答对题数／全部题数（完整论文集合 N=1,443），macro Avg = 14 个题型各自 accuracy 的等权平均；直接比对正解，无 LLM judge。各模型观测预算不同，例如 16／64／256／512 frames 或 1 fps，需保留。固定 tree 未含 README 所称的 Qwen 等脚本，因此无法核对答案字母 parser、多视频拼接／抽帧、错误／空回答如何入分母，也没有可追的 concrete scorer。

怎么接入我们的benchmark

可重用

可重用有来源的 14 题型、三认知层级、论文统计、文件示例 schema，以及 macro／micro 的分开定义；仓库先列文件来源。

需要转换

source 保留 paper v1 与候选 repo commit／身分状态；environment 用参与者与生活录像脉络；task 保留原生 task_type。release 到位后，case 以原始 QA ID 关联有序 video_path[]、question/options/correct_options，另保存 participant/day/session、媒体时间及观测预算；单片与跨片同属一题，不能按片重复计数。evaluator 分列 micro 与每类及 macro 分母。

仍需补齐

作者官方链接、QA／split／视频 manifest、可读 loader、实际答案解析与 scorer、跨日时间对齐、抽帧及例外处理。现阶段不能产生已验证可运行 case 清单。
