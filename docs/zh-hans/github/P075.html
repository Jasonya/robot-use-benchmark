P075 · VIMA

VIMA: General Robot Manipulation with Multimodal Prompts

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

VIMA-Bench提供任务、数据与成功判定，VIMA仓库提供模型与交互范例。已核读多模态prompt、四级partition、T+1/T数据对齐，以及visual_manipulation与without_touching的具体checker；primitive步数不能当低级控制步数。

版本与身份

train与L1 YAML整档相同（SHA256 bf577e269939b6b9850f1d4fe1deb4e532b1badae6711cb4c74b9f438c611322）；泛化须靠不同初始化，不能把相同YAML当已固定test cases。VIMA example.py一直重设seed42，reset失败才加seed；显示范例设hide_arm_rgb=False，README benchmark预设True。其TimeLimit是oracle_max_steps+2，并非完成全级评测的统计脚本。

对应arXiv:2210.03094v2（2023-05-28／ICML 2023），收录年份2022是首版年。两个官方仓库都连同一arXiv；VIMABench固定97e0af11e126fd477c9d81eeabfb6c739021c680，VIMA固定8449837aa453f8ec9ba229cb956e3bbef5c796ea。

领域
居家整理与清洁、通用对象与机动作业
环境
PyBullet／UR5桌面，前方与俯视RGB＋segmentation；基础physics为240 Hz。位置bounds为x=[0.25,0.75]、y=[−0.5,0.5]公尺。吸盘pick-place或spatula push是完整primitive，一次env.step内含多个移动、接触与settle步。
任务
全库17个模板；train/L1/L2各13、L3为12、L4为4个模板，不能直接算17×4套独立任务。L4是sweep_without_touching、novel_adj_and_noun、follow_motion、same_texture。visual_manipulation的goal含objects/matches/target poses/metric/params/max_progress；图像placeholder与语言由generate_prompt共同生成，不能把prompt_assets丢掉后称为同一任务。
题数与数据
发布说明为650K成功训练轨迹，非测试case总量且本轮未重新清点资产。每trajectory含rgb_front/<t>.jpg、rgb_top/<t>.jpg、obs.pkl（segm/ee）、action.pkl、trajectory.pkl（prompt/prompt_assets/steps/success/failure及seed、对象映射、action_bounds等meta）。writer明确保存T个actions与T+1个observations；loader将JPEG HWC转CHW。action为pose0/pose1各2D位置＋xyzw四元数，模型范例另运行位置反范式与quaternion范围转换。
评估方式
env.step→task.update_goals→具体check_success→info.success/failure；reward固定0，done也可能来自失败或primitive timeout。visual_manipulation设置pos_eps=0.1公尺，is_match只比xy距离，忽略z与旋转；完成的goal逐一移除，误把distractor当目标／对象亦失败。without_touching每50个physics steps检查对象点集与禁止区域重叠，一次违规即锁定failure，最后还需完成精确目标数；不是逐接触事件的检查。

怎么接入我们的benchmark

可重用

模板class、版本化partition/YAML参照、prompt_assets、obs/action时序、seed与具体几何／过程checker。

需要转换

case ID需含template、partition、seed、对象/材质及prompt媒体；保留T+1/T对齐、2D双pose primitive、oracle-only goals、违规记忆与50-frame检查频率。任务模板、轨迹量及rollout数分栏。

仍需补齐

正式eval seed/case manifest及跨task聚合设置、其余checker逐一覆核、全部示范／prompt媒体闭合，以及policy checkpoint与视觉信息条件验证。
