P043 · Embodied VideoAgent

Embodied VideoAgent: Persistent Memory from Egocentric Videos and Embodied Sensors Enables Dynamic Scene Understanding

返回逐篇总表内核内容已核读 方法／综述参考原作 ↗

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

Embodied VideoAgent 是可调用导航／操作工具的持续记忆agent，保留related_reference角色。本次确认程序实际用Habitat/HSSD场景与两agent流程，不能推定为ALFRED或TEACh移植。

版本与身份

此repo明确标ICCV2025 Embodied VideoAgent；README中VideoAgent为2024前作，不能将两者数据/评测混计。生成10 layouts不等于10种新任务，更不代表全套测例已创建。

领域
方法／综述参考，未另作来源用途归纳。
环境
Habitat-sim0.3.0 withbullet，generate_episodes 指向home-robot-remake/HSSD场景；scene_config与layout_i、agent_position、island_index分层。预设for循环生成同场景10个layout只是范例设置，不是已发布benchmark规模。
任务
另一LLM生成用户要求，agent用CHAT/GOTO/OPEN/CLOSE/PICK/PLACE/SEARCH及appearance/environment检索处理。object memory接受timestamp/RGB/depth/depth_mask/camera pose/FOV，对象记忆与工具技能不是固定题库。
题数与数据
episode JSON含scene、agent_position、island_index、objects；需另有pickable/unpickable/receptacle资产档。记忆相机座标定义为右x、下y、入画面z。生成器用对象／容器box提议位置与contact_test后稳定step；重新随机layout必须保存具体初态。
评估方式
two_agent_pipeline 限max_iterations=100，输出tool_cnt与action_cnt，核读入口未提供独立goal-success evaluator。PICK检查距离<=2及可见性后将对象移到y-10000并设STATIC；PLACE直接设translation/DYNAMIC后step，OPEN/CLOSE直接改joint velocities。这是抽象工具运行条件，不是末端效应器接触摸制benchmark。

怎么接入我们的benchmark

可重用

RGB-D/pose记忆界面、工具回馈、scene/layout初态与部分物理状态处理。

需要转换

method连父Habitat/HSSD/资产版本；environment分scene与layout，case需先固定user task生成结果、初始episode及合法sensor/tool约定。工具调用、sim actions、dialogue与终态证据分别记录，另加独立goal判定后才可列可评测。

仍需补齐

未下载场景／模型、运行agent或对外服务。尚缺固定任务清单、task生成seed、独立success checker与完整初态重播验证；executor回复success字符串不能单独当benchmark通过。真实机器人动作转移需新的控制与验证。
