核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

EgoT2 将七个 Ego4D 任务互相迁移，属方法参考；已核读数据源与 OSCC/PNR 的实际输入和评分，并辨识 eval_lta.py 的名字与当前输出不同。

版本与身份

论文表的 ED@20、repo 某个 eval_lta.py 及 challenge submission 属不同路径，须固定可重现入口后比较。父数据版本仍依 Ego4D 原来源，related_reference 不加到183份 benchmark/data 来源量。

领域
方法／综述参考，未另作来源用途归纳。
环境
共用 Ego4D 视频，分人与人交互 HHI、人与物 HOI。任务融合不等于跨数据集添加七套环境。
任务
LAM、TTM、ASD、PNR、OSCC、AR、LTA；各有原生条件。faces localized/tracked 是 HHI 的前置输入，PNR/OSCC 用状态变化片段，LTA 与 AR 共用 verb/noun vocabulary。
题数与数据
docs 分别连官方 social-interactions 的 lam/ttm 分支、ASD、hands-and-objects、forecasting。HOI batch 含 orig 的 frames/labels/state_change/fps/info，另有 recognition 或 pnr 辅助视觉输入。提交以 unique_id+state_change bool 或 clip-relative pnr_frame 识别。
评估方式
OSCC 逐例 argmax 后全样本正确率；PNR 仅 GT 有变化时计16-bin到frame的距离，再除各自fps成秒。eval_pnr.py 平均 batch 平均，无正例预设0需保留。通用输出 metric 在合法 token 子集再取 argmax，另列 out-of-task token 比率。当前 eval_lta.py 只评 forecast_labels 第一动作的 verb/noun accuracy，不是 README 的 ED@20。

怎么接入我们的benchmark

可重用

七项父任务关系、auxiliary inputs、输出 token 子集与 OSCC/PNR adapters。

需要转换

保持 source=P013 的 benchmark/case 身份，另记 translation method、可用辅助模型与输入。evaluator 对 PNR 秒误差、OSCC accuracy、LTA ED 各自留协定，不能依文件名将第一动作 accuracy 改叫长期 ED。

仍需补齐

未运行训练／推论。完整 HHI mAP 和 LTA ED 提交流程仍需追核；PNR/OSCC 通用 metric 的重复 unique_id 只打印、continue 被注解，需全量去重与分母检查。不得由融合模型结果估算新的任务数。
