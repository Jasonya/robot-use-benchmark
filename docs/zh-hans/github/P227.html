P227 · EggHand

EggHand: A Multimodal Foundation Model for Egocentric Hand Pose Forecasting

返回逐篇总表内核内容已核读 方法／综述参考原作 ↗

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

EggHand 是在 EgoH4／EgoExo4D 手部轨迹上评测的预测方法；「action」在这里是未来 42 个人体关节座标，不能直接当成机器人控制命令。已逐段核对采样、相机对齐与六项误差的有效样本口径。

版本与身份

已读 revision 的 implementation note 明载 warmup 为 1% 而非论文 5%；推论 BF16／四步 denoising 与训练精度分开。阅读范围是列出的来源段落，未声称重现论文分数。

领域
方法／综述参考，未另作来源用途归纳。
环境
EgoExo4D 衍生的 EgoH4 人体视频／手部轨迹，非新建模拟场景。相机外参为 world→camera 3×4；以最早可见帧（offset −19，含边界补帧）的相机位置与前向创建座标系。
任务
一个 3D 双手预测设置：42 关节 × xyz。state offsets −19…0，4 个图像 offsets −18／−12／−6／0，target offsets 0…9；target 包含当前 timestep，不能称为 10 个纯未来帧。
题数与数据
README 列 train 555 episodes／41,314 samples、val 109 episodes／8,830 samples，10 Hz，LeRobot v2.1。episode、重叠时间窗和关节数分开记；与 EgoH4／EgoExo4D 保留父数据关系。原始 126D 关节与 12D 外参经模型投影，32D latent action 不是原生 actuator 维度。
评估方式
以公尺计算 wrist ADE／FDE、绝对 MPJPE／MPJPE-F、wrist-relative R-MPJPE／R-MPJPE-F。论文的 MPJPE 栏对应后两项相对误差。GT 三轴全零才排除关节；relative 额外要求 wrist 有效，包含对齐后零误差的 wrist。ADE 先手腕→帧→sample 平均，MPJPE 池化有效 joint×time；不共用分母。全无效 sample 不计，异常直接停止并报 sample index。

怎么接入我们的benchmark

可重用

重用原生 joint keys、episode／frame 对照、相机对齐与原生 evaluator。；保留同一评测的 absolute／relative 六栏，不把不同 alignment 的 MPJPE 合成一栏。

需要转换

case 固定 source episode、base timestep、完整 observation／target offsets、padding mask、m 单位与 camera reference。；训练 per-coordinate 非零 mask 和评测 per-joint mask 各自保存；添加缺失值策略必须另立协定。；数据 split 沿用父 take／episode，防止重叠窗口跨 train／test。

仍需补齐

本次未下载视频／模型、未运行基线；数据与 checkpoint revision 仍需固定。；目前原生对齐会把全零缺失关节当点平移；不能事后把它误认为观测到的手。
