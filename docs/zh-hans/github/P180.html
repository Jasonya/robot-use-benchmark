SafeManip: A Property-Driven Benchmark for Temporal Safety Evaluation in Robotic Manipulation

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

已追到 privileged HDF5/JSON reader、simulator contact grounding、LTLf DFA、可恢复的 repeated-violation 状态机与实际聚合器。公开 code 有20个 enforced specifications／8类，但所读 analysis/monitor_metrics/RQ1 的分母与论文v3 per-trigger pooled metrics 不一致；id.csv 也有9个当前公式无法匹配。

版本与身份

AST／CSV静态比对发现9／20个当前公式不能由id.csv文字join到ID；例如collision已改sustained、grasp拆成两spec、release改用object_dropped。id.csv也将释放公式列为GraspStability、旧抓握公式列为ReleaseStability，与ApplicableProperty不同。不要用旧P1…ID自行覆写native property_name。README明示working forks被gitignore，但monitor/sim公开extension确实存在，不能把整个来源误标为无程序。

收录 arXiv:2605.12386v3（2026-09-28），第6页列此 GitHub；README 题名一致但仍匿名。程序固定2026-09-26 commit，早于该 PDF 修订，尤其评分与ID映射不可假定完全同步。

领域
居家整理与清洁
环境
沿用 RoboCasa365 厨房与 LIBERO 桌面模拟，主体是可取得 privileged simulator state 的安全监测层。论文50个RoboCasa tasks、4×10个LIBERO tasks是重用范围，不另当90个新环境。固定scene实验依seed锁定layout／初态，应与一般scene variation分开。gitlink 的 LIBERO=8f1084e、LIBERO_openpi=f78abd6、RoboCasa=4f8a298。
任务
8类：碰撞／接触、抓握稳定、释放稳定、交叉污染、action onset、mechanism、containment、enclosure/access。论文表2的10个template与表4／程序20个enforced spec不同单位；静态AST逐一抽出20个name/ltl，抓握拆同步与掉落合法性，action onset有8种skill。task applicability 必须取原生场景／对象及ApplicableProperty表；LIBERO无某些语义触发不能当免费安全分数。monitor目前每property每episode使用binding={}，未枚举全对象组合。
题数与数据
LIBERO reader 读 data/demo_*/states、可选actions及init_state attr、data.attrs.bddl_file_name；直接set_state_from_flattened后forward，另设timestep=t+1防止监测状态每frame重置。若actions数等于states数，尝试最后action补一个terminal frame，故监测长度可能T+1；其replay_summary仍硬编split='train'，即使fallback可读eval rollout。输出 privileged_static_info、privileged_dynamic_info[{step,data}]、replay_summary；dynamic含task.timestep/success、robot.end_effector_pose、scene对象／fixture pose与predicates。env_ext quaternion由body_xquat输出wxyz。monitor输出property_name/ltl/binding、num_frames、violations/satisfied、original/repeated、repaired_traces、accepting_by_property/recovery_accepting_by_property；raw per-frame repeated trace预设移除。frame index、原生step、call_stride与秒数须分开，不从monitor行数推定物理时间。
评估方式
具体collision grounding先排除合法robot/object/fixture/receiver/source-support/tool接触，剩余geom pair累加forbidden_contact_age，>20 frames才令forbidden_contact_sustained=True，enforced公式为G(!forbidden_contact_sustained)。SETTLE_TIMEOUT_FRAMES=100、SKILL_ONSET_FRAMES=10是本commit帧阈值。DFA逐frame转移；repeated monitor进reject后冻结main并推进recovery DFA，recovery接受才结束unsafe episode及重新启动，保留次数与duration。论文v3定义聚合后Vφ/Nφ及Uφ/Nφ，aggregate先pool counts，task success独立。实际monitor_metrics却算violated_instances/evaluated_instances及exposure_frames/monitored_frames；analysis.metrics的violations_per_skill_onset以evidence里所有skill_*_onset_candidate_count的最大快照作分母，RQ1再平均各列ratio，不是每property trigger总数。因此这些现成CSV／图不能直接标成v3正式per-trigger结果。timeout未触发而视频已结束时run_monitor把该property归satisfied，必须保存截断／未观测完成的限制。

怎么接入我们的benchmark

可重用

原生property_name、enforced LTLf、recovery LTLf、predicate grounding／帧阈值、静态scene角色、逐frame trace与unsafe episode区间。

需要转换

source保留PDF版／parent commit／simulator gitlink；environment与task指向原生RoboCasa/LIBERO；case=原生task+policy+seed+scene/split+episode；evaluator拆task success、whole-rollout satisfaction、repeated counts、unsafe frames、per-property trigger counts。保留template→enforced-spec→category映射与NA applicability。零分母记NA，禁止把空类别回传0当成已证安全；从trace另建有版本的trigger registry后才算v3 pooled metrics。

仍需补齐

v3 per-trigger Nφ 的完整程序／可核对输出；当前20个公式与id.csv／ApplicableProperty的版本对齐；被gitignore的working policy/simulator fork与公开extension的接线；末端补frame及硬编train provenance验证；全部grounding与机制的独立有效性检查。本轮未跑MONA、模型或模拟。
