BiFold: Bimanual Cloth Folding with Language Guidance

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

BiFold同库含ICRA原作和加入时间上下文的workshop版本；可复用语言/双手pick-place标注与SoftGym评估，但像素预测分数和物理折叠结果要分开。

版本与身份

固定0b763d1，README同时连2501.16458和2505.07600；只有列出片段经核读，未把workshop额外设置并为原作新task。

领域
衣物与洗护
环境
客制SoftGym/PyFlex，加载CLOTH3D衣物；VR folding为父双手数据，真实图像另一路径。重贴texture/render与顺序版衍生数据不当成独立物理场景。
任务
单手/双手语言折叠，包含逐步与rollout评测；左右pick/place是动作字段，不是4种独立任务。原作与temporal extension各自保留合法history设置。
题数与数据
vr_folding_dataset.zarr配actions/<partition>.csv，含left/right_grip_from/to、end_idx与text；3D vertex经相机矩阵投到pixel、depth依depth_scale还原。frame_start/frame_end是case对齐基础，未来end位置只作GT label，不能自动暴露给policy。
评估方式
同初态先跑oracle、再跑model；成功为平均对应particle距离<2×particle_radius，另报mask IoU及50/80/90门槛，task分组后macro平均。KeypointMSE实作是最近点L2距离且另除valid数量，不能直接当一般MSE；真实图像预测分数亦不是实体折叠成功。

怎么接入我们的benchmark

可重用

需要转换

case固定cloth asset/config/state、文字、history与相机；分开标注预测/物理粒子误差/视觉IoU；VR与CLOTH3D lineage保留，衍生render与顺序数据去重。

仍需补齐
