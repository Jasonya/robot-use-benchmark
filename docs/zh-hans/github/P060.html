P060 · Continuous 4D interaction forecasting

From Where to How: Continuous 4D Interaction Forecasting from Egocentric Video

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

此来源不只是项目页：有 Coherent4D 的事件分段、共同座标及 SMPL 附加程序。正式预测指针只能读到论文定义，尚无公开评分器可直接沿用。

版本与身份

固定67386704bf335af977232594d0f86428d0623c8e（2026-09-14）。非截断tree有网站、统计与process程序，没有发布完整训练／评分实作。SMPL指南指定外部 FIction-WHAM b520bc8f1d755be658c4d2bafdffe5081d09cfe2；本轮只读该依赖声明，未读取／运行外部模型。chunk脚本不创建split，须承接来源take分割，不能把每个chunk随机切分。

README 的完整标题、六位作者及 arXiv:2609.08636 与本地 v1 论文一致，论文作者页直接连 CorrineQiu/from-where-to-how。Coherent4D 是在 Ego-Exo4D 上建置的配对位置／姿态数据；HIGFlow 是方法名称。FIction、Detic、Llama 与 WHAM 是来源／依赖，不能替代本论文版本。

分类覆核：既有Coverage已将本作纳入数据／评测主来源；本次维持此判定。原文定义Coherent4D数据、固定split、联合预测目标和具体指针，应同时承认数据、评测与方法贡献。早期书目M／no标记属初筛快照，不能用来否定此后原文审阅结果。公开仓库未发布预测scorer是另一项可得性缺口。

领域
餐饮与烹饪、医疗与手术支持、交通移动与车辆维修、穿戴交互与动作界面
环境
Ego-Exo4D 的 Aria 第一视角程序视频；Cooking、Health、Bike Repair 三个 domain。第三视角用于脱机标注／SMPL 重建，不是预测输入。787 unique takes 是来源录制单位，不能当成787个独立机器人环境。
任务
共同预测有序3D交互位置与同时间的全身 SMPL 状态。原生21个程序任务由 CSV 按 domain 指定；Cooking/Health/Bike Repair 分别预测10/5/4个事件，并非秒数。公开统计为233828 samples（train193598、val20484、test19746）、1594186个非padding未来 targets、跨domain去重535个对象标签；这些均为来源统计，未以完整资产重算。
题数与数据
build_chunks 读 pickle 根层 dataset，按 interactions.time 排序并以 chunk_size 不重叠切分，产生 id={take_name}_{datum_idx}_{chunk_idx}。每笔含 observation_start/end_time_s、history_interactions、target_interactions、target_mask、source_meta 及可选 env_objects；事件有 time_s、time_rel_s、location_norm、object。首个未来事件是时间零，history 严格在前30秒（起点截于0）；尾段以 None 加 mask=0。F0 取自 source_meta.source_observation_end_time_s，不随 chunk 时间原点重新设置；位置用 clip(R0.T@(p-t0)/5,-1,1)。SMPL 附加 history/target_pose_mask、*_pose_frame、*_pose_time_delta_s、*_root_orient6d_f0、*_root_trans_f0_m、*_body_pose_local6d（23×6）、*_joints_f0_m（19×3）。pose位置保留公尺，6D旋转为3×3矩阵前两栏按列展平；不能套用不同6D排列。
评估方式
固定 tree 没有 HIGFlow 预测／benchmark 评分器。已读论文 §III-C：位置先反缩放至度量空间，ADE 先平均每样本有效事件再跨样本平均，ADE90 是每样本 ADE 的90百分位，FDE 取最后有效事件；姿态用19关节 MPJPE、每姿态相似变换对齐的 PA-MPJPE、Root Trans. 及23个非root关节 Body Geo.，位置报mm、旋转报度。Single 用第一候选；Best-5 以各样本有效步的关节误差选一条候选，再用同一候选算所有pose指针。数据建置的最近影格检查采 floor(time_s×fps)，预设fps30、误差上限0.49秒；它只是标注有效性检查，不能充作预测评分。配对有效性须用 target_mask & target_pose_mask。

怎么接入我们的benchmark

可重用

原生 domain/task_name 统计、take/datum/chunk 身分、事件时间、F0 metadata、位置／pose 分离遮罩与实际建置函数。

需要转换

source 记 Ego-Exo4D 派生与外部重建版本；task 保留 CSV domain/task_name，case 用 take+datum+chunk，保存30秒观测引用、事件horizon、绝对／相对秒与空间参照。位置范式／裁切、公尺pose及毫米／角度评分分开记；不可由裁切座标还原超界真值。

仍需补齐

需取得原始takes、确定的take-level split清单、建置后位置／pose caches、SMPL/19关节regressor与模型依赖；补公开预测/evaluator及30张观测影格抽取对照。再验证mask、数据规模、共同座标与论文报表一致性。
