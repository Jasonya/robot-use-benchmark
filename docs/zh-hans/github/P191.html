P191 · ClothesNet

ClothesNet: An Information-Rich 3D Garment Model Repository with Simulated Clothes Environment

返回逐篇总表实作尚未确认 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

ClothesNet官方页面可核对3D衣物及标注格式，下载须走作者表单；目前没有确认其官方GitHub，Google Sites依赖和同名旧研究已排除。

版本与身份

官方Google Sites页与2023原作题名/作者相符；google/safevalues是网站依赖，lixiangbao/ClothesNet_PyTorch自述为另一篇2018人体衣着生成实作，皆未当作本篇code。

领域
衣物与洗护
环境
约4400个3D garment models、11衣物类别，作模拟场景的资产来源；garment model不是robot环境或完整评测episode。
任务
衣物感知：分类、boundary segmentation、keypoint detection；robot交互方向：rearranging/folding/hanging/dressing。用途方向与11衣物类别不相乘当已定义task数。
题数与数据
每衣物folder含mesh OBJ/MTL/texture、边界OBJ/MTL、10个keypoint的PCD与2048个sampled mesh points。官网约4400是原作量，未下载资产，没有据此生成4400case。官方数据条款限非商业科学研究且禁止转发/分发。
评估方式
官网说明感知及robot交互基准，但未确认可取的完整evaluator/code；需原作split、keypoint语义对应、成功predicate及物理参数才可接入完整robot评测。
原作数字：保留论文的单位与页码

怎么接入我们的benchmark

可重用

需要转换

以source+garment ID登录asset并关联environment/task；metadata与我们的规格独立发布，原始衣物数据报保留官方下载方式与条款，未获允许前不纳入再分发包。

仍需补齐
