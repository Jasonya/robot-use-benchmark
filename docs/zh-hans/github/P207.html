P207 · EgoCoT-Bench

EgoCoT-Bench: Benchmarking Grounded and Verifiable Operation-Centric Chain of Thought Reasoning for MLLMs

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

GitHub DStardust/EgoCoT 是本篇官方补充网站，HF 另有公开 dev／test 标注、媒体重建 manifest 与实际 reconstruction reader。已核程序只有媒体处理与网站示例，未找到正式 Acc／R／SCR scorer 或 test 正解；不能把网站题目点击函数当成 benchmark evaluator。

版本与身份

GitHub 71e6114c155c7a593fa39e2af801b51e836b53ca 是网站；HF 31c4aa4adc88632c6efe984cf8c5399cc75f6fc3 是 clean public release，只重发自录媒体，不能将其与较早含第三方处理片的版本混用。raw README／CSV／reconstruction script 均固定 HF revision。viewer/rows endpoint 未回传 dataset revision，本轮只保存带时间与 SHA256 的一列 dev／test 与 features 作辅助字段核对，不声称已核 pinned Parquet 全体内容；未下载视频或运行 reconstruction。

pinned arXiv:2605.19559v1 连到 dstardust.github.io/EgoCoT，固定 repo index.html 与既有 website cache 的 SHA256 相同；其 Dataset 按钮连 DStardust/EgoCoT-Bench，dataset card 反连同一 paper／project。PDF 作者有 Yang Dai、Dian Jiao、Tianwei Lin、Wenqiao Zhang；网站页眉只列前三人，文献作者以 PDF 为准。搜索的 EmbodiedGPT/EgoCOT_Dataset 是 2023 年另一候选，未将同名视为本篇；页脚 Academic Project Page Template 亦非 benchmark。

领域
居家整理与清洁、餐饮与烹饪、装配与生产作业
环境
五个公共人类第一人称父来源 Ego4D、EPIC-KITCHENS、Charades-Ego、MECCANO、HD-EPIC 加自录像片，涵盖生活、厨房及组装操作；没有可交互的机器人环境。pinned reconstruction CSV 清点为 351 个 (source_dataset,source_video_id)，但有 352 个 processed_clip_id／output paths；MECCANO 0001_part1 有 416×234 与 588×331 两版，必须保留版本关系。
任务
4 groups／12 subtasks：Egocentric Grounding & Perception＝Active Object Grounding、Hand-Object Association、Manipulation State Perception；Spatio-Temporal Retrospection＝State Retrospection、Location/Visibility Retrospection、Hand-Object Temporal Retrospection；Predictive & Causal Inference＝Next State Anticipation、Next Action Anticipation、Local Cause-Outcome Inference；High-level Grounded Reasoning＝Progress Reasoning、Hand-Object Grounded CoT、Goal-Oriented Object Tracking。均是四选一视频理解及公开解释／证据品质，不是可运行操作技能。
题数与数据
HF pinned tree 的实际数据档为 data/dev-00000-of-00001.parquet 与 data/test-00000-of-00001.parquet；card 指定 load_dataset 后取 dev／test，300／2,872 题。小型官方 viewer 回应各抽一列：qid、question、choices[{label,text}]、answer、cot[{step,text}]、media_id、source、big_category_en、sub_category_en、type；dev 有答案与解释，test 范例 answer=""、cot=[]。两份 viewer 的 features 没有独立 evidence／bbox 栏，不能依 card 的 may include 自造结构化证据。pinned CSV 实际 3,172 个唯一 qid；columns 含 processed_clip_id、source_dataset/video_id、source_start_sec/end_sec、target_width/height、resize_mode、fps、preprocess_version、expected_local_output_path、coordinate_system。所有 start/end 为空、resize_mode=stretch、座标系 processed_clip；2,859 QA 引用 4 fps、313 QA 引用 8 fps，这是题目列数而非影格数。63 个自录输出与第三方待重建媒体分开。
评估方式
paper §3.2.4 的 Acc 为四选一 exact match／全部评测题；R 是 Qwen-Max 对公开生成解释与参考解释的 0–5 分；SCR = 答对且 R≤2 的题数／所有答对题数×100，分母不是全题数，零答对的处置未由公开程序核实。paper 的 3,172 题结果不可当作 public hidden-test 2,872 题分数；card 的 dev 193 个 video、test 351 个 video 与总 351 个来源显示不能假定 video-disjoint。paper 另以 2,800 responses 核对 judge，人类一致性样本不是额外 benchmark cases。GitHub handleAnswer 只对四个写死示例比字母，leaderboard 只排序 HTML；HF scripts tree 唯一程序 reconstruct_media.py 没有模型推论、judge、R／SCR 聚合或提交验证。正式 test scorer／labels 在本轮已核来源中未公开。

怎么接入我们的benchmark

可重用

可重用 qid、group／subtask／type、选项及 public dev 解释、来源／processed clip 映射、重建 CSV 与实际 reader；paper 的 Acc／R／SCR 保留各自定义。

需要转换

source 同时记 paper v1、website commit、HF revision 与五父数据源；task 按四群十二类，case 按 qid 保留 dev/test、media_id、options，将 cot 记公开参考解释而非模型私有思考。environment 记 human-egocentric context；媒体引用需带来源 ID、processed resolution／fps／coordinate_system，351 sources 与 352 processed variants 分开。evaluator 分别记 Acc 的 N、R 的判读数及 SCR 的答对分母；test 空正解标为 withheld，不能转成错误标签或零分。

仍需补齐

正式 evaluator／submission runner、hidden test labels、judge prompt与精确版本／解析／失败处置、完整结构化时空 evidence、父素材取得与重建验证。reconstruction script 用整段 source_video_id 视频，未使用 start/end／resize_mode 栏；CSV 的 start/end 全空，对含切段后缀的 source_video_id 仍须外部定位到正确已裁素材。读影格失败时 continue 而不补位，可能改变输出时间轴；需校核处理后 timestamps／bbox。
