原作仓库已转到Farama的现行Meta-World。当前代码可以核读任务、动作和评测界面，但README已引用MetaWorld+，必须保留与2019原作协议的版本差异。

版本与身份

发现现行state_space.md仍写9D且表格列18维，但程序_get_obs明确组成39维；字段标准化以固定程序与测试查核，不能只抄说明页。

旧入口rlworkgroup/metaworld的已保存GitHub metadata回应指向Farama-Foundation/Metaworld，按仓库别名保留，不另外算成未读的第二个仓库。

领域
居家整理与清洁、餐饮与烹饪、工艺与修缮、装配与生产作业、休闲与运动、通用对象与机动作业
环境
Sawyer/MuJoCo任务环境；source task/env ID不等于独立家居场景。
任务
MT与ML清单保留原生任务和train/test成员；现行v3任务与2019版不可仅删掉版本后缀就宣称等价。
题数与数据
四维动作是xyz增量控制加gripper；set_xyz_action另乘action_scale。基础观测为当前18维、前一观测18维与目标3维，goal可被屏蔽；benchmark还可加task ID。
评估方式
evaluation.py在成功时终止episode，用info.success按任务计成功率，再对任务平均。meta评测另外包含适应步数、适应episode和evaluation episode预算。
