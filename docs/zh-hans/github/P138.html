Diffusion Policy: Visuomotor Policy Learning via Action Diffusion

返回逐篇总表内核内容已核读 方法／综述参考原作 ↗

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

Diffusion Policy跨既有benchmark比较；Push-T的mean_score是每次rollout最高部分reward的平均，且checkpoint聚合有max与低loss选样两种口径。

版本与身份

固定5ba07ac；README/runner已公开说明原作与修正聚合范围。未运行原模型，未假定目前main可逐数字重现原paper。

领域
方法／综述参考，未另作来源用途归纳。
环境
Push-T、robomimic、Kitchen等父环境以及实机评测分开；方法repo包含多套实验，不代表这些全是新的独立环境数据。
任务
Diffusion Policy学习动作串行；每个task仍追到父benchmark。Push-T是将T形物推到目标pose，图像/lowdim两种观测不增语义任务。
题数与数据
Push-T Zarr含img/state/action，SequenceSampler按episode mask、horizon与padding出样本。模型观测image与agent_pos，action是2D推动控制目标；训练state还含物体pose但不是全数模型可见。
评估方式
coverage=物体与目标交集/目标面积；reward=clip(coverage/.95,0,1)，done在coverage>.95。runner取每episode最高reward平均为mean_score，仍可有部分分数。multirun的max与k_min_train_loss依不同epoch选样，需分开报；runner注记原作只聚合前n_envs的历史差异。

怎么接入我们的benchmark

可重用

父task/数据source、Zarr/串行窗口、具体Push-T grader与experiment config/log。

需要转换

case保留观测可见性、episode/seed、horizon/控制与图像前处理；metric保存coverage、scaled reward、binary done和checkpoint选择规则，不把mean_score全称成功率。

仍需补齐

各其他父benchmark版本/资产与checker接线、原作vs修正seed集合、固定checkpoint/held-out再现和全套baseline。
