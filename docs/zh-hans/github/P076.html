P076 · Ravens / Transporter Networks

Transporter Networks: Rearranging the Visual World for Robotic Manipulation

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

Ravens的具体评测链是task goal→delta reward→test累积return→plot平均，包含部分分数。已核读插入、清扫及数据writer/reader；done不是统一成功旗标，图表的百分比标签也不能直接当原生分数单位。

版本与身份

固定manifest显示仓库已封存。具体问题：plot.py把0–1 mean/std直接印成%且ylabel写Task Success，没有×100，也掩盖partial credit；6DOF插入子类设sixdof与pos_eps=0.02，仍继承只看xy/yaw的is_match，未增加z/roll/pitch判定。test预设task=hanoi但registry为towers-of-hanoi，应明设task。Dataset.sample是先等概率选episode再选非末步，不是全库frame均匀抽样。

对应Transporter Networks: Rearranging the Visual World for Robotic Manipulation，arXiv:2010.14406v3（2022-01-05；CoRL 2020作品）。README明称此论文的reference repository；正式作者清单以固定PDF为准。固定程序4752ffab487ebd387781ad7890aa540ae2780970为2024-03-14快照，非2020原始版本。

领域
居家整理与清洁、装配与生产作业、包装、仓储与物流、通用对象与机动作业
环境
PyBullet／UR5桌面，工作区0.5×1公尺；三个RealSenseD415模拟视角、640×480 RGB-D。环境预设240 Hz，demos/test脚本明设480 Hz；这是physics频率，不是示范frame或policy primitive频率。相机参数在固定cameras.py，没有逐episode嵌入color/depth档。
任务
论文十项桌面任务；当前registry有15个ID，包含五个额外子型，不能回填成15项原始benchmark。BlockInsertion的goal是object/match-matrix/target-pose与pose metric，最多3次动作；SweepingPiles配置50个小方块，最多20次push，以zone内对象采样点比例给部分分数。
题数与数据
Dataset分color/depth/action/reward/info五个文件夹，用相同NNNNNN-seed.pkl连接；color uint8、depth float32公尺。每个episode是(obs,act,reward,info)串行，最后一笔act=None。demos先保存当前obs/action与既有reward，才env.step，因此第t笔reward对应前一动作；导出transition时应将action[t]对上reward[t+1]。info保存GT对象position/quaternion/dimensions；test还会将末笔goal传给agent，信息可见性须按policy另记。action含pose0/pose1，各为xyz公尺＋xyzw四元数，并非VIMA的2D位置界面。
评估方式
Environment.step→task.primitive→Task.reward/done；pose metric用xy距离<0.01公尺及对称修正后yaw差<15°。zone metric将每对象局部采样点转入zone，算合法点比例；点集由visual-shape尺寸以0.02公尺网格创建，并非精确mesh体积。reward是累积进度差值；test加总成completion return，goal完结或_rewards>0.99才由Task.done回True，primitive timeout也可使env.done=True。论文每task100 unseen runs；程序实际遍历test Dataset.n_episodes。test数据只收oracle return>0.99的奇数seed，训练为偶数seed。

怎么接入我们的benchmark

可重用

十项原始task与变体映射、goal tuple、pose/zone evaluator、seed编码、RGB-D与原生pick-place/push。

需要转换

source分论文v3与2024commit；case记task变体、seed、goal、primitive步数与physics频率。保留terminal None action及reward后移配对；evaluator分开二元goal完成、delta reward、0–1累积完成度和展示用×100比例，不能全叫success rate。

仍需补齐

原论文checkpoint选择及完整100-case数据manifest、其余任务checker逐一覆核、相机／资产／seed闭合；6DOF及continuous变体需独立评测协定。
