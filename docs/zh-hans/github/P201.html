EgoSAT: A Comprehensive Benchmark of Egocentric Streaming Interaction Understanding

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

EgoSAT已有streaming runner、query helper与正式main-table scorer；标准化时必须保留完整native JSON和effective queryset，单纯压成答案JSONL会丢掉判分信息。

版本与身份

固定7f65bbb；原作2606.24422。examples/evaluation_fixtures是合成格式例，不记为本库添加真实评测题或原作模型跑分。本轮未运行模型/API/scorer。

领域
居家整理与清洁
环境
Ego4D的1997段第一人称视频、约165h/56场景类型；场景类型不是已取得的56个simulator环境。原始Ego4D视频不在此repo重新分发。
任务
回顾、当下、预测三模式，约4800QA；另有answerability/branchiness/surprise与state-switch probes。group、step、两probe配对及QA数分开，不从56×3推算task/case量。
题数与数据
原生GT含video_uid、video_metadata.interval_start/end、samples；helper产effective queryset保留idx/t_eval/t_eval_rel/window/horizon/options/memory。runner只裁整个interval，真正每query可见prefix需由adapter依window运行；共通格式须保存原JSON、token probabilities、queryset references与model flavor。
评估方式
MCQ对有效queryset中有GT的题计full denominator，缺/无效回答为错；缺GT略过。scorer先扫现有prediction文件，所以整份缺失的GT仍需外部expected-case manifest检查。confidence是有效cand_conf值均值，不能当accuracy或完整校准分数。state-switch需前后两probe均对，主值用valid pairs，另有total/missing/invalid计数及仅成功pair的after-confidence。

怎么接入我们的benchmark

可重用

真正runner/helper/scorer、合法时间窗口、prediction flavor与透明分子/分母。

需要转换

case保存source/video/interval/query idx与精确clock、options顺序和pair ID；central input loader限定可见frame，GT独立；score保留total/valid/missing和conditional confidence，不丢native payload。

仍需补齐

完整Ego4D/QA资产与release split、每model相同expected queryset、adapter实际prefix审核、全文件缺失计分及confidence字段可用性验证。
