CapMem: A Benchmark for Caption-Based Episodic Memory in Egocentric Video

领域
居家整理与清洁、宠物照护与动物活动
环境
75 段既有公共人类第一人称视频，共 33.7 小时，来源为 Ego4D、EgoLife、EgoPet、EPIC-KITCHENS、HoloAssist、ENIGMA-51、CASTLE2024。四用途是 Daily Life & Domestic、Outdoor & Mobility、Work & Procedural、Pet Related；16 scenario labels 不等于 16 个已去重可运行世界。
任务
主题是 Episodic Memory Video Caption QA；CleanQA（仅问题／选项）、Direct VideoQA（抽样影格）、CaptionQA（时间化文字记忆）是同题三种信息条件。Ego／Exo × Who／What／Where／When／How 为问题分类，50 templates 是出题样板；Object、Attribute、Spatial、Action 为可重叠标记，不是额外物理任务。
题数与数据
论文 Appendix E 的 2,109 人工 candidates 经双 reviewer 留 1,276，文字捷径 filter 删 352 后剩 924，再复核恢复 76，得到 1,000 题。Appendix G 指定每题包含 question identifier、父数据／视频 ID、四选项与正解、evidence timestamps、domain／scenario、Ego／Exo、4W1H、evidence-location、多视觉 tags；此为论文所述内容，没有实际文件可验证 JSON key 名称或 loader。单一 1,000-question evaluation split，无独立 dev；来源影音／原库标注不重发。影格 cache 是 1 fps，full-coverage caption 用连续 30／60 秒窗；caption 完成后以文字回答同视频各题。
评估方式
论文用四选一 QA accuracy（正确题／实际评测题）及每题 token 成本；主设置 N=1,000，Gemini 3 Flash Direct VideoQA 仅 N=786，相关配对比较须对齐这 786 题。duration 子集 208／792 题，evidence-location 子集 348／507／145 题；multi-label tags 的分母重叠。CleanQA 15%–35% 是 model 进入主评测的 gate，不是 case 成功门槛。Direct 的 InternVL／Qwen frame caps 为 128／768；full-caption 无 video-level cap，六 Qwen 的 frame-aligned control 才用与 direct 相同的 frames。Appendix D 的 retrieve-and-verify 最多三 seed、neighbor=1、NMS 45 秒，最多三段各四个影格验证；仅 strong 视觉支持、合法字母且无 clock-time cue 才覆盖原 CaptionQA。该 override policy 在全 benchmark 错误分析后选定，作者明示属 post-hoc proof of concept。未取得 concrete scorer，答案 parser、无效输出、例外／遗漏题入分母方式及实际 filter 实作均未核实。

怎么接入我们的benchmark

可重用

可重用原生用途／题型／多标签、单一 evaluation split 的论文统计、公开 prompt 文字、input-budget 对照与 post-hoc 限制。

需要转换

source 绑 paper v1 并保留七个父媒体来源；domain／environment 保留四用途与 scenario labels。case 用 CapMem QA ID 关联 parent video／evidence 与选项，三种信息条件及 30／60 秒 caption 版本作同题条件；evaluator 保存 matched question IDs、完整或 786 子集、frame IDs／captioner／QA model、caption 一次性成本与逐题摊提成本。retrieve-and-verify 另记 override／wrong→correct／correct→wrong，不能与无视觉 CaptionQA 混记。

仍需补齐

作者可验证 release URL、官方 annotations／question IDs／split manifest、JSON schema、reader、caption cache 索引、各协定实际 scorer 与可追溯排除清单；还需独立 dev／held-out policy 验证。未取得的 LICENSE-DATA／LICENSE-CODE 仅是论文声明，不列成已读文件。
