SpeedFolding: Learning Efficient Bimanual Folding of Garments

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

已核读 SpeedFolding 的真机流程、SQLite/PNG 格式、BiMaMa 数据 reader、折线指令与具体 coverage reward。evaluation.py 只记录事件／时间，folded 事件也不是独立成功判定；论文折衣成功须保留三位人类评阅者多数决。公开版本另有 reader／writer 界面不一致。

版本与身份

固定2023-12-11 commit，晚于2022论文；README已明示硬件相依参考程序。未连接数据库、相机或YuMi，未下载15.2GB数据集或运行模型。

README直接链接 arXiv:2208.10552 与 pantor 官方项目页，明示 IROS 2022／ABB YuMi＋PhoXi 的硬件相依参考实作。

领域
衣物与洗护
环境
实体ABB YuMi双臂平行夹爪、海绵工作面、PhoXi顶视灰阶／深度，以及额外webcam coverage。软件包含OMPL与PhoXi C++ wrappers，README明示不易直接运行。pixel_to_transform从校正point cloud取xyz、以theta设置gripper姿态；图像位姿不能直接当已校正机器人动作。
任务
流程是先平整衣物，再依用户折线／2-second heuristic／fling-to-fold完成折衣。shirt.json有两种顺序、每种三条折线，属同一目标的候选程序，不是6个任务。loader的fling、fling-to-fold、pick-and-hold、drag、done为训练primitive类别。论文每组实验15 trials，4300训练action records含1500拷贝重标；不能把records、物理操作、完整折衣trial及任务名称混算。
题数与数据
SQLite actions(id,episode_id,action_id,data JSON)与images(episode_id,action_id,scene,camera,hash)；PNG路径为collection/episode_id/{action_id}-{scene}-{camera}.png，scene含before/after，camera可为color/depth/ortho-color/ortho-depth。JSON保存type、poses[{x,y,theta}]、reward、needs_annotation、is_human_annotated、is_self_supervised。Saver把0.85–1.25m深度反向线性映射0–255并裁切，0深度先改1.25m，不能把PNG值当公尺。BiFoldingDataset读灰阶与量化深度两通道，按1032×772来源尺寸crop后resize到256×192、theta为弧度及20个离散方向。预设以episode_id的SHA256低16bit阈值做约80/20 train/test，非衣物对象切分；run.py每个action新建Episode，因此该ID未必代表整个物理trial。
评估方式
reward.segment以灰阶阈值90、形态学与最大轮廓产生mask；calculate_reward为tanh(64×A_before×(A_after−A_before))，A为mask像素占比。另一个coverage＋confidence reward函数存在，但run.py调用前者。Experiment.take_coverage用校正webcam、阈值130并回传轮廓面积/图像面积。done是模型分类的Sufficiently Smoothed停止决策；运行折线后直接记folded事件，不代表成品合格。Evaluation记相对启动秒数及profile duration，未实作三人投票或完整FPH。论文成功要求10动作内且三位评阅者多数通过，排除motion-planning早退；表I duration只平均成功trial，cycle time/FPH包含成功与失败。程序CLI horizon预设3，README实验设10；run.py horizon限制平整循环，后续折线及move另外运行，须明订共同action budget。

怎么接入我们的benchmark

可重用

折线JSON＋template、图像／action DB索引、primitive运行脉络、coverage reward及事件计时。

需要转换

source绑commit；environment绑YuMi工作站与相机校正；task绑衣物与折线程序；case添加完整trial_id、garment_id与初态，连到多个action record；evaluator分smoothing confidence、grasp failure、coverage、成品人评与duration/cycle/FPH，明列排除及分母。重标记录保留来源action关系，量化depth需用尺度／缺测mask解码。

仍需补齐

人评票决与完整trial成品图像／耗时表；去除重标后的数据lineage及物理trial切分；公开reader/writer兼容性修正；硬件／template／weights资产与校正接线。
