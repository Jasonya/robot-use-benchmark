Cloth Funnels: Canonicalized-Alignment for Multi-Purpose Garment Manipulation

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

已核读 Cloth Funnels 模拟的 task HDF5、mesh split、replay reader/writer、刚体／变形距离及实际 eval_buffer。生成脚本规划每类400个eval配置，但公开eval链只选hard子集；汇总固定取每回合最大IoU步，并非函数参数宣称的第n步或最终步。

版本与身份

固定2025-08-23 commit，晚于2022 arXiv；README标ICRA2023但BibTeX仍填2022，保留原论文与公开程序版本。只核读所列模拟来源段落，未运行GPU、下载task/weights或宣称真机全流程可用。

README 题名、七位作者与 arXiv:2210.09347 对应本篇；binding旧网址 columbia-ai-robotics/cloth-funnels 解析为 real-stanford/cloth-funnels。保留原始别名、canonical repo与同一commit，避免重复来源。 旧入口columbia-ai-robotics/cloth-funnels的已保存GitHub metadata回应指向real-stanford/cloth-funnels，按仓库别名保留，不另外算成未读的第二个仓库。

领域
衣物与洗护
环境
修改版FleX/PyFlex粒子衣物与抽象双picker，可达性与table参数另存；本轮核读README主张的模拟评测链。原生xyz中y为高度，canonicalized-alignment要求指定平面姿态与衣物形状；高coverage不能代替对齐。真机文件虽在tree，本轮未声称真机／熨烫评测已完整核读。
任务
主要目标为canonicalized-alignment，place/fling为预设primitive；longsleeve/pants/dress/jumpsuit/skirt为五衣物类别。生成脚本每类目标配额2000 train＝1500 hard＋500 easy、400 eval＝200 hard＋200 easy；第二次命令的num_tasks是累积配额，不再相加。实际eval loader只取hard，因此README的200与整份400有子集差异；未下载HDF5确认实际完成配额。fold_finish为下游shirt heuristic，不另当完成验证的benchmark。
题数与数据
类别JSON以train/test清单选mesh，生成器按args.eval抽对应衣物ID；不能用同档未被调用的is_eval前缀helper替代。task HDF5包含particle_pos（扰动后起始状态）、init_particle_pos（canonical目标）、particle_vel、shape_pos、phase、mesh_verts/faces/edges/nocs、cloth_instance、pkl_path、init_rgb/task_rgb、cloth_height/width与keypoint groups。flatten_area为mesh表面面积/2，get_config.cloth_area却是cloth_height×cloth_width；距离范式用后者。replay为episode_stepXX[_last]，有观测、单像素action mask、旋转／scale／primitive、pre/postaction_verts／masks、各metric与deformable_weight。writer丢掉task_name及cloth_instance，但保留task_pkl_path与init_verts；sum(init_verts)仅是既有查找惯例，不是可靠唯一ID。
评估方式
SimEnv.deformable_reward→learning.utils.deformable_distance：goal/current先将y设0，保留相同mesh顶点对应；以SVD及5次距离子集配准取得变形残差，逆向配准取得刚体偏移，允许x镜像取较小距离。原生l2_distance是变形项、icp_distance是刚体项、pointwise_distance是未配准点距；各除sqrt(cloth_height×cloth_width)，weighted_distance预设0.65×变形＋0.35×刚体。mask为RGB通道和>0；IoU=交集/联集，coverage=当前mask像素/目标mask像素。init mask失败时退用当前mask，应保留异常。SimEnv保存rewards=0，学习reader才从pre−post metric重建reward并用0.072等尺度标准化，不能直接平均rewards栏。eval_buffer先hard-only，再每个episode固定选postaction_iou最大步，无视evaluate(mode,n)，10轮循环实际重复相同选择，报mean与std/sqrt(N)。fold_finish在最后一步以三段shirt heuristic替代policy primitive，没有独立折衣成品checker；应分开canonicalization与downstream成功。

怎么接入我们的benchmark

可重用

mesh split与task目标／初态、固定对应顶点、分解距离／mask metric、HDF5状态与primitive数据。

需要转换

source绑canonical repo及commit；environment保留FleX/renderer/座标系；task保存对齐目标、衣物类及fold_finish协定；case用task来源哈希＋原group ID＋mesh ID＋扰动；evaluator把legacy名称映到deformable/rigid/pointwise并保存范式面积、镜像规则与step-selection。保留hard子集分母及policy-step与heuristic动作数，禁止自动转成共同success。

仍需补齐

实际task HDF5清单与case/replay稳定对照；非重复loader末笔等待修正；最大IoU／nth／last选步协定；失败reset未落档的分母；下游fold／真机与熨烫成功规则及资产校正。
