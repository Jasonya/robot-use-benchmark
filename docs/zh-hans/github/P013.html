Ego4D: Around the World in 3,000 Hours of Egocentric Video

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

Ego4D 是多项挑战共用的人类第一人称视频库。本次核读五类官方仓库入口，以及 NLQ、VQ3D、状态变化、长期预测和音频的核心格式／指针；各子挑战的完成度分开记录。

版本与身份

各仓库固定提交仍有 2022 挑战说明；不得自动视为所有后续版本的同一协定。episodic-memory 列出近零 NLQ 时窗问题，需固定 annotation release。PNR 无正例 batch 预设回 0，evaluate_trained 可回 None，统计时应保留。LTA 注解名称与实际使用函数应依赖锁定的 editdistance 版本核实。

领域
居家整理与清洁、餐饮与烹饪、工艺与修缮、零售与购物、交通移动与车辆维修、农业与园艺、休闲与运动、社交与沟通、穿戴交互与动作界面
环境
多种真实日常与工作观测；video_uid、clip_uid 与实体环境须分层。五个挑战仓库不是五批互不重叠的视频或机器人环境。
任务
episodic memory 包含 NLQ、MQ、VQ2D、VQ3D；手对象包含 PNR、状态变化分类与对象定位；其他入口涵盖 looking/talking-to-me、说话者与转录、短期／长期动作及未来手／移动预测。子任务数不可当做动作类别或 case 数。
题数与数据
NLQ 原生 videos→clips→annotations→language_queries，case ID 应用 clip_uid+annotation_uid+query_idx；保留 clip/video 的起迄秒与 feature-rate 映射。测试预处理填入的 0,0 是未知答案占位，不是 GT。音频 CTM 使用 channel/tb/dur/word，GT STM 另含 speaker/te/txt；RTTM 用于 diarization。
评估方式
NLQ 逐预测计算时间 overlap 与 top-K 超过阈值的比例，程序只列出 evaluated/GT 数，外层必须检查缺题与重复。PNR 仅对 GT 状态变化为真的片段，以 16-bin 映回 frame 再换秒。LTA 使用 N×Z×K 串行、每笔取 K 个预测中最小 editdistance.eval/Z，积分前缀 ED 得 AUED。VQ3D 提供 L2、角度与依两位标注者框大小／差异的阈值。转录先 lower-case/GLM 过滤后调用 SCTK WER；audio-only DER 用 pyannote，另外输出逐档平均。

怎么接入我们的benchmark

可重用

官方子挑战入口、NLQ 复合 ID／时窗、PNR／LTA 指针实作，以及音频格式转换。

需要转换

一个父 source 下建各 challenge 的 task/case/evaluator；精确保留输入可见范围、label/feature/frame/second 单位、K／Z／阈值及 GT 有效遮罩。原生视频重用以 uid 链接，评分逐项保存，不合成一个成功率。

仍需补齐

尚未取得视频或运行 evaluator。社交任务实作在 lam、ttm 分支，本次只读主分支入口，不能说无程序；VQ2D、MQ、STA、未来手／移动与社交的完整实作仍须逐支集成。SCTK／pyannote 外部实作未运行。
