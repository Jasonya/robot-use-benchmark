ARB4WM: An Adversarial Robustness Benchmark for World Models in Continuous Control

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

ARB4WM在既有DMC与Meta-World上加视觉攻击/防御评测；要保存攻击强度、时间窗口与底层task版本，不能把攻击条件当成新物理任务。

版本与身份

固定66ebc33；read-only核对，不运行对抗算法或policy。MetaWorld-v3及conditional metric界面是此版具体行为，不等同所有Dreamer/MetaWorld标准协定。

领域
通用对象与机动作业、居家整理与清洁、餐饮与烹饪
环境
DeepMind Control Suite vision与Meta-World visual manipulation，MetaWorld wrapper使用MT1(name-v3)及train_tasks[0]。source/backend/seed需保留，不把同底层task的五种attack objective当新环境。
任务
4种Dreamer-family模型、policy/value/latent/RSSM等目标与temporal/full/partial攻击是评估条件。动作任务仍来自父benchmark。
题数与数据
sweep记epsilon/alpha/attack steps、optimizer、defense/adaptive模式、seed、task/model与run_tag；大型logs/checkpoints未包含。world-model image界面与attack前处理需一起固定，0–1/0–255尺度不能共用同数值epsilon。
评估方式
DMC主值为累积return，MetaWorld sweep明确取success rate；同名returns容器仍需标metric。图像SSIM/PSNR按data_range255且在defense前计算。SES用SR×(1−平均首次成功步/该batch观察到的max steps)，不是固定budget范式。clean Tester用eval_envs，attack建构收到train_envs，需核对paired seeds/环境；success_once与图像统计对已结束env的遮罩也需验证。

怎么接入我们的benchmark

可重用

父env wrapper、可重现attack配置/命名、原生return/SR/SES及图像差异分项。

需要转换

case先绑定同父task/初态/seed，再加威胁模型/合法扰动budget；保留clean/attacked pairs、时间作用范围、defense前后metrics及不同episode分母。

仍需补齐

checkpoint/原始campaign、clean-attack环境与seed对齐、active-episode masking、固定budget效率指针与完整攻击规范重现。
