OopsieVerse: A Safety Benchmark with Damage-Aware Simulation for Robot Manipulation

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

OopsieVerse把机体／对象损伤追踪加到既有模拟器；任务成功和健康值是两条评分线。已核对thermal公式、health累积及观测／HDF5映射。

版本与身份

固定2026-10公开码；本次深入热损伤及共同health流程，未宣称所有损伤机制、全部任务或真实安全性能已验证。

领域
居家整理与清洁、餐饮与烹饪
环境
BEHAVIOR-1K/OmniGibson及RoboCasa/RoboSuite父环境＋damageable对象／机体部件；损伤模型扩充不自动产生新的生活场域。
任务
完成原操作目标并控制损伤；需要记录允许的damage条件、阈值及破坏后能力改变。各任务具体completion function仍由其配置提供。
题数与数据
obs.health为float32部件矢量；info.damage_info分object/part/evaluator，HDF5 attr health_list_link_names固定矢量映射，另存task_completion/reward。health是真实可见传感或仅sim特权信号需在protocol声明。
评估方式
各part由100开始，每次update扣各evaluator damage并下界0，object health取最小part。thermal超出阈值按scale×温差且cap100；OG取Temperature，读取失败回0。step有init_skip_steps和可覆写reward_fn；计量必须固定步频/暖机/scale，损伤分数是模拟模型输出。
