RoboTwin: Dual-Arm Robot Benchmark with Generative Digital Twins (early version)

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

P073 应绑官方early_version分支。已核读早期DP3的PKL→Zarr→reader→rollout→锤击checker与公开seed档；真实17项数据任务、论文6项实验、后续分支任务表必须分开。

版本与身份

本体固定early_version f14a315ac4c9c72bfea05b523874f787080dfcf2，非main ea8b21121ebb3cd201ff5b3fe361944ac94eda3f。早期README明记2024-10-01改get_obs及实验结果，真实数据仍标Coming Soon。TopK摘要写出各项suc/(topk×test_num)，没有求和成单一平均，不能直接把文字输出当总平均。

对应arXiv:2409.02920v3（2025-04-16），题名带early version、九位作者。早期与现行README都直接引用该arXiv；CVPR 2025的RoboTwin为2504.13059，不能替代P073。

领域
居家整理与清洁、餐饮与烹饪、工艺与修缮、协助、交接与陪伴
环境
早期SAPIEN双臂桌面，physics timestep预设1/250秒。锤击配置有头部、前方与两腕相机，320×240、1024个世界座标xyzRGB点；conbine=False只取头部点云。论文真实Cobot Magic数据另为30 Hz、三个640×480 RGB-D视角及主／从臂记录，不能与模拟schema混用。
任务
论文评测6项；真实数据设计17项各30条轨迹，标签可重叠。分支README列15个名称，但完整tree只有14个具体env档，block_sweep未在该commit提供。已读block_hammer_beat的play_once为pass，不能称expert产生器已公开。checker要求工具target_pose转到世界后，xy与方块各差<0.02公尺且0.78<z<0.81；没有接触、冲量或敲击次数检查。
题数与数据
PKL保存observation/<camera>的rgb/depth、intrinsic_cv/extrinsic_cv/cam2world_gl，以及pointcloud/joint_action/endpose。depth乘1000存float64，单位毫米；点云xyz为世界公尺、RGB限0–1。joint_action是左右各6关节get_drive_target加gripper，共14维，并非实测qpos；endpose为左右xyz/RPY/gripper。转档将joint_action同时写成Zarr data/state与data/action，endpose写tcp_action，meta/episode_ends为累积排他端点。DP3 reader读state/action/point_cloud，以episode mask和padding创建时间窗。
评估方式
eval_policy_dp3→test_policy→setup_demo→apply_dp3→check_success。指定checkpoint测100个seed；checkpoint=-1扫描300…3000十个checkpoint，各取前20 seeds再选Top5。锤击seed档100笔，范围100000–100102，略过100025/100029/100040。step_lim=400按预测chunk长度累计，TOPP再展为250 Hz动作；get_obs本身也会scene.step，因此400不能当400个physics frames。每episode成功只累加一次suc。

怎么接入我们的benchmark

可重用

early_version任务class、checker、eval seeds、相机／点云设置、PKL/Zarr转换及DP3评测。

需要转换

source分early/1.0/2.0，task保留论文子集关系；case存seed、checkpoint选择方式及chunk预算。state标为command target，另记depth的mm→m转换、world/OpenGL/OpenCV、RPY与episode边界。

仍需补齐

block_sweep程序、其他论文任务逐一checker覆核、17项真实数据manifest、可运行expert产生器、资产target_pose与兼容SAPIEN/DP3依赖锁定。
