EgoMimic: Scaling Imitation Learning via Egocentric Video

返回逐篇总表内核内容已核读 方法／综述参考原作 ↗

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

EgoMimic把Aria人类数据与Eve机器人数据转成相似HDF5结构，但人类future palm位置和机器人关节动作仍是不同动作语义。

版本与身份

主README仍连旧Eve名称；已读EgoMimic-Eve README明确回指本作。两repo commit各固定；不把hardware代码等同数据已取得。

领域
方法／综述参考，未另作来源用途归纳。
环境
Aria Glasses的人类观测与Eve/ViperX单臂或双臂桌面平台；实际camera extrinsics/arm侧及人机数据源要分开。
任务
人机共同模仿学习，示例包括groceries、laundry、小物放碗；mask/插值与同一demo多chunk是表示／样本扩充，不是添加语义任务。
题数与数据
人类future palm经future camera→world→目前camera变换，单手3D／双手6D，actions_xyz再插值成100步actions_xyz_act；每300frame另存demo。robot原HDF5为qpos/qvel/effort/action14D，图像可JPEG padded且compress_len另存。type栏明记human/robot。
评估方式
eval_real输出actions_joints_act，可temporal aggregate，按query_frequency送到实机；此选读程序是rollout，不提供统一任务成功判分。数据筛掉出界/跳动frame，case需保存原时间映射；offline action loss与physical success分开。
