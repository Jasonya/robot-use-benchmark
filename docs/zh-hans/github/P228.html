P228 · SFHand / EgoHaFL

SFHand: Learning Embodied Manipulation by Streaming Egocentric 3D Hand Forecasting

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

SFHand／EgoHaFL 有可读取的手部串流预测数据与 evaluator；目前 README 仍把 Franka Kitchen 评测与 3D 标注产生程序列为 Coming soon。已沿 loader→stream→模型输入→matching→metric 查核，将人体预测与机器人实作分开。

版本与身份

阅读版本为 pinned GitHub commit；DATA／MODEL 外部保存库另需固定 revision。论文尺度与程序 clip 子采样各自登记，不把新观测帧或四种输出当新任务。

领域
穿戴交互与动作界面、居家整理与清洁、餐饮与烹饪、通用对象与机动作业
环境
Ego4D v1 真实活动短片／自动 MANO 标注；EgoHaFL 为衍生 annotations，不是 247K 个模拟环境。Franka Kitchen 下游环境须追到父 benchmark，公开源代码尚未完整涵盖。
任务
串流、语言引导的 hand type／2D box／3D pose／3D trajectory 四类输出，共用同一 clip。每步喂入截至当下的新图像，hand state 由前次预测接续；不是一次只看首帧的全盲长期预测。
题数与数据
论文报告约 247K 个 3 秒 clips（242K train／5K test）、每 clip 16 个 annotated frames，约 3.95M 标注帧；不是 3.95M 独立问题。eval config clip_length=8、max_hand=10、camera depth 0<z<2.5。loader 保留前 10 个有效 hand，LMDB uid／video_id／start/end／caption 与 native split 一起保存。
评估方式
Hungarian matching 后，以 IoU>−1／0.5 及手别正确筛选，再计 camera translation ADE／最后一步 FDE、wrist-aligned MPJPE／PA-MPJPE，输出 cm。precision=matched 中达 IoU 且手别正确／matched 中达 IoU；recall 分母也是 matched pairs 数，未匹配额外预测不在该分母。误差是条件于匹配及分类正确的子集合，不能当完整 detection precision/recall 或所有手的平均误差。err_data 未看到跨 rank gather，正式分布式评测需核对汇总。

怎么接入我们的benchmark

可重用

重用 EgoHaFL CSV／LMDB uid、原始 clip 时间窗、有效手数与原生匹配 evaluator。；保留 4 类预测输出及 IoU 门槛，同列呈现 coverage／条件误差。

需要转换

标准 case 写明 rolling RGB observation、autoregressive hand input、文字来源、clip horizon／frame stride、深度过滤与 hand cap。；保留原始 metrics；若要完整 detection precision／recall，另建版本并将所有未匹配预测／GT 纳入分母。；跨 Ego4D 衍生数据以 video／时间交集去重，不将标注帧数乘成添加题数。

仍需补齐

本次未下载 Ego4D 视频／MANO 权重，未运行模型或确认论文分数。；embodied evaluation 与 annotation pipeline 尚未公开于本次 revision；matching error 空集合与多 rank 汇总需要 adapter 验证。
