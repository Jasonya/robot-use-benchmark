P021 · Ego-ExoLearn

EgoExoLearn: A Dataset for Bridging Asynchronous Ego- and Exo-centric View of Procedural Activities in Real World

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

EgoExoLearn 的核心是不同时间、不同视角的人类示范跟随。已核读标注、跨视角 association 的选项评分和 skill assessment 的成对排序，两者不是同一种成功率。

版本与身份

annotations README 开头仍说只有 train/val，结尾与 root 更新已提供 test GT；标准化应锁定实际文件，不直接采信旧段落。VQA 与 full-size videos 为后续更新，不能并称首发版本。

领域
餐饮与烹饪、实验室操作
环境
数据列 kitchen／lab，用于日常协助与实验室程序；scene 是粗场景用途，video_uid 才是视频 ID。ego/exo 是异步示范关系，不可当同步多相机标定数据。
任务
跨视角 association、动作分割／anticipation／planning、参考示范的 skill assessment／captioning；2024-08 又加入 VQA。能力题型与程序活动类别分开。
题数与数据
fine CSV 保留 video_uid、annotation_uid、subset、view、scene、start/end_sec、人工 narration_en；hand/no-hand prompt 文字是 GPT 改写。skill list 每列 better/worse 视频，NPZ arr_0 提供特征，use_exo 时依 action 从 exo 文件随机选一参考。association loader 回 query、options、answer、q_type、uid。
评估方式
association 对 query/options 特征相似度 argmax，按 Ego→Exo／Exo→Ego 分组 accuracy；skill train.py 的 accuracy 是 better 分数严格大于 worse 的配对比例，平手不算对。RankingAttentionLoss 为训练 loss，不能拿它代替评测 accuracy。

怎么接入我们的benchmark

可重用

原生标注／改写来源、跨视角配对、better/worse 排序与两种内核评分。

需要转换

保留 demo_reference 边及不同 video 时间线；同一视频多问答／配对透过 uid 共用，不能重算成新环境。case 保存配对顺序、选项、exo reference 与抽样 seed；人工与生成字幕 provenance 分开。

仍需补齐

尚未取得视频／gaze／特征或运行。完整 segmentation/planning/captioning 与添加 VQA evaluator 尚未核读；若比较参考示范版本，需锁定具体 exo reference，不能每次随机抽而不留纪录。
