VIP: Towards Universal Visual Reward and Representation via Value-Implicit Pre-Training

返回逐篇总表内核内容已核读 方法／综述参考原作 ↗

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

VIP学习的是视觉reward/表示；embedding距离和环境任务成功是不同评估。程序的success门槛是episode累积solved次数，并非连续稳定时间。

版本与身份

固定81b0520；前述sum门槛属目前公开env基底，具体task可能另override，集成每task时仍需沿具体class核对。未跑MPPI。

领域
方法／综述参考，未另作来源用途归纳。
环境
Ego4D人类训练视频、实机示例和MuJoCo系下游环境；原场景与数据仍属各父来源。
任务
以goal-image/embedding引导robot任务与reward learning；fold_towel等展示是应用例子，不能由曲线距离直接认定任务语义正确。
题数与数据
自订视频依video文件夹存frames；model依图像shape resize/crop224和normalization，max>2时除255。sim=-L2(embedding1,embedding2)，此单位是特征距离而非几何公尺。
评估方式
MPPI读goal_embedding并用H/paths_per_cpu/num_cpu/kappa配置优化；env.evaluate_success预设判sum(solved)>5再按paths算百分比，未要求连续。embedding reward、原生solved与工程时间分开保存。

怎么接入我们的benchmark

可重用

表示/goal数据界面、原reward数学定义、MPPI配置与环境成功引用。

需要转换

evaluator标明learned reward或ground-truth环境条件；case固定goal frame、相机、normalization、planner预算和solved门槛，避免将reward作通用正解。

仍需补齐

各task实际solved predicate、原素材/goal设置、planner与环境版本、reward与任务正确性的反例校准。
