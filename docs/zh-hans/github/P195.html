P195 · World models for unfolding

Learning to unfold cloth: Scaling up world models to deformable object manipulation

返回逐篇总表文件／网站 方法／综述参考原作 ↗

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

已找到与论文题名、三位作者相符的项目网站repo；其方法/结果区仍是模板文字，未包含Unity/Obi/DreamerV2实作。

版本与身份

网站a7b0550为2024版本，论文2602.16675于2026收录；题名/作者相符但网站不能证明2026实验程序已公开。

领域
方法／综述参考，未另作来源用途归纳。
环境
论文Unity/RFUniverse Gym界面与ObiCloth，固定一个cloth corner、Franka在空中展开；与桌面flattening有不同物理设置和目标。
任务
主目标为in-air unfolding，5种garment types×4种agent设置=20个trained agents，不能称20种新任务。
题数与数据
原文每step两张64×64×3图像，加EEF xyz/gripper width/张力boolean；action为4维[-1,1]位移与jaw控制。RGB/normal image及replay-buffer版本分开；每agent1M训练step不是1M评测case，完整数据/episodes未取得。
评估方式
原文用4×4网格估计unfold面积proxy、除最大值并加时间penalty；失败/近成功/成功按episode内最高unfold量分类，与末态/持续成功不同。没有scorer程序就无法核验门槛与投影/面积实作。

怎么接入我们的benchmark

可重用

原文action/observation界面、固定角约束、5garment×4agent对照与最高进度评估。

需要转换

case固定pinned corner/cloth parameters、输入RGB或normals、张力信息来源与budget；保存maximum progress和final state分项，标明privileged observation。

仍需补齐

真正方法repo、Unity/Obi资产/界面、demo/replay与split、成功界线/scorer、原生重现与跨backend可比性。
