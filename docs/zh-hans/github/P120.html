领域

环境
原文的人类pretraining scene labels与实机桌面评测场地不同层次；EgoDex和in-house来源保留来源链，未取得完整场景manifest。
任务
原文6,015人类训练标签、344对齐midtraining任务与5个主实机目标需分开；本次没有将训练标签当已可运行robot task。
题数与数据
官方页述20k+小时action-labelled egocentric video与少量人机对齐数据；原文细量与6D手／机体转换须原始数据／实作确认，未取得完整字段规格。
评估方式
原文whole-task成功与细项完成度；当前页未给可运行scorer、全量reset banks或逐次rollout纪录，不能由视频展示推算整体成绩。
