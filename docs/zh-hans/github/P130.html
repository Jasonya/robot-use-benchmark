Learning Fine-Grained Bimanual Manipulation with Low-Cost Hardware

返回逐篇总表内核内容已核读 方法／综述参考原作 ↗

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

ALOHA提供双臂搜集，ACT提供训练及两个模拟任务。sim的成功从最高reward判定；真实模式的reward占位不能当原文实机成功率。

版本与身份

ALOHA/ACT各固定commit；真实环境中的0 reward是软件界面占位，不能推论原论文实机研究使用此栏自动评分。未运行硬件或sim。

领域
方法／综述参考，未另作来源用途归纳。
环境
真实双臂ALOHA与MuJoCo/DM-Control两个模拟场景分开；数据中的四相机／四个主从臂不算四种任务环境。
任务
ACT repo两个sim任务为Transfer Cube/Bimanual Insertion；joint-control和EE-control是运行表示，scripted/human是示范来源，不能各算新的语义task。
题数与数据
HDF5 obs qpos/qvel/effort与action均14D，RGB相机分key。搜集T次action产T+1 timesteps，但保存配对只取前T。ACT real数据从start_ts−1取action，sim从start_ts取，padding与mean/std要保存。
评估方式
sim Transfer reward4为左gripper接触且方块不接触桌；Insertion reward4为peg碰到pin。eval用全episode最高reward==max_reward作成功，非最后稳定状态。real_env.get_reward固定0，eval real分支max_reward也0，此自动数值不能代替实机任务审核。
