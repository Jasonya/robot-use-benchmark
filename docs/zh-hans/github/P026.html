Fine-Grained Egocentric Hand-Object Segmentation: Dataset, Model, and Applications

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

EgoHOS 是细粒度手对象分割，第一／第二阶交互关系和 contact mask 有明确定义。已核读原生类别、数据配置与实际 MMSegmentation 评分路径。

版本与身份

此仓库内含 MMSegmentation，已钉选其本地版本；不能换成最新版同名套件而不记录差异。README 中 LaMa／FGVC／homan 等是应用依赖，不是额外 EgoHOS benchmark 来源。

领域
居家整理与清洁、餐饮与烹饪
环境
真实第一人称图像；来源内明列 train/val/test_indomain/test_outdomain。这里 domain 指来源分布测试条件，不直接等于生活用途领域数。
任务
左右手、由左／右／双手交互的第一阶／第二阶对象，以及 dense contact。9 个 label IDs 含背景，是像素类别，不能当 9 个操作任务或对象身份。
题数与数据
文件夹 image/label/contact，EgoHOSDataset 读 .jpg 和 .png，classes/palette 固定 0–8。handobj2 config 保留背景（reduce_zero_label=False）、padding ignore=255；test 预设 test_indomain，crop/resize 360×480。
评估方式
CustomDataset 预设 mIoU；metrics.py 先套 label map／ignore_index，再累加逐类 intersection、pred、GT、union，算 IoU/Acc，summary 以 nanmean。还支持 Dice/Fscore，但不能由支持函数推定原论文都采用。contact 二值 mask 需用其独立配置，不与 9-class 平均混算。

怎么接入我们的benchmark

可重用

原生 label/palette、contact 与 split、实际 dataset→metrics 调用。

需要转换

case 保留来源图像／split／raw label mask、接触关系与第一／第二阶；像素座标、resize、ignore=255、背景纳入和 nan 规则都进 evaluator profile。手对象分割与物理接触／抓取成功不同。

仍需补齐

尚未下载图像、mask、checkpoint 或运行。需取得各 head 配置与来源视频 ID 才能避免跨 split 同源视频；contact 与分阶段模型的全部依赖仍须逐配置测试。
