P104 · SIMPLER

Evaluating Real-World Robot Manipulation Policies in Simulation

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

SIMPLER是实机设置的模拟评测，不是新的实机大数据集；两种配置为视觉匹配与变体平均。已核对子模块中的done=success及抓取历史成功规则。

版本与身份

SimplerEnv main基于CPU ManiSkill2；README另连maniskill3分支。此tree的ManiSkill2_real2sim钉在ef7a4d4；不得替换为最新ManiSkill3后仍称同设置。

领域
居家整理与清洁
环境
Google Robot与WidowX+Bridge的SAPIEN/ManiSkill2实转模拟设置；背景overlay、纹理、光照、干扰物等变体是设置，不自动添加语义任务。
任务
抓取、移近、抽屉开关／放物，以及WidowX放置／堆栈等；ENVIRONMENT_MAP把不同罐姿态映射同class＋参数，需保留variant关系。
题数与数据
reset options指定robot xy/quat和object xy或episode_id；模型输出world_vector、rot_axangle、gripper、terminate_episode。控制频率、sim_freq、相机、overlay与subtask推进全部是case协定。
评估方式
此钉选子库get_done=info.success；外层直到模型停止或truncated，保存最后done。抓取可按提起>1cm且无有效外部接触，或连握5步；打开episode_stats时曾显著提起>2cm达5步亦可成功。另以Pearson/MMRV比较模型sim-real表现排序，不是单题完成率。

怎么接入我们的benchmark

可重用

真实setup对应、task alias/config、初态扫描及原生task metrics。

需要转换

case保留视觉匹配/变体平均、variant权重、时间/动作约定；evaluator存瞬间/历史成功旗标、subtask及固定子库版本。sim-real correlation另为模型层聚合。

仍需补齐

完整资产、真实结果配对与不确定性、每变体分母/权重、各task具体checker接线、原生模型运行。
