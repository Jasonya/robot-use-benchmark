AFF-ttention! Affordances and Attention models for Short-Term Object Interaction Anticipation

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

已核STA reader→预测affordance prior→AFF ROI head→OverallMeanAveragePrecision，以及添加EPIC STA pickle的读取格式。固定release的v2设置仍遇v1字段硬编码及未随repo提供的import；AFF、hotspots和完整运行环境尚未闭合，不能以README结果或外部权重链接宣称可重现整篇。

版本与身份

固定 1a1253fa2bde09ef1de4894f3bf872c1fbf270de（2024-07-15）。已核propagate_AFF_from_node.py用top1/3/5 visual及cross-modal邻居、1.5×最近距离筛选、softmax(2×similarity)加权后逐类max、max-normalize再softmax；论文式(3)是加权sum后exp，不能混成同一prior配方。该脚本np.save被注解，不能直接认定会产出reader所需档；其diagnostic n_samples从1起算、最后分母多1，也不是STA mAP。generate_AFF_labels.py是另一cluster频率版本，root标TRAIN但输出名含VAL，需要provenance而非靠文件名判split。README连的weights与config checkpoint亦不同。只核以上内核source／小型词表，未跑模型、simulator或下载大资产。

领域
餐饮与烹饪
环境
Ego4D v1/v2日常活动与作者整理的EPIC-Kitchens STA第一人称视频。affordance node/zone是视频中视觉相似的活动区域及其已观察交互，不是3D场景layout或机器人可运行技能；hotspot是图像中的人手交互概率。
任务
下一次对象交互的box、noun、verb、TTC与confidence。v1 taxonomy87 nouns/74 verbs，v2 128/81；类别、prediction frame、GT object、zone/visit与policy trial各为不同单位。P241有新的curated EPIC STA标注贡献，不能与P235的EK100 pseudo-box实验或母EK action数据直接合并计数。
题数与数据
Ego4D JSON读info.video_metadata与annotations；每ann含uid、video_id(v1)/video_uid(v2)、frame、objects[{box,noun_category_id,verb_category_id,time_to_contact}]。still图为video_id_七位frame.jpg；fast LMDB以video_id为父目录、video_id_十位frame为key，值是JPEG；sampler取frame-15..frame共16格、早于0补0，没有取未来影格。frame索引与TTC秒保留各自单位。target是boxes/noun_labels/verb_labels/ttc_targets；noun固定+1，verb在ROI_HEADS.VERSION不含v1时+1，因此两个aff设置都+1，与数据集v1/v2名称无关。train移除退化框／无对象ann；test无objects时loader制造假框与0 label，不能作GT。AFF档是list[dict]的numpy对象容器，key为v_id、frame、AFF_N_top3、AFF_V_top3等；reader把它们命名AFF_N_GT/AFF_V_GT，实际来源是predicted_AFF档，缺项填全1 prior。EPIC pickle则是[{eid,video_id,timestamp,objects:{noun_category_id[],verb_category_id[],boxes[],time_to_contact[]}}]；框被当normalized xyxy乘(1920,1080,1920,1080)。图像frame=int(timestamp*30+1)，AFF lookup却round(timestamp*30)+2；timestamp秒与这两个索引不可混用。EPIC noun合群/排除others、verb删除稀用词都会改case分母；test分支实际重用val_annotations.pkl。未取得完整标注资产，未宣称有效case总数。
评估方式
STATask.validation_epoch_end先list_gather所有rank、以uid创建pred/GT dict去重，再OverallMeanAveragePrecision(top_k=5)。每图依score排序，针对各配对条件对尚未匹配的GT选最大IoU；IoU用xyxy像素端点+1面积，门槛>0.5，TTC abs(error)<=0.25秒。Top-5对每图每条件豁免(5-1)×GT对象数个最高分FP；余下按confidence创建precision=TP/(TP+FP)、recall=TP/该类GT对象数，取单调precision envelope的VOC积分。12个输出中前8个是合并类别的AP，后4个map_box_noun、map_box_noun_verb、map_box_noun_ttc、map_box_noun_verb_ttc才按有GT的noun类别宏平均×100；checkpoint用最后一项，不能把global AP混入主表mAP。AFF head将预测prior×各head softmax后重新范式，去背景、每proposal保留verb_topk=1、noun×verb分数>0.002（不是config的0.05），per verb–noun NMS后最多100 detections；此预测budget与scorer的Top-5 FP豁免不同。export把noun减1、verb减相应offset，输出results[uid]的box/score/noun_category_id/verb_category_id/time_to_contact。test仅导出，无公开GT scorer结果。

怎么接入我们的benchmark

可重用

Ego4D v1/v2 taxonomy、STA JSON与EPIC pickle reader的原生字段、predicted-prior lookup／Bayes fusion、具体mAP与submission adapter。

需要转换

source记paper/commit、Ego4D或curated EPIC annotation revision、StillFast base与prior/hotspot资产；domain/environment为人类视频和zone provenance。task保持STA；case用dataset+split+uid/eid，另存video/frame/timestamp、原框座标、class_remap/背景offset。zone/visit/node及其training STA/narration是source附属数据，不增加case。evaluator固定score生成、verb_topk/NMS/100候选、Top-5豁免、TTC门槛、noun macro AP与uid去重；跨source不等价为robot success。

仍需补齐

优先修复Ego4D reader的video_id硬编码与v2 video_uid；固定StillFast base commit／安装布局，补缺的ego4d_sta_hands_still_video、faster_rcnn_HANDS_sta、faster_rcnn_prior_HANDS_sta、detr_criterion等被无条件import的模块。移除...及作者绝对路径，固定完整split/annotation与predicted_AFF/hotspot SHA。AFF数据库生成／descriptor采样仍需train-only及时间可见性核验；当前code以train_nodes匹配visual query，不能因GT栏名就指为oracle，也不能因文件名train就视为已证明无泄漏。EPIC需要固定class_names、实际class remap及两套frame偏移，且test=val不能当独立test。hotspot读入有外部placeholder，当前Ego4D __getitem__的contact-point调用与heatmap target被注解，selected aff链未核到完整hotspot重权重运行路径。
