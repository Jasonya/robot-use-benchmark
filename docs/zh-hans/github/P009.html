核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

EPIC-KITCHENS 原始版的标注、读取工具与评分库分开发布；旧网址现已转向明确的 55 版仓库。已核读动作／对象标注、GulpIO 流程与分类指针。 2026-10-11 补读官方共用 downloader 的版本选择；旧 download-scripts URL 的 404 保留为候选处置。

版本与身份

固定提交的 annotations／starter-kit／epic-lib 旧路径均转向 EPIC-55。epic-lib README 警告 v1.4.0 及更早版本的 Gulp flow 可能乱序；原始 GoPro 与发布抽帧版本的 fps／frame index 不可混用。 补读 downloader 固定 4f11fb2b579833f360c3c7bb917bf1e24a9787b5，不宣称是 download-scripts 的已验证转址。其 README 说 data/ 未追踪，但该提交完整 tree 列有四份 CSV，且两份 split 已实读；以固定文件为准。原 Snakefile 的 annotations/master 链接需替换为既有 55 固定版本，不能依今天的预设 challenge 选项推回 2018 评测。

领域
居家整理与清洁、餐饮与烹饪
环境
真实第一人称厨房视频；participant_id、video_id 与 seen／unseen kitchen 测试条件须保留。视频、拍摄者与厨房不是同一个环境计数。
任务
动作辨识以 verb_class、noun_class 及其组合定义；对象框另有自己的标注时间轴。这些是人类视频标签，不是可直接运行的机器人任务。
题数与数据
action CSV 含 uid、video_id、participant_id、narration、start/stop_timestamp、start/stop_frame、verb/noun_class 与 all_noun_classes。对象框使用 (top,left,height,width)；object_frame 和 action_frame 需依对照表对齐。S1/S2 测试只公开片段时间；narration 时间不可代替动作边界。 补读：原 55 starter-kit 的 Snakefile 由 train/test_seen/test_unseen_video_ids.csv 产生 Bristol 的逐视频 RGB／flow tar 路径。另由官方 2022 网页直接链接的 epic-kitchens-download-scripts 提供 epic_downloader.py：先读 55 的 video_id/split 和 100 的 ar/da/cmr 布尔 split CSV，依 video_id 后段长度辨认 extension，再以 --epic55-only 或 --extension-only 过滤；两旗标互斥，未指定时涵盖 100（含重用的 55）。输出一律使用 EPIC-KITCHENS/participant/媒体类型 目录，原始 55 远程 train/test 路径另由 epic_55_split 决定。
评估方式
epic-lib 计算 verb、noun、action 的 top-1/top-5；没有 action 分数时可由 verb/noun 分数构造。precision/recall 先逐类计算，再对指定 many-shot 类别平均；与 100 版的 tail／unseen 指针不同。top-k 使用每列排名内是否包含 GT 的平均。 下载器的 --action-recognition/--train 等筛选取自 100 版 challenge 字段；--epic55-only 只限制视频来源，不能替代原 55 的 S1/S2。需仍沿用 55 starter-kit 的 seen→s1、unseen→s2 与原标注契约。MD5 只用于判断文件是否可跳过下载，不是辨识指针；本次未运行下载或校验媒体。

怎么接入我们的benchmark

可重用

原生类别字典、片段 uid、S1/S2 切分、框座标、GulpIO 数据流程与评分函数。 可重用已钉选的取得程序、两版 split CSV 字段、原生 URL 与输出路径映射。

需要转换

source 固定为 EPIC-55；case 保留 uid 与原始 split；segment 同时保留秒与 frame，记录实际抽帧版本；动作／对象时间轴以显式映射关联。verb/noun/action 与 many-shot 报表分项保存。 另记录 acquisition_repo/commit、数据 edition、video_id、来源 split、challenge split、媒体类型与 errata/校验表版本；55/100 重用视频共用 ancestry，但各自保留评测切分。

仍需补齐

尚未取得视频／flow／隐藏测试标签，也未运行 GulpIO 或官方提交；跨来源与 EPIC-100 重用关系需由 video_id 创建。 需固定下载器实际依赖的 split/md5/errata CSV 版本，验证完整取得与哈希；本次 split 仅核读字段和列出的样列，未宣称逐列审核。
