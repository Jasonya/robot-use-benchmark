EgoDex: Learning Dexterous Manipulation from Large-Scale Egocentric Video

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

EgoDex官方库提供HDF5/MP4 loader及best-of-K轨迹误差。829小时包含split冻结后追加数据；每frame样本量不能当不同任务或episode数。

版本与身份

apple/ml-egodex已转址apple-aiml-research/ml-egodex，属同一源。README分约725h train/7h test/97h extra；不可将追加部分混进原冻结test。

领域
居家整理与清洁、衣物与洗护、装配与生产作业、穿戴交互与动作界面
环境
Vision Pro/ARKit第一人称桌面人类操作；每episode的ARKit origin由设备初始化，不保证跨episode一致，不能把相同world坐标当同一场所。
任务
作者报194种人类操作task，829小时数据；test/robot部署是不同用途。loader __len__回总frame数，不是194任务的题数。
题数与数据
同索引MP4/HDF5，30Hz对齐；camera intrinsic3×3、各joint transforms N×4×4、可选confidence；reversible语言用llm_description/description2及which_llm_description。loader比较字符串"1"，需验证实际attr类型。
评估方式
evaluate_distance采B×T×48 GT与K×B×T×48 prediction，排除任何padding的chunk，选出12个位置点而略过6D旋转；平均距离与终点距离各自best-of-K，可能选不同候选。这是人类轨迹预测误差，非机器人完成率。
