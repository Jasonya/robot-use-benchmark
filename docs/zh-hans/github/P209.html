HUI360: A 360{\deg} Egocentric Dataset and Baselines for Human-Robot Interaction Anticipation

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

HUI360 已核官方 baseline 与 Interact360 标注／CSV 管线。论文结果必须对应 baseline legacy 分支与固定 HF dataset revision；新版 main 的 32-frame／16-frame cutoff、数据 main 及最佳 F1 threshold 搜索不能直接当论文 30／15 协定。已追到实际 track reader、窗口标签、AUROC／F1／AP scorer，未运行模型或下载大型数据。

版本与身份

主核论文baseline legacy=32a90eb716e503ef8a0daabc052ce7c34ba36a95，README／config 指定 dataset rlorlou/HUI360@3c8a342548534b6b92d32b0099e266962facdf45，30-frame输入、15-frame两cutoff、25epochs。另读 main=a6bd61c8539061242cbf756a18847c0900a8707c（2026-08-29）新版内核设置／reader入口／scorer，预设32frames／16cutoff／75epochs及hf_dataset_revision: main，不能混用数字。Interact360=d11ec02d666965968293813b9c17501cf1568cf6（2026-05-06），其README的CSV教学虽TBD，实际export程序已存在且已核。以上是选定内核区段，不是全基线架构／整个标注模型codebase已审完。

arXiv:2608.11051v1 的官方 project 明确分开 Code (Baselines)=hucebot/HUI360-Baselines 与 Code (Pipeline)=RaphaelLorenzo/Interact360；前者 README 直接连同一 arXiv 并要求论文使用 legacy，后者虽仍有 arXiv TDB placeholder，但官方 project、HAL 与题名均指向本篇。SSUP-HRI 是重用父数据，不另当 HUI360 新收集来源。

领域
公共场馆与服务、协助、交接与陪伴
环境
robot-egocentric 360° equirectangular 观测。paper 的新 HUI360 有 9 真实场所、30 robot setups、68 recordings；71.3 小时原始数据裁成 1,937 episodes／11.3 小时（15 fps）。4,310 person tracks 中 375 有物理交互；另 SSUP-A 是 SSUP-HRI 两个 field sessions 的重标注，27,698 tracks／419 interactions，不可当独立新捕捉数据。本轮没有可交互 robot policy 环境，评的是脱机 anticipation。
任务
预测人是否即将与平台发生物理 interaction；positive onset 依投放、拿取等实际事件与人工修订，并非对 gaze／社交意图的通用判定。RF／MLP／LSTM 是模型，T_ADV horizons 5/10/15/20/30 frames（15 Hz 下约0.33/0.67/1/1.33/2秒）与输入降采样是同一 task 的条件。论文 HUI locations1–7 train、8–9 test，SSUP 第一／二场次 train/test；实际程序依 checkpoint 的 include_recordings_val 等清单选样，变量 val 不能擅自解读成另有第三份验证集。
题数与数据
Interact360 读 episodes/<id>/annotations_360.json 的 image_file/image_shape/detections；track_id 可由 associated_track_id 合并，含 validity、bbox、mask_rle、mask_size、engagement_level、17点 ViTPose 与308点 Sapiens。bbox／pose 是原全景像素，x 可跨图像宽度边界，不能直接裁成普通2D box。detect_interactions 的相交面积>min_pixels_intersection（预设10,000）给 level3，否则0，之后允许人工修订。export 只收 checked/valid 类 flags，依validity与quality连续段筛选，写 data-<recording>-<index>-of-<total>.csv；unique_track_identifier=recording_episode_track。timestamp 由文件名 %Y_%m_%d_%H_%M_%S_%f 解析；另存 timestamp_sec、相对track秒、time_to_first_interaction秒，无交互用99999.0 sentinel。缺 Sapiens 数据可填0，需视作缺失而非真座标。baseline CSV reader 把 engagement／时间／ID 列列为 metadata，指定LSTM features为 mask area+bbox+17×(x,y,score)，即56维／frame；keypoints先box-normalize再用固定HUI mean/std。
评估方式
legacy get_track_input_possible_indices 将 image_index 连续存在、validity、至少9个ViTPose score≥0.5与mask_size筛选做AND，再找连续段。第一个 engagement>0 定义 onset；interaction_cutoff／positive_cutoff 以frame计。非交互 track 可截到最大mask面积（近距离proxy），并依设置把窗口对齐该处。force_positive_samples 会排除交互track的早期负窗。__len__ 是合格track数，__getitem__ 为各track固定或随机选一个候选窗口；固定索引清单与subsample必须保存。legacy infer 对每个窗口得到 sigmoid(logit) 或 RF predict_proba[:,1]，用>0.5算 binary P/R/F1，整个pass的分数送 roc_auc_score；training.evaluate 另算 average_precision_score。其 N 是实际送入的合格track窗口，AUROC 比较正负样本排序，F1分母为2TP+FP+FN，不是4,310 raw tracks、375 interactions或百万detections。new main 可用 stride 展开多窗口，需重记样本数；main infer 直接算 AUROC/AP，并在同一集合用100个threshold搜索最佳F1。未下载实际CSV，因此不宣称验算任何eligible test case数。

怎么接入我们的benchmark

可重用

可重用两仓库原生track/frame结构、人工curation flags、mask-intersection标签、legacy reader／window selector／score path及固定normalization；SSUP重用关系独立记录。

需要转换

source 必须同存 paper v1、baseline legacy或main commit、dataset revision、Interact360 commit。environment 区分location／setup／recording；task 保存物理interaction定义与horizon。case 用dataset+recording+episode+track+window起讫／sample index，另保留raw track与条件化window父子关系；frame index、文件名时间、relative seconds、panorama seam／pose confidence／缺失标记分开。evaluator 保存正负样本N、filters、采样seed／stride、threshold来源、AUROC/AP/F1及normalization版本，不能转成机器人完成工作成功率。

仍需补齐

固定revision的完整CSV／track manifest与checkpoint protocol对齐、eligible windows实际清点、SSUP跨全景边界与missing-pose处理验证、legacy边界分支修正、独立threshold选择、原始图像／curation与标注版本闭合。只做静态核读；snapshot_download、大型骨架／图像、模型、GUI与模拟均未运行。
