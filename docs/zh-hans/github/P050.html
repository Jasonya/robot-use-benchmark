PALM: Predicting Actions through Language Models

返回逐篇总表内核内容已核读 方法／综述参考原作 ↗

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

已找到作者名下的PALM程序，README明列动作辨识、图像描述与语言模型预测三个模块；不能把论文引用的VideoBLIP仓库当成PALM。

版本与身份

固定commit为7d4e6cd6426a51857214cdd3ec818568624ab320。metric注解提到Damerau，但实作调用editdistance.eval；移植时应保持函数及套件版本，不能只照注解更换公式。annotation_utils也有作者本机绝对路径，需改成版本化数据引用。

GitHub精确名称搜索找到kim-sanghwan/PALM；README自述为ECCV2024 PALM官方实作，论文标题与作者Sanghwan Kim相符。原PDF只列VideoBLIP等引用，已分开处理。

领域
方法／综述参考，未另作来源用途归纳。
环境
Ego4D视频与clip观测脉络；annotation_utils将clip_uid映到video_uid和视频scenario，这些不是机器人可交互场景。
任务
先取得辨识动作与图像caption，再预测未来verb/noun串行；本篇是重用既有长期动作预测数据的方法，不添加独立机器人工作库。
题数与数据
README指定recognized-action JSON与caption JSON进入预测模块；annotation_utils保留clip/video关系，并将原生verbs/nouns词汇及同义字映成taxonomy索引。
评估方式
eval_utils对形状N×Z×K的候选串行计范式editdistance.eval，逐样本取K候选最小值再平均；AUED对不同前缀长度的ED做梯形积分。K、Z和文字到标签解析都影响分数。

怎么接入我们的benchmark

可重用

三段模型输入路径、clip/video血缘、词汇映射、候选串行与ED/AUED程序。

需要转换

创建以原生clip与观测截止点为键的forecast case；分开模型可见的辨识动作、caption、未来GT及候选预算，保留taxonomy和解析规则版本。

仍需补齐

原始视频、辨识/caption中间档与split闭合；需核对原作配置的预测长度、候选数及依赖版本，并接回正式Ego4D评测。
