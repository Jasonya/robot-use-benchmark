Assembly101: A Large-Scale Multi-View Video Dataset for Understanding Procedural Activities

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

Assembly101 的原生粗／细粒度和录制／视角可以明确分开；六个官方仓库分别是下载、标注、错误标注及三种理解 baseline。

版本与身份

下载 README 已加入 2026-05 Hugging Face 与更新的 AssemblyPoses.zip；不要把新特征／pose 视为 2022 原始实验。mistake 注释指向 2023 Every Mistake Counts in Assembly，与原始三项理解评测需创建衍生关系。

领域
装配与生产作业
环境
人类组装／拆卸玩具车；recording/sequence 与 8 固定 RGB、4 头戴单色视角分层。toy_id 是对象身份与泛化切分依据，不直接等于场景数。
任务
标注文件列 202 coarse actions（61 对象、11 verbs）与 1,380 fine-grained actions（90 对象、24 verbs），是原生类别数。粗标注供 temporal segmentation，细标注供 recognition/anticipation；mistake/correction 是另外的程序标签。
题数与数据
fine CSV 含 id、video、start/end_frame、action/verb/noun_id、toy_id/name、is_shared、is_RGB；coarse labels 为片段 frame 边界与 action_cls，coarse_splits 分 assembly/disassembly。视频原始 60fps，动作标注 frame 为 30fps；手 pose 又为 60fps。mistake CSV 含 start/end、verb、this/that、label、remark。
评估方式
temporal utils.py 将连续同类影格折成片段，计范式 edit、全影格 MoF、tIoU=.1/.25/.5 下逐 GT 至多匹配一次的 F1。anticipation 先对 action 分数 marginalize 得 verb/object，再算逐类平均 top-k recall，另列 tail/unseen；不是逐题 accuracy。TSM loader 以 start_frame+片段内采样位置读图。

怎么接入我们的benchmark

可重用

原生粗／细字典、toy/view/sequence 身份、跨 toy 切分、错误原因与 temporal evaluator。

需要转换

一个 recording 连多视角 case，分开 fine/coarse/mistake annotation schema；30fps 动作与 60fps pose 显式对时。evaluator 保存 label universe、背景类别、tail/unseen、augmentation 及 macro/micro 聚合，错误与修正另连到原程序上下文。

仍需补齐

尚未取得视频、LMDB、cleaned pose 或运行指针。mistake 仓库 tree 无 Python，发布的是标注并指向后续论文，不能当成已提供错误检测 baseline。anticipation 固定 1064 actions／17 verbs／90 objects，需核对其 CSV 子集，不能直接套用完整 1380／24 字典；缺题检查被注解，需 adapter 外层验证。
