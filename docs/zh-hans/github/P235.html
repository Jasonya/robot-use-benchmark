P235 · TransFusion

Summarize the Past to Predict the Future: Natural Language Descriptions of Context Boost Multimodal Object Interaction Anticipation

返回逐篇总表内核内容已核读 方法／综述参考原作 ↗

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

作者页直接连 algvr/transfusion，已核 Ego4D v1/v2 reader、语言摘要输入及实际 Top-5 STA mAP。此来源是脱机下一次人类对象交互预测；外部摘要、SlowFast TTC 替换与跨 GPU 合并都是结果协定的一部分。论文 EK100 路径在现行入口尚未闭合。

版本与身份

固定 55d3a4eca3325dc65f5f0391cc27105ba110c00f。论文方法、作者专页 CVPR 2024 release、Ego4D v1/v2 与 EK100 pseudo-label 实验各留版本关系；同名 LiDAR TransFusion 不属本篇。仅核上述内核来源，未运行上游、下载完整视频／模型／摘要套件。

精确题名与 Pasca、Gavryushin 等八位作者相符；清单 2023 是 arXiv 初稿，缓存为 arXiv:2301.09209v4（2024-03-10）。PDF p.1 连作者专页，专页 HTML 52–117 行显示相同题名、作者、CVPR 2024 与 Code→algvr/transfusion。专页／现行 repo 支持两版 Ego4D，不能把这个版本直接当 v4 文中全部 EK100 实验的完整 release。

领域
方法／综述参考，未另作来源用途归纳。
环境
Ego4D 人类第一人称日常场景，包含厨房、园艺、维修等；论文另以 EPIC-KITCHENS-100 厨房视频验证。输入是 prediction frame 与其过去的语言化情境，没有 robot state/action 或 simulator。
任务
每个 prediction uid 可有多个将交互的对象，预测 box、noun、verb、time_to_contact、score。v1 固定 mapping 有 87 nouns／74 verbs，v2 为 128／81；这些是词汇类别，不是添加任务数。Noun、Noun-Verb、Noun-TTC、Overall 为不同匹配限制的指针，另有 noun-only／verb-only 消融。
题数与数据
fho_sta_{train,val,test_unannotated}.json 以 annotations、noun_categories、verb_categories、info.video_metadata 组成；每笔 uid、video_id(v1)/video_uid(v2)、frame、clip_id、clip_uid、clip_frame、objects[{box,verb_category_id,noun_category_id,time_to_contact}]。框为原图像 xyxy 像素，TTC 为秒；det_sec=frame/fps，fps 读各视频 metadata，不能一律硬设 30。reader 转 Bboxes/all_nouns/all_verbs/det_diff，objects_to_entries 只留最后对象 TTC，再对所有对象拷贝，接轨应保留原始每对象 TTC 并验证此假设。LMDB 模式可缩至高 480，jpg 模式不先缩框。noun ID 0 移至末类以让 0 作背景，输出再还原；v1/v2 对 nut/tape 等字符串处理不同。设置 subset=0 实际使用原始 orig_split；另排除 5 个 UID、有框过滤与读图失败跳下一笔，故完整 case 分母须由版本化可读 uid manifest 计算，不能直接沿用论文的 64,798 统计。test 中 ball/take 与固定框为 loader placeholder，不能当 GT。语言 JSON 用 prediction uid 索引，v1 将 object_lang/action_lang 直接串接，v2 加分号；目前 current 策略消费预先生成摘要。
评估方式
EgoNAOTrainer 的 train/val 均建 STAMeanAveragePrecision(top_k=5)，先将预测与 GT 框转整数。每图按 confidence 递减、以最大有效 IoU 一对一配对；IoU 使用像素端点 +1 面积，实作 boxes>0.5，abs(TTC error)<=0.25 秒。论文 p.5 写 IoU>=0.5、TTC<0.25，边界不可混写。Top-5 实作对每种配对条件豁免该图最高分的 (5-1)×GT对象数个 FP；不是只计五类。剩余预测依 class/confidence 合并，recall=累积TP/该类GT对象数，precision=TP/(TP+FP)，取单调 precision envelope 的 VOC 积分；count_all_classes=False，对有 GT 的类别作宏平均×100，joint 指针按 noun 平均。trainer 输出 results[uid]=至多5个{box,noun_category_id,verb_category_id,time_to_contact,score}，所以在线 raw-pred 指针与导出档重评有额外截断差异。DDP 本地 AP 后同步不等于合并数据再计 AP；README 要合并 JSON 用 EGO4D/forecasting 正式脚本。TTC loss 在两设置均为 0，README 指论文结果使用外部 SlowFast TTC；这次没有把本地 scorer 充当已核正式 server 结果。

怎么接入我们的benchmark

可重用

版本化 category mapping、原始 annotation→case 字段、语言 uid lookup、STA 配对与 AP 聚合，以及 submission JSON 外形。

需要转换

source 记 paper/repo/Ego4D revision；domain/environment 指人类视频及该笔场景；task 保留下一次交互预测；case key=(dataset_version,split,uid)，frame 与 clip_frame 各留参照系，boxes 记 xyxy/原图尺寸，objects 与 TTC 逐笔保留。label 同时存原 category ID 与背景重编号；context 记生成模型、输入最大 frame/time、摘要资产 SHA、GT／预测模式。evaluator 区分本地／导出／正式 server、Top-5 FP 预算、noun macro AP、TTC来源及 DDP 合并策略。

仍需补齐

需固定外部 context、Ego4D 标注与 SlowFast TTC revision；目前 loader 只按 uid 取字符串，无法证明摘要只使用过去影格，w_leak=False 也不是此证明。核对多对象 TTC 被压成一值、5 笔输出截断与实际可读 case 分母。adapt_ttc_values.py 使用 argparse 的 description 参数、连字号 positional 名称却以底线取值，且 test_keys 未定义，不能视为可直接运行的 TTC 集成器；README 所述 evaluate_wandb_jsons.py 不在固定 tree。EK100 论文采 UniDet 产生 pseudo boxes 并依视频分割，现行 get_annotations_df 只接受 Ego4D，须找对应 release／处理过的 manifest 才能宣称重现。
