OpenVLA: An Open-Source Vision-Language-Action Model

返回逐篇总表内核内容已核读 方法／综述参考原作 ↗

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

OpenVLA是VLA方法，重用OXE/Bridge/LIBERO数据与任务。模型action解码依dataset专属q01/q99，LIBERO部署再改gripper范围与方向。

版本与身份

固定c8f03f4；README后加OFT/FAST并非vanilla OpenVLA同版本。此库是Prismatic fork且由原作者页认领，fork属性不代表非官方。

领域
方法／综述参考，未另作来源用途归纳。
环境
BridgeData V2真实WidowX和LIBERO模拟设置；添加模型／微调不新建独立benchmark环境。
任务
语言条件操作策略与既有task-suite评测。原作训练数据量和LIBERO任务数应追到父来源，不累加成新的任务联集。
题数与数据
predict_action以dataset专属unnorm_key解码action tokens，依mask使用q01/q99还原。维度由stats的q01长度决定；虽范例7D，不能忽略dataset/controller。LIBERO observation字典含state，但程序注明OpenVLA不使用proprio作输入。
评估方式
LIBERO使用固定initial_states[episode_idx]，suite预算220/280/300/520/400步，另有暖机；gripper[0,1]→[-1,+1]且OpenVLA再反号。成功取原env.done，原goals沿LIBERO。需记下成功/例外和整体分母。
