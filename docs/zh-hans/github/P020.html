EgoHumans: An Egocentric 3D Multi-Human Benchmark

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

EgoHumans 官方仓库提供多人体数据处理、COCO-video 转换与追踪评测。已沿 tracking 文件追到内含 MMTracking 的 dataset evaluator 与 MOT matching。

版本与身份

作者 TRACKING.md 说因 PyTorch 升级，公开结果与原论文有约 1% 变动；不能将当前程序当原表格的逐位重现。所核读的 external/MMTracking 文件是正式入口依赖，其他内嵌模型／数据集未据此宣称全数读完。

领域
休闲与运动、社交与沟通、穿戴交互与动作界面
环境
穿戴 Aria 与外部相机同步记录多人活动，含网球、击剑等；big_sequence/subsequence、相机与人物分层。拼接 COCO video 或增加 ego_slam/exo 视角不添加实体环境。
任务
多人侦测、2D/3D pose、mesh 和身份追踪；主要 tracking 比较以 ego_rgb 和指定 detector 条件进行。GT bbox 与 YOLOX bbox 是不同合法输入条件。
题数与数据
coco_video_format.py 以 parent_sequence+sequence+camera+mode 建 video_name；image 有 image_id/video_id/frame_id，annotation 保留 human_name/camera_name/camera_mode/time_stamp，instance_id 由 aria 人名解析，bbox 用 XYWH。frame_id 在可纳入图像串行内重新编号；无有效人框的 frame 会被跳过。MiDaS 深度／3D root 是加工输出，不是直接测量深度。
评估方式
CocoVideoDataset 按 frame_id==0 分视频并检查 track_bboxes 长度；eval_mot 用 1-IoU 距离、预设 .5 门槛、ignore IoF 和 MOTAccumulator，输出 IDF1/MOTA/MOTP/FP/FN/IDSw 等。MOTP 在此转成 1-distance，方向与底层距离不同；全体累积结果与逐类平均需分开。

怎么接入我们的benchmark

可重用

COCO-video 转换、原人物 ID／时间、tracking 输入条件与内含 MOT adapter。

需要转换

environment 留真实录制／subsequence，video ID 只作观测串行；维持原 time_stamp 到重编 frame_id 的对照。case/evaluator 记 detector、GT bbox 可用性、ego_rgb/ego_slam/exo、深度来源、忽略区域与匹配阈值，跨拼接需重命名 instance ID 并保存原值。

仍需补齐

尚未取得图像、pose、MiDaS 加工数据／模型或运行；主要验证流程需固定设置档与 detector 输出。2D/3D pose 和 mesh benchmark 的完整 evaluator 不包含在这次 tracking 核读范围。
