LIBERO-RECOVER: Beyond Task Success Towards Failure Recovery in Robotic Manipulation Models

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

已核读同名网站与同owner的LIBERO-Recovery评估库，但目前程序的人工XY扰动协定与论文「自然运行失败」不同；不能直接当作论文完整release。

版本与身份

网站c8cdf8d仍匿名且Paper/Code/Data皆Soon；code7584d1b README计划2026-10-20发布，该日期尚未到。2609.05178v3 p4明说不人工扰动，与此版做法不同，故处置identity_or_version_unresolved。

网站题名与论文相符、候选eval库同owner；未把匿名网站与当前custom-scene code的关系直接认定为完整论文版本。

领域
居家整理与清洁
环境
沿用LIBERO/MuJoCo；程序scene定义为.bddl+_sim_state.npy pair。这是任务设置/物理初态组合，非必然独立房屋。网站列2178recovery scenarios，未取得对应完整资产manifest。
任务
论文L1重试/L2调适/L3对象状态恢复/L4环境恢复；程序目前主要对custom state加±2cm自由对象XY扰动，5closed+5open起始试验。语义任务、failure scenario和10次trial不能相加。
题数与数据
原文2000+自然失败情境；网站另列3184恢复示范、625731frame、110task types，单位不同。程序frame记双相机、EEF/axis-angle/gripper状态，模型example只送image+lang；manifest存scene/trial/gripper_init/obj_deltas/success等。缺完整failure trajectory/原始goal与recover标注的链接。
评估方式
最多520step，done取原LIBERO goal conjunction；close/open分报。outer reset宣称12次重试，但内层env_wrapper.reset会吞RandomizationError并持续重试，须验证失败行为；建构/重置失败被跳过会影响分母。flat_state扰动索引还需确认time/qpos布局。没有据此重现论文四层恢复结果。
