EgoCross: Benchmarking Multimodal Large Language Models for Cross-Domain Egocentric Video Question Answering

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

EgoCross 的原作者工具库另指官方 EgoCrossCodes；已补钉选两者，核对开／闭集评分和官方testbed。两份内核eval文件的SHA256相同，README／数据发布内容则不同。

版本与身份

官方固定README说2026-05挑战结束后发布answers，故不再把它写成永久隐藏GT；本次仅取得questions-only metadata。官方脚本与原作者文件相同不表示两个repository或957题可重复计数。

领域
工艺与修缮、医疗与手术支持、休闲与运动、宠物照护与动物活动
环境
官方957题testbed JSON实际含CholecTrack20、ENIGMA、EgoPet、EgoSurgery、ExtrameSportFPV五个原生dataset标记。这是父数据源，不是5个实体环境；primary_category/question_type另为能力分类。
任务
闭集四选一与开集文字问答，保留多种活动／视角来源。官方文件区分source-limited/open-source challenge条件；不从benchmark名称推定统一robot action space。
题数与数据
实际解析questions-only档有957列、957唯一id，0列含correct_option_letter，0列含question_id；字段包括dataset、primary_category、question_type、question_text、options、original_video_fps、video_path列表。官方README说另可取得957题answers档，添加correct_option_letter/answer_text/detailed_answer及global question_id，未在本次取得。
评估方式
闭集从JSON prediction解析并小写后完全比correct_option_letter，模型例外记success=False。开集先以参考字符串／数字子字符串包含规则直接给5，否则文字裁判给0–5，score>=4才算success再平均；不是单纯平均0–5分。来源通常.5fps，部分手术影格条件为1fps，original_video_fps和实际观测采样不同。

怎么接入我们的benchmark

可重用

957题唯读metadata、来源标记、原题与四选项、原作者／官方core evaluators和答案发布说明。

需要转换

source保留原作者repo与challenge repo roles；case以官方id加source version，answers档以id一对一join，global question_id未取得则不杜撰。video_path串行保存原fps/采样率和父视频映射；closed exact-match、open substring shortcut／judge／>=4规则各自版本化。

仍需补齐

尚未取得影格与需另取得的answers档，也未运行／提交。questions-only不具eval脚本必需的answer和question_id字段，不能直接以README早期命令宣称能评分。开集substring捷径需保留原作口径并另分析误判；裁判/API程序仍有外部依赖。
