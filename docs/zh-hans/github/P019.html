P019 · EgoBody

EgoBody: Human Body Shape and Motion of Interacting People from Head-Mounted Devices

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

EgoBody 官方仓库主要是数据文件与可视化／座标转换工具；它有真实来源程序，但没有在此钉选 tree 找到公开 challenge evaluator。

版本与身份

README 包含 2022 全模态发布与 2023 Motion-X 文字扩充；主程序 calibration 路径多一层 cal_trans，需以实际下载版本核对。读过可视化程序不等于重现 README 的 baseline 成绩。

领域
休闲与运动、社交与沟通、穿戴交互与动作界面
环境
HoloLens 与 Azure Kinect 同步拍摄室内双人交互。文件分 125 sequences、36 subjects、15 scenes；环境以 scene_name/mesh 追溯，EgoSet、MVSet、interactee-visible 子集不是三批新场景。
任务
第一人称观察交互对象／穿戴者的 3D 人体 pose、shape、motion。Motion-X 的后加文字描述是衍生标注，不能直接视为原版任务或机器人协作成功。
题数与数据
data_info_release.csv 含 recording_name、body_idx_fpv、start/end_frame、scene_name，data_splits.csv 定义 sequence split。PV 图像名以 timestamp_frame 连 Kinect frame；pv.txt 提供每 frame 的 fx/fy/pv2world，keypoints.npz 有 BODY_25、center、scale；valid_frame 以至少 6 个 OpenPose 关节为可见条件。SMPL/SMPL-X 参数在 master Kinect RGB 座标。
评估方式
README 列 MPJPE、PA-MPJPE、V2V、PA-V2V 原作者结果与 challenge 链接；本次没有取得其精确 scoring 实作，因此不能由渲染器推定对齐／遮罩／单位的评分规则。核读渲染器确认 Kinect→HoloLens world→PV 变换及 OpenCV/OpenGL Y/Z 翻转。

怎么接入我们的benchmark

可重用

场景／recording/split 索引、时间同步、有效影格、人体参数与相机转换流程。

需要转换

scene_name 作 environment 关联，recording 与人物角色分开；case 保留 timestamp/frame、相机和 body index。EgoSet_interactee 作同源 subset；范围外 frame 依 start/end 丢弃，另记 valid 遮罩。pose shape profile 保留 SMPL 与 SMPL-X 模型版本。

仍需补齐

尚未取得注册后数据与人体模型，亦未运行或取得 challenge evaluator。需补齐原作的关节集合、对齐、可见性与 mesh error 协定，再标可评测。
