P222 · Uni-Hand

Uni-Hand: Universal Hand Motion Forecasting in Egocentric Views

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

已核读Uni-Hand human-video demo与作者指向的MMTwin/EgoPAT3D reader及具体ADE/FDE。主库现行流程只以首影格条件预测右手腕与接触转换；不能将论文全部2D/3D、多关节、head-motion及robot结果视为同一套已公开评测。

版本与身份

主库commit 7f3edd5955fcb786b78b343510d7b2297694393b；MMTwin commit bd0faf148ae574accd5a4c1e7cd173f6416a52e6。README称toy有100段视频，而本版split roster是100 train+5 test，保留此粒度/版本差异。主库unseen_envs已标deprecated且两个test loader读同档；MMTwin的test_novel才是实际不同scene split。论文表1的USST修正引用不能视为本轮已核读或新版metric等价证明。

arXiv:2511.12878v4（2026-05-11），Junyi Ma等，精确题名Uni-Hand: Universal Hand Motion Forecasting in Egocentric Views。PDF连作者项目页，页面Code指IRMVLab/UniHand、Data指IRMVLab/MMTwin；MMTwin README反向指Uni-Hand为extended version，本身论文为2504.07375。项目页footer的nerfies是网页模板，论文USST erratum是baseline依存，均非本篇模型库。

领域
穿戴交互与动作界面、通用对象与机动作业、居家整理与清洁、餐饮与烹饪
环境
主库为RealSense L515人类示范的pick-and-place／open-door场景，首RGBD影格产生固定相机座标点云；MMTwin用EgoPAT3D-DT移动头戴视角，以odometry将轨迹表成首camera参照。CABH的cup/apple/box与HAT robot-transfer属论文/前身不同子集，不可和主库toy split混成独立robot environment registry。
任务
Uni-Hand论文涵盖手部2D/3D中心与指定关节、head motion及contact/separation；本次主库实际epoch loop取joint0，注明TODO multi-finger，preprocess只读right_keypoints；motion_feat为全零，视觉使用第一张feature，观测mask只保留第0个手腕点。输出是未来腕点与两个接触/分离峰，非完整21关节姿态，也不是可直接运行的末端action。
题数与数据
主库以date folder读traj3d_in_cam_dict_refine.pkl、date.npy视觉特征、rgb数字文件名与date_folders.csv。所谓traj3d原始值实为21×(u像素,v像素,depth-mm)；reader对depth除1000、u/w与v/h、z/max_depth后各减0.5，保留有效frame IDs，截/零补至40。CSV两个原始frame ID映到有效串行的0-based index；没有FPS/秒换算。config为1280×720、max_depth=1、50³ voxel、0.02公尺格、origin[-0.5,-0.5,0]。split档有100 train与5 test唯一ID且无交集；它们是清单笔数，未下载素材核验有效case。val/test/test_novel全部走同一test_split.txt。MMTwin则有明列scene/record train/val/test；novel scenes13/14/15，pkl读traj2d/traj3d/num_preserve，最多40点，3D以odometry连乘转首camera，再以(u/w,v/h,z/3)-0.5编码，非train的未来motion/odometry先以最后观测值替代。
评估方式
主库实际scorer在epoch_feat.py：单次diffusion sample，gap=1、3点moving-average平滑；加回0.5并以内参反投影XYZ，z使用预设max_depth=1，单位公尺。future slice=[1,nframes)，ADE先对该case所有有效未来点的Euclidean error取平均，FDE只取最后有效点，最后对case平均，非全数据逐frame加权。CE将future contact曲线Gaussian平滑、取最高两个局部峰并排序，两个峰的绝对index误差平均后再跨case平均；缺峰用-1补而未剔除。存在明确索引疑点：pred峰是future slice相对index，GT是完整valid串行index，scorer未加start_=1或减GT offset，CE不是可直接当秒的MAE。MMTwin actual loop用固定ratio（预设0.6），floor(nframes×ratio)作观测长度，单次sample；相同逐case ADE/FDE，test_space=3d为公尺，其他值走投影、clip/floor像素再除图像尺寸的2D距离，并非best-of-K。论文robot SR为每task 10次trial的报告；已读repo没有该robot成功checker。

怎么接入我们的benchmark

可重用

重用两库各自split与reader、有效frame index、内参/voxel设置、逐case ADE/FDE与contact峰值定义；保留MMTwin为前身与母数据转接来源。

需要转换

case以repo版本+dataset+scene/date/clip+观测长度识别；把u/v/depth-mm、范式latent及XYZ-m分开保存，记录camera参照与有效frame至原frame映射。evaluator分开ADE、FDE、CE、paper-reported robot SR，保存每case未来点数、sample数、smoothing/gap与ratio。grasp_offset属另行校准的camera-frame几何转换。

仍需补齐

RGBD、refined trajectories、特征、点云与weights未取得，roster不等于可运行case数；需修正/核验CE offset、缺峰策略、改max_depth时的反范式一致性。需补独立validation/novel split、论文其余数据集/多target/robot协定，以及相机到robot基座外参、运动控制与成功判定。MMTwin不能充当Uni-Hand所有新版结果的实作证据。
