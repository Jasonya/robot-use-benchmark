P248 · HOIMotion

HOIMotion: Forecasting Human Motion During Human-Object Interactions Using Egocentric 3D Object Bounding Boxes

返回逐篇总表内核内容已核读 方法／综述参考原作 ↗

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

HOIMotion 以过去人体姿态和头部视角的 3D 对象框预测人体动作，重用 ADT／MoGaze。已核两套 loader、跨参与者设置与 MPJPE；对象框顶点、图节点和人物关节都不应计为任务数。

版本与身份

官方来源固定 commit；ADT preprocessing 明载数据版本 1.1.0。default script 的 train→eval 不是唯读测试命令，没有在本机运行。

领域
方法／综述参考，未另作来源用途归纳。
环境
Aria Digital Twin 与 MoGaze 的人类对象交互场景；ADT 原生 work／decoration／meal 三活动类，MoGaze pick／place 两类，不能把五个标签当五个新独立物理环境。
任务
单一人体 3D motion forecasting 任务，按用途与 holdout participant 分组。21 joints，10 个过去 frame→30 个未来 frame（评分假设 30 Hz）；两个 dynamic／两个 static objects，各 bbox 八个顶点作模型输入。
题数与数据
原生 .npy 档依 sequence 提供 pose xyz、head、dynamicbbx、staticbbx；loader 各自排序后用相同 list index 配对。每个连续 40-frame 窗口可重叠，train_sample_rate=2 只抽窗口，不把视频 FPS 降半。MoGaze 测试 p1／p2／p4／p5／p6／p7 六个 holdouts，每人可有多个 session。
评估方式
MPJPE=未来各关节 xyz 欧氏距离的平均，先 batch 平均×batch_size 累加再除总 sample；输出 mm、每未来 timestamp／joint 另列。zero-velocity baseline 重复末个观测 pose。velocity loss 仅训练用，没有加到报告 MPJPE。ADT training 将 test 目录作 validation 选 best checkpoint；MoGaze 也以 holdout participant 作 validation，完整模型选择条件应保留。

怎么接入我们的benchmark

可重用

可重用两父数据的 actor/session、动作标签、21-joint pose、3D bbox 与原生 MPJPE；用户研究 N=20 是独立感知评价，不并入样本题数。

需要转换

标准 case 以 parent sequence／window 起点识别，明定 30 Hz、21 joints／米、过去 bbox 可见性与 split role；文件配对改用 sequence key 并验证一致。添加真正 untouched test split 时另列为扩充协定。

仍需补齐

本次未下载 ADT／MoGaze 原始素材、未运行训练。各用途的精确窗口数需由完整文件 manifest 重算；原始数据及工具授权／版本各自保留。
