P126 · DROID

DROID: A Large-Scale In-The-Wild Robot Manipulation Dataset

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

DROID有原始搜集平台与policy-learning两个官方仓库；raw/RLDS、更新语言与相机标定是同一来源的不同发行物。实机成功由人员标记。

版本与身份

2024-12添加75k成功episodes的多语言、2025-04更新36k标定为作者公布更新，不添加独立数据集。policy loader依赖Octo85b83fc，不能自动换成目前HEAD。

领域
居家整理与清洁、餐饮与烹饪、办公与教育
环境
多站点DROID robot及相机配置；schema有lab/building/scene_id/robot_serial与外参，不用平台数代替环境数。scene_id=-1表示未提供值，须保留未知而非新场景。
任务
language/goal条件对象操作；示范、失败、下游自选任务和eval trials不同集合。三句语言描述对同episode不增加实体轨迹。
题数与数据
raw为trajectory.h5、metadata与多视角MP4/SVO；RLDS有episode_metadata和steps含3图、state、action_dict、多语言与episode flags。training transform用cartesian_position转pos3+rot6+gripper1，另移除第一action；预设只取success路径及有语言数据。
评估方式
实机GUI由人员按键保存success/failure，metadata未提供success时为None。RobotEnv的step返回action_info，不能当task success。文件flat action7D注解提6joint velocities，但RobotEnv区分cartesian7/joint8，使用时应以明确action_dict及converter核对语义。

怎么接入我们的benchmark

可重用

UUID/lab/scene/version、原始与RLDS映射、相机标定、action_dict、人评标签。

需要转换

一个parent episode连raw/RLDS/语言更新/标定版本；case固定模型可见相机、座标/control mode、初态与人评rubric；training选样不得当完整benchmark分母。

仍需补齐

大型素材、UUID至更新标定/语言的全量join、原成功标签和case集合、原生评分者一致性、实机或匹配模拟运行。
