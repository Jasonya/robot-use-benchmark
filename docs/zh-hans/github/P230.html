The Invisible EgoHand: 3D Hand Forecasting through EgoBody Pose Estimation

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

EgoH4 评测由头部／图像与可见 2D 手位置推估及预测 3D 手部，特别区分视野内外。已核对数据模块、20+10 帧切分与 metric 实作；这是 EgoExo4D 上的新评测任务，不是新采集的一批视频。

版本与身份

固定目前官方 commit；trainer 注解有 17-joint 遗留文字，但实际使用 57 joints。future condition 于 decoder 被排除，不能因 sample 接收 GT-shaped tensor 就直接判定数据泄漏。

领域
穿戴交互与动作界面
环境
EgoExo4D 的 Aria 头部相机、相机姿态及人体／手部标注。机器人控制与物理成功不在本来源评测范围内；场景应沿用父 take。
任务
3D 手轨迹及手姿态 forecasting，并可分离观测段 reconstruction；native 30 帧中前 20 帧观测、后 10 帧未来，按可见／视野外比例分组。全身 57 joints 是移除重复 wrist 后的输出维度，不是 57 个任务。
题数与数据
论文报告约 156K train／34K test sequences；公开 config 的 test.split=val，并 concatenate manual body dataset 与 manual hand+auto body dataset。窗口 size=30、slice=1、frame interval=3，需保存 take_uid／start_frame 和标注类型，避免把交叠片段或不同标注视为独立原片。
评估方式
原生 evaluator 分 body／wrist／hand／full，计 obs/fut ADE、末帧 FDE、10 个未来 timestep 和 in-/out-of-view 子群；不以单一 success 评分。calc_jpe 先乘 visibility，再以 jpe!=0 筛选，会连真正零误差也排除。该固定版本以绝对座标 L2 计手部误差，没有在所读 test_step 运行 wrist-relative 对齐；比较论文相对 MPJPE 栏时必须核对。

怎么接入我们的benchmark

可重用

重用 parent take／sequence indexing、可见性标注、原生 20+10 与分组 evaluator。；以各分项原生误差作基准；0…1 视野外比例是 case 属性，不直接标成难度分数。

需要转换

canonical case 固定 observation boundary、camera／pose 座标、joint order、3D／2D masks 及 annotation provenance。；保留 native evaluator；修正零误差 mask 或添加 wrist-relative metric 时另建协定与相同 fixture 对照。；test dataset 所称 test 对应父数据 val，标准格式同时保留两个 split 名称。

仍需补齐

本次只查核列出的公开来源段落，未取得完整数据或运行 diffusion。；body／hand concatenation 之重叠 take 与实际数量需要用下载后的 annotation manifest 核对。
