RobotArena $\infty$: Scalable Robot Benchmarking via Real-to-Sim Translation

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

RobotArena∞公开Genesis测试与GVL裁判流程，但自动场景生成仍列未发布。实际GVL入口使用图像加NPZ特权状态，不是单纯视频问答。

版本与身份

固定预设branch fix/stable_version_genesis；README的Preview措辞与bash实际gemini-2.5-pro参数不同，需以运行manifest为准。未调用Gemini。

领域
居家整理与清洁
环境
真实画面转成Genesis Robot Arenas；预设／生成scene及背景、相机、对象位置扰动。∞指生成扩展能力，不是无限个已取得环境；README自动生成码未勾选发布。
任务
指定语言的操作目标在多扰动设置下评测。支持多个policy server是方法界面，不能按policy数扩大任务量。
题数与数据
预设测试65步含5步预热，存5fps MP4和同名NPZ；world/base是末端pos/quat/gripper，对象是13维pos/quat/linear/angular velocity。可加入weld抓持约束，须记assistance模式。
评估方式
GVL入口以Gemini图像＋NPZ状态评0–100进度，可做no_object/no_robot/none ablation；接触文字由5cm距离启发式推估。分数regex抓整数后clip，解析/API失败可漏frame。聚合对repeat取逐frame median，再取最高30%等；avg_last_10实际取最后num_top帧，不固定10。需固定frame身份与完整分母。
