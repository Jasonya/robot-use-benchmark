SoftGym: Benchmarking Deep Reinforcement Learning for Deformable Object Manipulation

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

已核读 SoftGym 的环境／状态界面、10 个论文任务对应的具体计分及 picker 动作。它提供 FleX 柔性物与流体交互环境；normalized_performance 是任务专属连续量，不能当共同成功率。此 commit 的 ClothFoldCrumpled reward 与 performance 存在公式差异。

版本与身份

固定 2022-01-14 commit；README 含 2021 年添加 depth rendering，不能视为原论文提交时完整快照。内核核读限所列 Python 段落，未运行 FleX、基线或加载 pickle。 已补固定SoftAgent db2fbb5d的CEM／DrQ／初态生成核心段落；未运行baseline，也未把这个后续版本当成论文完整再现。

README 的完整题名、四位作者及 CoRL 2020 引用对应 arXiv:2011.07215；不是论文引用的 CURL、DrQ 或 rlpyt 基线仓库。

领域
衣物与洗护
环境
NVIDIA FleX／PyFlex，布料、绳索、流体以粒子及 shape states 表示。预设以抽象 picker 或杯子直接控制；程序含 sawyer／franka 分支，但本次未验证 Robotics 版 PyFlex，不能据此宣称完整手臂环境可运行。布料位置为原生 xyz、y 为高度、面积投影到 xz；camera 设置使用弧度值。
任务
README 列 6 Medium＋4 Hard 任务。SOFTGYM_ENVS 有 12 个注册名称：ClothFlattenPPP／ClothFoldPPP 是同 class 的控制变体；env_arg_dict 另外有未注册项目，不能全部算任务。RopeConfiguration 的 S/O/M/C/U 为 goal 变体。num_variations=1000 是预设生成预算，未读取实际初态资产，不能当已验证 case 数。
题数与数据
初态 pickle 保存 (cached_configs, cached_init_states)，以 config_id 关联；Flex 状态有 particle_pos(N×4，xyz＋inverse mass)、particle_vel(N×3)、shape_pos(N×14)、phase、camera_params。液体子类改用 glass_x／glass_y／glass_rotation、glass_states、poured_glass_states、glass_params 等字段，不能硬套同一状态 schema。布料 config 含 ClothPos／ClothSize／ClothStiff／camera_params／flip_mesh。观测可为 cam_rgb、key_point 或补零粒子 point_cloud；RopeConfiguration RGB 与 goal RGB 沿通道拼成 6 通道。未指定 config_id 时，训练从前 80% 初态抽取，eval_flag 从后 20% 抽取；1000 配置因而对应 800/200 索引，非 rollout 次数。 补核SoftAgent：generate_cached_states设置num_variations=1000，但main覆写env_names为仅ClothFold；DrQ预设num_variations=1，README要求另设1000才对应原论文条件。CEM输出initial_states／action_trajs／configs，不能把100万train steps或候选rollouts计为题数。
评估方式
FlexEnv.step 在 action_repeat 次物理步后计算 reward／info，到 horizon 才 done，没有通用成功门槛。ClothFlatten：100×100 xz 占格面积；ClothFold：−平均对应粒子距离−1.2×固定半侧偏移；ClothDrop：−平均粒子至 target_pos 距离；ClothFoldDrop 沿用 ClothFold。ClothFoldCrumpled 的 reward 以 flat_pos 与 norm(mean(...,axis=1)) 算固定项，info 却以 init_pos 与 mean(norm(...)) 计算，两者不能互换。RopeFlatten：−|端点距离−绳长|，以 −绳长与 0 范式；RopeConfiguration 预设对下采样点做 Hungarian 最小配对距离。PassWater：−10×杯外粒子比例−|terminal_x−glass_x|；PourWater：目标杯内且控制杯外的粒子比例；PourWaterAmount：−|int(N×target_amount)−目标杯有效粒子数|/N。多数 info 用初态与上界范式、未裁切；PourWaterAmount 延用父类 reward_max=1，与其负误差理论上界 0 不同。 补核SoftAgent实际baseline：CEM取得完整env state，在副本环境set_state后逐candidate累加reward作成本；是可查找真实模拟动力学的oracle规划条件。预算由timestep_per_decision／max_iters／plan_horizon决定。DrQ使用sample=False推论，报每episode回报的平均，以及info的episode×time平均与末帧平均；这些不等同任务成功率。

怎么接入我们的benchmark

可重用

任务 class、原生 task 名称、具体 metric、可重设的 config/state、camera 与 action_mode 设置。

需要转换

source→固定 commit；environment→FleX 场景与物理设置；task→论文目标并保留注册别名；case→config_id＋状态哈希＋split；evaluator→各 class 公式。保留 raw reward、performance、normalized_performance 三栏及 oracle/RGB 权限。picker 每支为 [dx,dy,dz,pick]，位移范围 ±0.01、pick>0.5；PPP 为 [x,y,z,pick]、内部步长 0.01，最多 300 步，不把 horizon 当秒或影格。

仍需补齐

初态／rope goal 资产与生成 seed 的清单；SoftAgent其余算法及paper checkpoint／跨seed聚合的完整闭合；ClothFoldCrumpled 与 PourWaterAmount 的 evaluator 差异决策；PyFlex 运行及分母为零的验证。
