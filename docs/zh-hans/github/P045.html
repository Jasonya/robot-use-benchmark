ManipBench: Benchmarking Vision-Language Models for Low-Level Robot Manipulation

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

ManipBench将真实机器人图像、布料及模拟图像问答拆成三个仓库；问答正确率与另行运行机器人的成功率须分开。 2026-10-11 补读官方直接链接的 robot-side 实作；仓库有实际运行程序，物理成功由人工输入纪录。

版本与身份

Fabric README保留main_old.py为论文版。真实Q1打印len(episodes)分母与回传有效total_count不同；Q2额外点数注明不是论文指针。 robot-side 固定 e25872ebd357559d5675daa07d05268afd5bd0b8；官方 question README 第25行证明其角色。readme.md 列的 moka_real_world_image_preprocess.py／moka_real_world.py 是服务器指令且不在此 robot repo 完整 tree；实际本地入口由 run.sh 和 pipeline main 确认。这是已取得的实作与尚待配对的环境／服务器契约，不是空白 README 或整库 unavailable。

领域
衣物与洗护
环境
题目使用真实或模拟场景图像；图片不等于相应可交互环境已取得。 补读 MOKA robot-side 路径使用 RealSense RGB／depth、已校准的相机到机器人 base 矩阵及预设右臂／夹爪；这是需现场设置的物理实验入口。
任务
真实数据含抓点与路径选择、抓点和落点双问；布料含状态、空间、时序和反事实题型。
题数与数据
question/options/answer/image或多图JSON；真实数据用correct_answer.json、wrong_answers_v批量、格点及随机候选顺序；完整图片外部提供。 补读：run.sh 指向 moka_real_world_pipeline.py，工作目录按 tasks/task_name/model_Vversion 创建。info.json 传 model_info、version、图像与 task_description 路径、点／格数；服务器 log.json 提供 plan_success、picking_point、points、end_point 和可选 height。相机存 color_image.png、显示用 depth_image.png 与原始 raw_depth_image.npy；程序用 depth[y,x]/1000 反投影，Z 再加 0.005，经固定 4×4 校准矩阵转 base。
评估方式
真实Q1解析选项后比对correct标记，Q2分抓点与落点；布料main.py比对答案；模拟脚本以文件名编码GT选项。解析失败、缺档及分母规则要保留。 补读：plan_success 只决定是否有抓放点可运行，不能当物理任务成功。generate_exp_seq.py 对模型次序 random.shuffle，运行后人工输入 y/n，其他输入记 false，将 {task_name_version: bool} 加入 vlm_list.json 的 task_tested，最后才写回。已读路径没有由传感器自动判定物理成功；其人工纪录、运行中止与问答 checker 的分母需分开。

怎么接入我们的benchmark

可重用

三子集的题目格式、GT、候选生成及答案检查。 可另重用 robot-side 的 info/log 契约、逐次模型／任务版本纪录及人工成功字段，作为独立物理 trial profile。

需要转换

case保留父episode、题型、候选批量与顺序、图像及答案引用；固定抽样seed，不将候选变换算成新的语义任务。 物理 trial 另保留 task_name、version、model、相机 intrinsics、raw depth 尺度、crop、calibration、抓放点／高度、人工判定来源与中止原因；原 VQA profile 不因此改成 robot episode。

仍需补齐

完整图片、版本一致题目集、统一解析与分母契约；物理操作另需robot-side实验程序。 更新：robot-side 选定源代码已补读；仍需配对服务器脚本／task_description、现场相机／机器人设置、可重播试验清单、人工判定规则与 seed。capture 路径未记录 depth_scale 或显式 RGB-depth 对齐；height_required 分支的 log.height 注解为 mm 却未作 /1000，需先验证单位，不能直接运行为标准 case。
