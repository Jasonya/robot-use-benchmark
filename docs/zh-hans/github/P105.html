领域
居家整理与清洁、餐饮与烹饪
环境
重用LIBERO桌面，扩充对象、纹理、相机、光照、机器人初态及noise。多扰动名称不代表不同房屋或独立原始数据。
任务
7扰动维度；分类档结构计数：spatial2,402、object2,518、goal2,591、libero_10为2,519，合10,030。这是native variant entries，不是本库10,030去重语义目标。
题数与数据
Task保留name/language/problem_folder/bddl_file/init_states_file；getter依_language_/_view_/_table_/_light_等字样回取共同或专属初态。分类JSON的id基准与API task index需明确映射。
评估方式
具体_check_success逐一AND goal_state predicate；rollout在max_steps内累积done成功。README要求num_trials_per_task由50改1，是该扰动协定，不等同所有来源都一试可充分估计成功率。difficulty_level为作者扰动级别，尚非跨benchmark校准难度。
