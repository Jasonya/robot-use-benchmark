DRAPER: Towards a Robust Robot Deployment and Reliable Evaluation for Quasi-Static Pick-and-Place Cloth-Shaping Neural Controllers

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

DRAPER的来源分散在SoftGym扩充、Agent-Arena和real-robot界面；两个仓库已有改名。需固定三者版本、数据模式与task config，不能把同一布料环境的fork视为独立benchmark。

版本与身份

softgym-deepcloth解析到halid1020/softgym(8a21966)，agent-arena-v0解析到actoris_harena(4d9c9c9)，硬件库405d4c2；目前generic框架不等于原论文固定实验release。

领域
衣物与洗护
环境
共用SoftGym布料整形与realadapt towel场景；realadapt config声明1000variation，但eval tier只取30、val取3。Franka/UR3e是另一硬件界面层，未运行。
任务
主要布料摊平/整形及跨sim-real适应；domain字符串如rainbow-rectangular-fabrics是布料分布设置，不是生活用途domain。多论文共享initial_states需创建reuse关系。
题数与数据
TrajectoryDataset以observation/action/goal/trajectory_lengths存数据，T+1观测对T个action并附terminal补0；whole/cross-trajectory模式与goal索引需验证。实机界面RGB由BGR转换，v1/v2 depth作单frame min-max并将背景置1，已非metric depth；action为4个[-1,1]pick-place座标另带orientation。
评估方式
Towel flattening成功需要keypoints全可见且normalized coverage≥0.99，canonical模式另加IoU。记录coverage/improvement/形状距离与首次成功步；perform_single可因environment done、agent terminate/success、arena success或max_steps终止，因此done不等于完成。当前towel.step调用reward参数数目与定义不同，正式adapter需修正/验证。
