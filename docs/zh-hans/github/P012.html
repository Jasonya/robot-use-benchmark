HD-EPIC: A Highly-Detailed Egocentric Video Dataset

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

HD-EPIC 的标注包含动作、对象移动、凝视、食谱／营养与音频；VQA 原始 schema 支持多视频／片段。已追到主程序实际使用的 BaseVLM 与 LlavaVideo 评分，而非把旧单视频 Dataset 当作全部界面。

版本与身份

固定提交文件已添加 MP4 对齐的中介 calibration／pose／gaze；不得假定与原论文首发资产同版。文件明列 mask 与 bbox 由不同团队标注可能不一致；YouTube 版本只供观看，不作复现输入。

vqa-eval README 自述为 HD-EPIC CVPR2025 benchmark 程序，指向官方 annotations；已核对项目名称和实际数据路径。

领域
居家整理与清洁、餐饮与烹饪
环境
佩戴 Aria 眼镜的真实厨房活动及对应 digital twin／fixture。video、participant、capture、fixture、3D 场景的 ID 分开，不把多个传感流计成新环境。
任务
以每个 JSON 的 question prototype 管理五选一 VQA；动作、对象关联、凝视 priming、食谱和声音是标注层，各自不自动成为可运行任务。
题数与数据
叙述含 unique_narration_id、秒制 start/end_timestamp、另列 narration_timestamp、多个 verb/noun pairs 与 main_actions；assoc_info 连到 mask_info 的 0-based MP4 frame、XYZ、XYXY bbox、fixture。音频以 48kHz sample index 标示。VQA 含 inputs/question/choices/correct_idx（0-based），保留多个 input 的 id 与时间窗。
评估方式
主程序调用模型 run_eval；核读 LlavaVideo 的 answer==correct_idx，再由 run_benchmark 对结果平均。BaseVLM 取回复第一个大写字母转选项索引；invalid 回 -1。analyse_output 按 prototype 前缀分组，另列 invalid／failure。输入会按模型 max_video_length_seconds 降采样，须一并报告 input_total_seconds 与 input_subsampled_seconds。
原作数字：保留论文的单位与页码

怎么接入我们的benchmark

可重用

原始标注层关联、五选一题目、时间／框 tag 解析、同输入题目分组及正确率流程。

需要转换

用原生 question ID 建 case，inputs 保留多视频与框；同一次 capture 的多传感／多题重用同一环境记录。保留完整毫秒时间和原始座标，另记 native adapter 对时间取整秒、框转 0–1000 的行为；模式 visual_text／narration 与采样预算入 evaluator 约定。

仍需补齐

尚未下载数 TB 传感数据、校准／digital twin 或运行模型。各模型 wrapper 的 parsing／API 版本仍需个别验证；data/vqa_dataset.py 只支持单视频且旧字段与正式 VQA 不同，不能直接通用。
