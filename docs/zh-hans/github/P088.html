FlingBot: The Unreasonable Effectiveness of Dynamic Manipulation for Cloth Unfolding

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

已核读 FlingBot 的模拟／真机 task 与 replay HDF5、coverage checker、evaluation 入口及汇总。原生 task 是衣物形状／材质／初态的一笔配置，目标仍是展布；模拟与真机 coverage 的原始单位不同。另确认非重复 loader 的末笔等待问题及汇总过滤会影响分母。

版本与身份

固定2021-10-13 commit，原论文PDF缓存为后续2021-10-18版；保留版本差异。environment/Memory.py是symlink文字，实作读到learning/Memory.py。未运行任何模拟、GPU模型、机器人控制或下载衣物HDF5。

论文 arXiv:2105.03655 与 README 作者 Huy Ha／Shuran Song 对应。binding 的 columbia-robovision/flingbot 在缓存 GitHub metadata 解析为 real-stanford/flingbot；保留 requested_repo 与 resolved_repo，不能当两个独立来源。论文亦使用 columbia-ai-robotics 旧网址。 旧入口columbia-robovision/flingbot的已保存GitHub metadata回应指向real-stanford/flingbot，按仓库别名保留，不另外算成未读的第二个仓库。

领域
衣物与洗护
环境
模拟为修改 SoftGym/PyFlex 的 CUDA 粒子布料环境，抽象双picker配合UR5可达性边界；使用Blender或OpenGL，论文设置为Blender。真机为两支UR5、RG2／WSG50、顶视Azure Kinect及前视RealSense；setup.py 只留一件衣物参考与设备位置参数，未提供完整论文实体资产清单。
任务
展布／最大覆盖面积是一个目标族；Normal Rect、Large Rect、Shirt 是形状／尺寸泛化设置。fling、stretchdrag、drag、place 是 action primitives，不是四个新的生活任务。TaskLoader 的 task_name 是 HDF5 配置ID；生成group key是对当时记录数字取SHA1，不是状态内容哈希。论文600模拟测试配置＝三类各200，真机三类各10次；2000训练配置及150真机调适回合另列，未下载HDF5验证实际记录数。
题数与数据
task HDF5 以group保存 particle_pos、particle_vel、shape_pos、phase、cloth_size、cloth_stiff、mesh_verts／faces／stretch/bend/shear edges；flatten_area、initial_coverage、cloth_mass、task_difficulty为attribute。方布尺寸为粒子数，预设半径0.00625m；mesh尺寸用[-1,-1]、flatten_area取trimesh面积/2。replay每个 {episode:09d}_step{step:02d}（尾步加_last）为一笔action；含observations、actions单像素mask、rewards、is_terminal、next_observations及rotation/scale/action_primitive/task_name/preaction_coverage/postaction_coverage/max_coverage。RGB/255＋depth为4×H×W、策略预设仅用RGB与64×64输入；action需连同图像旋转缩放与可达性转换解码。
评估方式
模拟coverage是100×100 xz占格的面积（原生m²）；step reward为A_after−A_before，学习label预设再除flatten_area。方布reference来自展平网格，mesh取表面面积/2。真机coverage是HSV背景分割后最大连通区像素占全图像比例，再除同相机的flatten_area参考；不能把此原始值当m²。10 primitive actions内可提前终止：模拟最大粒子位移<0.05，真机前后mask IoU>0.9，均代表停滞而非成功。collect_stats报normalized final/best/delta coverage，未裁至[0,1]；跳过failed_grasp/cloth_stuck/timed_out、缺max_coverage及postcoverage/reference<0.05的记录。其episode_length直接读零起始尾步索引，真正动作数需+1。run_sim预设统计最近128个step groups；visualize.summarize用1e7上限读全buffer，不可把在线平均当全测试分数。

怎么接入我们的benchmark

可重用

Task状态重设、HDF5 reader/writer、action transformation字段、raw与normalized coverage及failure flags。

需要转换

source保存旧repo别名及resolved commit；environment分模拟／真机与renderer；task保存展布目标及primitive；case用dataset哈希＋task_name＋形状设置；rollout另存episode/step/action_count；evaluator明列面积或像素比例、reference方法及过滤后分母。

仍需补齐

三测试HDF5／训练HDF5的哈希与mesh split；nonrepeat loader末笔问题修正或保留原版行为；未排除失败的系统评测分母；真机衣物完整表、校正与背景设置；native step index转操作次数验证。
