AntGPT: Can Large Language Models Help Long-term Action Anticipation from Videos?

返回逐篇总表内核内容已核读 方法／综述参考原作 ↗

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

AntGPT用LLM产生未来动作串行；Ego4D v1/v2、EPIC55及EGTEA仍是父数据，文字解析及串行修补是评测契约的重要部分。

版本与身份

此核读针对指定GPT ICL脚本；不能把其他GPT/Llama/Transformer脚本的配置及成绩当同一协定。

领域
方法／综述参考，未另作来源用途归纳。
环境
视频、caption／动作上下文和既有数据切分，非交互模拟环境。
任务
长期verb/noun/action串行预测；候选串行及不同语言模型不增加独立任务。
题数与数据
taxonomy/dicts.json、上下文与未来动作文字、LLM回应及相似度检索池；脚本将串行截断或补齐为20动作，并做词汇映射。
评估方式
eval_icl.py逐样本取K候选最小范式editdistance.eval。短/空答案有补齐策略，未知词有模糊匹配和预设类别；action ED在此脚本使用verb/noun索引相加，需与官方定义核对。
