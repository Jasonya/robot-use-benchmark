DreamDojo: A Generalist Robot World Model from Large-Scale Human Videos

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

DreamDojo具有动作条件视频生成的真实评估入口；内核输出为PSNR/SSIM/LPIPS。预训练视频时数、评估样本与机器人可运行任务需分开。

版本与身份

固定02f119b；从docs/EVAL追到cosmos_predict2/action_conditioned.py，不误把套件内一般VQA metrics当作本论文主scorer。没有下载44k小时数据或权重。

领域
居家整理与清洁、办公与教育、工艺与修缮、装配与生产作业、零售与购物、交通移动与车辆维修
环境
GR-1实验室机器人视频、EgoDex与DreamDojo-HV评估素材；人类视频库是预训练来源。README宣称44k小时不表示本次已取得或等量可评测。
任务
由首影格和动作串行预测后续视频；文件In-lab清单含10个原生dataset路径，另有EgoDex/HV两组来源。路径、100个抽样与49frame是不同单位。
题数与数据
统一reader输出video/lam_video/action/fps/num_frames/__key__/padding_mask/image_size/ai_caption；根据path字符串选MANO、一般视频或LeRobot。LeRobot schema保留state/action的start/end、rotation_type、absolute。restrict_len可以指定100，不等于底层独立episode总量；文件定义train前95%、test后5%，full全量，须落实固定抽样清单。
评估方式
生成片与GT先转[0,1]逐frame算PIQ PSNR/SSIM/LPIPS，再对样本平均；这段没有排除首个条件影格。恢复筛选查找*_psnr.json但输出为*_metrics.json，可能重算；plot脚本只接受恰501个档的文件夹。以上是程序限制，尚未运行验证，也不是robot物理成功率。

怎么接入我们的benchmark

可重用

评估集分组、LeRobot modality metadata、可追到metric实作的生成入口。

需要转换

以原生clip/episode ID和实际采样frame作case；保存action representation、完整GT视频及不可见未来、scorer前处理；预测视频与物理环境分列，父EgoDex重用关系明确。

仍需补齐

固定抽样及ID清单、checkpoint/套件版本、条件影格是否计分与断点恢复修正、原生跑分和物理行为有效性checker。
