TEACh: Task-driven Embodied Agents that Chat

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

TEACh需要保留game→EDH/TfD instance的关系；两种题目检查不同目标。现有CLI有静态可见的漏题／变量问题，不能下载后直接宣称可评测。

版本与身份

2022-12修订只保留有助主任务的EDH状态变化，删无相关变化instances与2个valid_unseen game；不能混用早期paper数字与当前文件。软件／图像／其他数据授权分开。

领域
居家整理与清洁、餐饮与烹饪、协助、交接与陪伴
环境
AI2-THOR家务场景，Commander与Driver/Follower不同视角和角色；game可派生多个EDH或TfD片段，不能各自算新屋子。
任务
EDH依对话／操作历史完成后续指定状态改变，TfD依完整任务参数检查终态。task definition有components、数量determiner及relations；Toast要求BreadSliced且isCooked=1。
题数与数据
game_id、instance_id、driver_actions_future、state_changes、expected_init_goal_conditions_*，输出game含初／终态objects及custom_object_metadata。dialog acts是后加da_metadata；答案状态不能当一般模型输入。
评估方式
EDH从state_changes建checker；TfD取原task_id并套task_params。check_episode_progress合成component/relation的成功与条件数。GC分母扣除初态已满足部分；PLW依future动作长度。cli/eval.py有未定义edh_instance_files纪录行，且缺输出题创建error纪录后未加入traj_stats；需修正并保留原版差异，否则可能阻断／漏计分母。这是静态阅读发现，未运行重现。
