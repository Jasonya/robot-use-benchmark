RoboMME-Interference: Benchmarking Robot Memory Under Interference

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

RoboMME-Interference在既有RoboMME任务上添加跨session干扰规则；已取得并结构核对25,200列发布结果，这些是多方法rollouts，不是25,200种任务。

版本与身份

此repo主要提供cross-session分析与检索扩充，README重现指令能重算发布CSV图表，不代表重新跑25,200个机器人试验。

领域
通用对象与机动作业、装配与生产作业
环境
重用RoboMME场景与任务；lesson session、k个干扰session、query是历史条件，不是增加k个新的场景种类。
任务
9native任务家族，no-history/k0/k1/k3/k7；同一query跨memory系统重跑属trial比较。原作者easy/medium/hard另为来源标签。
题数与数据
CSV已结构计数25,200rows，含variant/family/split/episode/seed/difficulty/condition/success/status、buffer构成与latency字段；前2例latency等字段为空。取得结果CSV不等于取得每次图像／状态或独立验证运行。
评估方式
analysis以字符串true转success_bool，按variant/condition及family分组计分母与Wilson CI。视觉gate利用lesson_span/filler真实边界校准阈值，再以query相似度选segment；校准集合须和最终test分开，purity/coverage是检索品质，不是物理成功。

怎么接入我们的benchmark

可重用

query/lesson/distractor protocol、发布结果表与原生聚合、检索选框证据。

需要转换

case固定query父episode、历史session有序列表、memory budget与k；trial才连variant/result。原task来源仍是RoboMME，不重算为独立新任务库。

仍需补齐

底层RoboMME环境/政策版本与可运行资产、历史图像/embedding、校准split证据、相同query配对不确定性及完整运行回执。
