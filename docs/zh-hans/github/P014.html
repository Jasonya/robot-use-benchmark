Ego-Exo4D: Understanding Skilled Human Activity from First- and Third-Person Perspectives

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

Ego-Exo4D 的主文件、姿态、步骤与视角关系仓库分工明确。已核对共享步骤 ID、姿态有效关节／座标以及具体评分；挑战年份与论文任务清单不能混为一谈。

版本与身份

已钉选文件的 challenge 页为 2026，但 pose 仓库 README 仍列 2024；不能把当年开放的 2 项挑战当整个 benchmark 覆盖量。body loader 排除含 bouldering 名称的 take 并依相机／标注可用性筛选，应保存实际纳入清单。relation README 的 translation 仍写 Coming Soon，不能只凭此推定 tree 完全无相关程序。

领域
餐饮与烹饪、个人照护、交通移动与车辆维修、休闲与运动、音乐与表演、穿戴交互与动作界面
环境
同时拍摄第一／第三人称的熟练活动，文件举运动、音乐、舞蹈、自行车维修。以 take_uid 连多相机与标注，camera 数不等于环境数，scenario 是活动分类。
任务
步骤辨识／程序理解、穿戴者身体／手部 3D pose、ego-exo 对象 correspondence 等分成子挑战。taxonomy 的 step_id 仅 scenario 内唯一；跨 scenario 共用步骤以 step_unique_id 表示，不能逐 scenario 直接加总。
题数与数据
keystep JSON 有 annotations/taxonomy/vocabulary，含 take_uid、scenario、segments 的 start/end_time、step_id、step_unique_id、is_essential。body loader 读 takes.json、camera_extrinsics、annotation／automatic 与可见旗标，提供 global／aria／当前相机座标选项。hand GT 以 take_uid/frame_number/right或left_hand_3d 及 hand_valid_3d 索引。
评估方式
手姿态要求 21×3、将公尺转毫米，仅有效关节计 MPJPE；PA-MPJPE 使用平移／旋转／尺度对齐，逐手影格误差再平均。offset 模式加回 GT wrist，须列成不同条件。细粒度步骤以 ego_segment_name 对齐 label_id，缺预测报错，计 top-1。correspondence 提供边界 F 与轮廓中心距离／图像对角线范式；完整聚合入口尚未验证。
