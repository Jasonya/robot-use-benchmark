领域
餐饮与烹饪
环境
EGTEA Gaze+与EPIC-KITCHENS-100脱机人类第一人称视频，包含厨房活动；没有本篇可reset的robot环境。§VI明言interaction analysis使用模拟confidence-gated decision policy，尚非real robotic deployment。母数据库约10K及逾90K action segments不是本篇已核test case清单。
任务
虽摘要反复使用short-term action recognition／temporal prefix措辞，§IV-A明确指定观测action onset之前的图像、预测紧接的next action。因此保留pre-onset anticipation标记，不将本篇径改成已开始动作的early recognition。输出是同一未来动作的Top-K候选verb–noun labels及confidence，K是候选数，不是K步未来串行。Fig.1的after 1 s为示意；实际观测时窗、提前量、采样FPS与prefix切点并未由reader固定。
题数与数据
每input以Gemini 2.5 Flash-lite black-box API及相同prompt独立抽样M=5次，temperature=0.8，每次K=10。以a[i,k]记第i次第k顺位动作、p[i,k]为该动作的verbalized confidence；这些是论文符号，非已核JSON key。Consistency逐rank多数决，c[k]为该rank支持胜出label的次数/M；Confidence-weighted逐rank以p加权，c[k]=胜出label的confidence总和／所有runs于该rank的confidence总和。PairRank先取跨runs唯一label集合A，由顺位生成pairwise preferences，再以Bradley–Terry MLE拟合s(a)，softmax成P(a)并选Top-K。rank-wise confidence不必形成总和1的类别分布，须保留各方法的原生尺度。单次baseline只有1次抽样；M、K及唯一label数不能计成额外case。缺prompt、label范式／parser、实际prediction文件、model revision、test ID与split reader。
评估方式
§III-C／IV-D：Top-1 accuracy与Recall@K按每input唯一GT动作比对。Top-1 ECE及Set-ECE均用[0,1]上的10个等宽bins；Set-ECE以z=1[GT在Top-K]为target、c_bar=(Σ_k c[k])/K为set confidence，再按bin样本占比加权绝对校准差。这是作者明定的平均confidence，不能暗换成Top-K概率总和。Selective policy只对首位label采c[1]≥τ；coverage分母为全部N个inputs，selective accuracy分母为通过门槛的inputs。Entropy另先将Top-K的c除以其总和，再算−Σp log p/log K；不得把此范式后的p倒灌到原生ECE／gating。§IV-A称官方train/test与test结果，但精确case IDs、GT取得／提交路径、匹配规则、bin边界与空bin／零coverage处理均未核到。Fig.5的K=5、τ=0.39只是澄清范例，不是预设整批评测设置或安全保证。

怎么接入我们的benchmark

可重用

可保留pre-onset next-action目标、M=5／K=10／temperature0.8、三种aggregation公式、10-bin ECE、作者定义的Set-ECE、coverage/selective-accuracy分母及entropy诊断。尚无可直接重用的已核程序。

需要转换

source固定v2与母数据集版本关系；domain/environment记人类视频观测，HRI是评测动机。每case保留onset/observation boundary、GT verb/noun、每run每rank的raw label/confidence及聚合结果；evaluator分correctness、calibration、selective utility与confidence geometry，明记confidence构造及entropy专用范式。保留abstain／retained case集合、model/prompt与采样预算，不创建跨方法通用success score。

仍需补齐

作者可确认的repo／commit、精确观测与test manifest、API model/prompt设置、动作同义词／label-ID parser、重复label及rank ties规则、Bradley–Terry拟合与正则化、零confidence／零分母／K=1 entropy边界，以及完整ECE与gating实作。实体HRI控制、clarification真值及安全验证不在本轮已取得来源内。
