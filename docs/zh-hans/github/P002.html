HowTo100M: Learning a Text-Video Embedding by Watching Hundred Million Narrated Video Clips

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

这个仓库提供视频—文字表征训练与跨数据集检索评测；HowTo100M 是训练数据源，程序的主要评测入口另外读 MSR-VTT、YouCook2 和 LSMDC。

版本与身份

本轮读取固定 commit 的公开程序；不把 README 的历史「largest」叙述当成现时排名。

领域
餐饮与烹饪、办公与教育、工艺与修缮、个人照护、交通移动与车辆维修、农业与园艺、休闲与运动、宠物照护与动物活动
环境
原作视频／YouTube 来源作观测脉络；这个仓库没有可直接当成本库交互环境的 scene registry。
任务
保留 CSV 的人类 task 标签与视频—文字检索题型；不能把字幕片段或人类活动直接改成机器人任务。
题数与数据
CSV video_id/task/path、caption 起讫时间、2D/3D 特征。loader 明示两种特征各自的采样频率；完整视频与特征由外部下载。
评估方式
eval.py 将视频与文字配对矩阵送到 metrics.py，以正确配对的排名算 R@1/5/10、median rank。README 指出 YouCook2 使用 validation 集合。

怎么接入我们的benchmark

可重用

视频 ID、字幕时段、活动标签、下游检索 split 与 metric 可以保留。

需要转换

转成 video/context 纪录与检索 case；分开保存原片时间、各特征频率及对应关系，另记真正使用的下游数据源。

仍需补齐

原始素材／特征下载闭合、跨来源视频重复、共同用途映射与本库 evaluator 接线。
