ManiSkill3: GPU Parallelized Robotics Simulation and Rendering for Generalizable Embodied AI

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

ManiSkill3的核心是矢量化场景／任务API，数据以HDF5+JSON链接episode、env kwargs和观测。读取训练loader时还要检查它是否删掉最终观测或改写label。

版本与身份

固定commit62ff3a58…。发现trajectory/dataset.py的device分支把success指定成terminated、fail指定成truncated；本库导入应保留原始label并针对此分支验证，不能盲用loader输出。本轮为静态核读，未运行重现此问题。

领域
居家整理与清洁、装配与生产作业、通用对象与机动作业
环境
SAPIEN矢量化环境可变机体、scene与对象；环境ID、asset场景与并行env数不是同一个数量。
任务
具体task子类提供evaluate，基底scene evaluate可能是空字典。PickCube成功为对象到位且机器人静止；is_grasped则另列。
题数与数据
JSON记episodes/env_info/env_id/env_kwargs；HDF5保存traj_ID和多模态obs/actions/terminated/truncated，reward/success/fail可选。训练Dataset会裁掉最后一笔obs，不适合作为原始保存格式。
评估方式
BaseEnv将success/fail合成terminated，time limit另由外层处理。baseline可输出回报、成功和失败；必须保留各自定义及矢量化episode边界。
