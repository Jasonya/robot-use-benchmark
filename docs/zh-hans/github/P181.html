RoboFolDeX: A Physical-World Benchmark for Long-Horizon Robotic Manipulation of Deformable Objects

返回逐篇总表实作尚未确认 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

完成 pinned PDF、GitHub 搜索缓存与官方 challenge 页的限量身分查找，仍未确认作者授权的公开程序仓库或数据 reader。保留长时程实体折衣任务、人工品质评分与 FoldScore 的论文规格；不以其他 cloth benchmark 或通用VLA程序替代。

版本与身份

以2026-09-18 v2 PDF为准；第3页仍称review期间省略access links，与首页已列Midea网址并存，不能据此补猜程序网址。无repo commit可记；各PDF/搜索/HTML/HTTP receipt均记本地SHA256及read范围。未运行JS、提交policy、联系作者或下载模型／数据。

RoboFolDeX 指 Chenhuan Liu、Yi Xu 等的 arXiv:2609.10243v2，机构为 Fudan／Midea／CMU。PDF第1页给出的第一方平台为 ai.midea.com/#/fold-challenge。FoldChallenge 是这篇的实体评测平台名称，不是可据以自动推定的 GitHub owner/repo。

领域
居家整理与清洁、衣物与洗护
环境
真实双臂长时程衣物整理，从篮中取衣、桌面翻转／摊平、多次折叠到最后放置／堆栈。数据涵盖桌面／家庭场景与照明、背景、layout变化；论文列Aloha、YAM、Piper、Astribot、Franka、UR5、自研移动双臂、AgiBot G2等，10+是宣称的embodiment规模，未取得完整registry。
任务
主题是衣物折叠，参考实验分Shirt、Skirt、Pants、Towel；完整数据另外含其他deformable及少量rigid任务。20+是论文来源层task宣称，不是已枚举的可运行task数。四个track为recovery-data utilization、cross-task、cross-scene、cross-embodiment；它们是训练／转移协定，不另计为四项操作技能。
题数与数据
论文宣称2,000+小时真实robot trajectories。观测为两腕相机+外部workspace相机RGB、自然语言指令、proprioception；action为未来end-effector pose trajectory。论文描述共用metadata语义：task、object category/instance、scene、embodiment、operator、data source、completion及failure/termination reason；本轮未取得实际文件名／keys、action维度与座标系、时间频率或split名册，因此不能将这些概念冒写成已验证JSON schema。hours、tasks、robot embodiments与episode/case数分开，case总数保持未知。
评估方式
论文标准完整episode需无人工介入且无不可恢复失败，通常每衣物类别30次独立实体trials、初态随机化；品质由至少两名相同评审跨方法独立评定，达成一致才记录。neatness等级0–5查看形状、紧密、平整、稳定与边缘；FoldScore=35×平均范式品质Q̄+35×完整success rate R+30×max(0,1−t/Tmax)，t只在成功trials平均，无成功时时间项为0。PDF称quality mapping及细rubric在Appendix，但固定版本共9页、第8–9页为references，未附该表；Tmax也未给数值。故不能自行用neatness/5或任意时限做『官方scorer』。π0.5的pre-flattened短流程baseline与basket-to-stack完整流程须分开。

可重用

需要转换
