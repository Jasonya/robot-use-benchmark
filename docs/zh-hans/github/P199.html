OpenEgo: A Large-Scale Multimodal Egocentric Dataset for Dexterous Manipulation

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

已确认OpenEgo官方对应repo，提供六来源的统一数据API与LeRobot转档。其290 tasks是原作来源表加总，与本库跨来源去重任务联集不同。

版本与身份

固定51f704a，README明确连2509.05513及原作网站；有MIT code不代表六份底层数据享有同一授权。未下载完整1107h或运行转档。

领域
居家整理与清洁、穿戴交互与动作界面
环境
汇整CaptainCook4D、HOI4D、HoloAssist、EgoDex、HOT3D、HO-Cap；原作1107h/119.6Mframes/344.5krecordings/600+environments沿用父来源，并非重新拍摄的独立环境池。
任务
意图对齐action primitives与dexterous hand trajectory学习。原表24+16+20+194+33+3=290个原生task labels；各父来源粒度可能不同，须保留来源再归并。
题数与数据
API按mp4列demo，读joints.hdf5、annotation.json、metadata.hdf5；Action.start/end是秒，round(timestamp×fps)并采end-exclusive slice。EgoDex joint slice与annotation getter仍NotImplemented；按parent目录建name索引会让同目录多视频互相覆写查找。EgoDex直接取transform平移，需核验与camera-frame声明的对齐。
评估方式
此repo主要是数据API/转档，不含可核验的手轨迹baseline evaluator。LeRobot action实际存下一frame双手21×3×2=126D座标，末frame重复，非robot actuator command。缺visibility会补全1、缺annotation会空列表、不同FPS仅warning并截各模态最短长度，正式case不得预设这些都有效。
