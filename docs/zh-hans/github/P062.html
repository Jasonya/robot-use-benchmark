RLBench: The Robot Learning Benchmark & Learning Environment

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

RLBench 以 Python Task、CoppeliaSim 场景／模型和 condition 对象组成任务。应沿 task 的成功条件读到 backend，而不是只看任务名称或示范档。

版本与身份

README 明示action mode曾有破坏性变更；本轮固定公开commit，不能混用其他版本的动作约定。

领域
居家整理与清洁、通用对象与机动作业
环境
CoppeliaSim/PyRep 任务场景与模型；任务 class 数、variation 数和独立环境数不能直接等同。
任务
Task class 绑定场景对象与 condition。open_drawer 包含 top/middle/bottom 三个 variation，并以 JointCondition 门槛0.15检查绝对关节位移。
题数与数据
示范将多视角 RGB、depth、mask 分档，并把图像从 observation 移除后保存低维数据；加载时需闭合图像与状态引用。
评估方式
各 task 注册具体 condition。ConditionSet 可累积有序条件或做同时 AND；OrConditions 做 OR。这些状态／过程语义要一起保留。

怎么接入我们的benchmark

可重用

task ID、variation、场景模型、语言描述、示范与 condition 程序。

需要转换

task、variation、初态、传感及 action mode 分开存；evaluator 指向具体条件程序。原生variation可作绑定变化，不自动当添加共同任务。

仍需补齐

完整模型／示范资产闭合、跨来源语义对齐及统一协定下的运行验证。
