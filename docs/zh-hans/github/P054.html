P054 · EgoVid-5M / EgoDreamer

EgoVid-5M: A Large-Scale Video-Action Dataset for Egocentric Video Generation

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-10。已读范围限所列片段；本轮未运行上游程序。

EgoVid的公开repo主要是Ego4D衍生视频标注与清洗工具；相机运动控制标注不能直接视为可运行机器人控制。

版本与身份

本笔覆盖公开数据处理路径；不宣称EgoDreamer模型或所有外部清洗依赖已核读。

领域
居家整理与清洁、办公与教育、工艺与修缮、休闲与运动
环境
Ego4D v1/v2来源视频及clip窗口；来源视频须另行取得。
任务
文字／相机运动条件的第一人称视频数据；本次固定tree见标注、pose及品质计算工具，未取得完整EgoDreamer生成／评测实作。
题数与数据
CSV的video_id=来源视频_起始影格_终止影格，含fps、frame_num、noun/verb、llava_cap、name和各项品质分数；pose资产含3×3 intrinsics及逐影格4×4相机外参。README提醒raw IMU已知问题。
评估方式
光流清洗程序每8影格采样，将flow按平均图像尺寸缩放到512基准，再存均值／分箱比例；这是素材品质证据，不是操作成功率。flow_0_4程序实为>0且≤5，与栏名／README有差异。
