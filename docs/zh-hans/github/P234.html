P234 · I-CVAE

Intention-Conditioned Long-Term Human Egocentric Action Forecasting

返回逐篇总表内核内容已核读 方法／综述参考原作 ↗

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

已沿 Ego4D clips→窗口／意图→ICVAE generate→本地 ED/AUED 核读内核程序。这是重用 Ego4D 的方法来源；52 个 scenario-derived intention、20 个未来位置与 K=5 候选是不同单位。串接预测、GT 条件消融及 challenge 分数必须分开。

版本与身份

固定作者 repo commit 5b95d85e0bec6bd94851c867054c535c1afc6248；此程序快照早于 arXiv v4，没有宣称逐版结果一致。README 的已提供完整 code 不是本次核读完整码库的证据；本次仅核以上内核区段与 taxonomy 结构。未取得权重、完整数据或重跑模型。

清单题名为 Intention-Conditioned Long-Term Human Egocentric Action Forecasting（2022 初稿）；已核缓存为 arXiv:2207.12080v4（2024-04-08），题名改为 Intention-Conditioned Long-Term Human Egocentric Action Anticipation。作者均为 Esteve Valls Mascaró、Hyemin Ahn、Dongheui Lee。repo README 保留 Forecasting 标题，但链接并引用 WACV 2023 的 Anticipation，且具名第一作者维护，可确认为同一方法的作者程序，而非同名第三方。

领域
方法／综述参考，未另作来源用途归纳。
环境
脱机人类第一人称 Ego4D 日常活动；物理场景信息来自 ego4d.json 的 scenarios，程序将单一 scenario 视为高层 intention。没有 robot reset、control 或可运行成功条件；scenario 数不代表场景 layout 或机器人任务数。
任务
H3M 由过去片段辨识 verb、noun、intention；I-CVAE 预测 Z=20 个未来 verb–noun 标签，通常产生 K=5 串行。固定 taxonomy 为 115 verbs、478 nouns、52 intentions；论文 p.6 的 53 scenarios 是另一统计口径。设置档 N=8，论文端到端表格包含 N=2/4/6/8，最佳结果用 N=6，不能一律写 N=4。
题数与数据
外部 fho_lta_{train,val,test_unannotated}.json 根为 clips；使用 video_uid、clip_uid、action_idx、verb_label、noun_label、action_clip_start_sec/end_sec，预处理另读 action_clip_start_frame/end_frame。按 clip_uid 分组、action_idx 排序；case key 为最后观测的 clip_uid_action_idx。input_clips／forecast_clips 各为 N／Z 笔，标签 tensor 次序 [verb,noun]，forecast_times.label_clip_times 保留秒；缺 test label 补 -1，不能当有效类别。意图 mapper 仅纳入恰一个且在 52 类 taxonomy 中的 scenario，未提供多 scenario 的明确处置。SlowFast 特征存 clip_uid_action_idx.pt；frame_to_feat 实际 int(frame/16)，W 参数未用；slice [start_feat:end_feat]，预设左补至 15 格。论文描述 2304 维特征，不能把 feature index 当秒或控制步。完整标注／features／ego4d.json 未随本次取得，没有声称完整 case 数。原生每 clip 窗口数为 max(0,L-N-Z)，循环缺 +1，最后一个完整窗口未取。
评估方式
ICVAE_Task.validation_step 分别评 verbs、nouns；pred [B,K,Z]→[B,Z,K]。lta_metrics.edit_distance 对每 case 取 min_k(editdistance.eval(pred_seq,gt_seq)/prefix_length)，再对 case 平均；AUED 对长度 1..Z 的 ED 做 trapz/(Z-1)，ED_19 是 Z=20 的末点，非第 19 个未来动作。validation_epoch_end 再不加权平均各 batch 指针；非 test 的 test_epoch_end 先依 clip key 合并去重后评分，两者分母流程不同。论文称 Damerau–Levenshtein 并报 action ED；此档实际 import editdistance、调用 eval，未见 transposition 专用实作，也未在这条 Task 链计 action-pair ED，不能直接宣称重现 challenge scorer。单模块 validation 使用 GT observed_labels 与 GT intention；create_prediction 才设 FROM_PREDICTION 串接 H3M。test GT 未公开，submission 每 case 含 verb／noun 的 K×Z 整数数组。

怎么接入我们的benchmark

可重用

固定 taxonomy、clips 字段及排序、case key、原生 ED/AUED 实作与 H3M→ICVAE 预测界面。

需要转换

source 记 paper version+repo commit 并指回 Ego4D；domain 记人类活动，environment 记 video/scenario provenance；task 分 H3M recognition 与 LTA forecasting；case 用 dataset revision+split+clip_uid+最后 observed action_idx+N/Z；保留观测秒／影格与特征索引三种座标、GT/predicted intention 来源及不可见未来 label。evaluator 保留 verb/noun、best-of-K、prefix normalization、AUED 与 batch/global 聚合差别；不转成机器人 success。

仍需补齐

须固定 Ego4D v1 标注／feature revision 与 split manifest；核对 52 类 intention 排除的视频与 case 分母、末窗口少取及 batch 平均；比对正式 Damerau/action scorer。FROM_PREDICTION 缺 clip 时会借用随机其他 clip 的 intention 并填 -1，接轨须改成可追踪缺件。preprocess_dataset.py 的 Namespace 以字典取用且未定义 dir_annotations 参数，Quickstart 的 test_model.py 也不在固定 tree；这些都须在允许运行前修复／指定正确入口。
