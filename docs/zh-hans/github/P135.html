Octo: An Open-Source Generalist Robot Policy

返回逐篇总表内核内容已核读 方法／综述参考原作 ↗

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

Octo提供可组合的多相机/语言/goal界面及OXE loader；其80万轨迹是训练混合，模型task字典与benchmark语义任务不是同一计数单位。

版本与身份

固定241fb35；DROID另钉较早Octo85b83fc，不可互相套用。README连1.5 checkpoint，模型版本、程序版本与数据版本分开保存。

领域
方法／综述参考，未另作来源用途归纳。
环境
重用多来源robot数据及既有ALOHA/WidowX运行环境；模型支持的机体/相机种类不等于独立benchmark环境。
任务
多任务goal-image或language条件policy；create_tasks组装的是一次条件输入，并不定义全库独立task。
题数与数据
task含goal/text及pad_mask_dict；缺模态填零但mask=False。observations为B×window×...，timestep_pad_mask区分padding。output为sample_shape×B×action_horizon×action_dim；以mean/std或p01/p99和mask反范式并裁到机体维度。
评估方式
例子在aloha-sim-cube-v0用history=1、exec_horizon=50，跑3次400step上限并记episode return。它是示例protocol，不能作全部Octo/所有机体的统一成功判定；底层checker仍属原环境。

怎么接入我们的benchmark

可重用

task/obs/action模块界面、missing/timestep masks、数据源stat与normalization。

需要转换

保留OXE子来源/episode与method分离；case固定language或goal、可见相机/历史、sample_shape与exec horizon，数值表示和缺失mask不可丢。

仍需补齐

完整pretraining mixture与来源去重、模型版本/目标机体stat、各原benchmark正式protocol、素材与原生运行验证。
