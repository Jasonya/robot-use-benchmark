P233 · OCT / HOI forecasting

Joint Hand Motion and Interaction Hotspots Prediction from Egocentric Videos

返回逐篇总表内核内容已核读 benchmark／数据／评测主来源原作 ↗ 用途与原生规模依据

核读快照 2026-10-11。已读范围限所列片段；本轮未运行上游程序。

OCT／HOI-Forecast 以既有厨房 Ego 视频自动创建训练 labels，另外人工标注评测轨迹与接触热区。已核对 labels、时间窗及实际评分入口，并记下目前程序的 ADE／FDE 命名对调与热图配对条件，供标准化时保留原始口径。

版本与身份

本次核对的是固定官方 commit。文中指出可直接验读的程序语义；不将未运行的静态差异扩张成对论文分数的判定。

领域
餐饮与烹饪、穿戴交互与动作界面
环境
EPIC-KITCHENS-55／100 与 EGTEA Gaze+ 的人类厨房视频；EK100 延伸 EK55，与 Diff-IP2D 等工作共享视频或 labels。不是添加模拟场景。
任务
两个相关输出：未来左右手 2D 轨迹与 next-active object 接触热区。典型 4 Hz、2.5 秒历史／1 秒未来；label 有边界点+4 future 点，epoch eval 去掉第一点。任务输出维度与多次生成 samples 不计为新情境。
题数与数据
训练 labels 自动产生，评测 hand trajectory／hotspot 人工标注；uid、participant／video、frame indices、RULSTM split 必须一起保留。README 600 MB 是含 feature／partition／labels 的文件大小，不是题数。未取得完整 labels，不能从目录片段宣称已集成全量。
评估方式
原生 compute_ade／compute_fde 正确区分平均／末点，但 evaluate_traj_stochastic 把 compute_fde 放入 ade_list、compute_ade 放入 fde_list，造成输出名称对调；实际 epoch 确实调用这个 wrapper。invalid GT 座标误差乘零、时间长度分母仍保留。hotspot 在 32×32 Gaussian heatmap 计 SIM／AUC-J／NSS，NaN 个别剔除；zip 两个 dict values 依 insertion order 配对，未按 uid join。另列的 F1 选当次数据最优 threshold，不是固定阈值分数。

怎么接入我们的benchmark

可重用

重用人工 eval uid／labels、native splits、可追溯自动标注来源。；保留原生 wrapper 输出及其实际定义，将任何更正以新 evaluator version 登记。

需要转换

先以 uid join 预测和 GT，再检查 expected-case coverage、顺序、shape、有效手及 frame boundary。；canonical metric 明列公式、单位、mask 分母、sampling 次数和热图 kernel；原 native 名称附别名映射，不静默改名后混报。；两个任务共享 clip/case lineage，多次 stochastic sample 仅增加 trial，不添加独立数据。

仍需补齐

本次未运行上游模型或重现 README 分数。；完整数据获取、生成标注程序的全流程及 licensed raw video 尚未集成；runtime adapter 需用小型有答案 fixture 查验原生／更正版差异。
