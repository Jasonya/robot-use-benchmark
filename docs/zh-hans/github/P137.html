π0.5与π0共用openpi，但state离散token、prompt预算和模型旗标不同。公开LIBERO示例还固定了双相机、5步action chunk与原suite预算。

版本与身份

README明示此repo目前只支持π0.5 flow matching head；不能宣称公开码已覆盖原作所有head和私有数据。与P136共用repo/commit但分开记录方法配置。

领域
方法／综述参考，未另作来源用途归纳。
环境
π0.5原研究开放环境泛化与公开LIBERO/DROID示例不是同一环境集合；公开示例重用父benchmark资产。
任务
升级的VLA方法和跨环境泛化；不因π0.5/model-head或checkpoint新名字重计底层LIBERO任务。
题数与数据
pi05旗标预设离散state输入，prompt max_token_len200（π0预设48）；TokenizePrompt需state与prompt。LIBERO范例传agentview/wrist RGB各旋转180度、EEF pose/gripper state及task文字，数据可见性和只RGB baseline不同。
评估方式
公开LIBERO预设50trials/task、10步暖机、每次运行action chunk前5步；suite上限220/280/300/520/400，按原env.done计成功，seed与预存初态都要固定。这些是公开示例协定，不等于原文全部open-world评测。
