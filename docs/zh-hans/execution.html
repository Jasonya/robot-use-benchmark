一段实际动作重播

这是已记录动作在相同模拟初态的渲染重播；不是人类视频。它是说明用的一个成功例，所有成败仍完整列入上方表格和下载纪录。

具体验证了哪些事情

  • 所有请求的测试都有纪录；没有遗漏、运行错误、非有限状态或跨方法 reset 不一致。
  • 100 次测试动作重播与原记录一致，观测比较容差为 1e-8。
  • reach/window 的 50,000 个步骤，透过 MuJoCo site 几何独立比对成功条件，没有分歧。其他任务仍需进一步判分器审核。
  • 10,000 个学习模型动作从保存权重重算，与纪录完全相同；训练与测试初态 hash 不重叠。

实作中发现并修正的 reset 问题

在固定套件版本组合，window-close 的 reset 会留下过期 kinematics／初始观测，让初态成功查找与实际 joint state 不一致。适配层加入 mj_forward，再同步当前与历史观测；没有改 qpos、qvel 或推进模拟时间。修正作为新的 reset contract 保存，旧实验亦保留。
