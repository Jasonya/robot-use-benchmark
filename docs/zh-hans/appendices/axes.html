v0.4：任务规模与广度共同验收

完整任务库初始目标为 2,000–3,000 个 G2；任务数与有效覆盖各以最大可比基准至少 2 倍为目标。添加场域、家族、材料与机体的支撑配额。180 个蓝图保留为设计种子，原 100–140 预算属历史方案。

阅读整体设计、配额、架构与 milestones →
完整保留原始整理版的定义和证据界线；目前仍无正式模拟评测结果。宽表格可以水平卷动。

本附录完整定义 34 个能力、12 个变化轴、8 个可重叠来源 preset、 7 组独立观测轴、6 个候选 robot profiles、5 个 learning regimes，以及 Q0–Q4 readiness。 这些是 coverage facets，不能直接相乘成任务数。

十二个变化轴

在家族内先控制单一变因，再研究组合；完整 Cartesian product 会包含不可解或冗余配置。可采分层、平衡或有限交叉设计，但须列出没有测到的交互作用。同时改材料、形状和背景时，结论只能描述混合 shift。

ID 变化轴 定义／有效性
V01 视角与传感 相机位置、遮挡、曝光、传感噪音；保留目标可辨识性
V02 对象身份／外观 同语义类别的新实例、材质外观；不自动等同物理材料改变
V03 几何与机构 尺寸、形状、界面、关节；各变化要确认目标仍可解
V04 物理／材料参数 质量、摩擦、柔顺、拉伸、弯曲；记录校准和有效范围
V05 场景与配置 新房间、布局、容器位置、可达性与背景
V06 功能替代与工具可用性 改变可用工具／对象但保持意图；每个替代经人工或专家验证
V07 任务组合 保留 primitives，改变依赖图、目标组合或必要顺序
V08 时间与记忆负荷 必需历史长度、干扰 session、延迟与来源混淆
V09 运行中扰动 明订语义checkpoint和扰动；完整成功／delivery／conditional recovery分报
V10 交互对象与行为 不同角色、意图、速度、可见线索与合作策略
V11 指令与信息充分性 改写、多语、语音噪音、矛盾／缺失；无唯一答案时需调整标签
V12 机体与界面 不同末端、DOF、移动能力；独立 eligibility 与 contract，不暗换控制器

来源 presets 与独立观测轴

Preset 只是便利设置。每个 instance／source 应另外记录以下轴，unknown 不自动填入某个来源。

Preset 来源设置 要求
O1 文字／语音目标 保留语音转录与延迟；完整目标文字与视频推断不得当成相同信息条件。
O2 人类头戴第一视角 记录头部运动、时间戳与来源 session；不能等同 robot ego camera。
O3 人类胸前／身体摄影机 单独记录相机安装位置、手部遮挡和相机座标；不是只有重命名 O2。
O4 第三视角／多视角人类示范 有校准才可使用跨视角3D指针；否则仅宣称语义对齐。
O5 VLOG／剪辑教学视频 标记剪接、遗漏步骤、旁白、目标信息充分性与非等速播放。
O6 模拟机器人示范 可开发环境与产生未来标签；不得标成人类视频或真实 body-camera 数据。
O7 多 session 观测与交互历史 追踪来源、时间和干扰；防止同一来源的 clips 跨 split。
O8 非人类第一视角诊断 只用于观测、egomotion或域移诊断，不冒充人类操作示范或robot action数据。

学习设置

Regime 条件
L0 冻结策略，没有 benchmark 驱动的参数更新
L1 使用明订固定训练池的脱机调适
L2 目标任务／机体上固定 few-shot support 预算
L3 明订交互与参数更新预算的在线调适
L4 预先排定任务串行与回测时程，保存 retained-task success matrix

L4 的任务保留／遗忘，与 T2 的推理时 history memory 不同。普通 trial 清空跨 trial 隐状态；记忆／continual tracks 只保留协定允许的范围。
