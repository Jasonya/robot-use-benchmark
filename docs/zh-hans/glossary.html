名词小辞典

从一般读者的角度，快速理解网站里常见的研究用语。

BENCHMARK

评测基准

一组有明确输入、任务、条件与评分规则的共同测试，用来比较不同方法。

深入阅读 →
TAXONOMY

文献分类

整理研究在测什么，例如视频理解、预测、操作、协作；不直接决定考题配额。

深入阅读 →
ONTOLOGY

任务概念结构

定义场域、家族、对象、目标、过程与证据之间的关系，让出题规格一致。

深入阅读 →
DOMAIN

应用场域（G0）

任务发生的应用背景，例如住家或工坊。同一个折叠家族可在多个场域出现。

深入阅读 →
FAMILY

任务家族（G1）

按共通语义结构分组，例如「打开、存入并关闭」。换个抽屉不一定是新家族。

深入阅读 →
BLUEPRINT

情境蓝图（B0）

尚未实作的具体出题构想，包含初态、目标与验收条件。本计划目前有 180 个。

深入阅读 →
SPEC

正式任务规格（G2）

明订目标逻辑、指涉、必要过程与机构要求。共同去重后的数量目前仍待定。

深入阅读 →
INSTANCE

任务实例（G3）

把任务绑定到实际资产、对象、物理参数与初始状态。文件中有名称不代表已有实例。

深入阅读 →
CASE

测例（G4）

一个有合法输入、条件、答案与评分器的测试题。QA 与机器人控制必须标示不同型态。

深入阅读 →
TRIAL

一次运行（G5）

某个模型在一个固定测例上跑一次。重跑会增加运行量，不自动增加任务种类。

深入阅读 →
EGO

第一人称观测

从行动者附近的视角观察活动；要另记头戴、胸前、robot camera 等相机位置。

深入阅读 →
CONTRACT

共同评测约定

模型能看什么、能做哪些动作、允许多少数据与时间，以及如何判成功。

深入阅读 →
EVALUATOR

判分器

根据状态和轨迹判断是否完成任务。它需要接受合法解，也能拒绝近失败。

深入阅读 →
ORACLE

诊断上界

提供正确目标、计划或特权状态的对照，用来定位瓶颈，与一般模型排名分开。

深入阅读 →
SPLIT

数据切分

定义训练与测试的边界；先按来源 session 分组，避免同源片段泄漏到两边。

深入阅读 →
READINESS

验证阶段 Q0–Q4

Q0 是语义设计，接着才是实例、专家可解性、判分器审核和基线重现。
