# G與T：計數粒度與評測模組速查

本計畫採用的整理編號，概念來自研究與評測實務；不是所有前作共同使用的G／T標準。

**G：在數哪一層。T：在測哪種能力。**

## G0–G5

G是granularity（粒度）標記，回答正在計數哪一層單位。

| 編號／單位 | 定義 | 摺毛巾例子 |
|---|---|---|
| G0 應用場域 | 固定分類版本與深度下的領域節點，與任務家族交叉分類。 | 居家生活、旅宿洗衣。 |
| G1 任務家族 | 按共通目標、操作或程序結構整理的任務類別；記錄共同分類規則。 | 布品摺疊、摺疊後收納。 |
| G2 任務規格 | 明訂目標、物件指涉、必要過程、限制與完成語義。規格可先按原作收集，跨來源對齊另記。 | 依指定摺法完成毛巾，放入籃子並保持摺法。 |
| G3 任務實例 | 將任務綁定具體資產、機體、材料參數與實際初態；保留可追溯資料。 | 某條毛巾、某張桌子與籃子、指定機器人及初始擺放。 |
| G4 評測測例 | 實例或合法來源證據，加上觀測／歷史、介入、預算、答案與判分約定；控制、QA、預測等型別分開。 | 給指定示範與觀測，在抓持後施加一次已定義滑脫，按固定預算評分。 |
| G5 一次評測執行 | 某個方法／checkpoint對固定測例的一次執行，記錄方法隨機性、輸出和結果。 | 模型A在這個固定測例執行一次，產生軌跡和成敗紀錄。 |

應用領域與任務家族是交叉分類；同一摺疊家族可出現在居家或旅宿。

## T1–T8

T是evaluation track／module（評測模組）標記，回答正在測什麼。

| 模組 | 例子 | 輸出 |
|---|---|---|
| T1 理解、定位與狀態 | 指出毛巾哪條邊、物件在哪裡、目前是展開還是摺好。 | 物件、關係、狀態、證據位置或答案 |
| T2 情節記憶 | 記住先前用的是哪條毛巾、它原來放在哪裡。 | 過去事件／位置、關聯證據、記憶引導的行動 |
| T3 動作、互動與軌跡預測 | 根據可見前綴，預測接下來的動作、接觸或手部路徑。 | 未來動作、物件／接觸、接觸時間、2D/3D 軌跡與不確定性 |
| T4 目標與計畫 | 決定目標摺法，列出抓取、對齊、摺疊和收納的計畫。 | 目標圖、子任務依賴圖、可執行的高層計畫 |
| T5 閉迴路任務執行 | 讓機器人邊觀察邊調整，實際完成摺疊與收納。 | 機器人動作與完整 trajectory |
| T6 診斷與恢復 | 發現毛巾滑脫或摺錯，診斷原因並恢復完成。 | 錯誤類型、狀態修復、恢復後完成 |
| T7 互動與協作 | 和另一個人或機器人分工拉平、接住或交接布品。 | 協作動作、詢問、等待、交接與角色分配 |
| T8 世界模型與可執行性 | 給定候選機器人動作，預測毛巾會形成什麼狀態，並檢查預測能否支持執行。 | 動作條件化的未來狀態／影片及可轉成動作的預測 |

同一來源或任務可以支援多個T，但每個模組都要有適用的輸入、答案或判分依據；不能只把任務數乘八當完成量。

## 與任務環境、Q狀態的關係

G2明訂任務的目標與規則；任務環境定義再連到世界／機體、觀測／動作、狀態變化和判分介面。G3是具體初態實例，G4補齊評測條件，G5記錄一次方法執行。

Q0–Q4另表示設計／驗證狀態。第二章示範藍圖的Q0是草案狀態，與G的計數粒度和T的評測模組分開。

T編號不表示必須依序執行；G與T都不是難度分級。
