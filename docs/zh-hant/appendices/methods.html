資料欄位、template 與空值規則

每個欄位都要區分未觀測、無效、不適用與失敗。null 不自動變成 0、false 或成功。 以下是現有 episode template；不是已收集 trial。欄位中的私有答案不得傳給 policy。

欄位群 主要內容 用途

evaluation_contract sim、asset、robot、action／observation、initial state、頻率、預算、判分版本 公平性與可重現性
method checkpoint、training data、inference config hashes 方法來源與可重跑條件
source_lineage activity、session、demonstration、split、human／synthetic 來源相依和 leakage
conditions private goal、held-out axes、assigned intervention／trigger 變化與介入定義
execution reset、checkpoint、delivery、validity、成本、crash、trace、clarification／partner 分母與方法結果
outcome final／trace、預算、幹預、goal／compliant、證據、排除／metric validity 判分與不確定性

Scale schema 的記錄欄位

欄位 含義
work／version 原工作與固定來源版本
native_term／reported_count_text 保留原始計數名稱與 + 等限定
value／qualifier 結構化值與 exact／reported_plus 等性質
aligned_level／typed_unit G0–G5／平行單位與具體型態

source_url／qualification 直接原始來源與比較界線
