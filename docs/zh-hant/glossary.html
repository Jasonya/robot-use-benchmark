RESEARCH ATLAS

名詞小辭典

從一般讀者的角度，快速理解網站裡常見的研究用語。

SOURCE-ENTRY

來源名錄條目

登記一個benchmark、評測資料資源或其版本；一條名錄可連到多個任務或設定索引。

深入閱讀 →
SOURCE-INDEX

原作定義／設定索引

從原作清單或程式提取的一筆任務、活動、模板、註冊或協定。本版5,349是這一層的數量。

深入閱讀 →
TASK-ENVIRONMENT

任務環境定義

把世界／機體、觀測／動作、狀態規則、任務目標及判分連成完整規格。定義可以先收錄，執行另驗證。

深入閱讀 →
SCENE

場景／layout

房間或工作站的空間與幾何配置。同一場景可以支援多個不同任務環境。

深入閱讀 →
SAMPLE

原始資料樣本

影片、QA、episode或軌跡等原作資料單位，按型別與split分項統計。原作量、已取得量、已整合量分開。

深入閱讀 →
BENCHMARK

評測基準

一組有明確輸入、任務、條件與評分規則的共同測試，用來比較不同方法。

深入閱讀 →
TAXONOMY

文獻分類

整理研究在測什麼，例如影片理解、預測、操作、協作；不直接決定考題配額。

深入閱讀 →
ONTOLOGY

任務概念結構

定義場域、家族、物件、目標、過程與證據之間的關係，讓出題規格一致。

深入閱讀 →
DOMAIN

應用場域（G0）

任務發生的應用背景，例如住家或工坊。同一個摺疊家族可在多個場域出現。

深入閱讀 →
FAMILY

任務家族（G1）

按共通語義結構分組，例如「開啟、存入並關閉」。換個抽屜不一定是新家族。

深入閱讀 →
BLUEPRINT

情境藍圖（B0）

尚未實作的具體出題構想，包含初態、目標與驗收條件。v0.2保留180個歷史藍圖，不算本版任務規格或題數實績。

深入閱讀 →
SPEC

正式任務規格（G2）

明訂目標邏輯、指涉、必要過程與機構要求。共同去重後的數量目前仍待定。

深入閱讀 →
INSTANCE

任務例項（G3）

把任務繫結到實際資產、物件、物理引數與初始狀態。檔案中有名稱不代表已有例項。

深入閱讀 →
CASE

測例（G4）

一個有合法輸入、條件、答案與評分器的測試題。QA 與機器人控制必須標示不同型態。

深入閱讀 →
TRIAL

一次執行（G5）

某個模型在一個固定測例上跑一次。重跑會增加執行量，不自動增加任務種類。

深入閱讀 →
EGO

第一人稱觀測

從行動者附近的視角觀察活動；要另記頭戴、胸前、robot camera 等相機位置。

深入閱讀 →
CONTRACT

共同評測約定

模型能看什麼、能做哪些動作、允許多少資料與時間，以及如何判成功。

深入閱讀 →
EVALUATOR

判分器

根據狀態和軌跡判斷是否完成任務。它需要接受合法解，也能拒絕近失敗。

深入閱讀 →
ORACLE

診斷上界

提供正確目標、計畫或特權狀態的對照，用來定位瓶頸，與一般模型排名分開。

深入閱讀 →
SPLIT

資料切分

定義訓練與測試的邊界；先按來源 session 分組，避免同源片段洩漏到兩邊。

深入閱讀 →
READINESS

驗證階段 Q0–Q4

Q0 是語義設計，接著才是例項、專家可解性、判分器審核和基線重現。
