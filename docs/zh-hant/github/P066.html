P066 · ManiSkill

ManiSkill: Generalizable Manipulation Skill Benchmark with Large-Scale Demonstrations

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

2021原作應讀haosulab/ManiSkill-Legacy，不能用現在ManiSkill3的main代替。其四種基本任務會依PartNet模型與目標link產生更多環境ID，這些不是全部新的工作種類。

版本與身份

來源版本固定為Legacy commit58964d08…；與ManiSkill2 v0.5.3和ManiSkill3分別儲存，不混用數量及API。

領域
居家整理與清潔
環境
SAPIEN場景繫結PartNet-Mobility模型；model/link ID與level控制資產及初態變化。
任務
OpenCabinetDoor、OpenCabinetDrawer、PushChair、MoveBucket四種原生基本任務，再衍生模型／link設定。
題數與資料
觀測可為點雲／RGBD／狀態；示範及資產外部取得，模型分割與初態在YAML／level設定。讀取時需保留觀測模式和模型身份。
評估方式
具體task先產生條件旗標，base_env要求連續保持0.5秒；Evaluator依episode終止時eval_info計比例，不能以某一幀接近目標替代。
