P226 · EgoTraj

EgoTraj: Real-World Egocentric Human Trajectory Dataset for Multimodal Prediction

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

EgoTraj提供戶外行人頭部/視線/影片資料與EgoViz reader；公開檔案可支援資料對齊，但不是完整trajectory預測baseline實作。四元數順序在README與reader註解不一致，需核驗。

版本與身份

固定902c354、原作2605.19004；README結果是原作報告，本輪只核讀資料/視覺化介面，未重跑預測模型。

領域
交通移動與車輛維修、穿戴互動與動作介面
環境
真實都市步行、7個預設waypoints間自行選路，MetaQuestPro錄制；75participants不是75個不同物理環境，位置為session-relative、Y向上、地平面x-z，沒有地理坐標。
任務
行人trajectory forecasting與AR導航研究，原文/README採1.5秒觀測→3.5秒預測；不同participant/waypoint/unfamiliar splits另列。不是robot實際導航任務完成benchmark。
題數與資料
HDF5按session含pose position/rotation/velocity/angular_velocity/timestamp、gaze origin/direction、video segment/frame/has_video；scene annotations為1fps，用pose_idx回連30Hz資料。README稱quaternion wxyz，reader按xyzw解讀；原始資料必須核定。未匹配影片frame以NaN標示。
評估方式
README列ADE/FDE(m)、L1_head與bootstrap結果，但repo主要EgoViz，未確認完整baseline/scorer。影片在拍攝時已疊紅色gaze dot，RGB-only是否允許這個線索需在case條件明示；1fps VLM scene descriptions也需有獨立可見性/生成版本。

怎麼接入我們的benchmark

可重用

session/pose_idx跨模態join、原生視線與local坐標、資料reader和source split設計。

需要轉換

case固定participant/session/觀測截止與預測視窗；統一quaternion及clock、保留has_video mask、原始/疊點影像與VLM annotation來源；模態消融先界定合法可見線索。

仍需補齊

全部資料/split manifest、quaternion查核、baseline/scorer與姿態metric定義、含gaze-dot版本的公平輸入設計。
