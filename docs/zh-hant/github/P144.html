P144 · CAP / EgoGym

Contact-Anchored Policies: Contact Conditioning Creates Strong Robot Utility Models

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

CAP/EgoGym來源有公開policy和real2sim抓取路徑；此路徑的稀疏成功是提升高度，且包含重力補償輔助，不能由此推定完整EgoGym實驗全部已可重現。

版本與身份

固定8ab1117；目前深入的是公開real2sim pick流程，未宣稱每個CAP應用、全部人類資料與實機checker皆公開或已執行。

領域
居家整理與清潔、辦公與教育
環境
MuJoCo real2sim scene.xml和可替換物件/幹擾物，另有實機/人類gripper資料；物件asset、機體與scene設定應各自有ID。
任務
接觸條件化policy；已核對的RUM-Pick-v0是具體抓取測試，不等於原文所有utility/EgoGym任務。
題數與資料
loader按同一trajectory slice取RGB、可選depth及action；sim observation含RGB和object_2d/3d_position。評測可明確使用這些位置作conditioning，屬資訊預算差異；2D投影引數480×360與obs宣告256需核對。
評估方式
default sparse以物件升高>carry_threshold(.02)給1，terminated=bool(reward)。dense模式reward一般非零，不能沿用此termination當成功。step含600次physics控制、首次grasp另gravcomp=1和2000步，應保留輔助/成本設定；總成功按指定episode數聚合。
