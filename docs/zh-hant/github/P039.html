RoboVQA: Multimodal Long-Horizon Reasoning for Robotics

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

RoboVQA 公開 GitHub 是資料讀取與示範評分 notebook，並非完整實機控制評測平臺。已讀所有 notebook source cells，包含 SequenceExample schema、任務tag解析和 mock eval。

版本與身份

公開 notebook 的 mock 範例與論文的真實機器人／人工介入實驗不同。程式授權與其餘資料授權在 README 分開列示，後續來源表應各自儲存。

領域
居家整理與清潔、餐飲與烹飪、辦公與教育
環境
已核原論文第1頁：資料來自3棟辦公大樓，含機器人、人、人持抓取工具的多 embodiment。公開 notebook 本身只讀 images/texts，未提供可直接重設的場景或 robot dynamics。
任務
長程／中程指令與高階 VQA，例如成功、affordance、離散進度及文字推理。<task:...> 是問題／標註型別，同一影片可帶多個 QA；29,520 unique instructions 與829,502 video-text pairs 是原論文報告的不同單位，不是本次取得或可執行題數。
題數與資料
Google Storage train/val TFRecord 裡是 tf.train.SequenceExample，feature_lists 的 images 為 JPEG bytes，texts[0] 為包含多個 task/pred/speaker tags 的UTF-8字串。Tasks 分成 tag→文字，再用 A: 分離輸入／答案；隨機抽 task 與 split 需儲存實際選到的內容。
評估方式
run_eval 只取 validation 第一筆 SequenceExample，對其中 QA 呼叫 mock_call_model 並示範 sentence_bleu，無全量平均或實機 intervention 統計。程式呼叫為 sentence_bleu(answer,pred_answer)，需按鎖定 SacreBLEU 核對候選／參考順序及型別，不能直接把示範印出的數字當正式 benchmark 成績。

怎麼接入我們的benchmark

可重用

原生多tag語料、TFRecord images/texts schema 與 task/source-target parser。

需要轉換

source 記 embodiment／episode／building 若來源metadata可取得；case 用record ID+task tag+該tag內QA序號，frame sequence 只儲存一次。raw text/tag 與去tag的prompt/answer同存；VQA字串評分與實機 intervention evaluator 分別建檔。

仍需補齊

尚未下載 TFRecords、執行 notebook 或機器人試驗。需要全量 ID/split/embodiment metadata、正式 BLEU 協定與 intervention 原始軌跡；get_splits 的 binary/discrete 路由引用未定義常數，使用時需修正並測試，A:範例不受該路由影響。
