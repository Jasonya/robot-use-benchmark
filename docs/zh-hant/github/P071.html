P071 · RoboCasa365

RoboCasa365: A Large-Scale Simulation Framework for Training and Benchmarking Generalist Robots

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

RoboCasa365 應從 TASK_SET_REGISTRY、split 建環境、LeRobot extras 和具體 task checker 讀起。現行程式的 all_tasks 來自資料registry而非365項完整任務名冊；論文與後續檔案的trial數、horizon也已不同。

版本與身份

主倉庫同時殘留舊eval_utils的PandaMobile/B split；365應沿env_utils＋Gym讀取。Gym預設split="test"，create_env只接受None/all/pretrain/target，因此呼叫時需明設split。LeRobot playback拒絕filter_key；--use_abs_actions沒有進入use_actions分支，而底層get_episode_actions(abs_actions=True)也明確未實作。README要求robosuite master，LeRobot與policy runner版本尚未固定；本次沒有宣稱執行相容。

對應 arXiv:2603.04356v1（2026-03-04／ICLR 2026），四位作者及題名與README的RoboCasa365引用一致。與P070共用官方倉庫，但這份筆記固定365時代main：456174f62b89b8fca99eaaf33949c29fec9cfc2a。

領域
居家整理與清潔、餐飲與烹飪
環境
pretrain由layout 11–60與style 11–60交叉組成2500組；target只用(1,1)…(10,10)十組，不是10×10。create_env同時切換obj_instance_split。Kitchen會再排除任務不支援的layout/style；2500不能保證每task都有2500個有效場景。
任務
論文365＝65 atomic＋300 composite；target50明列18 atomic-seen、16 composite-seen、16 composite-unseen。固定registry經AST計數為65 atomic＋252 composite＝317個key，all_tasks直接串接這兩表；pretrain300與target50聯集316，另外一個key是PlaceOnDishRack。這是資料／評測入口的覆蓋差異，不以317覆蓋論文365，也不推論未列者沒有環境實作。
題數與資料
get_ds_meta輸出path/horizon/filter_key/task/split/source；human預設pretrain100、target500 demos，MimicGen一般10000但OpenCabinet特例5000。缺folder回None，soup會略過。LeRobot讀data/*/episode_NNNNNN.parquet的action，按meta/modality.json重排；重播另需extras/dataset_meta.json的env_args，及每episode的states.npz、model.xml.gz、ep_meta.json。ep_meta保留layout_id/style_id/object_cfgs/fixture_refs/cam_configs/lang及底盤初態。action原始順序為eef平移3、旋轉3、gripper1、base/torso4、mode1；Gym提供三個video.*視角、state.*與annotation.human.task_description，不能直接按LeRobot欄位字典順序拼接。
評估方式
Gym.step→Kitchen.reward／具體_check_success；PickPlaceCounterToCabinet要求bbox位於某一櫃內區域且eef離物件>0.25公尺。obj_inside_of仍在未正規化軸投影使用0.05，非固定5公分容差。Gym將checker轉為reward 0/1與info.success；ignore_done=True且truncated固定False，registry的horizon必須由policy runner另行取用。論文§G.2每task30 trials、期限內曾成功即算成功、跨task平均；現行檔案改50 rollouts且v1.0.1把horizon增至1.5倍。

怎麼接入我們的benchmark

可重用

有版本的task sets、pretrain/target分割、LeRobot modality及extras、場景／物件生成設定與具體bool checker。

需要轉換

source記論文v1及commit；task全集、資料覆蓋、target集合分欄。case記split、layout/style pair、物件分割、seed、控制頻率及實際horizon；evaluator儲存trial數、期限內成功與跨task平均，禁止和P070或不同horizon結果直接合併。

仍需補齊

365任務與317個資料key的完整對照、正式policy runner依賴commit／seed清單、per-frame subtask標註的實際檔案schema，以及LeRobot影片／extras／資產的閉合驗證。
