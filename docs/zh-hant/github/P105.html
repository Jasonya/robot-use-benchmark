LIBERO-Plus的10,030是擾動任務條目；實際分類JSON確有10,030筆，但大量條目共享原LIBERO任務和初態。原difficulty level保留為來源標籤。

版本與身份

fork替代LIBERO套件使用方式不代表資料獨立；RLDS/LeRobot連結是訓練資料表示，不能各自重複計數。當前分類筆數為檔案結構核對，未執行全部變體。

領域
居家整理與清潔、餐飲與烹飪
環境
重用LIBERO桌面，擴充物件、紋理、相機、光照、機器人初態及noise。多擾動名稱不代表不同房屋或獨立原始資料。
任務
7擾動維度；分類檔結構計數：spatial2,402、object2,518、goal2,591、libero_10為2,519，合10,030。這是native variant entries，不是本庫10,030去重語義目標。
題數與資料
Task保留name/language/problem_folder/bddl_file/init_states_file；getter依_language_/_view_/_table_/_light_等字樣回取共同或專屬初態。分類JSON的id基準與API task index需明確對映。
評估方式
具體_check_success逐一AND goal_state predicate；rollout在max_steps內累積done成功。README要求num_trials_per_task由50改1，是該擾動協定，不等同所有來源都一試可充分估計成功率。difficulty_level為作者擾動級別，尚非跨benchmark校準難度。
