P060 · Continuous 4D interaction forecasting

From Where to How: Continuous 4D Interaction Forecasting from Egocentric Video

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

此來源不只是專案頁：有 Coherent4D 的事件分段、共同座標及 SMPL 附加程式。正式預測指標只能讀到論文定義，尚無公開評分器可直接沿用。

版本與身份

固定67386704bf335af977232594d0f86428d0623c8e（2026-09-14）。非截斷tree有網站、統計與process程式，沒有釋出完整訓練／評分實作。SMPL指南指定外部 FIction-WHAM b520bc8f1d755be658c4d2bafdffe5081d09cfe2；本輪只讀該依賴宣告，未讀取／執行外部模型。chunk指令碼不建立split，須承接來源take分割，不能把每個chunk隨機切分。

README 的完整標題、六位作者及 arXiv:2609.08636 與本地 v1 論文一致，論文作者頁直接連 CorrineQiu/from-where-to-how。Coherent4D 是在 Ego-Exo4D 上建置的配對位置／姿態資料；HIGFlow 是方法名稱。FIction、Detic、Llama 與 WHAM 是來源／依賴，不能替代本論文版本。

分類覆核：既有Coverage已將本作納入資料／評測主來源；本次維持此判定。原文定義Coherent4D資料、固定split、聯合預測目標和具體指標，應同時承認資料、評測與方法貢獻。早期書目M／no標記屬初篩快照，不能用來否定此後原文審閱結果。公開倉庫未釋出預測scorer是另一項可得性缺口。

領域
餐飲與烹飪、醫療與手術支援、交通移動與車輛維修、穿戴互動與動作介面
環境
Ego-Exo4D 的 Aria 第一視角程式影片；Cooking、Health、Bike Repair 三個 domain。第三視角用於離線標註／SMPL 重建，不是預測輸入。787 unique takes 是來源錄製單位，不能當成787個獨立機器人環境。
任務
共同預測有序3D互動位置與同時間的全身 SMPL 狀態。原生21個程式任務由 CSV 按 domain 指定；Cooking/Health/Bike Repair 分別預測10/5/4個事件，並非秒數。公開統計為233828 samples（train193598、val20484、test19746）、1594186個非padding未來 targets、跨domain去重535個物件標籤；這些均為來源統計，未以完整資產重算。
題數與資料
build_chunks 讀 pickle 根層 dataset，按 interactions.time 排序並以 chunk_size 不重疊切分，產生 id={take_name}_{datum_idx}_{chunk_idx}。每筆含 observation_start/end_time_s、history_interactions、target_interactions、target_mask、source_meta 及可選 env_objects；事件有 time_s、time_rel_s、location_norm、object。首個未來事件是時間零，history 嚴格在前30秒（起點截於0）；尾段以 None 加 mask=0。F0 取自 source_meta.source_observation_end_time_s，不隨 chunk 時間原點重新設定；位置用 clip(R0.T@(p-t0)/5,-1,1)。SMPL 附加 history/target_pose_mask、*_pose_frame、*_pose_time_delta_s、*_root_orient6d_f0、*_root_trans_f0_m、*_body_pose_local6d（23×6）、*_joints_f0_m（19×3）。pose位置保留公尺，6D旋轉為3×3矩陣前兩欄按列展平；不能套用不同6D排列。
評估方式
固定 tree 沒有 HIGFlow 預測／benchmark 評分器。已讀論文 §III-C：位置先反縮放至度量空間，ADE 先平均每樣本有效事件再跨樣本平均，ADE90 是每樣本 ADE 的90百分位，FDE 取最後有效事件；姿態用19關節 MPJPE、每姿態相似變換對齊的 PA-MPJPE、Root Trans. 及23個非root關節 Body Geo.，位置報mm、旋轉報度。Single 用第一候選；Best-5 以各樣本有效步的關節誤差選一條候選，再用同一候選算所有pose指標。資料建置的最近影格檢查採 floor(time_s×fps)，預設fps30、誤差上限0.49秒；它只是標註有效性檢查，不能充作預測評分。配對有效性須用 target_mask & target_pose_mask。

怎麼接入我們的benchmark

可重用

原生 domain/task_name 統計、take/datum/chunk 身分、事件時間、F0 metadata、位置／pose 分離遮罩與實際建置函式。

需要轉換

source 記 Ego-Exo4D 派生與外部重建版本；task 保留 CSV domain/task_name，case 用 take+datum+chunk，儲存30秒觀測引用、事件horizon、絕對／相對秒與空間參照。位置正規化／裁切、公尺pose及毫米／角度評分分開記；不可由裁切座標還原超界真值。

仍需補齊

需取得原始takes、確定的take-level split清單、建置後位置／pose caches、SMPL/19關節regressor與模型依賴；補公開預測/evaluator及30張觀測影格抽取對照。再驗證mask、資料規模、共同座標與論文報表一致性。
