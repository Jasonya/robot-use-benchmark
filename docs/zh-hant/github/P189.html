GPT-Fabric: Smoothing and Folding Fabric by Leveraging Pre-Trained Foundation Models

返回逐篇總表核心內容已核讀 方法／綜述參考原作 ↗

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

GPT-Fabric的folding、smoothing與physical分三庫。Folding比較多種合法expert終態，smoothing衡量覆蓋；這些不能合併成同一成功率。

版本與身份

folding102f4ce、smoothing06d9592、physical e0e6195；README提舊model版本變動只是歷史資訊，本次未呼叫LLM API或執行robot。實機庫本輪只核對README入口，核心核讀限兩個模擬分支。

領域
方法／綜述參考，未另作來源用途歸納。
環境
SoftGym/PyFlex方形/矩形布料，沿用Foldsformer初態與demonstration sub-goals；相同config與expert reference保持父來源關聯。實機庫另有平臺專用程式。
任務
4種原生folding樣式及smoothing；每個fold可有多個合法終態。smoothing的trails引數是pick-place步數，並非多次獨立episode或題數。
題數與資料
cached配置、expert info-*.pkl、model info.pkl、示範子目標與query訊息構成評測資料；每種reference fold只是同題多解。smoothing輸出message_step.jsonl和[coverage,improvement] CSV，3位小數為輸出格式；GIF跳frame倍速不代表控制時間。
評估方式
fold每次run對8/9/16個expert粒子終態取最小平均距離，再對run和config平均，輸出乘1000為mm；不取最低run當主結果。smoothing分(A−A0)/(Amax−A0)與A/Amax，前者Amax=A0需處理。naive loop傳last_step_info=None，即使回傳history也不能假設每模式有上一動作提示；LLM model/prompt/API失敗處理須固定。
