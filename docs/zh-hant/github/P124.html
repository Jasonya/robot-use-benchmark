版本與身份

固定2609.08209v2及網站a3589a9快照。網站source含動畫生成工具和展示影片，不宣稱robot benchmark程式／全資料已公開。

領域
居家整理與清潔
環境
原文是實拍桌面人類影片與ManiSkill3/SAPIEN對應場景；多相機影片不是多個獨立物理環境。
任務
10個操作task、4個evaluation suites；任務條件／幹擾和同一task的多視角保留關係，不乘為40種語義任務。
題數與資料
原文正文2,000人類示範，附錄含PD共3,000＝12,000視角影片，另2,000robot trajectories。這些是原文reported量；GitHub展示mp4不能替代正式資料release。
評估方式
原文用模擬predicate、固定初態bank及3runs×20rollouts之每cell設定；抽屜／toaster等閾值需保留。固定網站沒有原生checker／bank清單，未跑評測。

怎麼接入我們的benchmark

可重用

10task/4suites設計、paired人機來源關係、原文成功閾值與多視角區分。

需要轉換

human demo為parent，多view作同一示範媒體；robot episode別存，case固定suite/初態bank/合法觀測與原文predicate版本。

仍需補齊

正式code/data發布、配對及split manifest、初態bank數量矛盾釐清、每任務checker與資產取得。
