P190 · UniGarmentManip

UniGarmentManip: A Unified Framework for Category-Level Garment Manipulation via Dense Visual Correspondence

返回逐篇總表核心內容已核讀 方法／綜述參考原作 ↗

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

UniGarmentManip透過衣物dense correspondence把示範動作轉到新衣物。程式提供3類衣物/3種代表任務的研究框架，但資料配對樣本與實際操控episode須分開。

版本與身份

固定fe15994，CVPR2024原作；本次核讀雙手fold鏈與共用correspondence reader，未聲稱所有支線及實機實驗已重現。

領域
方法／綜述參考，未另作來源用途歸納。
環境
GarmentGym/PyFlex衣物模擬；3種衣物類別、單/雙臂、flat/messy與多步設定屬不同變化維度，不以笛卡兒積當全部已驗證場景。
任務
主要unfolding/fling、folding、hanging；訓練dense correspondence是支援方法，兩point cloud或20對correspondence不是20個robot任務。
題數與資料
HDF5有points/colors/vertices/visible_vertices/visible_indices、camera_intrisics/camera_extrisics、rgb/depth/faces。reader按mesh與deform層配對，__getitem__交替cross-shape/cross-deform，從visible vertices找20對correspondence。converter將.pkl換成h5漏了點，但reader只找.h5，需核對/修正檔名契約。
評估方式
動作從demo點的normalized feature相似度argmax對映到新point cloud，再投影回world控制；fold checker先等穩定，按final/init coverage比例與肩/袖/角點距離判定，各fold type門檻不同。此為幾何啟發式，不直接驗證層拓撲；GT mesh indices只供訓練/判分不能直接作policy觀測。
