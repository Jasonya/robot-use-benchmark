P013 · Ego4D

Ego4D: Around the World in 3,000 Hours of Egocentric Video

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

Ego4D 是多項挑戰共用的人類第一人稱影片庫。本次核讀五類官方倉庫入口，以及 NLQ、VQ3D、狀態變化、長期預測和音訊的核心格式／指標；各子挑戰的完成度分開記錄。

版本與身份

各倉庫固定提交仍有 2022 挑戰說明；不得自動視為所有後續版本的同一協定。episodic-memory 列出近零 NLQ 時窗問題，需固定 annotation release。PNR 無正例 batch 預設回 0，evaluate_trained 可回 None，統計時應保留。LTA 註解名稱與實際使用函式應依賴鎖定的 editdistance 版本核實。

領域
居家整理與清潔、餐飲與烹飪、工藝與修繕、零售與購物、交通移動與車輛維修、農業與園藝、休閒與運動、社交與溝通、穿戴互動與動作介面
環境
多種真實日常與工作觀測；video_uid、clip_uid 與實體環境須分層。五個挑戰倉庫不是五批互不重疊的影片或機器人環境。
任務
episodic memory 包含 NLQ、MQ、VQ2D、VQ3D；手物件包含 PNR、狀態變化分類與物件定位；其他入口涵蓋 looking/talking-to-me、說話者與轉錄、短期／長期動作及未來手／移動預測。子任務數不可當做動作類別或 case 數。
題數與資料
NLQ 原生 videos→clips→annotations→language_queries，case ID 應用 clip_uid+annotation_uid+query_idx；保留 clip/video 的起迄秒與 feature-rate 對映。測試預處理填入的 0,0 是未知答案佔位，不是 GT。音訊 CTM 使用 channel/tb/dur/word，GT STM 另含 speaker/te/txt；RTTM 用於 diarization。
評估方式
NLQ 逐預測計算時間 overlap 與 top-K 超過閾值的比例，程式只列出 evaluated/GT 數，外層必須檢查缺題與重複。PNR 僅對 GT 狀態變化為真的片段，以 16-bin 映回 frame 再換秒。LTA 使用 N×Z×K 序列、每筆取 K 個預測中最小 editdistance.eval/Z，積分字首 ED 得 AUED。VQ3D 提供 L2、角度與依兩位標註者框大小／差異的閾值。轉錄先 lower-case/GLM 過濾後呼叫 SCTK WER；audio-only DER 用 pyannote，另外輸出逐檔平均。

怎麼接入我們的benchmark

可重用

官方子挑戰入口、NLQ 複合 ID／時窗、PNR／LTA 指標實作，以及音訊格式轉換。

需要轉換

一個父 source 下建各 challenge 的 task/case/evaluator；精確保留輸入可見範圍、label/feature/frame/second 單位、K／Z／閾值及 GT 有效遮罩。原生影片重用以 uid 連結，評分逐項儲存，不合成一個成功率。

仍需補齊

尚未取得影片或執行 evaluator。社交任務實作在 lam、ttm 分支，本次只讀主分支入口，不能說無程式；VQ2D、MQ、STA、未來手／移動與社交的完整實作仍須逐支整合。SCTK／pyannote 外部實作未執行。
