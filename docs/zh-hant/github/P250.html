P250 · EgoMAN

Flowing from Reasoning to Motion: Learning 3D Hand Trajectory Prediction from Egocentric Human Interaction Videos

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

EgoMAN 將人類 6DoF 手部軌跡和推理 QA 配對，適合加入語意→預測的共同目錄；官方明確表示 processed dataset 與 model weights 不發布。已核資料建立、loader、trajectory／waypoint 評分鏈，不能把 repo 可讀當成 219K 軌跡或 3M QA 已可下載評測。

版本與身份

固定官方 commit；README 提到新 DINOv3／Qwen3-VL 等依賴，不能假設與 paper checkpoints 完全相同。raw metrics 的 closest_pred 選 minADE，summary 則用 ADE+ROT 係數，兩種 best index 必須分清；已有 processed.pkl 時會跳過重算，需用來源／evaluator hash 隔離。

領域
居家整理與清潔、餐飲與烹飪、交通移動與車輛維修、穿戴互動與動作介面
環境
人體互動影片的 EgoExo4D／Nymeria 衍生資料，HOT3D 作 OOD。camera-relative 手腕軌跡與人體視角推理不是機器人 actuator 命令；需保留原資料 take/sequence 關係。
任務
語意／空間／時間／階段 QA 與 3D 雙手 6DoF trajectory prediction。approach/contact/end stage、任務文字和兩種輸出共用 interaction clip；不把 3M QA 與 219K 軌跡相加成獨立情境。
題數與資料
README 報告 219K 軌跡／3M structured QA，processed dataset 及權重不公開。原生 meters、10 Hz、position+xyzw；模型以每手 position3+rotation6 的 18D 表達、past 5 frames，未來 tensor 最多 50 slots、−1000 sentinel。影片／tracking timestamp ns/us、reference camera transform、stage annotation 及自動 QA provenance 必須同存。品質篩選要求接觸／結束可見且非平凡動作，會影響難度分佈。
評估方式
trajectory：ADE/FDE 公尺、DTW按 warping path length 正規化、ROT度。GT有效 mask 為每 frame 任一座標非−1000，未逐手遮罩；空 GT 回零值且少 best_idx 欄，正式入口需拒收此情況。summary 的 best-of-K 選 ADE+0.001×ROT 最小同一條候選，再報四項，與單純 minADE／各指標各取最小不同。waypoint 取各方法 key 交集，>2 點以 GT 選最佳成對候選；--shift 僅對非 EgoMAN/GT 方法向 GT／最近軌跡點移最多 0.06m，各欄忽略 NaN 後平均。這是帶 oracle／容忍補償的協定，不能當實際物理接觸成功率。
原作數字：保留論文的單位與頁碼

怎麼接入我們的benchmark

可重用

可重用 trajectory／QA／stage 關聯結構、來源追蹤、建立標註的方法和四種幾何誤差定義；code 與 data 授權及發布範圍各自儲存。

需要轉換

case 固定 parent clip、標註者／模型與生成版本、起訖與合法過去輸入、meters／xyzw／rot6d、validity mask。將 raw single prediction、oracle best-of-K、shifted waypoint 分開報表；所有 expected cases 的遺漏／失敗另報 coverage。評測 loader 禁止訓練式壞樣本換下一筆。

仍需補齊

未發布 processed dataset／模型權重，所以本案未取得這 219K／3M 樣本，也未跑推論或 GPT 標註。QA correctness evaluator 與完整基線資產不在本次 trajectory 核讀範圍；新任務需要獨立取得合法資料並完成標註／評分驗證。
