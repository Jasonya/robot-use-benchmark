P244 · BiAnt

Bidirectional Action Sequence Learning for Long-term Action Anticipation with Large Language Models

返回逐篇總表實作尚未確認 方法／綜述參考原作 ↗

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

BiAnt的固定論文、Panasonic作者頁與精確arXiv-ID查詢均未提供可確認的方法repo。已核明forward為8段觀測→20段預測，backward為訓練時16→12；測試只做forward，以5組候選的最低edit distance評測。

版本與身份

快取「BiAnt」repository search共有74筆但只返回8筆，這8筆為無關帳號／專案，未聲稱已排除全部74筆。新增精確查詢「"2508.00374" in:readme」HTTP200、total_count=0、incomplete_results=false。Panasonic作者頁同篇條目只有arXiv link；arXiv頁無method repo連結。結論為限定查證範圍內尚未確認code，不是不存在證明；本輪小型讀取／查詢均200，未遇rate limit。

Bidirectional Action Sequence Learning for Long-term Action Anticipation with Large Language Models；Yuji Sato（Panasonic Connect）、Yasunori Ishii（Panasonic Holdings）、Takayoshi Yamashita（Chubu University）。固定arXiv:2508.00374v1（2025-08-01）；arXiv comments及Panasonic的Ishii作者頁均列MVA2025／Best Poster Award。同頁其他Panasonic code links、AntGPT基線及名稱相似BiAnt搜尋結果不代表本篇實作。

領域
方法／綜述參考，未另作來源用途歸納。
環境
Ego4D v2離線人類第一人稱日常活動，例子包含桌面紙板處理與洗衣。沒有可互動的robot環境；automated driving／robotics為動機，不是新增已測試場景。
任務
以過去action segments中的辨識noun／verb標籤預測未來verb–noun序列。訓練同時用[forward]和[backward]提示；原來8個observed加20個future action形成28段視窗，反向訓練取倒序16段作context、餘12段作target。推論只輸入8段已觀測動作作forward預測，backward所用未來標籤屬訓練資料，不能放進測試可見context。
題數與資料
§3–4將動作形式記為a=(n,v)，Fig.2的實際prompt文字則用verb noun；轉換時須以欄位身份而非tuple位置硬套。母庫詞彙為117 verbs／521 nouns；每segment約240 frames是論文概述，不是固定片長，沒有已核FPS／時間邊界或序列化key。visual encoder與action recognition在本方法LLM訓練時凍結，具體骨幹與reader未能核實，不以AntGPT目前程式補填。LLM為Llama2-7B、引數有效微調、8-bit量化；forward/backward loss權重均1。Table1是Ego4D v2 test；§4另明示task-token ablation使用官方validation中的160樣本，未提供這160筆ID或完整test case數。附錄S1的16是backward context長度，不是推論觀測長度。
評估方式
§4報noun／verb／action三種ED，越低越好；K=5生成候選中選最低ED，Z=20為每條預測的action位置數，不是20秒。未核到距離演算法的操作集合／正規化分母、三種指標是否各自挑不同候選、未知標籤／長短輸出處理、候選取樣引數與scorer。Table1的test分數與160-sample validation ablation及附錄S1數字需分開，不能將160當整個benchmark題數，亦不能將best-of-5 ED改叫單次成功率。

怎麼接入我們的benchmark

可重用

可保留Ego4D v2依存關係、117/521詞彙規模、8→20 forward／16→12 backward設定、方向提示與K=5 ED協定，以及test和160樣本ablation的區分。沒有可直接重用的已核BiAnt loader或evaluator。

需要轉換

source固定arXiv v1並記MVA2025；domain/environment歸人類影片。task將training direction和inference direction分開；case須保留video/clip/segment ID、stopping boundary、verb/noun taxonomy、observed window、20步GT與5條候選。backward pairs僅連train split；evaluator儲存ED種類及候選預算，native action index不任意轉成秒或robot控制命令。

仍需補齊

官方BiAnt repo及commit、28段視窗與反向樣本產生器、GT／辨識label來源和split隔離、prompt/output parser、精確label-ID表、160筆ablation manifest與ED實作。AntGPT是文中採用的baseline，未確認其任何固定commit包含BiAnt改動。
