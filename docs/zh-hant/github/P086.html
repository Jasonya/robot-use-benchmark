P086 · DeformableRavens

Learning to Rearrange Deformable Cables, Fabrics, and Bags with Goal-Conditioned Transporter Networks

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

已核讀模擬主倉庫與實體 cable 實驗補充倉庫。12 個新增柔性物任務共用 Task.reward 分支，但 cloth coverage、袋口凸包、袋子搬運與真機 mask IoU 是不同指標；bag-items 的 task.done 只要求正分，不能直接當論文完整成功。

版本與身份

兩倉庫均固定 2023-06-11 commit；模擬 README 的 metric 概述仍只寫 pose/zone，實際新增分支更多。原生狀態／示範及 PyBullet、Franka 控制均未執行。

模擬 README 明示 ICRA 2021 完整題名及作者、繼承 google-research/ravens，並直接連結 gctn_physical；後者 README 反向指向模擬倉庫。論文 arXiv:2012.03385v4 含後加真機章節，不能把 2023 真機程式視為 2020 初稿內容。

領域
衣物與洗護、包裝、倉儲與物流
環境
模擬為 PyBullet UR5 桌面與三臺 RGB-D camera，z 軸向上；柔性 cloth/bag 需 deformable world，environment 註解要求至少 480 Hz，CLI 預設卻是 240，必須保留實驗命令設定。真機另為 Franka Panda＋手部 Azure Kinect、foam 工作面及校正轉換。
任務
新增 5 cable、3 cloth、4 bag，共 12；全 registry 另含原 Ravens 任務與 insertion-goal。cloth-flat 等程式名稱對應論文 fabric-*；bag-items-easy/hard 對應 bag-items-1/2。cable-ring-notarget 只是無可見標線，load.py 未將它列為 goal-image conditioned 任務。bag-items 以開啟、插入、搬運三 stage 及各 stage primitive 引數組成。
題數與資料
Dataset 將 color/depth/action/info 存成各目錄相同的 {episode:06d}-{length}.pkl；RGB uint8 為 T×3×480×640×3，depth float32 為 T×3×480×640。最後一筆另存 last_color/last_depth/last_info，不在 action 長度內；goal 預設取同回合最後狀態，也可抽未來時間。action 有 camera_config、primitive、params.pose0/pose1；info 儲存 object_id→(position,rotation,dimensions) 及 extras。真機 trial_info 的 img_dict/eval_metrics 應比 act_dict/gctn_dict 多一筆，舊 trial 有缺尾；depth 原始毫米、mask 160×320，需保留 crop 與相機外參。人類示範取像不是 robot rollout。
評估方式
模擬 reward 回傳當步 delta，extras.total_rewards 保留當前值。cable-target 檢查每珠到任一目標 XY 距離 <3.5×radius、全數合格才 done；ring 面積除 πr² 達0.75，bag-alone-open 達0.70。cloth-flat 以目標交集/目標面積達0.85，另記 IoU；cloth-cover 要 cube 在 segmentation 不可見且距四角中心≤0.25。bag-items 在 stage3 以物體入 zone 比例與袋口珠入 zone 比例各佔0.5，done 只要求 total_rewards>0；訓練 main.py 另過濾不完整示範，測試 load.py 僅排除 t=0 或 exit_gracefully，不能沿用示範過濾作 test success。bag-color-goal 以目標物可見畫素位於目標袋口凸包的比例≥0.95，先要求可見袋口珠比例>0.33；不是完整3D containment。load.py 每2000 iteration 評測一次，共10 snapshots，各20個有效回合，seed 從10000開始，保留重抽計數與 final_info；論文第5頁對3訓練runs的60個指標先平均再取10 snapshots最大值，bag-color-goal僅1 run。真機 evaluate_masks 算交集/聯集，另有交集/min(mask面積)；論文成功為10動作內 IoU>0.25，程式只存連續值、README 使用手動退出，尚無完整自動成功彙總。

怎麼接入我們的benchmark

可重用

新增 task subclasses、metric 分支、RGB-D／goal 配對、seed 與 snapshot 的結果 pickle，以及真機 mask evaluator。

需要轉換

source 分兩個 commit；environment 分 UR5 模擬與 Panda 真機；task 儲存 paper_name↔code_name 與 Ravens 繼承；case 綁 seed／goal episode／初態；evaluator 分 delta、raw score、task.done、termination_reason 及 paper-success。t=0 為取像而非操作，所以 max_steps=21/11/3 等不能直接作動作數；有效 cable 通常20、cloth-flat10、cloth-cover2次，bag依子類8或9次。

仍需補齊

資料／goal 資產清單與每次重抽 seed；論文 bag-items 完整成功的結果彙總對接；10-snapshot 選擇與獨立測試分割；真機10-goal清單、手動停止紀錄、完整校正和缺尾 trial 處理。
