DROID: A Large-Scale In-The-Wild Robot Manipulation Dataset

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

DROID有原始蒐集平臺與policy-learning兩個官方倉庫；raw/RLDS、更新語言與相機標定是同一來源的不同發行物。實機成功由人員標記。

版本與身份

2024-12新增75k成功episodes的多語言、2025-04更新36k標定為作者公佈更新，不新增獨立資料集。policy loader依賴Octo85b83fc，不能自動換成目前HEAD。

領域
居家整理與清潔、餐飲與烹飪、辦公與教育
環境
多站點DROID robot及相機配置；schema有lab/building/scene_id/robot_serial與外參，不用平臺數代替環境數。scene_id=-1表示未提供值，須保留未知而非新場景。
任務
language/goal條件物件操作；示範、失敗、下游自選任務和eval trials不同集合。三句語言描述對同episode不增加實體軌跡。
題數與資料
raw為trajectory.h5、metadata與多視角MP4/SVO；RLDS有episode_metadata和steps含3圖、state、action_dict、多語言與episode flags。training transform用cartesian_position轉pos3+rot6+gripper1，另移除第一action；預設只取success路徑及有語言資料。
評估方式
實機GUI由人員按鍵儲存success/failure，metadata未提供success時為None。RobotEnv的step返回action_info，不能當task success。檔案flat action7D註解提6joint velocities，但RobotEnv區分cartesian7/joint8，使用時應以明確action_dict及converter核對語義。

怎麼接入我們的benchmark

可重用

UUID/lab/scene/version、原始與RLDS對映、相機標定、action_dict、人評標籤。

需要轉換

一個parent episode連raw/RLDS/語言更新/標定版本；case固定模型可見相機、座標/control mode、初態與人評rubric；training選樣不得當完整benchmark分母。

仍需補齊

大型素材、UUID至更新標定/語言的全量join、原成功標籤和case集合、原生評分者一致性、實機或匹配模擬執行。
