EgoMonth: A Month-Level Egocentric Video Benchmark for Long-Term Spatiotemporal Memory

返回逐篇總表檔案／網站 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

susu801/EgoMonth 的 README 與網站對應同名論文的 301 小時／738 clips／1,443 QA／14 題型，但 pinned 完整 tree 只有靜態頁面與圖片。檔案聲稱存在的 scripts/ 與評測程式均不在此 commit；尚不能視為已公開可執行 benchmark。

版本與身份

程式來源固定 81143141d98b4511ff1adcae9a5ccf3a9f0f9606（2026-09-22），PDF 為 2608.13113v1。非截斷 tree 的 15 個 entries 中沒有 scripts/、.py 或資料 JSON；README/index.html 的存在宣告與此版本實物不一致。未嘗試用別人的同名倉庫填補。

核對 arXiv:2608.13113v1 首頁題名、作者及正文。候選倉庫完整題名、統計與題型一致，足以確認內容所指論文；但 pinned PDF 未連到該倉庫，README/index.html 僅署名 EgoMonth Team，未提供作者名單或 arXiv 反向連結，因此 susu801 的作者官方身分仍未獨立證實。

領域
居家整理與清潔、餐飲與烹飪、辦公與教育、零售與購物、交通移動與車輛維修、休閒與運動
環境
人類日常第一人稱錄影，20 名參與者各跨 20–120 天、室內外與不同裝置；論文有學習工作、交通、飲食、購物、休閒、家務六種活動分類，沒有可執行 scene registry 或實體場所去重總數。
任務
保留 Table 1 的 14 QA 型別：Habit Inference、Personality Inference；Detail Retrieval、Spatial Relation、Self-localization、Temporal Ordering、Event Time、Object Location；Procedure Planning、Event Counting、Object Counting、Route Reasoning、Cross-view Spatial Reasoning、Direction Judgement。三組分別是 Schema Consolidation、Episodic Indexing、Cascading Reasoning；它們是影片記憶／推理題型，非機器人動作任務。
題數與資料
已讀到的 schema 僅是 README 檔案示例：JSON list，每筆 video_path 為一至多個相對影片路徑，question、四個 options、correct_options 字母與 task_type；檔案稱以 CONFIG["video_root"] 接路徑，但沒有可核對的 loader。論文報 738 clips、18,072 分鐘與 1,443 人工四選一題；這些是論文統計，未取得 QA manifest，不能宣稱已清點實際 release。跨日參與者／session ID、時間戳格式、每類實際題數與 split 檔均未見。
評估方式
論文 §4.1 與 README 定義 micro Acc = 全部答對題數／全部題數（完整論文集合 N=1,443），macro Avg = 14 個題型各自 accuracy 的等權平均；直接比對正解，無 LLM judge。各模型觀測預算不同，例如 16／64／256／512 frames 或 1 fps，需保留。固定 tree 未含 README 所稱的 Qwen 等指令碼，因此無法核對答案字母 parser、多影片拼接／抽幀、錯誤／空回答如何入分母，也沒有可追的 concrete scorer。

怎麼接入我們的benchmark

可重用

可重用有來源的 14 題型、三認知層級、論文統計、檔案示例 schema，以及 macro／micro 的分開定義；倉庫先列檔案來源。

需要轉換

source 保留 paper v1 與候選 repo commit／身分狀態；environment 用參與者與生活錄影脈絡；task 保留原生 task_type。release 到位後，case 以原始 QA ID 關聯有序 video_path[]、question/options/correct_options，另儲存 participant/day/session、媒體時間及觀測預算；單片與跨片同屬一題，不能按片重複計數。evaluator 分列 micro 與每類及 macro 分母。

仍需補齊

作者官方連結、QA／split／影片 manifest、可讀 loader、實際答案解析與 scorer、跨日時間對齊、抽幀及例外處理。現階段不能產生已驗證可執行 case 清單。
