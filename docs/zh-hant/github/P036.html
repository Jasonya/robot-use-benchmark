P036 · EgoT2

Egocentric Video Task Translation

返回逐篇總表核心內容已核讀 方法／綜述參考原作 ↗

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

EgoT2 將七個 Ego4D 任務互相遷移，屬方法參考；已核讀資料來源與 OSCC/PNR 的實際輸入和評分，並辨識 eval_lta.py 的名字與當前輸出不同。

版本與身份

論文表的 ED@20、repo 某個 eval_lta.py 及 challenge submission 屬不同路徑，須固定可重現入口後比較。父資料版本仍依 Ego4D 原來源，related_reference 不加到183份 benchmark/data 來源量。

領域
方法／綜述參考，未另作來源用途歸納。
環境
共用 Ego4D 影片，分人與人互動 HHI、人與物 HOI。任務融合不等於跨資料集新增七套環境。
任務
LAM、TTM、ASD、PNR、OSCC、AR、LTA；各有原生條件。faces localized/tracked 是 HHI 的前置輸入，PNR/OSCC 用狀態變化片段，LTA 與 AR 共用 verb/noun vocabulary。
題數與資料
docs 分別連官方 social-interactions 的 lam/ttm 分支、ASD、hands-and-objects、forecasting。HOI batch 含 orig 的 frames/labels/state_change/fps/info，另有 recognition 或 pnr 輔助視覺輸入。提交以 unique_id+state_change bool 或 clip-relative pnr_frame 識別。
評估方式
OSCC 逐例 argmax 後全樣本正確率；PNR 僅 GT 有變化時計16-bin到frame的距離，再除各自fps成秒。eval_pnr.py 平均 batch 平均，無正例預設0需保留。通用輸出 metric 在合法 token 子集再取 argmax，另列 out-of-task token 比率。當前 eval_lta.py 只評 forecast_labels 第一動作的 verb/noun accuracy，不是 README 的 ED@20。

怎麼接入我們的benchmark

可重用

七項父任務關係、auxiliary inputs、輸出 token 子集與 OSCC/PNR adapters。

需要轉換

保持 source=P013 的 benchmark/case 身份，另記 translation method、可用輔助模型與輸入。evaluator 對 PNR 秒誤差、OSCC accuracy、LTA ED 各自留協定，不能依檔名將第一動作 accuracy 改叫長期 ED。

仍需補齊

未執行訓練／推論。完整 HHI mAP 和 LTA ED 提交流程仍需追核；PNR/OSCC 通用 metric 的重複 unique_id 只列印、continue 被註解，需全量去重與分母檢查。不得由融合模型結果估算新的任務數。
