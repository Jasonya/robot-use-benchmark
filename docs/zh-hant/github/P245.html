Vision and Intention Boost Large Language Model in Long-Term Action Anticipation；Congqi Cao、Lanshu Hu、Yating Yu、Yanning Zhang，Northwestern Polytechnical University。固定arXiv:2505.01713v1（2025-05-03）；ICVL在本篇指Intention-Conditioned Vision-Language，不是同縮寫的其他資料庫或實驗室。AntGPT、PALM及候選帳號的STDD／Open-MeDe／Cue-R1均非本篇code。

領域
方法／綜述參考，未另作來源用途歸納。
環境
Ego4D人類第一人稱日常環境，及EPIC-KITCHENS-55／EGTEA Gaze+的廚房活動影片；都是離線影片預測。意圖是VLM從已觀測影格推斷的文字，並非新增人工意圖真值集，也沒有robot場景／控制介面。
任務
ICVL先辨識歷史verb–noun labels，再從按時間順序抽取的觀測影格逐步推斷intention；每次VLM輸入包含先前生成的intention context，以最後結果作最終意圖。ICAF以意圖embedding為query、視覺embedding為key/value，再與文字prompt合併預測未來序列。Ego4D目標是noun／verb／action序列；EK-55與EGTEA明定為剩餘影片中會出現的verb集合，不能把兩者共用一個sequence evaluator。
題數與資料
§3：segment Si對應Ai=(vi,ni)；每段均勻取k影格形成visual embeddings，總數T=Nseg×k，意圖另取Nfrm影格；k/Nfrm的數值、FPS、實際annotation key及split manifest未提供可核reader。歷史action recognition用CLIP ViT-L/14與Transformer加兩個MLP heads；ICAF的visual encoder為BLIP2-OPT-2.7B，意圖VLM原文明寫「LLaMA 3.2-9B」，text encoder及預測LLM為LLaMA 3-8B，精確模型ID／revision仍待設定檔核實。例子只從training pool取observed labels與future labels；先對視覺及文字embedding的L2距離各自min–max正規化，再用α加權，距離較小為較相似。α實際值、零距離範圍／ties處理未核到。§4.4雖說7例最佳，最終結果明確採3個例子。Ego4D的243小時／3472 clips、117 verbs／521 nouns以及EK-55的125／352與EGTEA的19／51詞彙量皆為原作母庫描述，非ICVL已核case數。
評估方式
§4.1的Ego4D：Nseg=8、Z=20、K=5，對noun／verb／action分別報minimum Damerau–Levenshtein ED。完整距離實作、正規化分母、三項是否各自取min及生成錯誤處理未核到。Ego4D只稱standard splits，Table1未明列具體版本／評測split ID。EK-55與EGTEA則沿EGO-TOPO設定：觀測首P%=25/50/75%，預測其餘部分的verbs only，於validation報multi-label mAP All/Freq/Rare；未取得序列轉verb分數、頻率分組與AP聚合程式。3個ICL例子、5條生成候選、8個觀測segments及20步預測是不同預算，均非題數。

怎麼接入我們的benchmark

可重用

可重用observed video→辨識labels／生成intention→ICAF→LLM的資料流、training-only例子來源、距離融合規則、3-shot例子預算與原生Ego4D ED／EK-EGTEA verb-mAP規格。沒有已核ICVL模型實作或evaluator可接線。

需要轉換

source保留arXiv v1及母資料集依存；domain/environment限定離線人類影片。task分有序verb–noun forecasting與無序verb presence。case應儲存觀測視窗、原生labels、生成意圖、visual/text表示引用、3個training example IDs與5條預測；intention標為model_generated，訓練例子的future labels與test GT隔離。evaluator分開儲存ED與All/Freq/Rare mAP，母庫clips、frames及詞彙不展開成虛構案例。

仍需補齊

官方ICVL repo／commit、精確模型型號與版本、影格／segment reader、資料／類別與split IDs、example pool及去重隔離規則、prompt/輸出parser、ED與verb-mAP scorer。需確認原文LLaMA 3.2-9B型號、α及frame抽樣值；不能借用AntGPT、PALM或STDD的程式視為ICVL已實作。
