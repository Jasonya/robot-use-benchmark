P242 · NAOGAT

Leveraging Next-Active Objects for Context-Aware Anticipation in Egocentric Videos

返回逐篇總表實作尚未確認 方法／綜述參考原作 ↗

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

已核NAOGAT原作、WACV刊載頁及作者現行project：GitHub仍標示Soon，EK-100新增NAO框標註須向作者索取。可收錄論文層級的STA方法與標註衍生關係，尚無可固定commit並核讀的官方reader／evaluator。

版本與身份

2023年arXiv摘要承諾接受後提供code；2026-10-11讀到同篇project仍為GitHub(Soon)，有Code標題但沒有方法連結。project文末誤標WACV 2023，刊載年份以CVF 2024為準；本筆技術內容僅按已固定arXiv v3核讀，未聲稱和會議PDF逐段一致。探索用/wacv24短網址返回404，其後由作者about找到可用現行project；這不是GitHub repo不可用或全球無code的證明。本輪小型HTML讀取除該404外均200，未遇429／rate-limited403；未聯絡作者或讀取內嵌影片。

精確題名為Leveraging Next-Active Objects for Context-Aware Anticipation in Egocentric Videos；Sanket Thakur、Cigdem Beyan、Pietro Morerio、Vittorio Murino、Alessio Del Bue。核讀快取arXiv:2308.08303v3（2023-10-05）；CVF確認WACV 2024、pp.8657–8666。作者about以略不同的Short-Term題名連回同一arXiv及本project。ANACTO、GANOv2是另篇方法；網站模板richzhang/webpage-template亦非NAOGAT程式。

領域
方法／綜述參考，未另作來源用途歸納。
環境
Ego4D人類第一人稱日常活動及EPIC-KITCHENS-100廚房影片，皆為離線觀測。STA假設下一互動物件在最後觀測影格可見；EK-100原有action anticipation並不保證此條件。未提供可reset的robot場景或動作控制介面。
任務
輸入截至T的RGB序列，預測下一active object的noun類別n、最後觀測影格中的bounding box b、未來動作verb v及距接觸的δ秒。NAO定位與動作／TTC聯合預測屬一個STA問題的不同輸出，不是四套機器人任務。EK-100實驗仍須和Ego4D STA分開記錄。
題數與資料
§3–4.2：16影格、4 FPS；訓練resize高度248–280 pixels並crop224。Faster R-CNN偵測輸入為每物件4個框座標加confidence，固定Q筆不足時padding；Q/Nq的實際值、座標順序／正規化與序列化key未能由reader核實。Ego4D forecasting部分稱逾1000影片、STA標註30 FPS；EK-100母庫97 verbs／300 nouns／約90K action segments皆非本篇有效case數。附錄§7的EK-100框由GT noun匹配偵測器結果產生，失敗再用hand-object ROI及top-3 noun候選；noun仍沿用EK標籤，不是新人工重標整庫。12.5% training、6% Unseen及約22% Tail的NAO缺失分別有不同分母；附錄另把22%稱validation中的「Test Set」，需原始ID核對。現行project只提供索取標註的聯絡方式，沒有已取得的annotation檔、split manifest或loader。
評估方式
僅核到paper protocol：§4.3以noun／verb top-1判對、box IoU≥0.5及|TTC誤差|≤0.25秒；聯合條件須全部滿足。Table1列8種b/n/v/δ組合的AP，但正文概述稱4組，應保留各欄位而非併成單一成功率。候選預算、AP積分／macro平均、confidence合成及漏標樣本處理沒有scorer可核，不能逕套另一篇Ego4D的Top-5實作。EK-100 Table2分Unseen/Tail/Overall及action/verb/noun；§4.3僅援引先前方法的metric，未在本版明列其Top-k／類別平均細節。§4.4剔除無NAO的tail clips後所得分數屬另一次過濾評測，不能覆蓋原validation分母。

怎麼接入我們的benchmark

可重用

可重用原作身份、Ego4D STA／EK-100衍生框標註關係、四項預測輸出、16frame/4FPS輸入及論文明列的IoU與TTC門檻；尚無已核可執行reader或scorer。

需要轉換

source保留arXiv v3及WACV 2024關係；domain/environment限定人類影片脈絡，task以STA定義建檔。未來case須帶video/segment身份、最後觀測影格、原生box參照、noun/verb taxonomy、δ秒及缺失NAO原因；Ego4D、EK原split及過濾子集分開。evaluator儲存各AP組合與尚待核實的EK metric，不把母庫frames/segments或模型queries當case數。

仍需補齊

作者可確認的官方方法repo／commit、EK衍生框檔案及授權、精確split與NAO缺失ID、座標／時間轉換reader、分類與AP evaluator。需釐清附錄Test Set／正文Tail Set及EK metric細節；ANACTO或GANOv2程式不可代填。
