Decision-Aware Uncertainty Evaluation of Vision-Language Model-Based Early Action Anticipation for Human-Robot Interaction

領域
餐飲與烹飪
環境
EGTEA Gaze+與EPIC-KITCHENS-100離線人類第一人稱影片，包含廚房活動；沒有本篇可reset的robot環境。§VI明言interaction analysis使用模擬confidence-gated decision policy，尚非real robotic deployment。母資料庫約10K及逾90K action segments不是本篇已核test case清單。
任務
雖摘要反覆使用short-term action recognition／temporal prefix措辭，§IV-A明確指定觀測action onset之前的影像、預測緊接的next action。因此保留pre-onset anticipation標記，不將本篇逕改成已開始動作的early recognition。輸出是同一未來動作的Top-K候選verb–noun labels及confidence，K是候選數，不是K步未來序列。Fig.1的after 1 s為示意；實際觀測時窗、提前量、取樣FPS與prefix切點並未由reader固定。
題數與資料
每input以Gemini 2.5 Flash-lite black-box API及相同prompt獨立抽樣M=5次，temperature=0.8，每次K=10。以a[i,k]記第i次第k順位動作、p[i,k]為該動作的verbalized confidence；這些是論文符號，非已核JSON key。Consistency逐rank多數決，c[k]為該rank支援勝出label的次數/M；Confidence-weighted逐rank以p加權，c[k]=勝出label的confidence總和／所有runs於該rank的confidence總和。PairRank先取跨runs唯一label集合A，由順位生成pairwise preferences，再以Bradley–Terry MLE擬合s(a)，softmax成P(a)並選Top-K。rank-wise confidence不必形成總和1的類別分佈，須保留各方法的原生尺度。單次baseline只有1次抽樣；M、K及唯一label數不能計成額外case。缺prompt、label正規化／parser、實際prediction檔案、model revision、test ID與split reader。
評估方式
§III-C／IV-D：Top-1 accuracy與Recall@K按每input唯一GT動作比對。Top-1 ECE及Set-ECE均用[0,1]上的10個等寬bins；Set-ECE以z=1[GT在Top-K]為target、c_bar=(Σ_k c[k])/K為set confidence，再按bin樣本佔比加權絕對校準差。這是作者明定的平均confidence，不能暗換成Top-K機率總和。Selective policy只對首位label採c[1]≥τ；coverage分母為全部N個inputs，selective accuracy分母為通過門檻的inputs。Entropy另先將Top-K的c除以其總和，再算−Σp log p/log K；不得把此正規化後的p倒灌到原生ECE／gating。§IV-A稱官方train/test與test結果，但精確case IDs、GT取得／提交路徑、匹配規則、bin邊界與空bin／零coverage處理均未核到。Fig.5的K=5、τ=0.39只是澄清範例，不是預設整批評測設定或安全保證。

怎麼接入我們的benchmark

可重用

可保留pre-onset next-action目標、M=5／K=10／temperature0.8、三種aggregation公式、10-bin ECE、作者定義的Set-ECE、coverage/selective-accuracy分母及entropy診斷。尚無可直接重用的已核程式。

需要轉換

source固定v2與母資料集版本關係；domain/environment記人類影片觀測，HRI是評測動機。每case保留onset/observation boundary、GT verb/noun、每run每rank的raw label/confidence及聚合結果；evaluator分correctness、calibration、selective utility與confidence geometry，明記confidence構造及entropy專用正規化。保留abstain／retained case集合、model/prompt與取樣預算，不建立跨方法通用success score。

仍需補齊

作者可確認的repo／commit、精確觀測與test manifest、API model/prompt設定、動作同義詞／label-ID parser、重複label及rank ties規則、Bradley–Terry擬合與正則化、零confidence／零分母／K=1 entropy邊界，以及完整ECE與gating實作。實體HRI控制、clarification真值及安全驗證不在本輪已取得來源內。
