OpenEQA: Embodied Question Answering in the Era of Foundation Models

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

OpenEQA 的 question/answer/history 格式和文字裁判已可具體追溯；本次核讀一筆原始 QA、歷史取得方式、兩種 prompt 與完整評分指令碼。

版本與身份

data README prose 寫 simulator2.5，但實際安裝命令是 habitat-sim0.2.5；以明確套件版本和歷史版本為準。RGB直接下載被作者標為第三方hosting，官方來源身份與實際分發者需分欄。

領域
居家整理與清潔、辦公與教育
環境
episode histories 來自 HM3D 與 ScanNet；HM3D 用 Habitat 重播 agent states，ScanNet 從原掃描資料抽取。episode_history 路徑連回 scene/source；RGB、depth、pose 是同歷史不同觀測，不新增場景。
任務
開放詞彙環境問答，可討論 episodic memory 和 active exploration；此核讀 evaluator 判文字答案，沒有證明某 agent 已完成探索或操作。
題數與資料
open-eqa-v0.json 例含 question_id、question、answer、category、episode_history，可另有 extra_answers。HM3D 版本為 hm3d-v0/場景路徑，資料檔案提供 RGB-only 或 RGB-D+intrinsics+pose；原 scan/agent state 與 extraction 版本要隨 case 儲存。
評估方式
llm_match 預設 gpt-4-1106-preview/seed1234/temperature.2/max_tokens32，以原參考與可選 extra_answers 判1–5；parse Your mark 後整數。evaluate-predictions 先核 ID/數量、截掉最後句點後的尾文、逐題快取，再將clip(score,1,5)線性映成0–100平均。prediction=None 回0後映為0；force 只對提供的 result 遍歷，dry-run 只取前5，均不能報全量分數。

怎麼接入我們的benchmark

可重用

穩定 question_id、scene/history 路徑、參考答案與替代答案、原始 judge prompt／正規化。

需要轉換

environment 儲存父 HM3D/ScanNet scene 和 extraction release；case 綁 question_id/history/modalities/觀測 budget。evaluator 固定裁判版本、prompt hash、預處理、cached score 來源；完整資料／結果 ID 一對一，force/dry-run 和缺題另標。

仍需補齊

尚未取得 histories、執行 simulator／baseline／付費裁判。只讀 QA /0 schema 範例，未逐題驗證全庫；若更換模型或 prediction，舊 metrics 快取需按輸入hash區分，並另外驗證裁判與人工一致性。
