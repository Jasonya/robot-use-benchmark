P248 · HOIMotion

HOIMotion: Forecasting Human Motion During Human-Object Interactions Using Egocentric 3D Object Bounding Boxes

返回逐篇總表核心內容已核讀 方法／綜述參考原作 ↗

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

HOIMotion 以過去人體姿態和頭部視角的 3D 物件框預測人體動作，重用 ADT／MoGaze。已核兩套 loader、跨參與者設定與 MPJPE；物件框頂點、圖節點和人物關節都不應計為任務數。

版本與身份

官方來源固定 commit；ADT preprocessing 明載資料版本 1.1.0。default script 的 train→eval 不是唯讀測試命令，沒有在本機執行。

領域
方法／綜述參考，未另作來源用途歸納。
環境
Aria Digital Twin 與 MoGaze 的人類物件互動場景；ADT 原生 work／decoration／meal 三活動類，MoGaze pick／place 兩類，不能把五個標籤當五個新獨立物理環境。
任務
單一人體 3D motion forecasting 任務，按用途與 holdout participant 分組。21 joints，10 個過去 frame→30 個未來 frame（評分假設 30 Hz）；兩個 dynamic／兩個 static objects，各 bbox 八個頂點作模型輸入。
題數與資料
原生 .npy 檔依 sequence 提供 pose xyz、head、dynamicbbx、staticbbx；loader 各自排序後用相同 list index 配對。每個連續 40-frame 視窗可重疊，train_sample_rate=2 只抽視窗，不把影片 FPS 降半。MoGaze 測試 p1／p2／p4／p5／p6／p7 六個 holdouts，每人可有多個 session。
評估方式
MPJPE=未來各關節 xyz 歐氏距離的平均，先 batch 平均×batch_size 累加再除總 sample；輸出 mm、每未來 timestamp／joint 另列。zero-velocity baseline 重複末個觀測 pose。velocity loss 僅訓練用，沒有加到報告 MPJPE。ADT training 將 test 目錄作 validation 選 best checkpoint；MoGaze 也以 holdout participant 作 validation，完整模型選擇條件應保留。

怎麼接入我們的benchmark

可重用

可重用兩父資料的 actor/session、動作標籤、21-joint pose、3D bbox 與原生 MPJPE；使用者研究 N=20 是獨立感知評價，不併入樣本題數。

需要轉換

標準 case 以 parent sequence／window 起點識別，明定 30 Hz、21 joints／米、過去 bbox 可見性與 split role；檔案配對改用 sequence key 並驗證一致。新增真正 untouched test split 時另列為擴充協定。

仍需補齊

本次未下載 ADT／MoGaze 原始素材、未執行訓練。各用途的精確視窗數需由完整檔案 manifest 重算；原始資料及工具授權／版本各自保留。
