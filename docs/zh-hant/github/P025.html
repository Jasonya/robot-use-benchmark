EgoPet: Egomotion and Interaction Data from an Animal's Perspective

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

EgoPet 分成動物互動 VIP、動物移動 LP，以及四足機器人資料上的 VPP。已核讀三項定義與實際評測，不能把動物影片或 latent 回歸直接算成機器人完成任務。

版本與身份

主 README 的會議年份文字不可單獨作書目依據，身份由標題／作者／專案互連確認；LP 文案的 40 點／4 秒和命令的 num_pose_prediction=120/fps/pps 需依實際 pose_skip 對映，不能只抄旗標數字。

領域
寵物照護與動物活動
環境
VIP/LP 是動物第一人稱影片；VPP 另用四足機器人在 office/park/beach 的錄製與日夜／地面移轉。影片來源、robot episode 與實體地點分層。
任務
VIP 判斷是否互動與 17 種互動物件；LP 預測尺度模糊的未來相對軌跡；VPP 從影像預測 proprioception-derived latent，在 -1.5、-.8、0、.8、1.5 秒條件分項比較。
題數與資料
VIP CSV 含 animal、ds_type、video_id、segment_id、start/end_time、interacting_object、video_path；LP 另存 DPVO stride 和 TUM trajectory。LP loader 用 training_set/validation_set、cat/dog、有效檔案過濾，test 最長截到 50 秒；sample index 不等於完整來源總量。
評估方式
VIP interaction 使用 sigmoid/accuracy/BinaryAUROC；object top-1/top-3 與 macro AUROC 僅在 GT 有互動樣本算。LP 以方向正規化增量預測，重建時乘回 GT 增量尺度，再用 evo align=True/correct_scale=True 的 ATE/RPE RMSE；不是無尺度輔助的導航成功率。VPP validation 用 MSE，loader 設 drop_last=True，分散式補齊可能重複樣本；百分比形式列印的 loss 不表示 accuracy。

怎麼接入我們的benchmark

可重用

三項原生 task、CSV、軌跡處理與 VIP/LP/VPP 評分流程。

需要轉換

animal source 與 robot transfer source 分開並連 pretraining 關係；case 保留 horizon、fps/pps、DPVO stride、方向／尺度、有效樣本、GT scale 使用範圍與 episode split。分類、軌跡 RMSE、latent MSE 保持分項。

仍需補齊

尚未取得影片、DPVO 軌跡、CMS robot 資料或執行。LP 例外只印出後略過，需儲存實際評分／失敗清單；VPP 須額外取得 latent 生成版本，不能宣稱提升實體走路成功。
