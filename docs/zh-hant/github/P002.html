HowTo100M: Learning a Text-Video Embedding by Watching Hundred Million Narrated Video Clips

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

這個倉庫提供影片—文字表徵訓練與跨資料集檢索評測；HowTo100M 是訓練資料來源，程式的主要評測入口另外讀 MSR-VTT、YouCook2 和 LSMDC。

版本與身份

本輪讀取固定 commit 的公開程式；不把 README 的歷史「largest」敘述當成現時排名。

領域
餐飲與烹飪、辦公與教育、工藝與修繕、個人照護、交通移動與車輛維修、農業與園藝、休閒與運動、寵物照護與動物活動
環境
原作影片／YouTube 來源作觀測脈絡；這個倉庫沒有可直接當成本庫互動環境的 scene registry。
任務
保留 CSV 的人類 task 標籤與影片—文字檢索題型；不能把字幕片段或人類活動直接改成機器人任務。
題數與資料
CSV video_id/task/path、caption 起訖時間、2D/3D 特徵。loader 明示兩種特徵各自的取樣頻率；完整影片與特徵由外部下載。
評估方式
eval.py 將影片與文字配對矩陣送到 metrics.py，以正確配對的排名算 R@1/5/10、median rank。README 指出 YouCook2 使用 validation 集合。

怎麼接入我們的benchmark

可重用

影片 ID、字幕時段、活動標籤、下游檢索 split 與 metric 可以保留。

需要轉換

轉成 video/context 紀錄與檢索 case；分開儲存原片時間、各特徵頻率及對應關係，另記真正使用的下游資料來源。

仍需補齊

原始素材／特徵下載閉合、跨來源影片重複、共同用途對映與本庫 evaluator 接線。
