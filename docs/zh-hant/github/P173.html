LabDex: A Hierarchical Benchmark for Dexterous Manipulation in Laboratories

返回逐篇總表檔案／網站 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

LabDex的GitHub目前是展示網站，Code標Coming Soon；作者連結的HF dataset card已核對，但還沒有可核驗的task evaluator實作。

版本與身份

固定3d1c43b網站與2608.18618一致；2026-10-11已讀serandt/LabDex公開card。Code仍Coming Soon，未把網站或8000+宣告當已整合case。

領域
實驗室操作
環境
實體與模擬共用Franka Research3+XHand，三個相機視角、20+laboratory assets；同場景多視角不增加環境數。
任務
原文概觀為30+Atomic、10+Compositional、1Long-Horizon workflow；實驗表實際比較26atomic instances、7種操作類別。整體collection、已報評估subset及family是不同層次。
題數與資料
HF card宣告8000+demo和1M+trajectory steps，包含同步多視角RGB、proprio、action、hierarchical annotations；card未給詳細鍵名/檔案佈局，本次沒有下載demo。50為每task評估trial數，非demo總量。
評估方式
原文成功要求末stage後狀態在目標容差內連續2秒；atomic報SR，composite/workflow另報各atomic成功及每rollout平均完成數。必須取得容差、stage/時間checker才可執行。

怎麼接入我們的benchmark

可重用

三層task結構、原生demo/trajectory量、2秒穩定成功協定與作者dataset入口。

需要轉換

environment保留robot/相機/asset版本；task建立atomic→composite→workflow關係，不重加共享subtask；case記phase/容差/穩定時間和split。

仍需補齊

正式code、可解析episode manifest、確切action/clock schema、容差與每task成功規則、真實/模擬資料分割。
