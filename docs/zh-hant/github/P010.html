核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

EPIC-KITCHENS-100 需保留五項挑戰各自的資料與評測約定；本次核讀總標註、敘述工具及 C1 動作辨識實際指標，沒有把其他挑戰概括成已整合。

版本與身份

固定提交的說明列出 P01_109、P27_103 預抽幀錯誤；原始影片與標註不受影響，資料取得時必須儲存修正版本。narrator 是工具，並非額外 benchmark。EPIC-55 many-shot P/R 不等於本版 tail 指標。

領域
居家整理與清潔、餐飲與烹飪
環境
沿用部分 EPIC-55 廚房影片並新增拍攝；PXX_YY 與 PXX_1YY 的影片來源不同，不能把兩版影片量相加當作獨立場景。
任務
包含動作辨識、弱監督辨識、動作預測、無監督領域適應、影片文字檢索。verb、noun、action 類別與檢索句子各有原生 ID，挑戰種類不等於獨立任務數。
題數與資料
train／validation／test_timestamps CSV 以 narration_id 對齊片段；narration_timestamp、start/stop_timestamp、frame 邊界各自儲存。anticipation 使用動作前 5 秒觀測並留 1 秒間隔；UDA 的 source/target 與 retrieval 的 sentence 表另列。C1 預測含 verb_output[N,97]、noun_output[N,300] 及 narration_id。
評估方式
C1 utils/metrics.py 計算全部樣本 verb／noun／action top-1/top-5，以及 unseen participants、tail verbs／nouns／actions 的對應 top-1 子集；布林遮罩決定分母。其他四項挑戰需各自取得 evaluator，不可沿用 C1 得分。
