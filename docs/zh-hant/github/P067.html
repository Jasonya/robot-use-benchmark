P067 · ManiSkill2

ManiSkill2: A Unified Benchmark for Generalizable Manipulation Skills

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

原ManiSkill2網址目前只是搬家說明；實作應固定mani-skill/ManiSkill的v0.5.3。它把episode設定、HDF5軌跡、JSON資訊和原生success評測分開儲存。 2026-10-11 另補讀 ManiSkill2-Learn 的 BC 資料與單程式評測入口，與主 benchmark 的 v0.5.3 契約分開記錄。

版本與身份

v0.5.3解析到commit493be361…；最新main是ManiSkill3，因此每個來源連結都帶ref/commit。 Learn 固定 e9860aff595da3ad34829d62c923be0b50001427，與主 benchmark v0.5.3 的提交分開；其 README 指明 0.5.0 起改 Gymnasium，較舊環境用 ms2_gym 分支（本次未核讀該分支）。README 另說早期 checkpoint／環境 0.3、0.4 的 RGBD camera order 不同，須保留實際 wrapper／觀測版本，不把 Learn、ManiSkill2022 challenge 或 ManiSkill3 當成同一版主 benchmark。

領域
居家整理與清潔、裝配與生產作業、通用物件與機動作業
環境
SAPIEN任務依env_id、asset模型、reset_kwargs和control_mode建立；柔體另外依賴原作Warp版本。
任務
註冊的env/task與原作家族保留其單位；不是每個asset模型、隨機seed都增加一個基礎任務。
題數與資料
HDF5 traj_id配合JSON episodes/env_info；reset初態使觀測／env_states比actions多一筆。depth以uint16儲存，原作寫入前乘2^10，必須儲存這個尺度。 補讀 Learn：tools/convert_state.py 依 HDF5 traj 字尾尋找 JSON episodes 的 episode_id/reset_kwargs，逐 state 重建剛體觀測，或由 env_init_state 重播動作取得柔體觀測；控制模式須先在主 ManiSkill2 轉好。輸出為 T 筆 obs/actions/rewards，dones 直接來自原 success，episode_dones 僅尾筆為真，next_obs 要加 --with-next。輸出 traj_{cnt} 重新編號，須另存原 episode 對映。BC 的 buffer_filenames 範例仍是 SOME_DEMO_FILE；ReplayMemory→FileCacheWorker 實際讀 HDF5 groups，num_samples 限制每檔前幾條排序軌跡，-1 才是全部，不能稱為隨機 split。
評估方式
Evaluator按episode_cfg的reset_kwargs重建，終止時讀info.success等scalar；PickCube示例要求物件放到目標且robot靜止。reward、terminated、truncated不互相替代。 補讀 Learn 的獨立路徑：run_rl.py --evaluation／--resume-from→build_evaluation→Evaluation.run；單程式策略預設 mode=eval，BC 範例 num=10、num_procs=1 只是設定值。live step_dict 把 terminated 命名為 dones，以 terminated OR truncated 判 episode_dones；Evaluation 在終止那一步把 dones 記為 finish，statistics.csv 存 length/reward/finish，顯示的是 mean(finish) 的「Success or Early Stop Rate」。此 caller 並未直接取 info.success；只有繫結環境的終止契約相符時才能解作成功率。only_save_success_traj 篩存檔、不縮減 statistics 的所有已評 trial 分母；與前述主 benchmark Evaluator 的 info.success 分開。

怎麼接入我們的benchmark

可重用

env/task IDs、episode ID、reset kwargs、control mode、HDF5/JSON及原生success。 可另重用 baseline 的 HDF5 視覺轉換、ReplayMemory 輸入及 length/reward/finish 原生報表。

需要轉換

原始T+1觀測與T個transition保留對齊；深度尺度、obs mode、state、success、時間上限分欄，不用共通dtype猜單位。 另儲存 Learn commit、checkpoint、實際 env_cfg、seed、num/eval_levels、sample_mode 與輸入／輸出 trajectory ID 對映；原 success、示範 dones、live terminated/truncated/finish 分欄。FileCache 的 purify_items 可補 worker_indices、把 dones 轉 bool，並將讀取片段末項 episode_dones 設真，不能依訓練 buffer 片段另增物理 episode。

仍需補齊

完整資產／示範閉合、共同split血緣與本庫eval adapter驗證。 Learn 的示範／checkpoint／資產未取得或執行；需替換示例佔位路徑、儲存完整 reset／split 血緣，驗證控制模式、觀測處理與主 benchmark 的 success／終止關係。converter 的 obs_frame 預設 base，而 make_gym_env 預設 world，資料生成／訓練／評測都需顯式對齊。
