P181 · RoboFolDeX

RoboFolDeX: A Physical-World Benchmark for Long-Horizon Robotic Manipulation of Deformable Objects

返回逐篇總表實作尚未確認 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

完成 pinned PDF、GitHub 搜尋快取與官方 challenge 頁的限量身分查詢，仍未確認作者授權的公開程式倉庫或資料 reader。保留長時程實體折衣任務、人工品質評分與 FoldScore 的論文規格；不以其他 cloth benchmark 或通用VLA程式替代。

版本與身份

以2026-09-18 v2 PDF為準；第3頁仍稱review期間省略access links，與首頁已列Midea網址並存，不能據此補猜程式網址。無repo commit可記；各PDF/搜尋/HTML/HTTP receipt均記本地SHA256及read範圍。未執行JS、提交policy、聯絡作者或下載模型／資料。

RoboFolDeX 指 Chenhuan Liu、Yi Xu 等的 arXiv:2609.10243v2，機構為 Fudan／Midea／CMU。PDF第1頁給出的第一方平臺為 ai.midea.com/#/fold-challenge。FoldChallenge 是這篇的實體評測平臺名稱，不是可據以自動推定的 GitHub owner/repo。

領域
居家整理與清潔、衣物與洗護
環境
真實雙臂長時程衣物整理，從籃中取衣、桌面翻轉／攤平、多次折疊到最後放置／堆疊。資料涵蓋桌面／家庭場景與照明、背景、layout變化；論文列Aloha、YAM、Piper、Astribot、Franka、UR5、自研移動雙臂、AgiBot G2等，10+是宣稱的embodiment規模，未取得完整registry。
任務
主題是衣物折疊，參考實驗分Shirt、Skirt、Pants、Towel；完整資料另外含其他deformable及少量rigid任務。20+是論文來源層task宣稱，不是已列舉的可執行task數。四個track為recovery-data utilization、cross-task、cross-scene、cross-embodiment；它們是訓練／轉移協定，不另計為四項操作技能。
題數與資料
論文宣稱2,000+小時真實robot trajectories。觀測為兩腕相機+外部workspace相機RGB、自然語言指令、proprioception；action為未來end-effector pose trajectory。論文描述共用metadata語義：task、object category/instance、scene、embodiment、operator、data source、completion及failure/termination reason；本輪未取得實際檔名／keys、action維度與座標系、時間頻率或split名冊，因此不能將這些概念冒寫成已驗證JSON schema。hours、tasks、robot embodiments與episode/case數分開，case總數保持未知。
評估方式
論文標準完整episode需無人工介入且無不可恢復失敗，通常每衣物類別30次獨立實體trials、初態隨機化；品質由至少兩名相同評審跨方法獨立評定，達成一致才記錄。neatness等級0–5檢視形狀、緊密、平整、穩定與邊緣；FoldScore=35×平均正規化品質Q̄+35×完整success rate R+30×max(0,1−t/Tmax)，t只在成功trials平均，無成功時時間項為0。PDF稱quality mapping及細rubric在Appendix，但固定版本共9頁、第8–9頁為references，未附該表；Tmax也未給數值。故不能自行用neatness/5或任意時限做『官方scorer』。π0.5的pre-flattened短流程baseline與basket-to-stack完整流程須分開。

怎麼接入我們的benchmark

可重用

已明確的實體任務流程、四track設計、observations/action的語義、0–5品質尺度及FoldScore公式。

需要轉換

source記PDF v2與FoldChallenge第一方平臺；environment儲存實體硬體／相機／場景；task儲存衣物類別與完整或區域性流程；case待原生trial/garment instance/init metadata公開後建立。evaluator先標人工評分及paper_specified_formula，品質／success／成功trial時間三項分存，資料重用track保留訓練來源與target embodiment。

仍需補齊

作者確認的程式repo、可檢驗reader/schema、公開資料manifest／授權／split、完整品質rubric及Q對映、Tmax、submission/execution介面與實體trial結果。SPA大型JS及可能需互動的頁面內容本輪未展開，平臺『operational』僅依論文宣告。
