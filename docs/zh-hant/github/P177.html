P177 · H2RBench（human transfer）

H2RBench: A Real-to-Sim Benchmark for Evaluating Human-to-Robot Transfer

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

H2RBench提供基於PolaRiS的6個Gym場景註冊與human-to-robot transfer評測。此版rubric按曾完成的子條件累積，與末態全部同時完成有差異。

版本與身份

固定5082e75。README arXiv仍TODO且clone示例為舊DavidZ2851/polaris；官方h2rbench.github.io連此庫並列精確2609.24778，身分相符。與P151影片生成H2R-Bench保持不同source。

領域
裝配與生產作業、通用物件與機動作業
環境
Isaac Lab與PolaRiS真實場景重建/3D Gaussian splat；固定registry6個Gym ID為放紅杯、疊積木、套環、掛杯、玩具入盒、疊碗。authoring scene.json與runtime scene.usda/渲染資產不是同一種環境描述。
任務
6個原生task setup有Rubric前置依賴；新case須儲存human/robot資料轉移的訓練條件與實際goal，不能把完整PolaRiS父資產庫當本篇全部已評任務。
題數與資料
initial_conditions.json含instruction/poses；task_config.yaml有object_randomization/waypoints。當前randomize以poses[0]為底再取range，未逐條使用所有原始pose；旋轉入參xyzw、輸出wxyz。policy推論入口送obs+language，human示範訓練/配對資料另需manifest，不能從此eval入口推定已有video prompting。
評估方式
每criterion曾達成即latched，progress=ever_reached/total，成功為全數曾達成；空criteria會success=True但progress0，應拒作合法case。放置看XY投影覆蓋與finger條件；插入有速度穩定/XY/Z檢查，其closure計數須確認跨episode重置。續跑先生成ic後快轉RNG，第一個恢復episode仍用舊ic，需修正或儲存實際初態。影片固定15fps不是控制clock證據。

怎麼接入我們的benchmark

可重用

6環境註冊、scene/initial_conditions/task_config介面、可追溯predicate與依賴進度。

需要轉換

case繫結source episode、重建/碰撞/渲染資產版本與座標系；記實際初態、human訓練子集和固定budget；保持ever-success與同時末態成功分項。

仍需補齊

human/robot完整配對資料、資產和training split、續跑初態一致性、stateful predicate reset、非空rubric/全部終態有效性及跨機體基線。
