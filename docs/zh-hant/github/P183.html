領域
裝配與生產作業
環境
以下為論文規格，尚無repo實作可驗證：Isaac Lab2.2.1／Isaac Sim4.5，另聲稱驗證5.1。DLO有PhysX D6剛性segment chain及FEM deformable兩種表示，對齊task／connector介面而非聲稱材料引數等價。模擬支援UR5、Franka、Trossen Stationary AI；實體validation用UR5+Robotiq2F-85、腕部與側視RGB、3D列印Ethernet接頭／task board。實體腕部force/torque sensor讀值未用於policy，只需在sim匹配其幾何offset。
任務
三個family為connector insertion、clip routing、channel seating。論文註冊五種connector geometry，其中cylinder/cuboid/Ethernet/DisplayPort進入所報實驗，USB-A為額外asset；不能把五個connector全當已評測tasks。clip difficulty最多3個clips；channel由5 segments組成，可為直線或每joint最多±20°彎曲。family、variant、fixture數、reset variation與episode均不同單位，無公開registry可確認精確全部task count。
題數與資料
論文稱scripted、RL rollout、sim teleoperation、real UR5四種來源共用LeRobot-compatible schema。UR5 state/action各7D（6 joint+gripper），雙RGB與instruction同步；這是論文語義，未取得實際feature keys、parquet/video path、dataset revision或reader。IL/VLA比較使用同一1,000條scripted insertion trajectories，非全benchmark總case數。RL另用42D privileged observation與Cartesian delta pose+gripper action，clip到[-1,1]再乘0.01；不與joint-space dataset action直接合併。原生physics dt=1/120 s、decimation=2、control=60 Hz，其他實體資料時間約定需待公開。
評估方式
只有paper-defined protocol：insertion分SRreach（夾持plug進入socket周邊2 cm）及SRinsert（tip就座），不得以reach代替insert；3 mm是Ethernet測試clearance，不是插入成功閾值。clip需seated於clips；channel需超過80%線長在channel內，尚無公開離散化／checker細節。RL報3 seeds的mean±std，8秒horizon；IL/VLA附錄F用4 seeds×16 rollouts=64/checkpoint、800 simulator steps，不可與8秒／60 Hz budget預設等同。checkpoint以相同evaluation rollouts的reach success取前三，並非held-out validation選模；insert來自同checkpoint、未另最佳化。公開tree無可執行scorer，不能聲稱已核對這些條件的程式實作。

怎麼接入我們的benchmark

可重用

可重用論文的task families／變化軸、兩種DLO表示、資料來源分類及reach/insert/channel的不同度量；README作release追蹤。

需要轉換

source保留paper v1及placeholder commit；environment按simulation model／robot／physical setup分開；task按family+fixture/connector geometry；case在公開reset seed／episode manifest後建立。evaluator先標paper_specified、runtime_unavailable，儲存native units、budget、policy可見資訊及checkpoint選擇協定。各data-source mixing實驗保留R/S/P組成，不做語義等價合併。

仍需補齊

11月release是否履行、真正task registry／reader／concrete scorer、dataset與3D assets manifest／授權、精確insert/clip判定、8秒vs800步預算對齊、各實驗checkpoint／split closure。
