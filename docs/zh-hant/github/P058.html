P058 · EgoPAT3Dv2

EgoPAT3Dv2: Predicting 3D Action Target from 2D Egocentric Vision for Human-Robot Interaction

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

EgoPAT3Dv2 的作者 repo 同時保留原版與擴充版讀取器；可追到逐幀 3D 目標誤差與進度分箱，但 HDF5 版本、手部特徵錯寫及評分彙整差異須先處理。

版本與身份

固定 a24b3a5a2453931de69a17dfc7116057dc849136（2024-03-19）。configs/README.md 在 manifest 中是空檔；README 測試命令未帶程式所需 model_epoch/checkpoint。test_DDP 後處理固定 4K 內參，v>=2160 分支錯改 u，且 x1/y1 使用前輪 z；重現前須確認保留原行為或另列修正版。論文 §IV-A 說擴充分配 9+2 新場景，§V-B 又說新增12場景，不能以文字自行決定總場景數。

README 的完整標題、十一位作者與論文 arXiv:2403.05046v1 一致；論文指定的 ai4ce 專案頁直接連本 repo 與 Hugging Face 資料。這是 ICRA 2024 EgoPAT3Dv2 的實作及 EgoPAT3D 擴充資料入口，原版 D1 與擴充版 D2 有重用關係，不能加總當作兩份互斥資料集。

領域
協助、交接與陪伴、穿戴互動與動作介面
環境
頭盔安裝 Azure Kinect 的人類物件操作影片。論文 §VI 的 UR10e 避讓／朝預測點移動是另行展示；已讀 repo 提供預測資料與模型測試，沒有該展示的機器人任務成功評分器。
任務
線上以 X1:t 預測同一段操作最終 3D 手部目標；目標必須轉到當前影格相機座標，並非未來全身動作或機器人控制。T1/T2 指原版／擴充訓練來源，D1/D2 指測試資料版本，seen/unseen 指場景是否在訓練出現。論文報告可用 clips 由 4129 增為 9579；本輪未下載資產核算此數。
題數與資料
原版 HDF5 用 /{annotrain|annovalidate|annotest}/{scene}/{video} 與 /sequences/{scene}/{video}/{color,transformation/odometry}；擴充版將 /color/{scene}/{video}/{frame} 與 annotation、/transformation/{scene}/{video}/{frame} 分置兩檔。annotation 每列前三值為三個邊界，3:6／6:9 為兩段目標 xyz；原版要求 z>0.1，擴充版 z>0。長度=end-start、RGB 讀 start+1…end，累乘 odometry 後以逆矩陣轉換目標，單位公尺。RGB resize 224×224；training 直接排除長度>25 的 clips，測試以最長段補零並回傳真實長度。handLM 為 21×2、hand 為 landmark 5 的 x/y；兩 RGB 讀取器的 handLM 奇數欄實際也寫 lm.x，不能當成正確的 x/y 特徵。
評估方式
test_DDP.py 依模型／epoch、scene、video 輸出 start-end.txt（逗號分隔 xyz）與 start-end_gt.txt。eval.py 算每幀 ||pred-gt||2，以 i/(L-1) 落入十個寬 0.1、兩端皆包含的區間；先在 clip 內平均，再平均同 recording 的 clips，最後等權平均 recordings，×100 得 cm；Overall 使用 linspace(2,1,10) 加權。邊界影格可能進入相鄰兩箱，短 clips 可出現空箱。論文 §IV-B 寫按影格等分十階段、餘數給較早階段，並報三個 seed 平均；目前入口不自動做三 seed 彙整。eval.py 的 --mode 是 store_true，僅用於輸出命名，真正 split 由 test_DDP 的設定決定。

怎麼接入我們的benchmark

可重用

scene/video/clip 邊界、逐幀目標與 odometry 引用、D1/D2 及 seen/unseen 分派、歐氏誤差實作。

需要轉換

case 儲存 dataset_version+split+scene+video+start/end，附實際影格索引、公尺相機座標、有效長度與手部缺失遮罩；evaluator 明列進度分箱、recording 平均、Overall 時間權重與 seed。原版／擴充版以來源重用關係相連。

仍需補齊

需取得並固定 Hugging Face HDF5 版本／場景清單，核對修正版標註與影格取樣時間；修正或隔離 handLM 的 x/x 特徵、補足 checkpoint/model_epoch 引數與私人路徑，再驗證評分分箱及後處理。
