P209 · HUI360

HUI360: A 360{\deg} Egocentric Dataset and Baselines for Human-Robot Interaction Anticipation

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

HUI360 已核官方 baseline 與 Interact360 標註／CSV 管線。論文結果必須對應 baseline legacy 分支與固定 HF dataset revision；新版 main 的 32-frame／16-frame cutoff、資料 main 及最佳 F1 threshold 搜尋不能直接當論文 30／15 協定。已追到實際 track reader、視窗標籤、AUROC／F1／AP scorer，未執行模型或下載大型資料。

版本與身份

主核論文baseline legacy=32a90eb716e503ef8a0daabc052ce7c34ba36a95，README／config 指定 dataset rlorlou/HUI360@3c8a342548534b6b92d32b0099e266962facdf45，30-frame輸入、15-frame兩cutoff、25epochs。另讀 main=a6bd61c8539061242cbf756a18847c0900a8707c（2026-08-29）新版核心設定／reader入口／scorer，預設32frames／16cutoff／75epochs及hf_dataset_revision: main，不能混用數字。Interact360=d11ec02d666965968293813b9c17501cf1568cf6（2026-05-06），其README的CSV教學雖TBD，實際export程式已存在且已核。以上是選定核心區段，不是全基線架構／整個標註模型codebase已審完。

arXiv:2608.11051v1 的官方 project 明確分開 Code (Baselines)=hucebot/HUI360-Baselines 與 Code (Pipeline)=RaphaelLorenzo/Interact360；前者 README 直接連同一 arXiv 並要求論文使用 legacy，後者雖仍有 arXiv TDB placeholder，但官方 project、HAL 與題名均指向本篇。SSUP-HRI 是重用父資料，不另當 HUI360 新收集來源。

領域
公共場館與服務、協助、交接與陪伴
環境
robot-egocentric 360° equirectangular 觀測。paper 的新 HUI360 有 9 真實場所、30 robot setups、68 recordings；71.3 小時原始資料裁成 1,937 episodes／11.3 小時（15 fps）。4,310 person tracks 中 375 有物理互動；另 SSUP-A 是 SSUP-HRI 兩個 field sessions 的重標註，27,698 tracks／419 interactions，不可當獨立新捕捉資料。本輪沒有可互動 robot policy 環境，評的是離線 anticipation。
任務
預測人是否即將與平臺發生物理 interaction；positive onset 依投放、拿取等實際事件與人工修訂，並非對 gaze／社交意圖的通用判定。RF／MLP／LSTM 是模型，T_ADV horizons 5/10/15/20/30 frames（15 Hz 下約0.33/0.67/1/1.33/2秒）與輸入降取樣是同一 task 的條件。論文 HUI locations1–7 train、8–9 test，SSUP 第一／二場次 train/test；實際程式依 checkpoint 的 include_recordings_val 等清單選樣，變數 val 不能擅自解讀成另有第三份驗證集。
題數與資料
Interact360 讀 episodes/<id>/annotations_360.json 的 image_file/image_shape/detections；track_id 可由 associated_track_id 合併，含 validity、bbox、mask_rle、mask_size、engagement_level、17點 ViTPose 與308點 Sapiens。bbox／pose 是原全景畫素，x 可跨影像寬度邊界，不能直接裁成普通2D box。detect_interactions 的相交面積>min_pixels_intersection（預設10,000）給 level3，否則0，之後允許人工修訂。export 只收 checked/valid 類 flags，依validity與quality連續段篩選，寫 data-<recording>-<index>-of-<total>.csv；unique_track_identifier=recording_episode_track。timestamp 由檔名 %Y_%m_%d_%H_%M_%S_%f 解析；另存 timestamp_sec、相對track秒、time_to_first_interaction秒，無互動用99999.0 sentinel。缺 Sapiens 資料可填0，需視作缺失而非真座標。baseline CSV reader 把 engagement／時間／ID 列列為 metadata，指定LSTM features為 mask area+bbox+17×(x,y,score)，即56維／frame；keypoints先box-normalize再用固定HUI mean/std。
評估方式
legacy get_track_input_possible_indices 將 image_index 連續存在、validity、至少9個ViTPose score≥0.5與mask_size篩選做AND，再找連續段。第一個 engagement>0 定義 onset；interaction_cutoff／positive_cutoff 以frame計。非互動 track 可截到最大mask面積（近距離proxy），並依設定把視窗對齊該處。force_positive_samples 會排除互動track的早期負窗。__len__ 是合格track數，__getitem__ 為各track固定或隨機選一個候選視窗；固定索引清單與subsample必須儲存。legacy infer 對每個視窗得到 sigmoid(logit) 或 RF predict_proba[:,1]，用>0.5算 binary P/R/F1，整個pass的分數送 roc_auc_score；training.evaluate 另算 average_precision_score。其 N 是實際送入的合格track視窗，AUROC 比較正負樣本排序，F1分母為2TP+FP+FN，不是4,310 raw tracks、375 interactions或百萬detections。new main 可用 stride 展開多視窗，需重記樣本數；main infer 直接算 AUROC/AP，並在同一集合用100個threshold搜尋最佳F1。未下載實際CSV，因此不宣稱驗算任何eligible test case數。

怎麼接入我們的benchmark

可重用

可重用兩倉庫原生track/frame結構、人工curation flags、mask-intersection標籤、legacy reader／window selector／score path及固定normalization；SSUP重用關係獨立記錄。

需要轉換

source 必須同存 paper v1、baseline legacy或main commit、dataset revision、Interact360 commit。environment 區分location／setup／recording；task 儲存物理interaction定義與horizon。case 用dataset+recording+episode+track+window起訖／sample index，另保留raw track與條件化window父子關係；frame index、檔名時間、relative seconds、panorama seam／pose confidence／缺失標記分開。evaluator 儲存正負樣本N、filters、取樣seed／stride、threshold來源、AUROC/AP/F1及normalization版本，不能轉成機器人完成工作成功率。

仍需補齊

固定revision的完整CSV／track manifest與checkpoint protocol對齊、eligible windows實際清點、SSUP跨全景邊界與missing-pose處理驗證、legacy邊界分支修正、獨立threshold選擇、原始影像／curation與標註版本閉合。只做靜態核讀；snapshot_download、大型骨架／影像、模型、GUI與模擬均未執行。
