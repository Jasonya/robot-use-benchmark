Robobench: A Comprehensive Evaluation Benchmark for Multimodal Large Language Models as Embodied Brain

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

RoboBench 的釘選版本已分 MCQ 與 Planning，並提供原生粒度表。本次核讀 loader、MCQ、Q1–Q3 planning 的核心規則，以及 point/IoU 輔助 evaluator；不把模型裁判等同物理執行。

版本與身份

README已是ECCV2026 release，不能無版本註記地替換2025 arXiv表。IoU檔案開頭提mAP，但實際回傳平均IoU／pass rates，沒有AP排序積分；點／IoU工具存在也不代表32 manifest全都使用它們。

領域
居家整理與清潔
環境
影像／影片中的機器人或人類操作觀測；unique_id 中的 images 路徑定位樣本。cross-embodiment/object/view/attribute 是泛化條件，5 dimensions 是能力分類，不是5種生活用途。
任務
2026 release README 列5 dimensions、14 groups、25 tasks、32 subtask manifests、6,092 QA，MCQ=1,895、Planning=4,197；這是版本化原作者規模，非本次資料整合實數。Q1 多步計畫、Q2 下一步、Q3 狀態估計會共用同一來源影像。
題數與資料
system_prompt.json 和 dimension/subtask/questions.json；question 有 unique_id、task_type、image_urls、robotic_type、question/options，轉 request_id/prompt。Q1–Q3 suffix 在找圖時去除；Q1另讀 dag.json 的 id→gt_dag，navigation 無同樣 DAG。human 在 prompt 被轉成 single-arm，原始 embodiment 不能因此覆寫。
評估方式
MCQ 取 answer tag／清除 think 後比A–D集合，不明確輸出可用另設裁判正規化。Q1模型看首圖、GT nodes/DAG、預測計畫，給 node correctness與task completion各0–10後平均映0–100；空 critical-state集合依prompt直接Completion=10。Q2 skill/object/parameter三項平均，前兩任一0則parameter=0；Q3 yes/no精確比。Q1/Q2解析失敗排除均分但overall按原count加權；point/IoU亦只用有效解析作分母，需附valid率。

怎麼接入我們的benchmark

可重用

原生32 manifest層級、題目/skill/DAG/prompt格式與逐項判分證據。

需要轉換

source 固定 release+commit，task 保留原25/32對映，不把 Q1/Q2/Q3 或新視角當新環境；case 保留 raw_question/來源圖/embodiment/DAG及觀測預算。evaluator 分MCQ、Q1/Q2/Q3和point/IoU等可選工具，native分數、parse_failures與分母同存。

仍需補齊

未取得完整HF資料／DAG或執行模型裁判。需查 empty-goal cases、裁判一致性、skill語義與可用資產；MLLM imagined rollout 不能宣稱物理穩定性／真實任務成功。trajectory evaluator 未在本次核讀範圍。
