RoboTwin: Dual-Arm Robot Benchmark with Generative Digital Twins (early version)

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

P073 應綁官方early_version分支。已核讀早期DP3的PKL→Zarr→reader→rollout→錘擊checker與公開seed檔；真實17項資料任務、論文6項實驗、後續分支任務表必須分開。

版本與身份

本體固定early_version f14a315ac4c9c72bfea05b523874f787080dfcf2，非main ea8b21121ebb3cd201ff5b3fe361944ac94eda3f。早期README明記2024-10-01改get_obs及實驗結果，真實資料仍標Coming Soon。TopK摘要寫出各項suc/(topk×test_num)，沒有求和成單一平均，不能直接把文字輸出當總平均。

對應arXiv:2409.02920v3（2025-04-16），題名帶early version、九位作者。早期與現行README都直接引用該arXiv；CVPR 2025的RoboTwin為2504.13059，不能替代P073。

領域
居家整理與清潔、餐飲與烹飪、工藝與修繕、協助、交接與陪伴
環境
早期SAPIEN雙臂桌面，physics timestep預設1/250秒。錘擊配置有頭部、前方與兩腕相機，320×240、1024個世界座標xyzRGB點；conbine=False只取頭部點雲。論文真實Cobot Magic資料另為30 Hz、三個640×480 RGB-D視角及主／從臂記錄，不能與模擬schema混用。
任務
論文評測6項；真實資料設計17項各30條軌跡，標籤可重疊。分支README列15個名稱，但完整tree只有14個具體env檔，block_sweep未在該commit提供。已讀block_hammer_beat的play_once為pass，不能稱expert產生器已公開。checker要求工具target_pose轉到世界後，xy與方塊各差<0.02公尺且0.78<z<0.81；沒有接觸、衝量或敲擊次數檢查。
題數與資料
PKL儲存observation/<camera>的rgb/depth、intrinsic_cv/extrinsic_cv/cam2world_gl，以及pointcloud/joint_action/endpose。depth乘1000存float64，單位毫米；點雲xyz為世界公尺、RGB限0–1。joint_action是左右各6關節get_drive_target加gripper，共14維，並非實測qpos；endpose為左右xyz/RPY/gripper。轉檔將joint_action同時寫成Zarr data/state與data/action，endpose寫tcp_action，meta/episode_ends為累積排他端點。DP3 reader讀state/action/point_cloud，以episode mask和padding建立時間窗。
評估方式
eval_policy_dp3→test_policy→setup_demo→apply_dp3→check_success。指定checkpoint測100個seed；checkpoint=-1掃描300…3000十個checkpoint，各取前20 seeds再選Top5。錘擊seed檔100筆，範圍100000–100102，略過100025/100029/100040。step_lim=400按預測chunk長度累計，TOPP再展為250 Hz動作；get_obs本身也會scene.step，因此400不能當400個physics frames。每episode成功只累加一次suc。

怎麼接入我們的benchmark

可重用

early_version任務class、checker、eval seeds、相機／點雲設定、PKL/Zarr轉換及DP3評測。

需要轉換

source分early/1.0/2.0，task保留論文子集關係；case存seed、checkpoint選擇方式及chunk預算。state標為command target，另記depth的mm→m轉換、world/OpenGL/OpenCV、RPY與episode邊界。

仍需補齊

block_sweep程式、其他論文任務逐一checker覆核、17項真實資料manifest、可執行expert產生器、資產target_pose與相容SAPIEN/DP3依賴鎖定。
