GarmentLab: A Unified Simulation and Benchmark for Garment Manipulation

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

已核讀 Isaac Sim 場景、Fold／Hang／Bimanual 範例、點雲資料管線及 RL fold 的具體 evaluator。公開程式可作來源與部分任務參考，但所讀路徑未實現論文整套20任務及持續5秒成功驗收；多處資料鍵、split 與計分接線尚未閉合。

版本與身份

固定 2025-03-02 commit，晚於2024論文；READMEs與論文宣稱不代表此公開版本已實現所有協定。本次未啟動 SimulationApp、未下載 USD/模型，亦未將 template 或檔案數當核讀完整性。

README 直接連結 arXiv:2411.01200、官方 GarmentLab 頁面與同名倉庫，BibTeX 題名及作者對應 NeurIPS 2024 論文。LearningBaseline/unigarmentmanip 是本倉庫中的基線實作，不另外算新 benchmark。

領域
居家整理與清潔、衣物與洗護、個人照護
環境
Isaac Sim 4.0.0／PhysX；BaseEnv 匯入 USD 房間與地面、啟用 GPU dynamics／CCD；GarmentConfig 儲存 USD、pos、ori、scale、stretch/bend/shear stiffness、friction 和 collision offsets。FoldEnv 使用 Franka、頂視 Recording_Camera 的 depth／point-cloud／segmentation；BimanualEnv 配兩支 Franka。原生 Euler／quaternion 與 USD scale 混用，不能直接假定所有輸入角度或資產尺寸相同。
任務
README 宣稱20任務、5互動群、11衣物類別、20場景及9000+資產，均為不同單位且非本次驗證的可執行 case 數。本輪追查 Fold、Hang、雙臂展布及 RL fold 子路徑；demo 是固定資產／抓點序列。RL fold/config 實際 task_name 為 hang，須由協調者核對任務名稱與實驗配置，不能僅依資料夾分類。
題數與資料
collector 把 pcd_points／mesh_points 寫入 {garment}/p_{index}.npz、另存 rgb_{index}.png；loader 還要求 keypoints_visible_mask、pcd_keypoints_id、visible_mesh_indices，需補前處理來源。loader 回傳兩份點雲與 correspondence 索引，交替產生同衣物跨變形及跨衣物配對，不是 robot episode。get_deformation_paths 先按衣物目錄數字排序再切 split；config.train_ratio=1 會把所有衣物給 train、val 為空，不能套用論文 split。BaseEnv 的 .npy record/replay 是 callback 框架，base callback 為 pass，未提供統一有效軌跡 schema。
評估方式
HangEnv.get_reward 讀 garment_mesh.get_world_pose() 的 z>門檻（預設0.3，demo傳0.5），未檢查掛架接觸或5秒穩定。FoldEnv 與 FoldDemo 沒有 fold success checker。BimanualEnv 以 trial/reference coverage>0.75，但 evaluator 會停止／重設衣物姿態且面積 min/span 使用xy、pos2d卻使用xz，必須標為原生疑點。RL fold 的 eval_policy 平均30次 SimEnv.step(...,True) 布林值；SimEnv 計算抓點到指定粒子的誤差，兩個 reward_action>0 才成功，誤差恰為0.1經非線性分支後仍為正。雖計算0.8×reward_action＋0.2×reward_result，非eval實際回傳 reward_action，eval也未用結果形狀誤差。FoldTask.calculate_metrics 是 Cartpole 範本，不是主 fold evaluator。點雲 simple_val 以歸一化特徵 argmax 找 correspondence，報平均歐氏距離與 distance<threshold 比例；val_score.py 卻讀 points/keypoints_id、取 train 的0.8子集，而且呼叫 cal_distance_accuracy 時少了必填 distance_threshold。

怎麼接入我們的benchmark

可重用

USD／材料設定、場景與感測配置、固定任務指令碼、點雲配對結構及已查明的原生 checker。

需要轉換

source 綁 commit；environment 綁資產與物理引數；task 對應實際指令碼／配置及論文標籤；case 需另建 garment_id＋初態＋示範／seed；evaluator 分 geometry matching、抓點成功、掛衣高度、論文持續成功。資料配對數、render frames、衣物物件與30次RL評測不可混算。

仍需補齊

完整20任務 case/split manifest；fold IoU／持續5秒的可執行 checker；原始npz→標註npz→val_score的欄位橋接與threshold修正；coverage軸向與state mutation決策；資產、真機benchmark檔案及校正尚未納入可執行接線。
