P011 · EPIC-KITCHENS VISOR

EPIC-KITCHENS VISOR Benchmark: VIdeo Segmentations and Object Relations

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

VISOR 是 EPIC-KITCHENS 影片上的分割與物件關係標註。五個倉庫分別承擔 VOS、HOS、來源追溯、視覺化與抽幀工作，不能算成五批獨立環境。

版本與身份

VISOR-FrameExtraction 要求先修正插值並列出 P02_01、P03_14；新版名詞表追加左右手／手套，仍保留舊 hand/glove 類別。VOS 不是未修改的 DAVIS 評分：末影格被納入。

領域
居家整理與清潔、餐飲與烹飪
環境
EPIC-100 的廚房影片子集；video、subsequence、image 各是不同層級。VISOR 重新抽幀，需 frame_mapping.json 才能對回 EPIC。
任務
VOS 在給定首影格物件遮罩後追蹤分割；HOS 判斷手側、接觸與手物件組合；WDTCF 用查詢物件遮罩追溯來源物件與證據影格。這些為視覺理解，不是機器人完成操作。
題數與資料
每影片 JSON 的 video_annotations 含 image.name/video/subsequence 及 mask id/name/class_id/segments/exhaustive/in_contact_object/on_which_hand。dense type=0 為插值、type=1 為端點 GT，不可同當人工標註。VOS 轉成 DAVIS 的 JPEGImages、Annotations、ImageSets 與物件色碼對映。
評估方式
VOS 實作排除首影格但保留末影格，以逐物件 J（IoU）與 F（邊界 F-measure）評分；空 union 的 J=1。HOS 將手側／接觸轉類別、遮罩轉 RLE，交給 COCO evaluator。WDTCF 必須 query 類別、證據影格字串吻合，source 類別才可計分，另算 query/source mask IoU；錯類別或錯影格會歸零，非單純來源分類正確率。

怎麼接入我們的benchmark

可重用

原生分割多邊形、接觸 ID、首影格輸入限制、VOS evaluator、WDTCF JSON 與四項輸出。

需要轉換

保留 parent=EPIC-100、frame mapping、subsequence 和 mask ID；人工／插值標註分開；以 VOS／HOS／WDTCF 建立獨立 case/evaluator profile，且記錄 480p／1080p 座標與縮放。

仍需補齊

尚未取得影格與 mask；HOS 的外部 COCO 實作和線上 C6 提交流程未完整追核；資料轉換需驗證色碼與 frame mapping，不能從視覺化結果推定可評測。
