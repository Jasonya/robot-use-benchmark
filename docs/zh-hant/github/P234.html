P234 · I-CVAE

Intention-Conditioned Long-Term Human Egocentric Action Forecasting

返回逐篇總表核心內容已核讀 方法／綜述參考原作 ↗

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

已沿 Ego4D clips→視窗／意圖→ICVAE generate→本地 ED/AUED 核讀核心程式。這是重用 Ego4D 的方法來源；52 個 scenario-derived intention、20 個未來位置與 K=5 候選是不同單位。串接預測、GT 條件消融及 challenge 分數必須分開。

版本與身份

固定作者 repo commit 5b95d85e0bec6bd94851c867054c535c1afc6248；此程式快照早於 arXiv v4，沒有宣稱逐版結果一致。README 的已提供完整 code 不是本次核讀完整碼庫的證據；本次僅核以上核心區段與 taxonomy 結構。未取得權重、完整資料或重跑模型。

清單題名為 Intention-Conditioned Long-Term Human Egocentric Action Forecasting（2022 初稿）；已核快取為 arXiv:2207.12080v4（2024-04-08），題名改為 Intention-Conditioned Long-Term Human Egocentric Action Anticipation。作者均為 Esteve Valls Mascaró、Hyemin Ahn、Dongheui Lee。repo README 保留 Forecasting 標題，但連結並引用 WACV 2023 的 Anticipation，且具名第一作者維護，可確認為同一方法的作者程式，而非同名第三方。

領域
方法／綜述參考，未另作來源用途歸納。
環境
離線人類第一人稱 Ego4D 日常活動；物理場景資訊來自 ego4d.json 的 scenarios，程式將單一 scenario 視為高層 intention。沒有 robot reset、control 或可執行成功條件；scenario 數不代表場景 layout 或機器人任務數。
任務
H3M 由過去片段辨識 verb、noun、intention；I-CVAE 預測 Z=20 個未來 verb–noun 標籤，通常產生 K=5 序列。固定 taxonomy 為 115 verbs、478 nouns、52 intentions；論文 p.6 的 53 scenarios 是另一統計口徑。設定檔 N=8，論文端到端表格包含 N=2/4/6/8，最佳結果用 N=6，不能一律寫 N=4。
題數與資料
外部 fho_lta_{train,val,test_unannotated}.json 根為 clips；使用 video_uid、clip_uid、action_idx、verb_label、noun_label、action_clip_start_sec/end_sec，預處理另讀 action_clip_start_frame/end_frame。按 clip_uid 分組、action_idx 排序；case key 為最後觀測的 clip_uid_action_idx。input_clips／forecast_clips 各為 N／Z 筆，標籤 tensor 次序 [verb,noun]，forecast_times.label_clip_times 保留秒；缺 test label 補 -1，不能當有效類別。意圖 mapper 僅納入恰一個且在 52 類 taxonomy 中的 scenario，未提供多 scenario 的明確處置。SlowFast 特徵存 clip_uid_action_idx.pt；frame_to_feat 實際 int(frame/16)，W 引數未用；slice [start_feat:end_feat]，預設左補至 15 格。論文描述 2304 維特徵，不能把 feature index 當秒或控制步。完整標註／features／ego4d.json 未隨本次取得，沒有聲稱完整 case 數。原生每 clip 視窗數為 max(0,L-N-Z)，迴圈缺 +1，最後一個完整視窗未取。
評估方式
ICVAE_Task.validation_step 分別評 verbs、nouns；pred [B,K,Z]→[B,Z,K]。lta_metrics.edit_distance 對每 case 取 min_k(editdistance.eval(pred_seq,gt_seq)/prefix_length)，再對 case 平均；AUED 對長度 1..Z 的 ED 做 trapz/(Z-1)，ED_19 是 Z=20 的末點，非第 19 個未來動作。validation_epoch_end 再不加權平均各 batch 指標；非 test 的 test_epoch_end 先依 clip key 合併去重後評分，兩者分母流程不同。論文稱 Damerau–Levenshtein 並報 action ED；此檔實際 import editdistance、呼叫 eval，未見 transposition 專用實作，也未在這條 Task 鏈計 action-pair ED，不能直接宣稱重現 challenge scorer。單模組 validation 使用 GT observed_labels 與 GT intention；create_prediction 才設 FROM_PREDICTION 串接 H3M。test GT 未公開，submission 每 case 含 verb／noun 的 K×Z 整數陣列。

怎麼接入我們的benchmark

可重用

固定 taxonomy、clips 欄位及排序、case key、原生 ED/AUED 實作與 H3M→ICVAE 預測介面。

需要轉換

source 記 paper version+repo commit 並指回 Ego4D；domain 記人類活動，environment 記 video/scenario provenance；task 分 H3M recognition 與 LTA forecasting；case 用 dataset revision+split+clip_uid+最後 observed action_idx+N/Z；保留觀測秒／影格與特徵索引三種座標、GT/predicted intention 來源及不可見未來 label。evaluator 保留 verb/noun、best-of-K、prefix normalization、AUED 與 batch/global 聚合差別；不轉成機器人 success。

仍需補齊

須固定 Ego4D v1 標註／feature revision 與 split manifest；核對 52 類 intention 排除的影片與 case 分母、末視窗少取及 batch 平均；比對正式 Damerau/action scorer。FROM_PREDICTION 缺 clip 時會借用隨機其他 clip 的 intention 並填 -1，接軌須改成可追蹤缺件。preprocess_dataset.py 的 Namespace 以字典取用且未定義 dir_annotations 引數，Quickstart 的 test_model.py 也不在固定 tree；這些都須在允許執行前修復／指定正確入口。
