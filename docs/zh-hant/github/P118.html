EgoMimic: Scaling Imitation Learning via Egocentric Video

返回逐篇總表核心內容已核讀 方法／綜述參考原作 ↗

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

EgoMimic把Aria人類資料與Eve機器人資料轉成相似HDF5結構，但人類future palm位置和機器人關節動作仍是不同動作語義。

版本與身份

主README仍連舊Eve名稱；已讀EgoMimic-Eve README明確回指本作。兩repo commit各固定；不把hardware程式碼等同資料已取得。

領域
方法／綜述參考，未另作來源用途歸納。
環境
Aria Glasses的人類觀測與Eve/ViperX單臂或雙臂桌面平臺；實際camera extrinsics/arm側及人機資料來源要分開。
任務
人機共同模仿學習，示例包括groceries、laundry、小物放碗；mask/插值與同一demo多chunk是表示／樣本擴充，不是新增語義任務。
題數與資料
人類future palm經future camera→world→目前camera變換，單手3D／雙手6D，actions_xyz再插值成100步actions_xyz_act；每300frame另存demo。robot原HDF5為qpos/qvel/effort/action14D，影像可JPEG padded且compress_len另存。type欄明記human/robot。
評估方式
eval_real輸出actions_joints_act，可temporal aggregate，按query_frequency送到實機；此選讀程式是rollout，不提供統一任務成功判分。資料篩掉出界/跳動frame，case需儲存原時間對映；offline action loss與physical success分開。

怎麼接入我們的benchmark

可重用

需要轉換

source保留raw VRS/MPS與Eve session；case分domain/action語義/arm/camera/normalization，300frame chunk共享parent demo避免split洩漏，插值點不當獨立觀測。

仍需補齊
