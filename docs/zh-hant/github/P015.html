Assembly101: A Large-Scale Multi-View Video Dataset for Understanding Procedural Activities

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

Assembly101 的原生粗／細粒度和錄製／視角可以明確分開；六個官方倉庫分別是下載、標註、錯誤標註及三種理解 baseline。

版本與身份

下載 README 已加入 2026-05 Hugging Face 與更新的 AssemblyPoses.zip；不要把新特徵／pose 視為 2022 原始實驗。mistake 註釋指向 2023 Every Mistake Counts in Assembly，與原始三項理解評測需建立衍生關係。

領域
裝配與生產作業
環境
人類組裝／拆卸玩具車；recording/sequence 與 8 固定 RGB、4 頭戴單色視角分層。toy_id 是物件身份與泛化切分依據，不直接等於場景數。
任務
標註檔案列 202 coarse actions（61 物件、11 verbs）與 1,380 fine-grained actions（90 物件、24 verbs），是原生類別數。粗標註供 temporal segmentation，細標註供 recognition/anticipation；mistake/correction 是另外的程式標籤。
題數與資料
fine CSV 含 id、video、start/end_frame、action/verb/noun_id、toy_id/name、is_shared、is_RGB；coarse labels 為片段 frame 邊界與 action_cls，coarse_splits 分 assembly/disassembly。影片原始 60fps，動作標註 frame 為 30fps；手 pose 又為 60fps。mistake CSV 含 start/end、verb、this/that、label、remark。
評估方式
temporal utils.py 將連續同類影格折成片段，計正規化 edit、全影格 MoF、tIoU=.1/.25/.5 下逐 GT 至多匹配一次的 F1。anticipation 先對 action 分數 marginalize 得 verb/object，再算逐類平均 top-k recall，另列 tail/unseen；不是逐題 accuracy。TSM loader 以 start_frame+片段內取樣位置讀圖。

怎麼接入我們的benchmark

可重用

原生粗／細字典、toy/view/sequence 身份、跨 toy 切分、錯誤原因與 temporal evaluator。

需要轉換

一個 recording 連多視角 case，分開 fine/coarse/mistake annotation schema；30fps 動作與 60fps pose 顯式對時。evaluator 儲存 label universe、背景類別、tail/unseen、augmentation 及 macro/micro 聚合，錯誤與修正另連到原程式上下文。

仍需補齊

尚未取得影片、LMDB、cleaned pose 或執行指標。mistake 倉庫 tree 無 Python，發布的是標註並指向後續論文，不能當成已提供錯誤檢測 baseline。anticipation 固定 1064 actions／17 verbs／90 objects，需核對其 CSV 子集，不能直接套用完整 1380／24 字典；缺題檢查被註解，需 adapter 外層驗證。
