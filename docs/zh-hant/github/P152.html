RoboWM-Bench: A Benchmark for Evaluating World Models in Robotic Manipulation

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

RoboWM-Bench把生成影片經IDM/手部軌跡抽取後放入Isaac Lab評估，能連到真實task checker；其成功定義仍須逐題保留，不能只比較影片品質。

版本與身份

固定0a8b0ea；README的Code badge實際連HF權重，核讀本GitHub內實作。未安裝Isaac或執行任何世界模型。

領域
餐飲與烹飪、衣物與洗護、通用物件與機動作業
環境
IsaacSim5.1與庫內IsaacLab_5_1、LeHome式操作場景；robot track列7個Gym名稱，其中pull_and_push共享名稱。human track列12個原生task目錄；不能加上隨附IsaacLab全部任務當RoboWM規模。
任務
robot影片經IDM解碼為Franka動作；human影片經Phantom抽手軌跡再執行。pick/擺盤/丟垃圾/抽屜/按鈕/推拉及human track柔性、倒水等，各有獨立判分。
題數與資料
World-model輸入為初始RGB和prompt；robot軌跡檔名.json實為每行一個action，pose.jsonl依episode檔名索引。parquet轉檔按episode尾3位排序後重編0..N，須儲存對映避免pose錯配。Franka為7arm+2gripper joint targets，夾爪有額外閾值與關節裁切。
評估方式
回放先30step穩定，再取軌跡中曾成功；例外回False列入attempts。pick用abs(z−ori_z)>0.05，未限制向上；擺盤成功只看XY各≤0.15；倒水預設至少1%粒子落在XY±0.02、Z±0.5的對稱盒內。step_interval計數跨呼叫，部分成功條件不檢查穩定、容器內部或釋放；需保留原版並另定嚴格擴充。

怎麼接入我們的benchmark

可重用

兩條video-to-action管線、原始初圖/prompt、具體success與stage score。

需要轉換

case固定原影片ID、解碼器/軌跡/pose對映及sim資產；將影片生成、動作解碼、物理回放結果分別儲存；新增規則用新evaluator版本，不覆寫原作score。

仍需補齊

完整初態/資產取得、原生case清單、各task checker全覆蓋、時間/間隔計數核驗、IDM/Phantom抽取誤差與GPU執行基線。
