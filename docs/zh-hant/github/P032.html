P032 · EgoTaskQA

EgoTaskQA: Understanding Human Tasks in Egocentric Videos

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

EgoTaskQA 可用於「從程式標註產生可追溯問題」的流程。已核讀 generation 說明、direct/indirect 切分、LEMMA loader，以及實際答案索引 accuracy。

版本與身份

已核讀一種 baseline 的評分路徑；其他 HCRN/HGA/PSAC/VisualBERT 的輸入及聚合不據此推定完全相同。direct 名稱不表示該 split 只含 direct 問題，原程式實際對 all_qas 分配。

領域
居家整理與清潔、餐飲與烹飪、社交與溝通
環境
沿用 LEMMA 人類活動影片與世界狀態標註；interval 裡的 video_name/fpv/start/end 是觀測區間，不是新的場景資產。
任務
world state+template/program 產生 query/localize/counterfactual 等問答，再作答案分佈平衡。reasoning_type 可重複附在同一題上，各類分母不互斥。能生成更多問句不等於增加同樣數量的程式或環境。
題數與資料
raw parsed.json 與 templates 產出 direct/indirect/merged/balanced QA；maskX 表示物件遮蔽數。baseline 的 tagged QA 有 interval、question、answer_encode、reasoning_type、各詞／字編碼；vid_intervals 對 feature video_id，HDF5 預設取20 frames。interval=[start,end)，影像檔名為1-based，feature indices 為0-based。
評估方式
所核讀 LSTM baseline 對 logits argmax 與 answer_encode 完全比較，validate 先算各 batch accuracy 再平均；另依多個 reasoning tags 計 true/total。test loader shuffle=True/drop_last=True，故不是保證所有 test 題都進分母。direct split 依答案平衡比例3:1:1；indirect 將 direct 題與特定 query/iterate_until 程式留 train，其餘 indirect 一分為二。

怎麼接入我們的benchmark

可重用

可追溯 world state／program／template、答案分佈平衡、direct/indirect split 與原生 QA schema。

需要轉換

task/規則保留 program 和生成版本；case 保留父影片+fpv+半開 frame 區間、maskX、template、answer vocabulary/hash。題數按唯一 QA ID 計，影片／模板／reasoning tags 另算；原 split 按問題分，不自動宣稱 video-disjoint。

仍需補齊

尚未取得世界狀態／影片／特徵或執行生成與評分。需確認穩定 ID、完整 split 檔及欄位，而非重跑未固定 seed 的 split.py；評估 all-cases adapter 與原 drop_last 結果需各自標版本。
