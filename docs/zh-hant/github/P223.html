Intention-Guided Cognitive Reasoning for Egocentric Long-Term Action Anticipation

返回逐篇總表核心內容已核讀 方法／綜述參考原作 ↗

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

精確INSIGHT舊網址已轉址至iLearn-Lab/AAAI26-INSIGHT；已讀feature reader、stage1分類、具體序列ED與GRPO reward。ED只平均有GT對應的prediction records、沒有強制五候選或20步；另有reader語法錯誤及reward/plugin命名缺口，尚不能直接執行完整流程。

版本與身份

commit ab9495968b80ccae7a905ecb663a9d101873cf75（canonical iLearn-Lab/AAAI26-INSIGHT）。read-only靜態解析沒有匯入/執行上游程式；全部模型、ms-swift與MiniLM均未執行。README稱完整兩階段，但本輪只核讀所列來源段，未認定論文分數可重現。

論文為 Intention-Guided Cognitive Reasoning for Egocentric Long-Term Action Anticipation，Qiaohui Chu、Haoyu Zhang、Meng Liu、Yisen Feng、Haoxiang Shi、Liqiang Nie；cached PDF為arXiv:2508.01742v2（2025-11-15），第1頁直接指向CorrineQiu/INSIGHT。GitHub metadata依repository ID轉址後full_name為iLearn-Lab/AAAI26-INSIGHT，README題名/作者與AAAI26引用一致；這是搬移別名，不是另一篇同名專案。 舊入口CorrineQiu/INSIGHT的已儲存GitHub metadata回應指向iLearn-Lab/AAAI26-INSIGHT，按倉庫別名保留，不另外算成未讀的第二個倉庫。

領域
方法／綜述參考，未另作來源用途歸納。
環境
離線人類第一人稱影片，Ego4D-v2 LTA及EPIC-Kitchens-55／EGTEA Gaze+；stage1讀full-frame與hand-object區域的預抽特徵。不存在可供policy rollout的互動環境。
任務
stage1是verb/noun action recognition，stage2產生think/intention/answer文字與未來verb-noun序列。Ego4D論文協定觀測8個action segments、預測5條各20個action的序列；8不是8張frame。EK55/EGTEA則預測影片前25/50/75%之後會出現的verb集合，報All/Freq/Rare mAP，不是同一ED題型。
題數與資料
ActionDataset按train.json／val.json／fho_lta_test_unannotated.json的clips分組clip_uid，再依action_idx排序；長clip切window_size=8、stride=1重疊視窗，短clip逐action成例。每action讀split/<clip_uid>_<action_idx>.pt兩路特徵，標籤verb_label/noun_label；缺feature會使不完整視窗被捨棄。main配置input_dim=1408、117 verb／521 noun，collate再攤平視窗，因此同action可能重複計數。reader未提供原影格時間/fps/feature取樣manifest；test就算is_test=True仍會在getitem讀mask feature。stage2依外部ms-swift chat JSONL，messages assistant含<answer>與<intention>，images提供路徑；cal_ED把images[0]父目錄當clip_uid，GT同ID會覆寫。pred JSONL用clip_uid、res_list；沒有公開的完整stage1→chat/prediction轉換與split資產。
評估方式
stage1 train/validate是分類正確action occurrences除以flattened有效標籤數×100；main的co-occurrence validation在各top5 verb/noun組閤中挑raw_cooccurrence>0且機率乘積最大的pair。prior缺檔時只由train建立，但重疊視窗會重複action。cal_ED以逗號分動作、第一個詞為verb，其餘為noun；保留大小寫，不做taxonomy ID校驗。具體DP允許插入/刪除/替換及相鄰交換（受限交換遞迴，未證明與官方Damerau實作等價）。對每條res_list候選截至GT長度L，分別取最小action/verb/noun距離，三項可來自不同候選，再各除L、最後按處理到的prediction records平均。候選數不強制5、L不強制20；缺GT的prediction被跳過，完全缺prediction的GT不進分母，重複prediction ID可重複計數，L=0給0，空res_list會使min失敗。reward不是此ED：只接受兩個英文字token的pair並lowercase，至少20對才開gate，內容分數分母固定20；intention為MiniLM cosine經β=0.8、γ=40 sigmoid對映，R=gate×(0.85內容+0.05意圖+0.05語言+0.05格式)，shell再以0.9此R+0.1外部soft_overlong組合。意圖reward不是意圖分類accuracy；EK55/EGTEA的All/Freq/Rare mAP scorer未在此版本公開。

怎麼接入我們的benchmark

可重用

保留clip/action身份、兩路feature schema、stage1 taxonomy與train-only co-occurrence規格、離線ED的實際parser/DP，以及reward各分量。公開來源以canonical repo記錄並保留舊alias。

需要轉換

分開source、action-occurrence、8-action context window、20-action forecast case與多候選輸出；case鍵應包含clip_uid+最後觀測action_idx，不能只用image父目錄。evaluator分列stage1 accuracy、各自best-of-K normalized ED、intention相似度reward及論文mAP；保留實際K、L、分母、缺失/重複UID與大小寫/多詞noun策略。

仍需補齊

完整annotation/features與chat生成/預測指令碼、8→20對齊及五候選驗證；需對所有GT補齊失敗case並核驗官方ED一致性。靜態ast.parse確認HandObject/dataset.py第25行assert末尾逗號造成SyntaxError；plugin匯入my_rewards_new_intention但樹只有my_rewards_intention.py，shell指plugin_new_in_log_intention.py但樹只有plugin_in_log_intention.py；reward使用nullcontext卻未匯入。需修正這些執行缺口及補EK55/EGTEA mAP實作。
