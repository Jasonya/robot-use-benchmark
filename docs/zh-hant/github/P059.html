P059 · EMAG

EMAG: Ego-motion Aware and Generalizable 2D Hand Forecasting from Egocentric Videos

返回逐篇總表核心內容已核讀 方法／綜述參考原作 ↗

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

EMAG 是重用 Ego4D／EPIC-Kitchens-55 的雙手位置預測方法。已讀資料與 ADE/FDE 計算程式，但公開設定、讀取器與 trainer 的欄位／時間維度不一致；不可標成可直接執行的跨資料集評測。

版本與身份

固定 0386bd9de2bd2ec3504e5b645a095c46e9a565ca（2025-03-25），與 2024 論文區分。loader 傳 ego_feat，trainer 卻讀 egos_input；loader 保留五時點且沒有裁切，test_step reshape 明定四時點；兩份設定皆未定義 trainer 初始化所讀的 model_config.loss。論文稱 homography，檔案路徑／變數稱 fundamental/fmat，未取得矩陣資產前不能宣稱兩者等價。非截斷 tree 未列 EPIC 專用 loader 或前處理釋出。

README 自稱 ECCVW 2024 官方實作，列 Hatano、Hachiuma、Saito，與 arXiv:2405.20030 論文及其指定作者頁一致；作者頁 Code 連至 masashi-hatano/EMAG。論文也引用 SORT、hoi-forecast、EGO4D/forecasting 作為相關工具／比較方法，不能把它們替代成本論文的實作。

領域
方法／綜述參考，未另作來源用途歸納。
環境
論文在 EPIC-Kitchens-55 廚房影片及 Ego4D 多種人類活動上做同資料集／跨資料集預測；資料屬人類第一視角影像，沒有機器人可執行動作介面。已讀程式入口使用 Ego4D schema，EPIC 另有設定但沒有獨立 loader／轉換指令碼。
任務
論文 §4.2 用八張 4 FPS 觀測，預測未來一秒四時點的左右手 2D 位置，並以未來 ego-motion 為輔助訓練目標。跨資料集的方向（EPIC→Ego4D 或反向）及 train/val 必須各自保留；活動類別分析不是新增機器人任務。
題數與資料
讀 annotations/fho_hands_{mode}.json 的 /clips/*/{video_uid,clip_uid,frames}，由 frames/*/{pre_45,pre_30,pre_15,pre_frame,contact_frame}/boxes 的 left_hand/right_hand 建立 [2,5,2] 座標與 [2,5] mask；以來源 w/h 正規化。排除設定 delete 清單、pre_45.clip_frame≤interval×8 或全零 mask。輸入 image_frame/{clip_uid}/{frame:06d}.png、optical_flow/{clip_uid}/npy/*.npy、fundamental/{clip_uid}/*.npy，另讀 hand-objects/interval={interval}/{clip_uid}/{pre45}.pkl 的 bboxes_obj/bboxes_hand/attention_mask。回傳 frames、flows、bboxes、ego_feat、future_hands、future_egos、hands_mask、egos_mask 與影格 h/w；八個觀測索引終於 pre45-interval。影格步長不能直接當秒；pickle 與影像均未下載／反序列化。
評估方式
論文 §4.3 定義影像高度256 px尺度的 ADE（所有未來時點、左右手）與 FDE（末時點、左右手）。實作 test_step 固定四時點、套 hands_mask，scaling_original 按 meta 中的來源 w/h 還原畫素；calculate_L2_loss 排除 GT=(0,0)，分別累積左右手所有有效時點與第四時點的 L2 距離，test_epoch_end 只輸出四個分手平均。沒有此處的左右手合併報表，也沒有保證來源 PNG 高度為256的轉換步驟；原始解析度不同會改變分數。

怎麼接入我們的benchmark

可重用

原生 clip_uid、觀測錨點、標註時點與有效性 mask，左右手／物件框引用及分手位移演算法。

需要轉換

case 以父資料集版本+split+clip_uid+錨點定位；保留 2D x/y、來源影格尺寸與秒／幀對照，明列四步 horizon、兩手缺失規則與影像高度256的評分尺度。跨資料集保留訓練來源與評測來源，不合併其原生 case。

仍需補齊

須補齊影像、flow、手物框與 ego-motion 前處理來源／版本及 EPIC 格式轉換；修復 ego_feat/egos_input key、五標註時點對四輸出時點的契約與缺少的 model_config.loss 設定，確認兩手合併、解析度及遮罩後才可執行驗證。
