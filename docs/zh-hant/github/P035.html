P035 · EgoVLPv2

EgoVLPv2: Egocentric Video-Language Pre-training with Fusion in the Backbone

返回逐篇總表核心內容已核讀 方法／綜述參考原作 ↗

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

EgoVLPv2 是跨模態預訓練方法與既有 benchmark 的適配實作，保持 related_reference 身份；沒有把其下載特徵和下游結果當作新環境或新題庫。

版本與身份

root README 指明基於 EgoVLP 的特定提交，不能與 P034 的當前固定快照視為完全相同程式。EgoTaskQA 的資料仍屬 P032/LEMMA 衍生範圍。

領域
方法／綜述參考，未另作來源用途歸納。
環境
沿用 EgoClip/Ego4D、EPIC-100、Charades-Ego、EgoTaskQA、QFVS 等父來源；此方法不獨立定義一組新生活場景。
任務
預訓練與 video-text fusion，於 EgoMCQ、retrieval、動作、NLQ/MQ、QA／summarization 進行遷移。任務清單引用原 benchmark，模型比較本身不增加 canonical tasks。
題數與資料
EgoTaskQA 子目錄明確沿原作者預處理，formatted_*_qas_encode.json 的 interval 加 .mp4 定位加工影片，question/answer_encode 和 reasoning_type 保留；tokenizer 以30 token 為上限截斷，frame 預算由配置定義。NLQ 保留 clip_uid/annotation_uid/query_idx/predicted_times。
評估方式
核讀 NLQ 原生時間 overlap/top-K 閾值 recall，分母為傳入預測且只列 evaluated/GT。QA validate 在分散式 allgather 後 argmax 對 answer 索引，另計 reasoning tag 正確率；直接 all_acc 公式寫成 correct/B*world_size，需檢查分母與 tag 報表的一致性，不直接採用此摘要作新結果。

怎麼接入我們的benchmark

可重用

父 benchmark adapters、固定特徵／模型版本、EgoTaskQA 的原生 ID 和 NLQ evaluator。

需要轉換

用 method→evaluated_on/source 與 derived_feature 邊連父資料，不新建一份重複環境／任務數。case 在原 benchmark namespace 下儲存，另記模型、16frame/224px、30token、分散式取樣與 adapter 提交版本。

仍需補齊

未下載權重／features 或執行。需核驗 DistributedSampler padding 的去重、QA pooled 分母及 checkpoint 選擇 split；本次讀 EgoTaskQA/NLQ 核心，不能代替其他下游完整 adapter 審核。
