WatchAct: A Benchmark for Behavior-Grounded Robot Manipulation

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

WatchAct有14種行為理解題型，規劃用符號狀態評分，LIBERO另跑物理執行；Plan Success、完整終態一致和實體成功不能合併成同一數值。

版本與身份

本次固定97d8873；先前原作索引使用7036927快照，不能直接當同版本。未呼叫VLM、translator或policy server，也未執行LIBERO。

領域
居家整理與清潔、通用物件與機動作業
環境
觀察人類影片後在LIBERO桌面執行；影片camera_perspective/spatial_reference與模擬相機／世界坐標要分開。符號場景圖不等於新的物理場景。
任務
14native題型如Imitation/Reversal/Temporal_Sort、Count/Moment、Implicit Intent與Episodic等，屬行為條件與推理方式；具體robot goal／物件／初態另定，不把14題型當14生活用途。
題數與資料
row有id/original_id、language_instruction、video、camera_perspective、spatial_reference；按original_id群組抽樣。規劃輸出action_plan_json，翻譯/符號推演產initial/final/goal_state；執行端是BDDL、init_state、prompt切換與policy action chunk。
評估方式
Plan SR對需變化的interest objects全對即成功，可能忽略side effects；all_success才要求完整終態相等。Imitation/Reversal可改用序列匹配SR。LIBERO物理成功從done取，progress另記max(0,final-initial)，Right/Horizontal檢查幾何且物件已釋放、接觸桌面。彙總依evaluated_count加權，error_count與缺題需另保留。

怎麼接入我們的benchmark

可重用

影片/語言/視角條件、原題型、original_id lineage、planning與physical兩種checker。

需要轉換

同一來源題分planning case與execution case，各固定translator/模型資訊/預算；存PlanSR/all_success/physical_success、原始及net progress不同metric。新加無副作用規則另版。

仍需補齊

全影片與BDDL/init-state資產對齊、翻譯前後語義驗證、底層LIBERO版本、初態已達標剔除與完整missing/error分母協定。
