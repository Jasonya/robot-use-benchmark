EgoCast: Forecasting Egocentric Human Pose in the Wild

返回逐篇總表核心內容已核讀 方法／綜述參考原作 ↗

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

EgoCast 的預設分支與 forecasting 分支是兩個不同版本。已追到預測分支的 loader→test_fcast→report；目前 pred_input=True 路徑會改寫回傳 gt，不能直接把這個快照視為可重現論文 ground-truth 評測。

版本與身份

default commit 1db0c6e 與 forecasting commit 6ba9eec7 各自鎖定。README 的影片下載範例重複 annotation 命令；需依父資料工具取得真正影像。此處只報靜態可查的路徑差異，不聲稱論文結果有誤。

領域
方法／綜述參考，未另作來源用途歸納。
環境
EgoExo4D 與 Aria Digital Twin 的人體姿態預測，沒有新機器人環境。已深入核讀的 forecast 路徑為 EgoExo4D；ADT loader 雖存在，本次未聲稱完整核對其 forecast evaluator。
任務
先估當前全身姿態，再由歷史頭部軌跡與估計姿態預測未來。論文比較 0.5／1／2／3／4／5 秒 horizons；default repo 的姿態估計、forecast branch 的預測與 oracle-GT pose input 必須分條件。
題數與資料
EgoExo4D take_uid、camera_pose、body annotation、17-joint skeleton、visible flags、time index、cached prediction route。forecast train config window_size=80、future_frames=15，test config 為 30；檔名與 dataroot 中的 fps 字樣不足以證明實際 sampling frequency。test loader 排除 take_name 含 bouldering，且為 prediction input 使用外部 camera 檔絕對路徑。
評估方式
test_fcast 滑窗產生多個預測，skeletal MPJPE 乘 visibility 後除 (error!=0) 計數，真正零誤差也被排除；速度沿相鄰視窗軸相減並乘 10，aria 分支乘 30，不能直接視為同一 future-time 速度。外層每 take 等權平均，跳過 enumerated index 17/62。更關鍵的是 pred_input=True 時 skeletons_window 被 cached prediction 覆蓋，且同變數作輸入及回傳 gt，feed_data→test_fcast 沿用；需修復／核實獨立 GT 才能發布結果。論文的跨 horizon AUC 不在本次讀到的 caller 中實作。

怎麼接入我們的benchmark

可重用

可重用 current-estimation→forecast 的任務分解、take／frame 對照、17-joint schema；固定兩個 branch commits 與父資料版本。

需要轉換

以 task 記錄 forecasting 目標，case 指明 estimated-pose 或 GT-pose 條件、history／horizon／sampling、visibility 和獨立 GT 資產。將 default／forecast revision 分開；修訂 gt、mask、velocity 或 index exclusions 時新增 evaluator version 與原生對照。

仍需補齊

未下載完整 EgoExo／ADT、cached predictions 或 checkpoint，未執行模型。當前原始碼有上述評分鏈缺口與本機路徑依賴，尚不能認為可直接重現 paper horizon curve。
