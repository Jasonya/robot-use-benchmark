EgoScale: Scaling Dexterous Manipulation with Diverse Egocentric Human Data

返回逐篇總表實作尚未確認 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

NVIDIA官方EgoScale頁目前提供論文與方法／影片介紹，未提供可確認的GitHub實作；相似名稱搜尋結果不可直接當官方benchmark程式。

版本與身份

以2602.16710與NVIDIA研究頁核對身份；Exoscale雲端SDK、EgoScaler不同論文及unofficial候選不視為本作官方實作。 已補看dipfocus候選README（論文整理／骨架）及paragonLab候選（實為Fast-WAM）；wingAGI候選README介面404，未據此斷言repo不存在。

領域
居家整理與清潔、衣物與洗護、辦公與教育、裝配與生產作業、零售與購物、實驗室操作
環境
原文的人類pretraining scene labels與實機桌面評測場地不同層次；EgoDex和in-house來源保留來源鏈，未取得完整場景manifest。
任務
原文6,015人類訓練標籤、344對齊midtraining任務與5個主實機目標需分開；本次沒有將訓練標籤當已可執行robot task。
題數與資料
官方頁述20k+小時action-labelled egocentric video與少量人機對齊資料；原文細量與6D手／機體轉換須原始資料／實作確認，未取得完整欄位規格。
評估方式
原文whole-task成功與細項完成度；當前頁未給可執行scorer、全量reset banks或逐次rollout紀錄，不能由影片展示推算整體成績。

怎麼接入我們的benchmark

可重用

需要轉換

仍需補齊
