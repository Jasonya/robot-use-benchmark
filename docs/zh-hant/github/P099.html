HomeRobot: Open-Vocabulary Mobile Manipulation

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

HomeRobot的OVMM流程分找物、抓物、找容器、放置；真正overall成功還要求零robot-scene碰撞。已沿官方submodule讀到實際放置與穩定性checker。

版本與身份

home-robot tree把Habitat-Lab釘在b727ca9f7123101aaedb737ca9ccc1b153525dd9；本次直接讀此版checker，沒有用現行HabitatHEAD代替。README另指定home-robot-ovmm-challenge-2024 tag，與本main快照分開。

領域
居家整理與清潔
環境
真實Stretch與Habitat模擬分開；模擬依賴HSSD ovmm資產、物件、Stretch模型和episode配置。相同HSSD屋子被多工重用需按父資產鍵去重。
任務
將指定類別物件從起始容器搬到目標容器；四階段是同一長程任務進度，不自動算4道獨立題。原生episode允許多個candidate物件／容器。
題數與資料
OVMMEpisode記object_category/start_recep_category/goal_recep_category及candidate goal集合。wrapper讀head_rgb/depth、GPS/compass/joint及task goal；depth由[0,1]對映min/max並特判邊值；相機座標模式與GT semantic開關必須記入protocol。
評估方式
原子放置量測檢查物件與合法容器接觸、排除地板與過深穿透，父checker再檢查放開、末端回rest距離及可選的穩定步數。階段success具有歷史累積性；metrics_utils的overall_success=END.ovmm_place_success且robot_scene_colls==0，partial=(找物+抓物+找容器+overall)/4。缺失欄位在聚合時被略過，須額外儲存完整預期episode與缺值數。

怎麼接入我們的benchmark

可重用

物件／容器category、候選集合、場景episode身份、觀測/動作轉換、原子與階段checker。

需要轉換

case固定資料版本、scene_episode、機體、GT或感知模式、步數與控制比例；native放置、overall零碰撞及partial三項分開存。依賴源釘選b727ca9而非目前Habitat main。

仍需補齊

HSSD/機體/episode資產閉合、感測配置與相機內參檢查、原生感知／控制執行驗證、論文與2024挑戰版本對照。
