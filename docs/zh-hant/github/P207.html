P207 · EgoCoT-Bench

EgoCoT-Bench: Benchmarking Grounded and Verifiable Operation-Centric Chain of Thought Reasoning for MLLMs

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

GitHub DStardust/EgoCoT 是本篇官方補充網站，HF 另有公開 dev／test 標註、媒體重建 manifest 與實際 reconstruction reader。已核程式只有媒體處理與網站示例，未找到正式 Acc／R／SCR scorer 或 test 正解；不能把網站題目點選函式當成 benchmark evaluator。

版本與身份

GitHub 71e6114c155c7a593fa39e2af801b51e836b53ca 是網站；HF 31c4aa4adc88632c6efe984cf8c5399cc75f6fc3 是 clean public release，只重發自錄媒體，不能將其與較早含第三方處理片的版本混用。raw README／CSV／reconstruction script 均固定 HF revision。viewer/rows endpoint 未回傳 dataset revision，本輪只儲存帶時間與 SHA256 的一列 dev／test 與 features 作輔助欄位核對，不聲稱已核 pinned Parquet 全體內容；未下載影片或執行 reconstruction。

pinned arXiv:2605.19559v1 連到 dstardust.github.io/EgoCoT，固定 repo index.html 與既有 website cache 的 SHA256 相同；其 Dataset 按鈕連 DStardust/EgoCoT-Bench，dataset card 反連同一 paper／project。PDF 作者有 Yang Dai、Dian Jiao、Tianwei Lin、Wenqiao Zhang；網站頁首隻列前三人，文獻作者以 PDF 為準。搜尋的 EmbodiedGPT/EgoCOT_Dataset 是 2023 年另一候選，未將同名視為本篇；頁尾 Academic Project Page Template 亦非 benchmark。

領域
居家整理與清潔、餐飲與烹飪、裝配與生產作業
環境
五個公共人類第一人稱父來源 Ego4D、EPIC-KITCHENS、Charades-Ego、MECCANO、HD-EPIC 加自錄影片，涵蓋生活、廚房及組裝操作；沒有可互動的機器人環境。pinned reconstruction CSV 清點為 351 個 (source_dataset,source_video_id)，但有 352 個 processed_clip_id／output paths；MECCANO 0001_part1 有 416×234 與 588×331 兩版，必須保留版本關係。
任務
4 groups／12 subtasks：Egocentric Grounding & Perception＝Active Object Grounding、Hand-Object Association、Manipulation State Perception；Spatio-Temporal Retrospection＝State Retrospection、Location/Visibility Retrospection、Hand-Object Temporal Retrospection；Predictive & Causal Inference＝Next State Anticipation、Next Action Anticipation、Local Cause-Outcome Inference；High-level Grounded Reasoning＝Progress Reasoning、Hand-Object Grounded CoT、Goal-Oriented Object Tracking。均是四選一影片理解及公開解釋／證據品質，不是可執行操作技能。
題數與資料
HF pinned tree 的實際資料檔為 data/dev-00000-of-00001.parquet 與 data/test-00000-of-00001.parquet；card 指定 load_dataset 後取 dev／test，300／2,872 題。小型官方 viewer 回應各抽一列：qid、question、choices[{label,text}]、answer、cot[{step,text}]、media_id、source、big_category_en、sub_category_en、type；dev 有答案與解釋，test 範例 answer=""、cot=[]。兩份 viewer 的 features 沒有獨立 evidence／bbox 欄，不能依 card 的 may include 自造結構化證據。pinned CSV 實際 3,172 個唯一 qid；columns 含 processed_clip_id、source_dataset/video_id、source_start_sec/end_sec、target_width/height、resize_mode、fps、preprocess_version、expected_local_output_path、coordinate_system。所有 start/end 為空、resize_mode=stretch、座標系 processed_clip；2,859 QA 引用 4 fps、313 QA 引用 8 fps，這是題目列數而非影格數。63 個自錄輸出與第三方待重建媒體分開。
評估方式
paper §3.2.4 的 Acc 為四選一 exact match／全部評測題；R 是 Qwen-Max 對公開生成解釋與參考解釋的 0–5 分；SCR = 答對且 R≤2 的題數／所有答對題數×100，分母不是全題數，零答對的處置未由公開程式核實。paper 的 3,172 題結果不可當作 public hidden-test 2,872 題分數；card 的 dev 193 個 video、test 351 個 video 與總 351 個來源顯示不能假定 video-disjoint。paper 另以 2,800 responses 核對 judge，人類一致性樣本不是額外 benchmark cases。GitHub handleAnswer 只對四個寫死示例比字母，leaderboard 只排序 HTML；HF scripts tree 唯一程式 reconstruct_media.py 沒有模型推論、judge、R／SCR 聚合或提交驗證。正式 test scorer／labels 在本輪已核來源中未公開。

怎麼接入我們的benchmark

可重用

可重用 qid、group／subtask／type、選項及 public dev 解釋、來源／processed clip 對映、重建 CSV 與實際 reader；paper 的 Acc／R／SCR 保留各自定義。

需要轉換

source 同時記 paper v1、website commit、HF revision 與五父資料來源；task 按四群十二類，case 按 qid 保留 dev/test、media_id、options，將 cot 記公開參考解釋而非模型私有思考。environment 記 human-egocentric context；媒體引用需帶來源 ID、processed resolution／fps／coordinate_system，351 sources 與 352 processed variants 分開。evaluator 分別記 Acc 的 N、R 的判讀數及 SCR 的答對分母；test 空正解標為 withheld，不能轉成錯誤標籤或零分。

仍需補齊

正式 evaluator／submission runner、hidden test labels、judge prompt與精確版本／解析／失敗處置、完整結構化時空 evidence、父素材取得與重建驗證。reconstruction script 用整段 source_video_id 影片，未使用 start/end／resize_mode 欄；CSV 的 start/end 全空，對含切段字尾的 source_video_id 仍須外部定位到正確已裁素材。讀影格失敗時 continue 而不補位，可能改變輸出時間軸；需校核處理後 timestamps／bbox。
