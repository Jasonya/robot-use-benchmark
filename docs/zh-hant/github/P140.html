VIP: Towards Universal Visual Reward and Representation via Value-Implicit Pre-Training

返回逐篇總表核心內容已核讀 方法／綜述參考原作 ↗

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

VIP學習的是視覺reward/表示；embedding距離和環境任務成功是不同評估。程式的success門檻是episode累積solved次數，並非連續穩定時間。

版本與身份

固定81b0520；前述sum門檻屬目前公開env基底，具體task可能另override，整合每task時仍需沿具體class核對。未跑MPPI。

領域
方法／綜述參考，未另作來源用途歸納。
環境
Ego4D人類訓練影片、實機示例和MuJoCo系下游環境；原場景與資料仍屬各父來源。
任務
以goal-image/embedding引導robot任務與reward learning；fold_towel等展示是應用例子，不能由曲線距離直接認定任務語義正確。
題數與資料
自訂影片依video資料夾存frames；model依影像shape resize/crop224和normalization，max>2時除255。sim=-L2(embedding1,embedding2)，此單位是特徵距離而非幾何公尺。
評估方式
MPPI讀goal_embedding並用H/paths_per_cpu/num_cpu/kappa配置最佳化；env.evaluate_success預設判sum(solved)>5再按paths算百分比，未要求連續。embedding reward、原生solved與工程時間分開儲存。

怎麼接入我們的benchmark

可重用

表示/goal資料介面、原reward數學定義、MPPI配置與環境成功引用。

需要轉換

evaluator標明learned reward或ground-truth環境條件；case固定goal frame、相機、normalization、planner預算和solved門檻，避免將reward作通用正解。

仍需補齊

各task實際solved predicate、原素材/goal設定、planner與環境版本、reward與任務正確性的反例校準。
