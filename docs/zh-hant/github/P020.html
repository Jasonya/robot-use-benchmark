EgoHumans: An Egocentric 3D Multi-Human Benchmark

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

EgoHumans 官方倉庫提供多人體資料處理、COCO-video 轉換與追蹤評測。已沿 tracking 檔案追到內含 MMTracking 的 dataset evaluator 與 MOT matching。

版本與身份

作者 TRACKING.md 說因 PyTorch 升級，公開結果與原論文有約 1% 變動；不能將當前程式當原表格的逐位重現。所核讀的 external/MMTracking 檔案是正式入口依賴，其他內嵌模型／資料集未據此宣稱全數讀完。

領域
休閒與運動、社交與溝通、穿戴互動與動作介面
環境
穿戴 Aria 與外部相機同步記錄多人活動，含網球、擊劍等；big_sequence/subsequence、相機與人物分層。拼接 COCO video 或增加 ego_slam/exo 視角不新增實體環境。
任務
多人偵測、2D/3D pose、mesh 和身份追蹤；主要 tracking 比較以 ego_rgb 和指定 detector 條件進行。GT bbox 與 YOLOX bbox 是不同合法輸入條件。
題數與資料
coco_video_format.py 以 parent_sequence+sequence+camera+mode 建 video_name；image 有 image_id/video_id/frame_id，annotation 保留 human_name/camera_name/camera_mode/time_stamp，instance_id 由 aria 人名解析，bbox 用 XYWH。frame_id 在可納入影像序列內重新編號；無有效人框的 frame 會被跳過。MiDaS 深度／3D root 是加工輸出，不是直接測量深度。
評估方式
CocoVideoDataset 按 frame_id==0 分影片並檢查 track_bboxes 長度；eval_mot 用 1-IoU 距離、預設 .5 門檻、ignore IoF 和 MOTAccumulator，輸出 IDF1/MOTA/MOTP/FP/FN/IDSw 等。MOTP 在此轉成 1-distance，方向與底層距離不同；全體累積結果與逐類平均需分開。

怎麼接入我們的benchmark

可重用

COCO-video 轉換、原人物 ID／時間、tracking 輸入條件與內含 MOT adapter。

需要轉換

environment 留真實錄製／subsequence，video ID 只作觀測序列；維持原 time_stamp 到重編 frame_id 的對照。case/evaluator 記 detector、GT bbox 可用性、ego_rgb/ego_slam/exo、深度來源、忽略區域與匹配閾值，跨拼接需重新命名 instance ID 並儲存原值。

仍需補齊

尚未取得影像、pose、MiDaS 加工資料／模型或執行；主要驗證流程需固定設定檔與 detector 輸出。2D/3D pose 和 mesh benchmark 的完整 evaluator 不包含在這次 tracking 核讀範圍。
