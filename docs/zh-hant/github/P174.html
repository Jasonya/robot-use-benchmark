Labimus: A Simulation and Benchmark for Humanoid Dexterous Manipulation in Chemical Laboratory

返回逐篇總表檔案／網站 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

Labimus的官方網站可核對6種原子操作和1條七步秤重流程；目前這個GitHub只有展示內容，尚未取得模擬與精度checker。

版本與身份

網站固定caea61f，原作2606.31037；所讀GitHub tree展示index.html與媒體，沒有benchmark Python實作，不據此宣稱pipeline已復現。

領域
實驗室操作
環境
Isaac Sim化學工作站、Tianyi humanoid、30+功能資產，包含可動儀器、粉末粒子與數位秤量測；網站影片不是可執行USD資產包。
任務
6atomic operations加1個7-step workflow。三種評估層(task completion/precision/step progress)×四個appearance條件形成12格評測設計；不能稱12個新語義任務。
題數與資料
原文/網站描述procedural layout及Standard/Lighting/Textures/Combined；仍未取得具ID的scene、episode、示範和控制資料，未能算本次可用case數。
評估方式
同一物理動作分報binary completion、protocol precision和長流程stage進度；網站秤重例以原文±0.001g作模擬量測容差，另有位置容差。這些是原作任務標準，需相應物理量/儀器讀值及校準，不只看物件是否放到秤上。

怎麼接入我們的benchmark

可重用

6+1任務粒度、動作完成與量測有效性分離、四種環境條件。

需要轉換

case保留儀器狀態/粒子質量、單位、stage順序和容差；evaluator同時輸出完成/精度/進度；新增精度規則另有版本與支援證據。

仍需補齊

可公開取得的simulation code、asset與episode清單、instrument/particle校準、精度與stage scorer、各條件實際基線。
