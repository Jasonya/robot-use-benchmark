P241 · AFF-ttention

AFF-ttention! Affordances and Attention models for Short-Term Object Interaction Anticipation

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

已核STA reader→預測affordance prior→AFF ROI head→OverallMeanAveragePrecision，以及新增EPIC STA pickle的讀取格式。固定release的v2設定仍遇v1欄位硬編碼及未隨repo提供的import；AFF、hotspots和完整執行環境尚未閉合，不能以README結果或外部權重連結宣稱可重現整篇。

版本與身份

固定 1a1253fa2bde09ef1de4894f3bf872c1fbf270de（2024-07-15）。已核propagate_AFF_from_node.py用top1/3/5 visual及cross-modal鄰居、1.5×最近距離篩選、softmax(2×similarity)加權後逐類max、max-normalize再softmax；論文式(3)是加權sum後exp，不能混成同一prior配方。該指令碼np.save被註解，不能直接認定會產出reader所需檔；其diagnostic n_samples從1起算、最後分母多1，也不是STA mAP。generate_AFF_labels.py是另一cluster頻率版本，root標TRAIN但輸出名含VAL，需要provenance而非靠檔名判split。README連的weights與config checkpoint亦不同。只核以上核心source／小型詞表，未跑模型、simulator或下載大資產。

AFF-ttention! Affordances and Attention models for Short-Term Object Interaction Anticipation，Lorenzo Mur-Labadia、Ruben Martinez-Cantin、Jose J. Guerrero、Giovanni Maria Farinella、Antonino Furnari；Guerrero在清單/README也寫Josechu。快取arXiv:2406.01194v2（2024-06-05），README對應ECCV 2024，PDF hyperlink discovery直接指lmur98/AFFttention。README另連2407.04369 challenge report，不能混為本篇PDF版本或後續STAformer++。

領域
餐飲與烹飪
環境
Ego4D v1/v2日常活動與作者整理的EPIC-Kitchens STA第一人稱影片。affordance node/zone是影片中視覺相似的活動區域及其已觀察互動，不是3D場景layout或機器人可執行技能；hotspot是影像中的人手互動機率。
任務
下一次物件互動的box、noun、verb、TTC與confidence。v1 taxonomy87 nouns/74 verbs，v2 128/81；類別、prediction frame、GT object、zone/visit與policy trial各為不同單位。P241有新的curated EPIC STA標註貢獻，不能與P235的EK100 pseudo-box實驗或母EK action資料直接合併計數。
題數與資料
Ego4D JSON讀info.video_metadata與annotations；每ann含uid、video_id(v1)/video_uid(v2)、frame、objects[{box,noun_category_id,verb_category_id,time_to_contact}]。still圖為video_id_七位frame.jpg；fast LMDB以video_id為父目錄、video_id_十位frame為key，值是JPEG；sampler取frame-15..frame共16格、早於0補0，沒有取未來影格。frame索引與TTC秒保留各自單位。target是boxes/noun_labels/verb_labels/ttc_targets；noun固定+1，verb在ROI_HEADS.VERSION不含v1時+1，因此兩個aff設定都+1，與資料集v1/v2名稱無關。train移除退化框／無物件ann；test無objects時loader製造假框與0 label，不能作GT。AFF檔是list[dict]的numpy物件容器，key為v_id、frame、AFF_N_top3、AFF_V_top3等；reader把它們命名AFF_N_GT/AFF_V_GT，實際來源是predicted_AFF檔，缺項填全1 prior。EPIC pickle則是[{eid,video_id,timestamp,objects:{noun_category_id[],verb_category_id[],boxes[],time_to_contact[]}}]；框被當normalized xyxy乘(1920,1080,1920,1080)。影像frame=int(timestamp*30+1)，AFF lookup卻round(timestamp*30)+2；timestamp秒與這兩個索引不可混用。EPIC noun合群/排除others、verb刪除稀用詞都會改case分母；test分支實際重用val_annotations.pkl。未取得完整標註資產，未宣稱有效case總數。
評估方式
STATask.validation_epoch_end先list_gather所有rank、以uid建立pred/GT dict去重，再OverallMeanAveragePrecision(top_k=5)。每圖依score排序，針對各配對條件對尚未匹配的GT選最大IoU；IoU用xyxy畫素端點+1面積，門檻>0.5，TTC abs(error)<=0.25秒。Top-5對每圖每條件豁免(5-1)×GT物件數個最高分FP；餘下按confidence建立precision=TP/(TP+FP)、recall=TP/該類GT物件數，取單調precision envelope的VOC積分。12個輸出中前8個是合併類別的AP，後4個map_box_noun、map_box_noun_verb、map_box_noun_ttc、map_box_noun_verb_ttc才按有GT的noun類別宏平均×100；checkpoint用最後一項，不能把global AP混入主表mAP。AFF head將預測prior×各head softmax後重新正規化，去背景、每proposal保留verb_topk=1、noun×verb分數>0.002（不是config的0.05），per verb–noun NMS後最多100 detections；此預測budget與scorer的Top-5 FP豁免不同。export把noun減1、verb減相應offset，輸出results[uid]的box/score/noun_category_id/verb_category_id/time_to_contact。test僅匯出，無公開GT scorer結果。

怎麼接入我們的benchmark

可重用

Ego4D v1/v2 taxonomy、STA JSON與EPIC pickle reader的原生欄位、predicted-prior lookup／Bayes fusion、具體mAP與submission adapter。

需要轉換

source記paper/commit、Ego4D或curated EPIC annotation revision、StillFast base與prior/hotspot資產；domain/environment為人類影片和zone provenance。task保持STA；case用dataset+split+uid/eid，另存video/frame/timestamp、原框座標、class_remap/背景offset。zone/visit/node及其training STA/narration是source附屬資料，不增加case。evaluator固定score生成、verb_topk/NMS/100候選、Top-5豁免、TTC門檻、noun macro AP與uid去重；跨source不等價為robot success。

仍需補齊

優先修復Ego4D reader的video_id硬編碼與v2 video_uid；固定StillFast base commit／安裝佈局，補缺的ego4d_sta_hands_still_video、faster_rcnn_HANDS_sta、faster_rcnn_prior_HANDS_sta、detr_criterion等被無條件import的模組。移除...及作者絕對路徑，固定完整split/annotation與predicted_AFF/hotspot SHA。AFF資料庫生成／descriptor取樣仍需train-only及時間可見性核驗；當前code以train_nodes匹配visual query，不能因GT欄名就指為oracle，也不能因檔名train就視為已證明無洩漏。EPIC需要固定class_names、實際class remap及兩套frame偏移，且test=val不能當獨立test。hotspot讀入有外部placeholder，當前Ego4D __getitem__的contact-point呼叫與heatmap target被註解，selected aff鏈未核到完整hotspot重權重執行路徑。
