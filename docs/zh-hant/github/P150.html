DreamDojo: A Generalist Robot World Model from Large-Scale Human Videos

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

DreamDojo具有動作條件影片生成的真實評估入口；核心輸出為PSNR/SSIM/LPIPS。預訓練影片時數、評估樣本與機器人可執行任務需分開。

版本與身份

固定02f119b；從docs/EVAL追到cosmos_predict2/action_conditioned.py，不誤把套件內一般VQA metrics當作本論文主scorer。沒有下載44k小時資料或權重。

領域
居家整理與清潔、辦公與教育、工藝與修繕、裝配與生產作業、零售與購物、交通移動與車輛維修
環境
GR-1實驗室機器人影片、EgoDex與DreamDojo-HV評估素材；人類影片庫是預訓練來源。README宣稱44k小時不表示本次已取得或等量可評測。
任務
由首影格和動作序列預測後續影片；檔案In-lab清單含10個原生dataset路徑，另有EgoDex/HV兩組來源。路徑、100個抽樣與49frame是不同單位。
題數與資料
統一reader輸出video/lam_video/action/fps/num_frames/__key__/padding_mask/image_size/ai_caption；根據path字串選MANO、一般影片或LeRobot。LeRobot schema保留state/action的start/end、rotation_type、absolute。restrict_len可以指定100，不等於底層獨立episode總量；檔案定義train前95%、test後5%，full全量，須落實固定抽樣清單。
評估方式
生成片與GT先轉[0,1]逐frame算PIQ PSNR/SSIM/LPIPS，再對樣本平均；這段沒有排除首個條件影格。恢復篩選查詢*_psnr.json但輸出為*_metrics.json，可能重算；plot指令碼只接受恰501個檔的資料夾。以上是程式限制，尚未執行驗證，也不是robot物理成功率。

怎麼接入我們的benchmark

可重用

評估集分組、LeRobot modality metadata、可追到metric實作的生成入口。

需要轉換

以原生clip/episode ID和實際取樣frame作case；儲存action representation、完整GT影片及不可見未來、scorer前處理；預測影片與物理環境分列，父EgoDex重用關係明確。

仍需補齊

固定抽樣及ID清單、checkpoint/套件版本、條件影格是否計分與斷點恢復修正、原生跑分和物理行為有效性checker。
