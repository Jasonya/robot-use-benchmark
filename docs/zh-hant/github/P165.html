版本與身份

領域
居家整理與清潔
環境
沿用LIBERO/MuJoCo；程式scene定義為.bddl+_sim_state.npy pair。這是任務設定/物理初態組合，非必然獨立房屋。網站列2178recovery scenarios，未取得對應完整資產manifest。
任務
論文L1重試/L2調適/L3物件狀態恢復/L4環境恢復；程式目前主要對custom state加±2cm自由物件XY擾動，5closed+5open起始試驗。語義任務、failure scenario和10次trial不能相加。
題數與資料
原文2000+自然失敗情境；網站另列3184恢復示範、625731frame、110task types，單位不同。程式frame記雙相機、EEF/axis-angle/gripper狀態，模型example只送image+lang；manifest存scene/trial/gripper_init/obj_deltas/success等。缺完整failure trajectory/原始goal與recover標註的連結。
評估方式
最多520step，done取原LIBERO goal conjunction；close/open分報。outer reset宣稱12次重試，但內層env_wrapper.reset會吞RandomizationError並持續重試，須驗證失敗行為；建構/重置失敗被跳過會影響分母。flat_state擾動索引還需確認time/qpos佈局。沒有據此重現論文四層恢復結果。
