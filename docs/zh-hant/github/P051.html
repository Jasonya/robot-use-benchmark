P051 · USST / EgoPAT3D trajectories

Uncertainty-aware State Space Transformer for Egocentric 3D Hand Trajectory Forecasting

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

USST的實作包含EgoPAT3D-DT／H2O-PT重標註資料流程；未來手軌跡須連同觀測比例、相機座標與seen／unseen切分儲存。

版本與身份

已核讀EgoPAT3D主要資料與評分路徑；不將H2O分支或外部EgoPAT3D新版本視為已同等驗證。

領域
居家整理與清潔、穿戴互動與動作介面
環境
第一人稱影片中的既有拍攝場景；EgoPAT3D loader明列scene與record切分，不是新增可操作模擬場景。
任務
由過去影像／位置預測未來2D或3D手部軌跡；global與local版本是不同座標／輸入設定。
題數與資料
EgoPAT3D的pkl含traj2d、traj3d及num_preserve；mp4和T×4×4 odometry以scene/record/clip對齊。loader儲存有效長度、正規化引數並裁切或補零。
評估方式
utils先反正規化，再依觀測比例計逐軌跡平均歐氏距離ADE、最後一點FDE及各軸絕對誤差；3D、2D畫素、norm2d不可混報。test.py分開seen與unseen。

怎麼接入我們的benchmark

可重用

父資料ID、場景切分、軌跡／odometry欄位與原生距離函式。

需要轉換

case保留scene/record/clip、有效影格、觀測比例與座標系；camera pose是觀測或轉換證據，不能當作robot action。

仍需補齊

原始影片與重標註資產閉合、H2O專用loader／評分分支細讀及可執行adapter驗證。
