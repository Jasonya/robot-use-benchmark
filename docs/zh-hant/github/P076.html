P076 · Ravens / Transporter Networks

Transporter Networks: Rearranging the Visual World for Robotic Manipulation

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

Ravens的具體評測鏈是task goal→delta reward→test累積return→plot平均，包含部分分數。已核讀插入、清掃及資料writer/reader；done不是統一成功旗標，圖表的百分比標籤也不能直接當原生分數單位。

版本與身份

固定manifest顯示倉庫已封存。具體問題：plot.py把0–1 mean/std直接印成%且ylabel寫Task Success，沒有×100，也掩蓋partial credit；6DOF插入子類設sixdof與pos_eps=0.02，仍繼承只看xy/yaw的is_match，未增加z/roll/pitch判定。test預設task=hanoi但registry為towers-of-hanoi，應明設task。Dataset.sample是先等機率選episode再選非末步，不是全庫frame均勻抽樣。

對應Transporter Networks: Rearranging the Visual World for Robotic Manipulation，arXiv:2010.14406v3（2022-01-05；CoRL 2020作品）。README明稱此論文的reference repository；正式作者清單以固定PDF為準。固定程式4752ffab487ebd387781ad7890aa540ae2780970為2024-03-14快照，非2020原始版本。

領域
居家整理與清潔、裝配與生產作業、包裝、倉儲與物流、通用物件與機動作業
環境
PyBullet／UR5桌面，工作區0.5×1公尺；三個RealSenseD415模擬視角、640×480 RGB-D。環境預設240 Hz，demos/test指令碼明設480 Hz；這是physics頻率，不是示範frame或policy primitive頻率。相機引數在固定cameras.py，沒有逐episode嵌入color/depth檔。
任務
論文十項桌面任務；當前registry有15個ID，包含五個額外子型，不能回填成15項原始benchmark。BlockInsertion的goal是object/match-matrix/target-pose與pose metric，最多3次動作；SweepingPiles配置50個小方塊，最多20次push，以zone內物件取樣點比例給部分分數。
題數與資料
Dataset分color/depth/action/reward/info五個資料夾，用相同NNNNNN-seed.pkl連線；color uint8、depth float32公尺。每個episode是(obs,act,reward,info)序列，最後一筆act=None。demos先儲存當前obs/action與既有reward，才env.step，因此第t筆reward對應前一動作；匯出transition時應將action[t]對上reward[t+1]。info儲存GT物件position/quaternion/dimensions；test還會將末筆goal傳給agent，資訊可見性須按policy另記。action含pose0/pose1，各為xyz公尺＋xyzw四元數，並非VIMA的2D位置介面。
評估方式
Environment.step→task.primitive→Task.reward/done；pose metric用xy距離<0.01公尺及對稱修正後yaw差<15°。zone metric將每物件區域性取樣點轉入zone，算合法點比例；點集由visual-shape尺寸以0.02公尺網格建立，並非精確mesh體積。reward是累積進度差值；test加總成completion return，goal完結或_rewards>0.99才由Task.done回True，primitive timeout也可使env.done=True。論文每task100 unseen runs；程式實際遍歷test Dataset.n_episodes。test資料只收oracle return>0.99的奇數seed，訓練為偶數seed。

怎麼接入我們的benchmark

可重用

十項原始task與變體對映、goal tuple、pose/zone evaluator、seed編碼、RGB-D與原生pick-place/push。

需要轉換

source分論文v3與2024commit；case記task變體、seed、goal、primitive步數與physics頻率。保留terminal None action及reward後移配對；evaluator分開二元goal完成、delta reward、0–1累積完成度和展示用×100比例，不能全叫success rate。

仍需補齊

原論文checkpoint選擇及完整100-case資料manifest、其餘任務checker逐一覆核、相機／資產／seed閉合；6DOF及continuous變體需獨立評測協定。
