P045 · ManipBench

ManipBench: Benchmarking Vision-Language Models for Low-Level Robot Manipulation

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

ManipBench將真實機器人影像、布料及模擬影像問答拆成三個倉庫；問答正確率與另行執行機器人的成功率須分開。 2026-10-11 補讀官方直接連結的 robot-side 實作；倉庫有實際執行程式，物理成功由人工輸入紀錄。

版本與身份

Fabric README保留main_old.py為論文版。真實Q1列印len(episodes)分母與回傳有效total_count不同；Q2額外點數註明不是論文指標。 robot-side 固定 e25872ebd357559d5675daa07d05268afd5bd0b8；官方 question README 第25行證明其角色。readme.md 列的 moka_real_world_image_preprocess.py／moka_real_world.py 是伺服器指令且不在此 robot repo 完整 tree；實際本地入口由 run.sh 和 pipeline main 確認。這是已取得的實作與尚待配對的環境／伺服器契約，不是空白 README 或整庫 unavailable。

領域
衣物與洗護
環境
題目使用真實或模擬場景影像；圖片不等於相應可互動環境已取得。 補讀 MOKA robot-side 路徑使用 RealSense RGB／depth、已校準的相機到機器人 base 矩陣及預設右臂／夾爪；這是需現場設定的物理實驗入口。
任務
真實資料含抓點與路徑選擇、抓點和落點雙問；布料含狀態、空間、時序和反事實題型。
題數與資料
question/options/answer/image或多圖JSON；真實資料用correct_answer.json、wrong_answers_v批次、格點及隨機候選順序；完整圖片外部提供。 補讀：run.sh 指向 moka_real_world_pipeline.py，工作目錄按 tasks/task_name/model_Vversion 建立。info.json 傳 model_info、version、影像與 task_description 路徑、點／格數；伺服器 log.json 提供 plan_success、picking_point、points、end_point 和可選 height。相機存 color_image.png、顯示用 depth_image.png 與原始 raw_depth_image.npy；程式用 depth[y,x]/1000 反投影，Z 再加 0.005，經固定 4×4 校準矩陣轉 base。
評估方式
真實Q1解析選項後比對correct標記，Q2分抓點與落點；布料main.py比對答案；模擬指令碼以檔名編碼GT選項。解析失敗、缺檔及分母規則要保留。 補讀：plan_success 只決定是否有抓放點可執行，不能當物理任務成功。generate_exp_seq.py 對模型次序 random.shuffle，執行後人工輸入 y/n，其他輸入記 false，將 {task_name_version: bool} 加入 vlm_list.json 的 task_tested，最後才寫回。已讀路徑沒有由感測器自動判定物理成功；其人工紀錄、執行中止與問答 checker 的分母需分開。

怎麼接入我們的benchmark

可重用

三子集的題目格式、GT、候選生成及答案檢查。 可另重用 robot-side 的 info/log 契約、逐次模型／任務版本紀錄及人工成功欄位，作為獨立物理 trial profile。

需要轉換

case保留父episode、題型、候選批次與順序、影像及答案引用；固定抽樣seed，不將候選變換算成新的語義任務。 物理 trial 另保留 task_name、version、model、相機 intrinsics、raw depth 尺度、crop、calibration、抓放點／高度、人工判定來源與中止原因；原 VQA profile 不因此改成 robot episode。

仍需補齊

完整圖片、版本一致題目集、統一解析與分母契約；物理操作另需robot-side實驗程式。 更新：robot-side 選定原始碼已補讀；仍需配對伺服器指令碼／task_description、現場相機／機器人設定、可重播試驗清單、人工判定規則與 seed。capture 路徑未記錄 depth_scale 或顯式 RGB-depth 對齊；height_required 分支的 log.height 註解為 mm 卻未作 /1000，需先驗證單位，不能直接執行為標準 case。
