TEACh: Task-driven Embodied Agents that Chat

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

TEACh需要保留game→EDH/TfD instance的關係；兩種題目檢查不同目標。現有CLI有靜態可見的漏題／變數問題，不能下載後直接宣稱可評測。

版本與身份

2022-12修訂只保留有助主任務的EDH狀態變化，刪無相關變化instances與2個valid_unseen game；不能混用早期paper數字與當前檔案。軟體／影像／其他資料授權分開。

領域
居家整理與清潔、餐飲與烹飪、協助、交接與陪伴
環境
AI2-THOR家務場景，Commander與Driver/Follower不同視角和角色；game可派生多個EDH或TfD片段，不能各自算新屋子。
任務
EDH依對話／操作歷史完成後續指定狀態改變，TfD依完整任務引數檢查終態。task definition有components、數量determiner及relations；Toast要求BreadSliced且isCooked=1。
題數與資料
game_id、instance_id、driver_actions_future、state_changes、expected_init_goal_conditions_*，輸出game含初／終態objects及custom_object_metadata。dialog acts是後加da_metadata；答案狀態不能當一般模型輸入。
評估方式
EDH從state_changes建checker；TfD取原task_id並套task_params。check_episode_progress合成component/relation的成功與條件數。GC分母扣除初態已滿足部分；PLW依future動作長度。cli/eval.py有未定義edh_instance_files紀錄行，且缺輸出題建立error紀錄後未加入traj_stats；需修正並保留原版差異，否則可能阻斷／漏計分母。這是靜態閱讀發現，未執行重現。

可重用

需要轉換
