AutoBio: A Simulation and Benchmark for Robotic Automation in Digital Biology Laboratory

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

AutoBio初步版有真實task/evaluator程式與LeRobot資料；MuJoCo和Blender是同任務的兩種渲染版本。必須保留render lineage與各task具體量測，不能只拿生成影片數當題數。

版本與身份

固定0850421，README明列Preliminary Version。未安裝MuJoCo/Blender或執行policy；未將renderer份數當新任務或獨立示範。

領域
實驗室操作
環境
MuJoCo生物實驗室資產與Blender Cycles外觀渲染；pipette例為雙UR5e和靈巧手/夾爪。physics scene、相機和render edition分別記錄，Blender不另增物理環境。
任務
當前factory接受13個原生task名稱，README列9種dataset各有MuJoCo/Blender版本；這兩個範圍不是同一清單。原子操作與完整儀器任務需要按原作版本對照；pickup匯入模組未在固定tree找到。
題數與資料
LeRobot v2.0每episode parquet與videos，meta包含episodes/info/stats/tasks；README影片224²@50fps。runtime使用observation/state、影像與prompt，task_info指定state_indices/action_indices/camera_mapping。RDT資料用fps建立action/history timestamps並儲存缺影像mask；不可將補0當真實sensor。
評估方式
每action保持10個MuJoCo physics步，chunk外檢查time_limit/early_stop，可能超出名義budget到chunk末；不健康模擬回False。pipette checker追蹤tip入液麵、拇指命令變化與最後抬離液麵，未直接對抽取體積作容差檢查。history deque追加qpos未明確copy，也需驗證歷史狀態是否別名。

怎麼接入我們的benchmark

可重用

明確task/serializer/factory、LeRobot結構、paired renderer來源、具體task checker與seed協定。

需要轉換

source+task+episode為底層ID，render variant作observation版本；case固定physics/action時間、joint順序、初態及scorer；量化體積/精度可作新增規則，保持原版可比。

仍需補齊

preliminary版本缺件、13factory與原作task清單對齊、完整資產/資料、command/state normalizer、history/budget驗證與全部task重現。
