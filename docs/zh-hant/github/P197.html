P197 · EgoSim / MultiEgoView

EgoSim: An Egocentric Multi-view Simulator and Real Dataset for Body-worn Cameras during Motion and Activity

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

EgoSim提供真正的身體穿戴相機模擬擴充，核心在SIPCharacter C++，不是AirSim通用的image benchmarker。它產生多相機/IMU/骨架資料，並非robot任務成功評測器。

版本與身份

固定e48780e；NeurIPS2024作品於2502.18373存檔。只核讀實際EgoSim擴充，未把整個AirSim所有功能當成本文評測範圍。

領域
穿戴互動與動作介面
環境
Unreal Engine/AirSim的SIPCharacter avatar，可接FBX/SMPL系列動畫與多socket身體攝影機；6camera sockets是同avatar的感測位置，非6個獨立場景。MultiEgoView實拍資料另有下載來源。
任務
身體相機視角、運動/活動資料生成及下游感知研究。avatar動畫和camera placement本身不構成已帶robot goal/scorer的操作task。
題數與資料
record有VehicleName、相對建立時間TimeStampMs、TimeStampAnimationS、6組相機position/quaternion(xyzw)、IMU acc/velocity及bone世界pose。settings採NED轉換，record直接寫Unreal Actor/Bone位置；位置/加速度單位需驗證，不能看到註解convert to meters就假定已換算。
評估方式
本次未確認完整語義下游benchmark scorer，capture FPS不是活動理解成功率。tick依clock_speed和record_interval取樣；camera2角速度噪聲用dist_vel1，camera3所讀角速度噪聲被註解，與六份std設定未完全對稱，需逐sensor記實際生成條件。

怎麼接入我們的benchmark

可重用

SIPCharacter生成器、sensor mount/lag設定、完整record欄位與雙時計。

需要轉換

environment儲存UE場景/avatar/animation/外掛版本；case儲存socket視角、noise與時序/座標轉換，body poses作label時不得作隱式policy輸入；觀測生成與下游任務/判分分層。

仍需補齊

MultiEgoView原生reader與split、UE資產/animation權利及取得、坐標/時間/IMU統計實測、下游task/scorer與部署驗證。
