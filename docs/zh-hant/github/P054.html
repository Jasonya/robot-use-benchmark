P054 · EgoVid-5M / EgoDreamer

EgoVid-5M: A Large-Scale Video-Action Dataset for Egocentric Video Generation

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

EgoVid的公開repo主要是Ego4D衍生影片標註與清洗工具；相機運動控制標註不能直接視為可執行機器人控制。

版本與身份

本筆覆蓋公開資料處理路徑；不宣稱EgoDreamer模型或所有外部清洗依賴已核讀。

領域
居家整理與清潔、辦公與教育、工藝與修繕、休閒與運動
環境
Ego4D v1/v2來源影片及clip視窗；來源影片須另行取得。
任務
文字／相機運動條件的第一人稱影片資料；本次固定tree見標註、pose及品質計算工具，未取得完整EgoDreamer生成／評測實作。
題數與資料
CSV的video_id=來源影片_起始影格_終止影格，含fps、frame_num、noun/verb、llava_cap、name和各項品質分數；pose資產含3×3 intrinsics及逐影格4×4相機外參。README提醒raw IMU已知問題。
評估方式
光流清洗程式每8影格取樣，將flow按平均影像尺寸縮放到512基準，再存均值／分箱比例；這是素材品質證據，不是操作成功率。flow_0_4程式實為>0且≤5，與欄名／README有差異。

怎麼接入我們的benchmark

可重用

父影片ID、精確clip範圍、文字／pose標註和清洗provenance。

需要轉換

source記Ego4D重用關係；case保留frame/fps、caption來源、pose座標與quality filter版本。5M名稱不能直接算成本庫已取得評測題數。

仍需補齊

完整CSV與影片／pose資產閉合、實際clip去重、生成模型與正式evaluator，以及清洗欄名／實作差異校核。
