Bench2Dex: Benchmarking Visuo-Tactile Bimanual Dexterous Manipulation Across Dexterous Hands

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

Bench2Dex有可追溯的YAML任務、視觸覺HDF5 reader與具體success engine。26任務、12機體、8模態和1300示範各有不同單位；雙手/多模態不直接倍增任務。

版本與身份

固定fd90dcc；success語義依metric_schema_version與evaluation_protocol而變，不能拿不同版本同名success_rate直接合併。只核讀所列實際片段，未跑Isaac或policy。

領域
裝配與生產作業、通用物件與機動作業
環境
IsaacSim5.1/IsaacLab2.3.2；26個task YAML包含桌面、資產路徑、物理屬性、佈局與generalization flags，跨12種robot embodiment。相同場景的雙手與多感測不算獨立環境。
任務
原生26task從放置/分類、清潔、工具使用、拼圖到盛湯/琴鍵等；YAML stages可有depends_on。task_manifest先選scenes_final再scenes；其中task.md只有3欄但parser要求6欄，可能退回Unknown，需我們的匯入器自行正確對映原表。
題數與資料
HDF5 robot/qpos、action/commanded、cameras/*/rgb、robot/tactile/tacmap/*與site_names。同一start_ts取所有模態；缺commanded會改用qpos作action，必須記來源。tactile為uint8影像且順序跨episode嚴格一致；activeDOF/padding/NaN mask儲存，尾chunk mask長度仍需測試。1300demo為原作宣告，未取得payload。
評估方式
core-v1.8：reach_and_stop以terminal條件持續dwell(預設0.5秒)為成功，fixed_horizon改看budget末態；instant/at_end/stable分開。Soup Serving以湯杓進鍋→到碗上方兩次，再歸杓/擺碗/碗直立判分，沒有直接量測流體體積。安全成功另排drop/high-speed；joint limits預設diagnostic。空結果回0在本庫應標N/A；robust ratio需baseline和perturbed兩組才定義。

怎麼接入我們的benchmark

可重用

需要轉換

仍需補齊
