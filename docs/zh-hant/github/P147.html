HRIBench: Benchmarking Interaction-Centric Human-Robot Collaboration

返回逐篇總表實作尚未確認 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

此篇2026 HRIBench研究互動型人機協作，與2025年的同名感知benchmark不同；目前核對的原文與搜尋未確認其官方程式庫。

版本與身份

核對2607.13056v1及cached exact-title/HRIBench搜尋；命中interaction-lab/HRIBench對應另一篇2025感知工作，未作此篇實作。no_confirmed_code_repository是本次有界查核結果。

P147是Interaction-Centric Human-Robot Collaboration；P168是2025 robot perception，兩者保留不同source ID。

領域
協助、交接與陪伴
環境
論文設計動態人類、物件與robot共處的模擬互動場景；可變layout/人類動作/時序/視角，尚無取得的scene asset或instance manifest。
任務
論文p4分Instructor、Collaborator、Intruder三角色，13個task，每task超過50trajectory variants，合計超過650episode；數量屬論文宣告。
題數與資料
論文scenario script將每個act寫為(role,goal,temporal/causal constraints,human-motion distribution,reward/success)。生成經指令碼、場景、motion synthesis與simulation filtering；尚未取得序列/標註與可解析schema。
評估方式
論文p5列Effectiveness(CSR/CT/IR)、Coordination(TSync/Rsp/OC)、Safety/robustness(CFR/HCS/CIR/DSR)；未取得對應實作，因此只作原作協定記錄，不宣稱已跑或可直接整合。

怎麼接入我們的benchmark

可重用

角色/互動指令碼分解、13任務與650+episode的原作規模及多維評估構想。

需要轉換

task儲存人類角色/目標/允許介入，case固定motion/timing seed；每個指標指向其原文公式和未來scorer；不可合併P168同名HRIBench。

仍需補齊

官方repo/資料入口、13task清單與case manifest、成功/安全/恢復checker、生成資產與執行重現。
