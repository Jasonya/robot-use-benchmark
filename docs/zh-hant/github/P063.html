Meta-World: A Benchmark and Evaluation for Multi-Task and Meta Reinforcement Learning

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

原作倉庫已轉到Farama的現行Meta-World。當前程式碼可以核讀任務、動作和評測介面，但README已引用MetaWorld+，必須保留與2019原作協議的版本差異。

版本與身份

發現現行state_space.md仍寫9D且表格列18維，但程式_get_obs明確組成39維；欄位標準化以固定程式與測試查核，不能只抄說明頁。

舊入口rlworkgroup/metaworld的已儲存GitHub metadata回應指向Farama-Foundation/Metaworld，按倉庫別名保留，不另外算成未讀的第二個倉庫。

領域
居家整理與清潔、餐飲與烹飪、工藝與修繕、裝配與生產作業、休閒與運動、通用物件與機動作業
環境
Sawyer/MuJoCo任務環境；source task/env ID不等於獨立家居場景。
任務
MT與ML清單保留原生任務和train/test成員；現行v3任務與2019版不可僅刪掉版本字尾就宣稱等價。
題數與資料
四維動作是xyz增量控制加gripper；set_xyz_action另乘action_scale。基礎觀測為當前18維、前一觀測18維與目標3維，goal可被遮蔽；benchmark還可加task ID。
評估方式
evaluation.py在成功時終止episode，用info.success按任務計成功率，再對任務平均。meta評測另外包含適應步數、適應episode和evaluation episode預算。
原作數字：保留論文的單位與頁碼
