P231 · MADiff

MADiff: Motion-Aware Mamba Diffusion Models for Hand Trajectory Prediction on Egocentric Videos

返回逐篇總表核心內容已核讀 方法／綜述參考原作 ↗

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

MADiff 是重用多個既有 Ego 資料集的手軌跡方法。已讀到的官方版本提供 H2O／EgoPAT3D 兩個 backend，並附 ACT 條件輸入教學；論文五個資料集的覆蓋、目前程式入口與新增機器人教學分開登記。

版本與身份

目前 README 為 T-PAMI 2025、引用同一 arXiv；版本新增 H2O／EgoPAT3D backend 與 ACT 教學。已讀原生程式與論文範圍不相同，必須按版本列出。 補查MMTwin README：它對應2504.07375，CABH列三種人類操作任務，CABH專用模型仍待發布；EgoPAT3D配套程式已在P222核讀。這是相關延伸，不改寫MADiff本篇的任務或可執行範圍。

領域
方法／綜述參考，未另作來源用途歸納。
環境
父資料 EK55、EK100、EGTEA Gaze+、EgoPAT3D-DT、H2O-PT；目前公開入口主要為後兩個。EgoPAT3D loader 有 11 個已見 scene IDs 與 novel 13／14／15；ID 是父資料場景，不能當 MADiff 新建環境。
任務
同一手部軌跡 forecasting 方法在不同資料與觀測配置測試。現行兩個 backend 設定 target=2d、observation ratio=0.6；H2O max_frames=64，EgoPAT3D=40。ACT 教學將 forecast 作額外 token，沒有提供一套新的正式 robot benchmark 題單／判分器。
題數與資料
原生資料與權重需外部下載，來源依賴 USST 預處理。讀取 native filename、scene/recording split、有效幀數、trajectory／GLIP／motion features；論文五資料集的 train/test 樣本表不能算為五批全新原始影片。
評估方式
實際 H2O／EgoPAT3D eval loop 對純未來區間逐序列計 normalized-image ADE 與末點 FDE，並非檔內未用 helper 的 weighted error。H2O 每題 1 次抽樣、gap=999；EgoPAT3D gap=333。test_novel 雖有 loader，traineval 對 tuple 取 [0]，預設入口只評 test。H2O rank 檔只彙整 ADE、檔名需隔離執行以免讀到舊檔。

怎麼接入我們的benchmark

可重用

重用父資料 split、scene IDs、有效長度、座標轉換與實際呼叫的 ADE／FDE。；ACT forecast-token 教學可作 human-to-robot 介面參考，與正式測題清單分開。

需要轉換

case 包含 dataset revision、backend、filename、60% boundary、max_frames、normalization 與 feature revision。；novel test 建獨立入口和完整 expected-case manifest；抽樣次數、diffusion gap 各自固定。；把論文五資料集與目前兩 backend／MMTwin 3D 延伸保留版本關係，不合併報為新環境。

仍需補齊

未跑模型、未取得特徵／checkpoint；沒有重現論文數字。；機器人教學缺可下載任務／示範／evaluator；MMTwin本次僅補讀README；其EgoPAT3D程式核讀見P222，不把CABH待發布模型當成已可用。
