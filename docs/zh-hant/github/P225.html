領域
裝配與生產作業、穿戴互動與動作介面
環境
離線AssemblyHands/Assembly101玩具組裝、Ego-Exo4D活動與EgoMe正確模仿配對影片；AssemblyHands/Ego-Exo4D有同步多視角，EgoMe-pose的Ego/Exo配對可能不同步。CALVIN ABC→D是另行teacher-to-policy蒸餾的robot下游實驗。
任務
VL-EHPF在t時刻輸入1–10步Ego影格、語言instruction與同段手姿，輸出t+1至t+10的42×3座標（兩手各21點）及42點validity。論文DERM把涵蓋觀測與未來的配對Exo影片當訓練監督，從Ego輸入重建Exo表徵，再交GLMM；推論公式只含Ego/語言/pose，不能把實際未來Exo影格加入test條件。它預測人體pose，不直接輸出robot動作。
題數與資料
論文報AssemblyHands衍生episode train/val/test=6,120/355/355，Ego-Exo4D=10,869/1,540/1,540，EgoMe-pose=6,067/1,344/2,648；這是episode數，不是10-frame forecast windows、joint數或實際可下載case數。AssemblyHands/EgoMe-pose為15FPS、Ego-Exo4D為30FPS，RGB resize224×224，10步預測因此有不同時間長度。AssemblyHands保留每手>10個valid joints且root有效的frame，world→Ego camera並依共用frame ID連Assembly101文字；隨機Exo view配對，從原val隨機切50%作test。Ego-Exo4D須Aria去畸變、world→camera及joint-order對映，文字window為atomic timestamp前0.5秒至後1秒且每frame pose有效，也將原val隨機半分作test。EgoMe-pose以InterHand相對姿態+RootNet root-depth轉絕對座標，剔除false imitation、hand confidence<0.6或有效frame比例≤95%的episode；非同步Exo以片段相對位置線性對齊。上述隨機seed、episode/frame清單、joint permutation、標註檔schema均無公開reader可核。
評估方式
僅論文§4.1.2：MPJPE比較root-aligned predicted/GT關節的Euclidean距離；MPJVE比較關節位移，論文單位寫mm，沒有可核程式證明另除Δt，不能改記mm/s。這與EMPIRE的absolute-camera MPJPE不同。雖模型預測validity，實際scorer使用GT或pred mask、兩手/root是否計入、分母是有效joint-frame或先逐episode平均、位移是否包含最後觀測點及缺失鄰接frame處理均待程式確認，不能用10×42固定分母填空。CALVIN表列連續完成1–5任務比例、Avg.L.與Avg.R.，採ABC訓練→D測試及Exo2EgoPose teacher蒸餾GR-1類student；本版無robot action adapter、trial manifest或具體success checker可讀，不能把手姿誤差換成robot成功率。

怎麼接入我們的benchmark

可重用

重用已確認paper/repo身份、三個衍生資料集的母來源、42點/10步/validity任務契約及論文明列的split/取樣條件；repo僅提供發布狀態證據。

需要轉換

case以母資料版本+衍生episode+query frame+split+FPS識別；儲存world/camera/root-aligned三層座標、兩手joint-order與validity。另記train-only Exo監督、同步/相對時間線性對齊、原val→新val/test關係；CALVIN蒸餾獨立為下游reuse關係，metric保留pose與robot兩類原生單位。

仍需補齊

程式與EgoMe-pose benchmark尚未發布；缺前處理、reader、精確split/seed、有效case manifest、MPJPE/MPJVE具體分母與root/mask約定、weights及CALVIN蒸餾/執行成功判定。不能執行或聲稱本輪重現論文分數。
