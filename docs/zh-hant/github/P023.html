P023 · EgoProceL

My View is the Best View: Procedure Learning from Egocentric Videos

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

EgoProceL 是程式學習資料與 CnC 方法的共同發布；它明確重用 CMU-MMAC、EGTEA、MECCANO、EPIC-Tent 並加入電腦組拆。已核讀資料來源、PC Assembly loader 和主評分呼叫。

版本與身份

download README 明列舊 OneDrive 過期與新 Google Drive，並說父庫只有部分影片被使用；以新程式標註清單作 subset 證據。PC_Assembly.py 開頭註解仍寫 MECCANO，但類別及配置實際為 PC_Assembly。

領域
餐飲與烹飪、工藝與修繕、裝配與生產作業、農業與園藝
環境
烹飪、玩具／電腦組拆、帳篷搭建等人類程式影片；parent dataset→category→video 需要保留。16 個原生 task 是程式活動，不是 16 個獨立房間或全部錄製環境。
任務
由同一程式多段影片學習 key-step 與次序，包含缺步、重複步和背景。重用父資料的影片被加上程式標註，不可和父庫相加當全新影片。
題數與資料
CSV 與原影片同名，三欄為 step 起始秒、結束秒、step 名；子集按來源／category 分目錄。PC_Assembly loader 配對影片與標註、抽 HDF5 frames/labels；train/val/test 分支尚為 NotImplemented，真正公開路徑是 mode=all。
評估方式
procedure_learning→gen_print_results→compute_align_MoF_UoI，以 GT/pred frame overlap 做 Hungarian cluster-label assignment，再計 MoF/IoU/precision；per_keystep 模式排除無 GT 類別並平均。另有 procl_eval 函式實作補上未配對類別的 P/R/F1，但不是本主入口呼叫，二者不混用。GT 用於事後 cluster 對齊不代表模型已輸出語義標籤。

怎麼接入我們的benchmark

可重用

父資料重用清單、原生秒制 step CSV、PC 組裝新來源與聚類評分。

需要轉換

source→parent video→新 annotation 建 ancestry；task 記來源內 category，case 是指定多影片集合／取樣與合法 GT 使用範圍。cluster ID 儲存 Hungarian assignment 作評分證據；K、背景、per_keystep 與全體聚合明列。

仍需補齊

尚未取得影片／標註、產生 HDF5 或執行。需要逐子集對應原影片及相同 frame 取樣；不能自行發明 train/test split 或把 mode=all 的結果標為未見環境泛化。
