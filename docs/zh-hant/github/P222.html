P222 · Uni-Hand

Uni-Hand: Universal Hand Motion Forecasting in Egocentric Views

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

已核讀Uni-Hand human-video demo與作者指向的MMTwin/EgoPAT3D reader及具體ADE/FDE。主庫現行流程只以首影格條件預測右手腕與接觸轉換；不能將論文全部2D/3D、多關節、head-motion及robot結果視為同一套已公開評測。

版本與身份

主庫commit 7f3edd5955fcb786b78b343510d7b2297694393b；MMTwin commit bd0faf148ae574accd5a4c1e7cd173f6416a52e6。README稱toy有100段影片，而本版split roster是100 train+5 test，保留此粒度/版本差異。主庫unseen_envs已標deprecated且兩個test loader讀同檔；MMTwin的test_novel才是實際不同scene split。論文表1的USST修正引用不能視為本輪已核讀或新版metric等價證明。

arXiv:2511.12878v4（2026-05-11），Junyi Ma等，精確題名Uni-Hand: Universal Hand Motion Forecasting in Egocentric Views。PDF連作者專案頁，頁面Code指IRMVLab/UniHand、Data指IRMVLab/MMTwin；MMTwin README反向指Uni-Hand為extended version，本身論文為2504.07375。專案頁footer的nerfies是網頁模板，論文USST erratum是baseline依存，均非本篇模型庫。

領域
穿戴互動與動作介面、通用物件與機動作業、居家整理與清潔、餐飲與烹飪
環境
主庫為RealSense L515人類示範的pick-and-place／open-door場景，首RGBD影格產生固定相機座標點雲；MMTwin用EgoPAT3D-DT移動頭戴視角，以odometry將軌跡表成首camera參照。CABH的cup/apple/box與HAT robot-transfer屬論文/前身不同子集，不可和主庫toy split混成獨立robot environment registry。
任務
Uni-Hand論文涵蓋手部2D/3D中心與指定關節、head motion及contact/separation；本次主庫實際epoch loop取joint0，註明TODO multi-finger，preprocess只讀right_keypoints；motion_feat為全零，視覺使用第一張feature，觀測mask只保留第0個手腕點。輸出是未來腕點與兩個接觸/分離峰，非完整21關節姿態，也不是可直接執行的末端action。
題數與資料
主庫以date folder讀traj3d_in_cam_dict_refine.pkl、date.npy視覺特徵、rgb數字檔名與date_folders.csv。所謂traj3d原始值實為21×(u畫素,v畫素,depth-mm)；reader對depth除1000、u/w與v/h、z/max_depth後各減0.5，保留有效frame IDs，截/零補至40。CSV兩個原始frame ID映到有效序列的0-based index；沒有FPS/秒換算。config為1280×720、max_depth=1、50³ voxel、0.02公尺格、origin[-0.5,-0.5,0]。split檔有100 train與5 test唯一ID且無交集；它們是清單筆數，未下載素材核驗有效case。val/test/test_novel全部走同一test_split.txt。MMTwin則有明列scene/record train/val/test；novel scenes13/14/15，pkl讀traj2d/traj3d/num_preserve，最多40點，3D以odometry連乘轉首camera，再以(u/w,v/h,z/3)-0.5編碼，非train的未來motion/odometry先以最後觀測值替代。
評估方式
主庫實際scorer在epoch_feat.py：單次diffusion sample，gap=1、3點moving-average平滑；加回0.5並以內參反投影XYZ，z使用預設max_depth=1，單位公尺。future slice=[1,nframes)，ADE先對該case所有有效未來點的Euclidean error取平均，FDE只取最後有效點，最後對case平均，非全資料逐frame加權。CE將future contact曲線Gaussian平滑、取最高兩個區域性峰並排序，兩個峰的絕對index誤差平均後再跨case平均；缺峰用-1補而未剔除。存在明確索引疑點：pred峰是future slice相對index，GT是完整valid序列index，scorer未加start_=1或減GT offset，CE不是可直接當秒的MAE。MMTwin actual loop用固定ratio（預設0.6），floor(nframes×ratio)作觀測長度，單次sample；相同逐case ADE/FDE，test_space=3d為公尺，其他值走投影、clip/floor畫素再除影像尺寸的2D距離，並非best-of-K。論文robot SR為每task 10次trial的報告；已讀repo沒有該robot成功checker。

怎麼接入我們的benchmark

可重用

重用兩庫各自split與reader、有效frame index、內參/voxel設定、逐case ADE/FDE與contact峰值定義；保留MMTwin為前身與母資料轉接來源。

需要轉換

case以repo版本+dataset+scene/date/clip+觀測長度識別；把u/v/depth-mm、正規化latent及XYZ-m分開儲存，記錄camera參照與有效frame至原frame對映。evaluator分開ADE、FDE、CE、paper-reported robot SR，儲存每case未來點數、sample數、smoothing/gap與ratio。grasp_offset屬另行校準的camera-frame幾何轉換。

仍需補齊

RGBD、refined trajectories、特徵、點雲與weights未取得，roster不等於可執行case數；需修正/核驗CE offset、缺峰策略、改max_depth時的反正規化一致性。需補獨立validation/novel split、論文其餘資料集/多target/robot協定，以及相機到robot基座外參、運動控制與成功判定。MMTwin不能充當Uni-Hand所有新版結果的實作證據。
