P113 · REPAIR-Bench

REPAIR-Bench: A Benchmark for Robot Error Perception And Interaction Recovery

返回逐篇總表實作尚未確認 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

已核對REPAIR-Bench原作與有界GitHub搜尋；目前未確認此篇的官方程式庫。同名軟體修復benchmarks不屬於這篇HRI研究。

版本與身份

固定2606.29937v1 PDF與既有原文閱讀紀錄。搜尋未確認不代表作者永遠沒有code；不把GitHub軟體RepairBench套上這篇。

領域
醫療與手術支援、協助、交接與陪伴
環境
原文是實驗室／醫院的crash-cart取物引導互動，重用RFM-HRI人類反應資料；不是可操作整套醫院任務的模擬環境。
任務
三種端點：失敗時刻定位、失敗型別分類、使用者偏好的恢復策略；人類偏好預測不同於機器人實際恢復成功。
題數與資料
原作來源214互動/41人；排除後分析184互動/38人，含面部AU、頭姿、語音／文字與問卷。native code schema未核實，不能把論文欄位描述當可直接匯入的檔案規格。
評估方式
原文有時序定位誤差／tIoU F1、分類F1及恢復Hit/precision/recall/F1@k。視覺與文字端點split不同；濾波等前處理敘述尚需程式釐清。未執行scorer。
原作數字：保留論文的單位與頁碼

怎麼接入我們的benchmark

可重用

原文三種端點、排除規則、participant/session來源鏈與人類偏好標籤設計。

需要轉換

資料取得後以participant→interaction→temporal case編號；各端點保留資訊／時間截止及split，恢復偏好標明human label而非physical success。

仍需補齊

官方實作／資料檔schema、184筆分析subset清單、前處理及端點split、GT時間與偏好對映。
