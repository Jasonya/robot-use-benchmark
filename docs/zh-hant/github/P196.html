P196 · Deform360

Deform360: A Massive Multi-view Visuotactile Dataset for Deformable World Models

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

Deform360有明確多視角/觸覺對齊與annotation contract，可直接作資料層參考；README明示world-model訓練、baseline和checkpoint未公開。

版本與身份

固定d8522a4；所讀公開庫定位access/preprocessing/annotation/alignment，未把能生成annotation推論為已發布world-model baseline。

領域
衣物與洗護
環境
BRICS capture dome真實柔性物互動；原作198物件/13類、1980互動，41同步RGB相機及4組16×32觸覺sensor。13物件類別不是13生活domain，41views不是41episodes。
任務
柔性物世界模型/多視觸覺研究資料；dataset utility提供對齊和annotations，不等同機器人物理任務registry或已釋出的world-model benchmark runner。
題數與資料
原作215.7h、約23.3Mframes須保留其跨視角統計口徑。episode/<camera>/undistorted.mp4與K/c2w、aligned timestamps、provenance hash；預設檢查相機frame/timeline一致。H5鍵data：mask bool/uint8二值、depth uint16毫米且0無效、velocity m/s；不可像RGB除255。
評估方式
這些檢查驗證資料形狀/時間/校準一致性，不是world-model或robot成功分數。觸覺nearest配對保留match/accepted/duplicate資訊，未接受格補0須連valid mask使用；用於預測task時另外限制query以前的可見資料。
原作數字：保留論文的單位與頁碼

怎麼接入我們的benchmark

可重用

明確影像/姿態/深度/速度/觸覺契約、common timeline與output hash校驗，可復用到標準化來源層。

需要轉換

source/episode是主lineage，camera/frame/sensor作子記錄；儲存微秒時間、c2w方向、單位、invalid值與alignment政策，case另繫結真正預測目標和scorer。

仍需補齊

完整資料/annotations取得、interaction/物件split、world-model評測協定/程式與checkpoint、從感知資料建立物理可執行task的驗證。
