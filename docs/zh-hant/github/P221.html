P221 · STAformer++

Integrating Affordances and Attention models for Short-Term Object Interaction Anticipation

返回逐篇總表實作尚未確認 方法／綜述參考原作 ↗

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

P221精確論文連到作者AFFttention庫，但pinned版本停在2024年；已實讀舊版STA reader與metric，尚無法把它核定為2026 STAformer++的完整實作。入口雖引用DETR，但必要模組不在完整樹中，且新版Swin-T/EgoVideo/DETR配置未對上。

版本與身份

固定commit 1a1253fa2bde09ef1de4894f3bf872c1fbf270de，日期2024-07-15；2026論文§4是明確架構延伸。完整tree未truncated，因此缺失的DETR/hand模組不是快取挑檔漏抓。README要求依StillFast配置，程式仍import stillfast但目錄叫stillfast_code，另有硬編碼本機/省略號路徑；只能主張已讀具體舊版程式段，不能主張新版可重現。

論文為 Integrating Affordances and Attention models for Short-Term Object Interaction Anticipation，Lorenzo Mur-Labadia等，arXiv:2602.14837v1；P221-discovery保留PDF第1、9頁指向lmur98/AFFttention的超連結。這是2024 AFF-ttention的延伸，作者與repo關聯已確認；未確認的是2026新版方法與公開程式版本的一致性。

領域
方法／綜述參考，未另作來源用途歸納。
環境
離線Ego4D STA v1/v2及由EPIC-KITCHENS active-object tracks/action segments衍生的STA影片標註。environment affordance為歷史影片相似場域的noun/verb先驗，並非互動模擬器或新機器人場景。
任務
每query輸出(box,noun,verb,TTC,score)，另利用environment affordance及interaction hotspot調整預測。論文新增STAformer++的Swin-T、EgoVideo、DETR與learned affordance integration，不能只因同一repo有字樣就視為已公開可執行；舊版配置是Dino2D_with_EgoVLP、ROI_HEADS.VERSION=aff。論文EPIC-STA的33,804 train／7,055 val是衍生標註instances，104 noun／51 verb是taxonomy，不是新增robot tasks。
題數與資料
Ego4D reader依TRAIN/VAL/TEST_LISTS讀info.video_metadata及annotations；每例uid、video_id、frame、objects[*].box/noun_category_id/verb_category_id/time_to_contact。v2配置指向v2資料，但活躍讀取仍用video_id、video_uid行被註解，需明確版本適配。fast clip以frame-arange(N×stride)[::-1]取歷史，負索引夾到0；配置N=16、stride=1，不能未讀metadata就假設FPS。noun+1，非v1 ROI verb+1；writer再減回。AFF檔以v_id/frame尋找AFF_N_top3、AFF_V_top3，找不到用全1先驗。EPIC pkl為eid、video_id、timestamp、objects內平行arrays；合併noun群組、剔除含others的整例及指定verb後重編ID。EPIC框被乘(1920,1080,1920,1080)，影格int(timestamp×30+1)，16張含當前影格、最低1；AFF卻以round(timestamp×30)+2查詢，兩個frame convention不可混同。test分支直接讀val_annotations.pkl，不能列成獨立test split。
評估方式
STATask.validation_epoch_end先以uid建dict（重複UID會覆寫），再呼叫OverallMeanAveragePrecision(top_k=5)，輸出8個class-agnostic AP及4個按noun平均的mAP。匹配為+1像素面積IoU>0.5、TTC誤差≤0.25秒及各項noun/verb條件，按score貪婪一對一配GT；每query、每metric忽略前4×GT物件數個FP。recall分母是已加入GT中的相應類別物件數；AP為VOC precision-envelope積分×100，mAP預設僅平均有GT的noun，不按noun-verb joint class平均。需保留程式缺陷：add的空preds={}分支再次判斷len(preds)>0，因而不加入GT；空array字典與真正空字典行為不同，不能宣稱未檢測案例分母已安全處理。Ego4D _load_annotations對無objects例還會造出[0,0,100,100]及零標籤dummy target，不能拿test-unannotated當validation真值。

怎麼接入我們的benchmark

可重用

可重用已核讀的舊版Ego4D/EPIC reader規格、noun/verb offset、affordance sidecar schema與原生AP/mAP定義，標成AFF-ttention 2024 lineage；論文2026方法另存版本關係。

需要轉換

保留source→Ego4D/EPIC衍生標註關係；case使用版本+split+uid/eid，區分原annotation、清理後有效case與taxonomy。顯式對映EPIC normalized xyxy→1920×1080畫素、timestamp→影格及獨立AFF lookup frame；保留noun合併/剔除表、background offset、FP-budget及AP vs noun-macro mAP。

仍需補齊

新版STAformer++正確revision與Swin-T/EgoVideo/DETR/learned-affordance完整實作；pinned tree缺少入口匯入的detr_criterion.py、detr_backbone.py、detr_transformer.py、detr_matcher.py及ego4d_sta_hands_still_video.py，DETR_head也未在入口定義。另缺正式annotation/sidecar資產與portable路徑、v1/v2欄位適配、EPIC雙frame偏移核驗及空預測/無GT的計分測例。
