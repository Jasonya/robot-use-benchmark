Egocentric Video-Language Pretraining

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

EgoVLP 同時提供 EgoClip 預訓練與 EgoMCQ 開發評測；本次核讀 EgoMCQ 格式、chunk loader 和實際 accuracy。其他 Ego4D／EPIC／Charades 評測保留父來源。

版本與身份

EgoMCQ 被用來選預訓練 checkpoint，應標 development set，不自動當獨立最後測試。EgoVLPv2 為後續方法，新聞連結不代表本 repo 已包含其新增結果與全部程式。

領域
居家整理與清潔、工藝與修繕
環境
影片來自 Ego4D；600 秒 chunk 是儲存切塊，不是物理環境。intra/inter-video 指候選來自同／異影片的難度條件，不等於生活用途。
任務
EgoMCQ 給文字查詢，從五個影片候選找正解；與從影片選文字答案的 QA 方向不同。EgoClip 數百萬 narration clips 是訓練單位，不能當 EgoMCQ 測試題或新動作任務。
題數與資料
EgoClip TSV 含 clip_idx/video_uid/narration_source/narration_ind/narration_time/clip_start/end/clip_text/tag_verb/tag_noun；MCQ JSON 有 query/choices/answer/types。loader 依 clip 秒數取可能跨兩個600秒檔案的 frames，返回 video/text/text_ops/correct/type。val 與 test 都讀同一 egomcq.json。
評估方式
egomcq_accuracy_metrics 在各 type 內 argmax 對 label 算 accuracy。重要不一致：loader 註解寫 1=inter、2=intra，但 metric 將排序後 type 配給 Intra-video、Inter-video；需對原 JSON 定義後判斷，不能直接抄標題。eval config 4frames/224px/loading=lax，失敗會以黑圖補，應另計資料讀取失敗。

怎麼接入我們的benchmark

可重用

原生五候選 query/choice metadata、來源切塊對映、pretraining 與 development 分界。

需要轉換

case 保留 EgoMCQ ID、候選順序及各父 video/time；source 分 EgoClip/EgoMCQ/下游父 benchmark，tag 字典作原生訓練詞彙。evaluator 儲存 type 數值與已核定名稱、4frame 預算、缺檔回退，不能把同 JSON 的 val/test 加成兩套題。

仍需補齊

尚未取得 egoclip/egomcq 全量 metadata、影片或執行。需解決 type 名稱矛盾、有效樣本清單與跨來源影片去重；下游 NLQ/MQ/PNR/OSCC 完整 adapters 仍另按父協定驗證。
