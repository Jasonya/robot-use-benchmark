P009 · EPIC-KITCHENS

Scaling Egocentric Vision: The EPIC-KITCHENS Dataset

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

EPIC-KITCHENS 原始版的標註、讀取工具與評分庫分開發布；舊網址現已轉嚮明確的 55 版倉庫。已核讀動作／物件標註、GulpIO 流程與分類指標。 2026-10-11 補讀官方共用 downloader 的版本選擇；舊 download-scripts URL 的 404 保留為候選處置。

版本與身份

固定提交的 annotations／starter-kit／epic-lib 舊路徑均轉向 EPIC-55。epic-lib README 警告 v1.4.0 及更早版本的 Gulp flow 可能亂序；原始 GoPro 與釋出抽幀版本的 fps／frame index 不可混用。 補讀 downloader 固定 4f11fb2b579833f360c3c7bb917bf1e24a9787b5，不宣稱是 download-scripts 的已驗證轉址。其 README 說 data/ 未追蹤，但該提交完整 tree 列有四份 CSV，且兩份 split 已實讀；以固定檔案為準。原 Snakefile 的 annotations/master 連結需替換為既有 55 固定版本，不能依今天的預設 challenge 選項推回 2018 評測。

領域
居家整理與清潔、餐飲與烹飪
環境
真實第一人稱廚房影片；participant_id、video_id 與 seen／unseen kitchen 測試條件須保留。影片、拍攝者與廚房不是同一個環境計數。
任務
動作辨識以 verb_class、noun_class 及其組合定義；物件框另有自己的標註時間軸。這些是人類影片標籤，不是可直接執行的機器人任務。
題數與資料
action CSV 含 uid、video_id、participant_id、narration、start/stop_timestamp、start/stop_frame、verb/noun_class 與 all_noun_classes。物件框使用 (top,left,height,width)；object_frame 和 action_frame 需依對照表對齊。S1/S2 測試只公開片段時間；narration 時間不可代替動作邊界。 補讀：原 55 starter-kit 的 Snakefile 由 train/test_seen/test_unseen_video_ids.csv 產生 Bristol 的逐影片 RGB／flow tar 路徑。另由官方 2022 網頁直接連結的 epic-kitchens-download-scripts 提供 epic_downloader.py：先讀 55 的 video_id/split 和 100 的 ar/da/cmr 布林 split CSV，依 video_id 後段長度辨認 extension，再以 --epic55-only 或 --extension-only 過濾；兩旗標互斥，未指定時涵蓋 100（含重用的 55）。輸出一律使用 EPIC-KITCHENS/participant/媒體型別 目錄，原始 55 遠端 train/test 路徑另由 epic_55_split 決定。
評估方式
epic-lib 計算 verb、noun、action 的 top-1/top-5；沒有 action 分數時可由 verb/noun 分數構造。precision/recall 先逐類計算，再對指定 many-shot 類別平均；與 100 版的 tail／unseen 指標不同。top-k 使用每列排名內是否包含 GT 的平均。 下載器的 --action-recognition/--train 等篩選取自 100 版 challenge 欄位；--epic55-only 只限制影片來源，不能替代原 55 的 S1/S2。需仍沿用 55 starter-kit 的 seen→s1、unseen→s2 與原標註契約。MD5 只用於判斷檔案是否可跳過下載，不是辨識指標；本次未執行下載或校驗媒體。

怎麼接入我們的benchmark

可重用

原生類別字典、片段 uid、S1/S2 切分、框座標、GulpIO 資料流程與評分函式。 可重用已釘選的取得程式、兩版 split CSV 欄位、原生 URL 與輸出路徑對映。

需要轉換

source 固定為 EPIC-55；case 保留 uid 與原始 split；segment 同時保留秒與 frame，記錄實際抽幀版本；動作／物件時間軸以顯式對映關聯。verb/noun/action 與 many-shot 報表分項儲存。 另記錄 acquisition_repo/commit、資料 edition、video_id、來源 split、challenge split、媒體型別與 errata/校驗表版本；55/100 重用影片共用 ancestry，但各自保留評測切分。

仍需補齊

尚未取得影片／flow／隱藏測試標籤，也未執行 GulpIO 或官方提交；跨來源與 EPIC-100 重用關係需由 video_id 建立。 需固定下載器實際依賴的 split/md5/errata CSV 版本，驗證完整取得與雜湊；本次 split 僅核讀欄位和列出的樣列，未宣稱逐列審核。
