P052 · StillFast

StillFast: An End-to-End Approach for Short-Term Object Interaction Anticipation

返回逐篇總表核心內容已核讀 方法／綜述參考原作 ↗

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

StillFast在Ego4D STA上預測下一個互動物件、動作與接觸時間；官方測試提交和本機validation必須分開記錄。

版本與身份

本機Overall mAP有更多診斷組合，不等於官方只報的STA欄位；靜態核讀還發現add的空字典分支有不可達的內層len(preds)>0條件，整合前須核對空輸出對分母的影響。

領域
方法／綜述參考，未另作來源用途歸納。
環境
Ego4D影片的觀測影格及短歷史片段，無互動模擬環境。
任務
共同預測box、noun、verb、time_to_contact；四種STA指標組合不是四份獨立素材。
題數與資料
annotation以uid、video_id、frame和objects索引；objects含box／noun_category_id／verb_category_id／time_to_contact。訓練標籤有noun+1與依ROI版本決定的verb offset，輸出JSON再還原。
評估方式
實際validation呼叫OverallMeanAveragePrecision(top_k=5)：IoU嚴格大於0.5、TTC誤差不超過0.25；依GT數折免(K−1)×GT個高分false positives。正式成績依README指定的Ego4D evaluator／隱藏test。

怎麼接入我們的benchmark

可重用

STA annotation、uid結果格式、類別offset還原及原生匹配規則。

需要轉換

case保留版本、frame／歷史視窗、物件GT與TTC單位；box數與影片題數分開，evaluator儲存top_k、IoU/TTC及類別平均規則。
