P102 · NavVerse

NavVerse: Benchmarking Indoor-to-Outdoor Embodied Navigation in Continuous Robot Simulation

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

NavVerse提供室內、室外與連線場景的連續導航；原程式的成功距離是參考路徑近似值，collision指標是卡住代理量，不等同接觸感測。

版本與身份

原PDF p1連umich-curly.github.io/NavVerse-Benchmark，與此同名組織庫和題名相符；本次固定2026-09後更新之commit，非宣稱逐項重現7月版本。

領域
公共場館與服務
環境
作者報100室內＋50室外＋50連線場景，來源USD/navmesh/scene_scale/collider設定另存。這是作者release宣告，尚非本庫已取得200個資產。
任務
ObjNav/VLN/PlaceNav三種條件導航；原episode_target_type分obj/place，instruction_type分target/vln，避免把同一終點的兩種指令視為新場景。
題數與資料
VLNEpisode含scene_id/scene_type/episode_id/path/scale/navmesh_preset、goals(instance/type/location/radius/reference_path)、start_position/start_rotation；episode_label=scene_id+episode_id。JSON讀取錯誤會continue，匯入應另列遺漏。
評估方式
距離取當前點到各reference_path點的直距＋後續路徑長，再扣目標半徑；成功需STOP且距離<1.6。SPL由該初始距離與實走長計。collision以有移動指令但pose變化<0.015判斷，collision_rate平均此代理訊號，非直接物理碰撞次數；保留原名與操作定義。

怎麼接入我們的benchmark

可重用

場景與episode schema、split manifests、語言/目標條件和native measures。

需要轉換

environment固定場景包hash+navmesh/collider；case存scene_episode+目標/指令/機體/控制模式；metric存實際距離近似、STOP及卡住判定而非僅縮寫。

仍需補齊

10,000作者報episode的全量取得／ID完整性、各機體控制與場景有效性、物理contact及近似指標對照。
