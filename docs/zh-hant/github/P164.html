The Imitator Game: Benchmarking Robot Imitative Ability Beyond Action Prediction

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

The Imitator Game提供人類影片→robot模仿的配對資料、分級場景與模擬評估。任務完成、軌跡相似及盲測偏好是三種不同證據。

版本與身份

固定d6d16ec；README對應2608.22301。所讀為共用DP評測鏈與兩個具體task版本，未宣稱整個ManiSkill內含任務或全部基線已驗證。

領域
居家整理與清潔、餐飲與烹飪、包裝、倉儲與物流、零售與購物、實驗室操作、醫療與手術支援
環境
ManiSkill/SAPIEN雙Panda imitator scene，人類demonstrator另有影片。pinned tree中L0/L1/L2/L3各50個config，合計200個task-level設定；不能未去重就宣稱200個獨立語義任務。
任務
以示範模仿操作，可用video-only、language-only或兩者。task透過human/robot/sim ID mapping關聯，L-level與input mode保留case設定；盲測arena另有human preference協定。
題數與資料
LeRobot metadata/parquet/video對齊timestamp秒與episode；MANO姿態是同episode特徵，不是另一資料集。is_right=-1表示缺偵測、數值補0需mask。評測按task隨機抽human episode與video frame；原始action範例雙臂8+8=16D，應固定reference IDs與normalizer。
評估方式
例子成功為兩物件幾何中心在各籃XY bounds及Z上界，is_robot_static另外輸出但未加入success。TSS=1/(1+DTW/path_length)，直接對action向量L2，尺度/單位會影響分數；success軌跡截到首次成功，fail截GT長度；ss<2走fail分支需核驗。eval status=success代表流程完成，物理完成另看success_once/at_end。GT seed=None且batch任一truncated就重置群組，需要固定抽樣/同步假設。

怎麼接入我們的benchmark

可重用

人類/robot/sim mapping、native level configs、LeRobot schema、完成與TSS的獨立指標。

需要轉換

case固定human示範及frame IDs、sim資產/初態、level/input mode、雙臂action spec；reference trajectory與方法輸出分隔，success/TSS/human preference分欄報告。

仍需補齊

所有task checker覆蓋、完整IG10K資產取得、case固定種子、action尺度/TSS可比性、同步batch條件與盲測評審一致性。
