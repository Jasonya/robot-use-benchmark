P043 · Embodied VideoAgent

Embodied VideoAgent: Persistent Memory from Egocentric Videos and Embodied Sensors Enables Dynamic Scene Understanding

返回逐篇總表核心內容已核讀 方法／綜述參考原作 ↗

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

Embodied VideoAgent 是可呼叫導航／操作工具的持續記憶agent，保留related_reference角色。本次確認程式實際用Habitat/HSSD場景與兩agent流程，不能推定為ALFRED或TEACh移植。

版本與身份

此repo明確標ICCV2025 Embodied VideoAgent；README中VideoAgent為2024前作，不能將兩者資料/評測混計。生成10 layouts不等於10種新任務，更不代表全套測例已建立。

領域
方法／綜述參考，未另作來源用途歸納。
環境
Habitat-sim0.3.0 withbullet，generate_episodes 指向home-robot-remake/HSSD場景；scene_config與layout_i、agent_position、island_index分層。預設for迴圈生成同場景10個layout只是範例設定，不是已發布benchmark規模。
任務
另一LLM生成使用者要求，agent用CHAT/GOTO/OPEN/CLOSE/PICK/PLACE/SEARCH及appearance/environment檢索處理。object memory接受timestamp/RGB/depth/depth_mask/camera pose/FOV，物件記憶與工具技能不是固定題庫。
題數與資料
episode JSON含scene、agent_position、island_index、objects；需另有pickable/unpickable/receptacle資產檔。記憶相機座標定義為右x、下y、入畫面z。生成器用物件／容器box提議位置與contact_test後穩定step；重新隨機layout必須儲存具體初態。
評估方式
two_agent_pipeline 限max_iterations=100，輸出tool_cnt與action_cnt，核讀入口未提供獨立goal-success evaluator。PICK檢查距離<=2及可見性後將物件移到y-10000並設STATIC；PLACE直接設translation/DYNAMIC後step，OPEN/CLOSE直接改joint velocities。這是抽象工具執行條件，不是末端效應器接觸控制benchmark。

怎麼接入我們的benchmark

可重用

RGB-D/pose記憶介面、工具回饋、scene/layout初態與部分物理狀態處理。

需要轉換

method連父Habitat/HSSD/資產版本；environment分scene與layout，case需先固定user task生成結果、初始episode及合法sensor/tool約定。工具呼叫、sim actions、dialogue與終態證據分別記錄，另加獨立goal判定後才可列可評測。

仍需補齊

未下載場景／模型、執行agent或對外服務。尚缺固定任務清單、task生成seed、獨立success checker與完整初態重播驗證；executor回覆success字串不能單獨當benchmark通過。真實機器人動作轉移需新的控制與驗證。
