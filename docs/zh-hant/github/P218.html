How You Move Tells What You'll Do: Trajectory-Conditioned Egocentric Prediction

返回逐篇總表檔案／網站 方法／綜述參考原作 ↗

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

已核對 arXiv:2605.20388v1、作者專案頁及同實驗室 TrajPilot 候選庫；固定版本的完整檔案樹只有一行 README，沒有 data reader、模型或 metric 實作。以下任務與協定來自論文，不能視為已完成程式評測整合。

版本與身份

固定 repo commit 85afac4ae7a800fc104a4499c349b09979c34941 的完整樹只有 README.md；未將作者網頁算成模型程式。論文附錄稱 atomic/Keystep 等使用 validation takes，但結果表稱 test split，需保留原文標示差異並取得 manifest 才能對齊。Aria pose 與 RGB估計 PI3 的 oracle 條件也不可混同。

論文題名 How You Move Tells What You’ll Do: Trajectory-Conditioned Egocentric Prediction，作者 Sejoon Jun、Hai Nguyen-Truong、Luigi Seminara、Lorenzo Torresani。PDF 連到 farsightlab.github.io/TrajPilot，頁面題名、作者與 arXiv ID 一致；farsightlab/TrajPilot 與該專案共用名稱空間，但公開 README 只有名稱，專案頁未提供可核驗的方法程式連結。排除搜尋中的 mimozing3003/TrajPilot-AI-Autonomous-Driving-Research-Platform：它描述自動駕駛，與本篇論文不符。

領域
方法／綜述參考，未另作來源用途歸納。
環境
離線人類第一人稱影片：Ego-Exo4D atomic／Keystep、Ego4D GoalStep、EgoPER，另做 EPIC-KITCHENS-100 anticipation 與 Ego-Exo4D 籃球投籃結果分類。相機運動是觀測／條件訊號，並非可直接執行的機器人控制。
任務
分開記錄提供 start+goal 的程式規劃、移除 goal 的未來動作預測，以及 made／missed 二分類。規劃 horizon H=3–8 是動作序列長度；8,472 個 atomic 文字標籤、1,165 類 closed collapse、375 個 Keystep 標籤、310 個 GoalStep 標籤和57個 EgoPER 標籤均為各自詞彙表，不能加總成任務數。Scorer 使用訓練集候選未來軌跡，Oracle 使用實際未來軌跡，兩者資訊條件分開。
題數與資料
論文附錄 A.1：atomic 為 take-disjoint 的140,413 train segments／2,237 takes 與11,425 validation segments／312 takes；連續 segment 形成 H=3–8 windows，但未提供公開 window manifests。每段16張 RGB，384×384，V-JEPA 池化為1664維特徵；atomic 區間以相鄰時間戳中點決定，其餘以標註區間中點與邊界取樣。Aria 或 PI3 相機姿態對齊影片時間並轉成相對 [Δx,Δy,Δz,Δrx,Δry,Δrz]，旋轉為 rotation vector；實際 tensor schema、尺度／單位與插值實作未公開。籃球子集294 train／74 test events、42／10 takes，test 為37 made+37 missed；模型僅看平均1秒的出手前片段，16張取樣自30 fps來源影片。
評估方式
沒有具體 metric/scorer 程式可讀。論文區分 middle-step R@1/5 與 full-sequence R@1/5，MSeq/FSeq 為整段全對比例；Full 包含觀測端點，Future 不含 observed Start。Closed-vocabulary 另報 Mid/Full mAcc、exact-sequence SR、mIoU、Levenshtein，實際 macro/micro、重複標籤與跨 horizon 權重須等程式確認。EK100 的 verb/noun/action 為 mean-class Recall@5，另列 instance accuracy；籃球 accuracy 分母為74個事件，balanced accuracy 為兩類 recall 平均，各類 recall 分母37。模型內部 Scorer 的候選排序／fallback 不是 benchmark 成功判定，不能取代 evaluator。

怎麼接入我們的benchmark

可重用

重用論文所界定的來源資料集、take 層級 split、原生動作詞彙與規劃／anticipation／outcome 任務分類；repo 僅可重用身份與版本證據。

需要轉換

source 連回各母資料集；case 以 take_id+segment/window+H+split+詞彙版本識別，儲存 start/goal 可見性與 No-Traj／Scorer／Oracle。camera_pose 另存來源 Aria/PI3、時間軸與相對6DoF格式；evaluation 分列 step retrieval、sequence exact match、class recall、event accuracy及其分母。

仍需補齊

公開 reader、window／label-bank manifests、軌跡取樣與單位、實際 scorer/gating 和全部 metric 實作；尚不能核驗論文指標或形成可執行套件。
