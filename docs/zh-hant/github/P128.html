RoboNet: Large-Scale Multi-Robot Learning

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

RoboNet原生loader會檢查資料hash，統一T個影像/狀態與T−1個action；不同機體維度可補零、截短或推估autograsp，必須保留轉換來源。

版本與身份

固定d83eee2的2019來源實作；RoboNet另被OXE重發為RLDS，需保留同一父episode關係。未執行TF模型或原資料loader。

領域
通用物件與機動作業
環境
多機器人HDF5 interaction sequences，metadata帶robot/ncam/維度/長度/檔案hash。任務環境或物件配置不能由機體名與record數推定。
任務
動作條件影片預測、逆動態／視覺控制及標註點預測；frame、subsequence、同episode多camera皆不是新增語義任務。
題數與資料
env/state、policy/actions、camera影像及可選bbox_annotations；loader以min(state_T,img_T,action_T+1)決定可用T，action取T−1。Mismatch模式可PAD_ZERO/CLEAVE，autograsp根據後一state及邊界推估新增控制維。
評估方式
標註variant預設拆non-annotated train/val/test並另列annotated robots；指定train_ex_per_source時另走分支，須固定split規則。metrics提供分佈畫素距離和normalize到1的PSNR/MSE等，值受resize/camera/horizon影響，不是物理task完成率。

怎麼接入我們的benchmark

可重用

內容hash、原robot/相機/維度、T/T−1對齊、標註模式與視覺metrics。

需要轉換

case記parent HDF5、選取camera/起始frame/context/horizon、原維度和補零/截斷/autograsp推估；畫素誤差附影像解析度，原標註缺失與零placeholder分開。

仍需補齊

資料資產與完整metadata、場景/語義目標對映、原train/test與annotated子集隔離、視覺控制真實成功協定及跨來源去重。
