P070 · RoboCasa

RoboCasa: Large-Scale Simulation of Everyday Tasks for Generalist Robots

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

2024 RoboCasa 的資料介面可由官方 v0.2 tag 核讀：25項 single-stage 資料註冊、5項 multi-stage 資料註冊、HDF5 重播與具體幾何 checker。這些資料入口不是論文100項任務的完整清單；現行 main 已轉為 RoboCasa365。

版本與身份

v0.2固定756598a5be52e052339bb2d957426e39015c2afb；目前main固定456174f62b89b8fca99eaaf33949c29fec9cfc2a，屬P071。不可把v0.2的0-based layout/style、PnPCounterToCab、HDF5 env_args與365的1-based ID、PickPlaceCounterToCabinet、LeRobot格式按名稱直接合併。舊版仍要求robosuite master並留有舊controller入口，需要額外鎖定相容版本。

對應 arXiv:2406.02523v1（2024-06-04）及八位作者的 RSS 2024 論文。v0.2 README 直接列此題名／作者並連原論文；v0.2 是同一作品的後續維護版，未宣稱其commit就是投稿時程式。

領域
居家整理與清潔、餐飲與烹飪
環境
原論文10個floor plans×12個styles＝120種廚房組合；v0.2 scene_registry 的layout ID為0–9、style為0–11，分別解到YAML。fixtures包括櫃子、檯面、家電；一個layout的材質變化不另算平面配置。
任務
論文100項＝25 atomic＋75 composite。已讀PnPCounterToCab把物件從檯面放入櫃內；get_ep_meta.lang插入抽樣物件名稱，_get_obj_cfgs給name/obj_groups/graspable/placement及兩個幹擾物。資料registry的5個composite入口只涵蓋ArrangeVegetables、MicrowaveThawing、RestockPantry、PreSoakPan、PrepareCoffee，不能據此說其餘任務不存在。
題數與資料
registry以human_path、mg_path、horizon及download_links連線v0.1資料；human_raw讀demo.hdf5，human_im／mg_im分別挑選帶影像／生成材質的檔案，NavigateKitchen沒有mg_path。HDF5 data.attrs.env_args提供env_name/type/env_kwargs；data/demo_N內含states、actions或actions_abs、obs/<camera>_image，attrs含model_file與ep_meta。ep_meta、XML、資產與初態需一起還原，frame index、控制頻率與影片抽幀分開記。
評估方式
已閉合run_random_rollouts→PnPCounterToCab._check_success→obj_inside_of AND gripper_obj_far。前者檢查物件8個bbox角點對fixture內部3軸的投影，後者要求eef與物件中心距離>0.25公尺。obj_inside_of的0.05加在未正規化軸向量的內積上，不能直接標為5公分容許誤差。create_eval_env固定(1,1)/(2,2)/(4,4)/(6,9)/(7,10)，obj_instance_split=B。論文每task50 trials；這裡main只是3回合×100步隨機動作示例，不是正式BC-Transformer評測預算。

怎麼接入我們的benchmark

可重用

layout/style YAML引用、原生task class、物件抽樣與語言模板、v0.1 HDF5資料來源、task checker。

需要轉換

source固定論文v1與程式v0.2；environment分layout/style/asset；task保留PnP等原生ID；case記物件split、場景pair、初態與控制設定；evaluator分開bool成功、step horizon及trial數。raw、rendered、MimicGen資料保留派生關係。

仍需補齊

完整75 composite與已公開資料入口的逐項對應、原始2024程式／robosuite精確版本、正式policy runner設定與50 trials seed清單，以及HDF5／資產閉合驗證。
