DexH2R: A Benchmark for Dynamic Dexterous Grasping in Human-to-Robot Handover

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

DexH2R提供人到機器人的動態交接資料與抓取/接近策略。所讀DP評測將進入最終抓取插值記為成功，不能直接解讀為真實物件已穩定交接。

版本與身份

固定43c5e5c；README仍用wang-youzhuo舊owner和空DiffusionPolicy連結，所讀為4DVLab當前固定版。只核讀列出的DP核心片段，未宣稱CVAE/MotionNet全部核讀。

領域
協助、交接與陪伴
環境
真實多視角人類交接，Kinect/RealSense/ZCam合計18視角；人類MANO與Shadow Hand qpos、物件mesh/point cloud及逐時刻物件pose。相機數不當作環境數。
任務
動態靈巧抓取、人到機器人的接近與交接；subject/object/sequence形成資料階層，grasp pose preparation和approaching motion是方法/子流程。
題數與資料
原資料按subject zip；sequence含calibration、mano、obj_pose、qpos和real_obj_pcd。depth原始int16需按檔案轉uint16；DP loader又將image/depth除255，需區分原始物理深度與模型輸入。Zarr包含agent_pos/action/final_grasp/traj_index等；先建隨機val_mask後被索引區間覆寫，應儲存實際mask_start/end。
評估方式
compute_pose_distance最後只回傳平移距離×100(cm)，算出的旋轉差未加入。接近門檻、非零物件變化與最少frame觸發Is_interpolate，dp_success_rate取此旗標。安全率扣除GT穿透基線後判斷是否零穿透；名為max_pener_depth的量在累加後除總frame，不能直接稱最大深度。這是靜態程式判讀，未跑策略。

怎麼接入我們的benchmark

可重用

多相機標定、原生split、物件與手姿態、DP輸入及指標公式。

需要轉換

environment繫結拍攝/標定與robot；task描述交接條件；case保留subject/object/sequence與完整初態；將接近、抓取穩定、交接完成分別定義evaluator。

仍需補齊

資料/mesh資產取得、depth尺度驗證、穿透函式及最末trajectory匯總完整查核、實際穩定抓取/交接checker與重現。
