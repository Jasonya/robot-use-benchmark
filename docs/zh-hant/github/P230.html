P230 · EgoH4

The Invisible EgoHand: 3D Hand Forecasting through EgoBody Pose Estimation

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

EgoH4 評測由頭部／影像與可見 2D 手位置推估及預測 3D 手部，特別區分視野內外。已核對資料模組、20+10 幀切分與 metric 實作；這是 EgoExo4D 上的新評測任務，不是新採集的一批影片。

版本與身份

固定目前官方 commit；trainer 註解有 17-joint 遺留文字，但實際使用 57 joints。future condition 於 decoder 被排除，不能因 sample 接收 GT-shaped tensor 就直接判定資料洩漏。

領域
穿戴互動與動作介面
環境
EgoExo4D 的 Aria 頭部相機、相機姿態及人體／手部標註。機器人控制與物理成功不在本來源評測範圍內；場景應沿用父 take。
任務
3D 手軌跡及手姿態 forecasting，並可分離觀測段 reconstruction；native 30 幀中前 20 幀觀測、後 10 幀未來，按可見／視野外比例分組。全身 57 joints 是移除重複 wrist 後的輸出維度，不是 57 個任務。
題數與資料
論文報告約 156K train／34K test sequences；公開 config 的 test.split=val，並 concatenate manual body dataset 與 manual hand+auto body dataset。視窗 size=30、slice=1、frame interval=3，需儲存 take_uid／start_frame 和標註型別，避免把交疊片段或不同標註視為獨立原片。
評估方式
原生 evaluator 分 body／wrist／hand／full，計 obs/fut ADE、末幀 FDE、10 個未來 timestep 和 in-/out-of-view 子群；不以單一 success 評分。calc_jpe 先乘 visibility，再以 jpe!=0 篩選，會連真正零誤差也排除。該固定版本以絕對座標 L2 計手部誤差，沒有在所讀 test_step 執行 wrist-relative 對齊；比較論文相對 MPJPE 欄時必須核對。

怎麼接入我們的benchmark

可重用

重用 parent take／sequence indexing、可見性標註、原生 20+10 與分組 evaluator。；以各分項原生誤差作基準；0…1 視野外比例是 case 屬性，不直接標成難度分數。

需要轉換

canonical case 固定 observation boundary、camera／pose 座標、joint order、3D／2D masks 及 annotation provenance。；保留 native evaluator；修正零誤差 mask 或新增 wrist-relative metric 時另建協定與相同 fixture 對照。；test dataset 所稱 test 對應父資料 val，標準格式同時保留兩個 split 名稱。

仍需補齊

本次只查核列出的公開來源段落，未取得完整資料或執行 diffusion。；body／hand concatenation 之重疊 take 與實際數量需要用下載後的 annotation manifest 核對。
