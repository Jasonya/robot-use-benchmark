P085 · SoftGym

SoftGym: Benchmarking Deep Reinforcement Learning for Deformable Object Manipulation

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

已核讀 SoftGym 的環境／狀態介面、10 個論文任務對應的具體計分及 picker 動作。它提供 FleX 柔性物與流體互動環境；normalized_performance 是任務專屬連續量，不能當共同成功率。此 commit 的 ClothFoldCrumpled reward 與 performance 存在公式差異。

版本與身份

固定 2022-01-14 commit；README 含 2021 年新增 depth rendering，不能視為原論文提交時完整快照。核心核讀限所列 Python 段落，未執行 FleX、基線或載入 pickle。 已補固定SoftAgent db2fbb5d的CEM／DrQ／初態生成核心段落；未執行baseline，也未把這個後續版本當成論文完整再現。

README 的完整題名、四位作者及 CoRL 2020 引用對應 arXiv:2011.07215；不是論文引用的 CURL、DrQ 或 rlpyt 基線倉庫。

領域
衣物與洗護
環境
NVIDIA FleX／PyFlex，布料、繩索、流體以粒子及 shape states 表示。預設以抽象 picker 或杯子直接控制；程式含 sawyer／franka 分支，但本次未驗證 Robotics 版 PyFlex，不能據此宣稱完整手臂環境可執行。布料位置為原生 xyz、y 為高度、面積投影到 xz；camera 設定使用弧度值。
任務
README 列 6 Medium＋4 Hard 任務。SOFTGYM_ENVS 有 12 個註冊名稱：ClothFlattenPPP／ClothFoldPPP 是同 class 的控制變體；env_arg_dict 另外有未註冊專案，不能全部算任務。RopeConfiguration 的 S/O/M/C/U 為 goal 變體。num_variations=1000 是預設生成預算，未讀取實際初態資產，不能當已驗證 case 數。
題數與資料
初態 pickle 儲存 (cached_configs, cached_init_states)，以 config_id 關聯；Flex 狀態有 particle_pos(N×4，xyz＋inverse mass)、particle_vel(N×3)、shape_pos(N×14)、phase、camera_params。液體子類改用 glass_x／glass_y／glass_rotation、glass_states、poured_glass_states、glass_params 等欄位，不能硬套同一狀態 schema。布料 config 含 ClothPos／ClothSize／ClothStiff／camera_params／flip_mesh。觀測可為 cam_rgb、key_point 或補零粒子 point_cloud；RopeConfiguration RGB 與 goal RGB 沿通道拼成 6 通道。未指定 config_id 時，訓練從前 80% 初態抽取，eval_flag 從後 20% 抽取；1000 配置因而對應 800/200 索引，非 rollout 次數。 補核SoftAgent：generate_cached_states設定num_variations=1000，但main覆寫env_names為僅ClothFold；DrQ預設num_variations=1，README要求另設1000才對應原論文條件。CEM輸出initial_states／action_trajs／configs，不能把100萬train steps或候選rollouts計為題數。
評估方式
FlexEnv.step 在 action_repeat 次物理步後計算 reward／info，到 horizon 才 done，沒有通用成功門檻。ClothFlatten：100×100 xz 佔格面積；ClothFold：−平均對應粒子距離−1.2×固定半側偏移；ClothDrop：−平均粒子至 target_pos 距離；ClothFoldDrop 沿用 ClothFold。ClothFoldCrumpled 的 reward 以 flat_pos 與 norm(mean(...,axis=1)) 算固定項，info 卻以 init_pos 與 mean(norm(...)) 計算，兩者不能互換。RopeFlatten：−|端點距離−繩長|，以 −繩長與 0 正規化；RopeConfiguration 預設對下取樣點做 Hungarian 最小配對距離。PassWater：−10×杯外粒子比例−|terminal_x−glass_x|；PourWater：目標杯內且控制杯外的粒子比例；PourWaterAmount：−|int(N×target_amount)−目標杯有效粒子數|/N。多數 info 用初態與上界正規化、未裁切；PourWaterAmount 延用父類 reward_max=1，與其負誤差理論上界 0 不同。 補核SoftAgent實際baseline：CEM取得完整env state，在副本環境set_state後逐candidate累加reward作成本；是可查詢真實模擬動力學的oracle規劃條件。預算由timestep_per_decision／max_iters／plan_horizon決定。DrQ使用sample=False推論，報每episode回報的平均，以及info的episode×time平均與末幀平均；這些不等同任務成功率。

怎麼接入我們的benchmark

可重用

任務 class、原生 task 名稱、具體 metric、可重設的 config/state、camera 與 action_mode 設定。

需要轉換

source→固定 commit；environment→FleX 場景與物理設定；task→論文目標並保留註冊別名；case→config_id＋狀態雜湊＋split；evaluator→各 class 公式。保留 raw reward、performance、normalized_performance 三欄及 oracle/RGB 許可權。picker 每支為 [dx,dy,dz,pick]，位移範圍 ±0.01、pick>0.5；PPP 為 [x,y,z,pick]、內部步長 0.01，最多 300 步，不把 horizon 當秒或影格。

仍需補齊

初態／rope goal 資產與生成 seed 的清單；SoftAgent其餘演算法及paper checkpoint／跨seed聚合的完整閉合；ClothFoldCrumpled 與 PourWaterAmount 的 evaluator 差異決策；PyFlex 執行及分母為零的驗證。
