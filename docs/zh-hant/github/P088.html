FlingBot: The Unreasonable Effectiveness of Dynamic Manipulation for Cloth Unfolding

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

已核讀 FlingBot 的模擬／真機 task 與 replay HDF5、coverage checker、evaluation 入口及彙總。原生 task 是衣物形狀／材質／初態的一筆配置，目標仍是展布；模擬與真機 coverage 的原始單位不同。另確認非重複 loader 的末筆等待問題及彙總過濾會影響分母。

版本與身份

固定2021-10-13 commit，原論文PDF快取為後續2021-10-18版；保留版本差異。environment/Memory.py是symlink文字，實作讀到learning/Memory.py。未執行任何模擬、GPU模型、機器人控制或下載衣物HDF5。

論文 arXiv:2105.03655 與 README 作者 Huy Ha／Shuran Song 對應。binding 的 columbia-robovision/flingbot 在快取 GitHub metadata 解析為 real-stanford/flingbot；保留 requested_repo 與 resolved_repo，不能當兩個獨立來源。論文亦使用 columbia-ai-robotics 舊網址。 舊入口columbia-robovision/flingbot的已儲存GitHub metadata回應指向real-stanford/flingbot，按倉庫別名保留，不另外算成未讀的第二個倉庫。

領域
衣物與洗護
環境
模擬為修改 SoftGym/PyFlex 的 CUDA 粒子布料環境，抽象雙picker配合UR5可達性邊界；使用Blender或OpenGL，論文設定為Blender。真機為兩支UR5、RG2／WSG50、頂視Azure Kinect及前視RealSense；setup.py 只留一件衣物參考與裝置位置引數，未提供完整論文實體資產清單。
任務
展布／最大覆蓋面積是一個目標族；Normal Rect、Large Rect、Shirt 是形狀／尺寸泛化設定。fling、stretchdrag、drag、place 是 action primitives，不是四個新的生活任務。TaskLoader 的 task_name 是 HDF5 配置ID；生成group key是對當時記錄數字取SHA1，不是狀態內容雜湊。論文600模擬測試配置＝三類各200，真機三類各10次；2000訓練配置及150真機調適回合另列，未下載HDF5驗證實際記錄數。
題數與資料
task HDF5 以group儲存 particle_pos、particle_vel、shape_pos、phase、cloth_size、cloth_stiff、mesh_verts／faces／stretch/bend/shear edges；flatten_area、initial_coverage、cloth_mass、task_difficulty為attribute。方布尺寸為粒子數，預設半徑0.00625m；mesh尺寸用[-1,-1]、flatten_area取trimesh面積/2。replay每個 {episode:09d}_step{step:02d}（尾步加_last）為一筆action；含observations、actions單畫素mask、rewards、is_terminal、next_observations及rotation/scale/action_primitive/task_name/preaction_coverage/postaction_coverage/max_coverage。RGB/255＋depth為4×H×W、策略預設僅用RGB與64×64輸入；action需連同影像旋轉縮放與可達性轉換解碼。
評估方式
模擬coverage是100×100 xz佔格的面積（原生m²）；step reward為A_after−A_before，學習label預設再除flatten_area。方布reference來自展平網格，mesh取表面面積/2。真機coverage是HSV背景分割後最大連通區畫素佔全影像比例，再除同相機的flatten_area參考；不能把此原始值當m²。10 primitive actions內可提前終止：模擬最大粒子位移<0.05，真機前後mask IoU>0.9，均代表停滯而非成功。collect_stats報normalized final/best/delta coverage，未裁至[0,1]；跳過failed_grasp/cloth_stuck/timed_out、缺max_coverage及postcoverage/reference<0.05的記錄。其episode_length直接讀零起始尾步索引，真正動作數需+1。run_sim預設統計最近128個step groups；visualize.summarize用1e7上限讀全buffer，不可把線上平均當全測試分數。

怎麼接入我們的benchmark

可重用

Task狀態重設、HDF5 reader/writer、action transformation欄位、raw與normalized coverage及failure flags。

需要轉換

source儲存舊repo別名及resolved commit；environment分模擬／真機與renderer；task儲存展布目標及primitive；case用dataset雜湊＋task_name＋形狀設定；rollout另存episode/step/action_count；evaluator明列面積或畫素比例、reference方法及過濾後分母。

仍需補齊

三測試HDF5／訓練HDF5的雜湊與mesh split；nonrepeat loader末筆問題修正或保留原版行為；未排除失敗的系統評測分母；真機衣物完整表、校正與背景設定；native step index轉操作次數驗證。
