P236 · ActFusion

ActFusion: a Unified Diffusion Model for Action Segmentation and Anticipation

返回逐篇總表核心內容已核讀 方法／綜述參考原作 ↗

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

已核 ActFusion 的 feature/label loader、full_len 遮罩推論、TAS scorer 與 LTA MoC。固定 release 的預設 LTA 仍使用完整影片長度；不可標成論文 ActFusion† 的未知未來長度協定。訓練亦用 test split 分數選 best checkpoint，需保留模型選擇條件。

版本與身份

固定 00ba6c1df0ac30cfcb90110278dd3616a589ced4。release 的 50 Salads epochs=7001、n_mask=10，Breakfast batch_size=16、feature layers=[7,8,9]；論文表 S5／§5.2 有 5000 epochs、50 Salads mask=25、Breakfast batch_size=4 等差異，不能把公開 JSON 稱作逐項相同的論文設定。README 的 default_configs.py 實際位於 src/default_configs.py。本次未執行任何上游模型或訓練。

arXiv:2412.04353v1（2024-12-05），Dayoung Gong、Suha Kwak、Minsu Cho，NeurIPS 2024。官方作者帳號 gongda0e 的 README 明列相同 arXiv、題名、作者與會議；搜尋中更早同名 magrogovich/ActFusion 不採用。PDF 提及 FUTR 和 DiffAct 是比較方法／重用程式，不能拿它們當 ActFusion release。此 repo 建立及固定 commit 為 2025-07-08，晚於論文。

領域
方法／綜述參考，未另作來源用途歸納。
環境
離執行緒序活動影片；Breakfast 與 50 Salads 是第三人稱烹飪來源，GTEA 是第一人稱烹飪來源，不能全部標 Ego 或機器人環境。程式以預先提取 I3D 特徵為輸入，不提供物理控制或 robot success。
任務
同一模型做 temporal action segmentation（TAS，完整觀測）及 dense long-term anticipation（LTA，部分觀測）；論文 TAS 用 50 Salads/Breakfast/GTEA，LTA 用前兩者。原生 action 數從外部 mapping.txt 的列數取得，event_list 的行序編碼與 read_mapping_dict 的首欄數字必須一致；這次未取得該資料包，未冒稱固定程式類別數。論文 50 Salads 的 50 videos/17 fine-grained labels、Breakfast 的 1712 videos/48 labels、GTEA 的 28 videos/11 labels是原作統計，不能直接當本次載入的有效 case 數。
題數與資料
datasets/{dataset}/features/{video}.npy、groundTruth/{video}.txt（一行一個 frame label）、mapping.txt（ID 名稱）、splits/{train,test}.split{split}.bundle。reader 接受二／三維 features，swapaxes 後為 augmentation×T×F，assert T 與 GT/boundary 長度一致；未知 label=-100。事件邊界在 label 改變點及前一格置1，再可 Gaussian smoothing。sample_rate=8（50 Salads）或1（Breakfast），temporal_aug 對各 offset::rate 建樣本，但 dataset 長度仍是 video 數；回復用 nearest interpolation 與首末值填充。時間原生為 annotation frame index，無可靠 fps/秒轉換資產隨 repo；2048 是輸入 feature 維度。paper 指 5/4/4 folds，程式每次只讀指定 --split，沒有自動跨 fold 聚合；完整資料包及有效長度未下載。
評估方式
預設 decoder-agg：LTA α=0.2/0.3，full_len=feature[0]時間長度，observed_len=round(α×full_len)，切掉未來視覺特徵後仍把 full_len 傳給 ddim_sample 追加 mask tokens；這是已知全長設定。各 temporal offset 機率平均，median filter（50 Salads=30、Breakfast=15 個取樣位置）、argmax，回復至 GT 全長。LTA 對 β=0.1/0.2/0.3/0.5，以 [int(αT):int((α+β)T)] 的原始 frame 範圍計各 GT 類別 n_T/n_F，先跨 videos 累加，再對有 GT frame 的類平均 n_T/(n_T+n_F)×100；不是 frame micro accuracy，也不是 best-of-K。TAS Acc=所有評測 frame 正確數/總 frame；Edit=每影片壓縮連續同標籤後的 (1-Levenshtein/max(segment_count))×100 再影片平均；F1@10/25/50 以同類 segment IoU 門檻一對一配對，跨影片累積 TP/FP/FN 後計 F1。只排除字面 background，不能預設所有 SIL/action_start 類被排除。LTA 同時回傳的 Acc/Edit/F1 是 observed prefix 上的分段分數，不能標成 future MoC。sampling seed=video_idx，25 sampling steps／1000 diffusion steps；offset 不是新增試驗數。

怎麼接入我們的benchmark

可重用

bundle/video key、mapping、逐格 labels/features 對齊、TAS 具體 Edit/F1 與 LTA class-count scorer。

需要轉換

source 儲存 paper version/commit 及 MS-TCN feature來源；domain/environment 依資料集視角分開；task 分 TAS 和 LTA，case=(dataset revision,fold,video,α,β,length_protocol)，frames/segments/augmentation 不互相加總。另記 F、feature_stride、offset、original_frame_index、round/int 邊界、median 窗、seed、DDIM budget；evaluator 區分 frame micro、video-mean Edit、pooled segment F1、class macro MoC。

仍需補齊

需固定完整 mapping/split/feature bytes與原始 fps，檢驗 mapping 行序=數字 ID、未知 -100、背景與末 segment end 的邊界（實作最終 end=i，非 i+1）。論文 §5.4 的 ActFusion† 用 r=4×observed length，此 release 的 CLI/config/已核 sampler 未提供該協定；須新增明確 adapter/取得對應作者版本。train 在 test_test_dataset 上計 TAS 五項平均與八格 LTA MoC 平均選 best／combined 模型，須改為獨立 validation 或如實標註。TAS及不同 α 共寫同一 prediction/{video}.txt，匯入須另用 protocol key 防覆寫。GTEA 無隨附設定與資料；不能只憑 main.py 的分支宣稱已接通。
