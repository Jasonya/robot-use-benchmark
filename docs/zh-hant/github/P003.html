P003 · COIN

COIN: A Large-scale Dataset for Comprehensive Instructional Video Analysis

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

COIN 將標註、下載與評測拆成不同倉庫。要先讀 annotations 的 domain/task/step 與影片 JSON，再讀 code 的時段定位／逐影格分割評測。 2026-10-11 補讀 annotation-tool 的實際匯出與時段生成。

版本與身份

12 domains／180 tasks 是作者的活動分類，並非本庫21類用途或180個已去重的機器人任務。 annotation-tool 為獨立固定提交，CSV 標註工作檔不能視為已發布的 database JSON；sample 的 0.5 秒間隔不能推為所有影片 fps。

領域
居家整理與清潔、餐飲與烹飪、工藝與修繕、個人照護、交通移動與車輛維修、休閒與運動
環境
影片觀測脈絡；原作生活用途不是互動場景 ID。
任務
原生 domain/task/step 分類與人類程式活動；定位、分割是資訊評測題型，不能等同機器人工作規格。
題數與資料
ActivityNet 風格 database JSON、YouTube ID、影片 URL、步驟 label/segment 及 taxonomy。README 範例的 class 與下載器的 recipe_type 欄位需對實際版本檢查。 補讀：annotation-tool 讀 URLID/URL、TagID/Tag、URLID/Frame/Time 三表，匯出 instruction_時間.txt 的 CSV 八欄 URLID,URL,TagID,Tag,Start,End,Time,State。輸出 Time 為 times（確認儲存次數），有別於 frame.txt 的抽幀秒數；Start/End 為時段秒數。影格模式依 newSpace 分開不連續區段，影片模式先以 toFixed(0) 儲存整秒文字。匯出只保留有 URLID/TagID 的 tagInfo 列，不含沒有標註的影片。
評估方式
定位結果包含 action_id、start、end、confidence、video_name；evaluate.number_label 需設為相符的原生標籤空間。分割另報逐影格 accuracy；各自保留分母。 補讀工具的 State=0/1/2 分別是未標註／已標註／刪除；checked 是另存於瀏覽器的布林值，八欄匯出沒有帶出。這些是標註流程狀態，並非 AP/F1、GT 品質或獨立複核指標。

怎麼接入我們的benchmark

可重用

活動／步驟 ID、影片血緣、原生時段及 AP/F1 等判分程式。 可另重用工具輸入字典、逐影片 tagInfo 與匯出欄位。

需要轉換

活動放 human_activity_definition；影片與時間標註放 context/annotation；定位與分割 case 分開建立，保留秒與影格換算。 工具 URLID/URL → 來源影片引用，TagID/Tag → 工具版本內標籤，Start/End → 原生秒區段；Time/State 放標註流程 metadata。需明確建立這些本地 ID 與已發布 COIN JSON/taxonomy 的對映。

仍需補齊

影片有效取得、完整 split 清單、欄位別名核對及本庫資訊題型的 evaluator 接線。 工具讀寫採直接逗號／換行切分，未處理引號包覆的逗號；仍需匯出往返、整秒精度、缺列及 checked 遺失驗證。此補讀未取得影片或執行瀏覽器工具。
