P227 · EggHand

EggHand: A Multimodal Foundation Model for Egocentric Hand Pose Forecasting

返回逐篇總表核心內容已核讀 方法／綜述參考原作 ↗

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

EggHand 是在 EgoH4／EgoExo4D 手部軌跡上評測的預測方法；「action」在這裡是未來 42 個人體關節座標，不能直接當成機器人控制命令。已逐段核對取樣、相機對齊與六項誤差的有效樣本口徑。

版本與身份

已讀 revision 的 implementation note 明載 warmup 為 1% 而非論文 5%；推論 BF16／四步 denoising 與訓練精度分開。閱讀範圍是列出的來源段落，未聲稱重現論文分數。

領域
方法／綜述參考，未另作來源用途歸納。
環境
EgoExo4D 衍生的 EgoH4 人體影片／手部軌跡，非新建模擬場景。相機外參為 world→camera 3×4；以最早可見幀（offset −19，含邊界補幀）的相機位置與前向建立座標系。
任務
一個 3D 雙手預測設定：42 關節 × xyz。state offsets −19…0，4 個影像 offsets −18／−12／−6／0，target offsets 0…9；target 包含當前 timestep，不能稱為 10 個純未來幀。
題數與資料
README 列 train 555 episodes／41,314 samples、val 109 episodes／8,830 samples，10 Hz，LeRobot v2.1。episode、重疊時間窗和關節數分開記；與 EgoH4／EgoExo4D 保留父資料關係。原始 126D 關節與 12D 外參經模型投影，32D latent action 不是原生 actuator 維度。
評估方式
以公尺計算 wrist ADE／FDE、絕對 MPJPE／MPJPE-F、wrist-relative R-MPJPE／R-MPJPE-F。論文的 MPJPE 欄對應後兩項相對誤差。GT 三軸全零才排除關節；relative 額外要求 wrist 有效，包含對齊後零誤差的 wrist。ADE 先手腕→幀→sample 平均，MPJPE 池化有效 joint×time；不共用分母。全無效 sample 不計，異常直接停止並報 sample index。

怎麼接入我們的benchmark

可重用

重用原生 joint keys、episode／frame 對照、相機對齊與原生 evaluator。；保留同一評測的 absolute／relative 六欄，不把不同 alignment 的 MPJPE 合成一欄。

需要轉換

case 固定 source episode、base timestep、完整 observation／target offsets、padding mask、m 單位與 camera reference。；訓練 per-coordinate 非零 mask 和評測 per-joint mask 各自儲存；新增缺失值策略必須另立協定。；資料 split 沿用父 take／episode，防止重疊視窗跨 train／test。

仍需補齊

本次未下載影片／模型、未執行基線；資料與 checkpoint revision 仍需固定。；目前原生對齊會把全零缺失關節當點平移；不能事後把它誤認為觀測到的手。
