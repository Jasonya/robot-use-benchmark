EgoDex: Learning Dexterous Manipulation from Large-Scale Egocentric Video

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

EgoDex官方庫提供HDF5/MP4 loader及best-of-K軌跡誤差。829小時包含split凍結後追加資料；每frame樣本量不能當不同任務或episode數。

版本與身份

apple/ml-egodex已轉址apple-aiml-research/ml-egodex，屬同一源。README分約725h train/7h test/97h extra；不可將追加部分混進原凍結test。

領域
居家整理與清潔、衣物與洗護、裝配與生產作業、穿戴互動與動作介面
環境
Vision Pro/ARKit第一人稱桌面人類操作；每episode的ARKit origin由裝置初始化，不保證跨episode一致，不能把相同world坐標當同一場所。
任務
作者報194種人類操作task，829小時資料；test/robot部署是不同用途。loader __len__回總frame數，不是194任務的題數。
題數與資料
同索引MP4/HDF5，30Hz對齊；camera intrinsic3×3、各joint transforms N×4×4、可選confidence；reversible語言用llm_description/description2及which_llm_description。loader比較字串"1"，需驗證實際attr型別。
評估方式
evaluate_distance採B×T×48 GT與K×B×T×48 prediction，排除任何padding的chunk，選出12個位置點而略過6D旋轉；平均距離與終點距離各自best-of-K，可能選不同候選。這是人類軌跡預測誤差，非機器人完成率。

怎麼接入我們的benchmark

可重用

需要轉換
