EgoSchema: A Diagnostic Benchmark for Very Long-form Video Language Understanding

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

EgoSchema 官方倉庫含資料取得、原 Ego4D 對映和遠端提交 wrapper；完整 GT 未公開。已核讀提交程式與兩筆來源對映樣本，未把遠端介面當作本機 evaluator。

版本與身份

README 同時有 Kaggle 入口與舊 coming-soon 文句；這次只確認釘選檔案與 wrapper，不用舊介紹推定平臺狀態。Wasabi 簽署網址會過期，下載網址不是穩定資料 ID。

領域
居家整理與清潔、餐飲與烹飪、工藝與修繕、農業與園藝
環境
從 Ego4D 截出的第一人稱影片；q_uid 對應一個影片片段，uid_to_ego4d.json 另連 video_uid、starting_sec、ending_sec。多片段可能來自同一原影片／場景。
任務
零樣本長影片五選一 QA。README 的完整 5,031 題與公開答案 500 題是不同口徑，500 題為子集，不能加總；這是原作者檔案數字，非本次已整合題數。
題數與資料
影片名對 q_uid；提交 JSON 是 question_uid→0–4 整數。已讀兩筆 parent mapping，其中一例把 q_uid 對到原影片 240–420 秒；只核對欄位與例子，不宣稱全量對映已人工審查。
評估方式
validate.py 直接 POST JSON 到作者服務，返回 full/subset MCQ accuracy；程式本身沒有本機 scoring 邏輯或完整 hidden labels。未送出任何提交，也未驗證服務現時可用性。500 題離線結果不能當完整 benchmark 成績。

怎麼接入我們的benchmark

可重用

原生 q_uid、五選一輸出範圍、公開 subset 口徑及 Ego4D 來源時間對映。

需要轉換

case 留 q_uid 與 parent video/time window；split/label_access 明確區分 public-500、完整公開問題與 hidden answers。evaluator 分 local_subset／remote_full，記錄影片取樣預算、輸出解析和提交回執。

仍需補齊

本次未取得全量影片與 questions.json（超過本工作者小型文字取得上限），未執行模型或服務。需全量 schema／ID 唯一性與 public subset 對齊檢查後，才計已取得／已整合 cases。
