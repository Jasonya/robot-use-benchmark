RLBench: The Robot Learning Benchmark & Learning Environment

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

RLBench 以 Python Task、CoppeliaSim 場景／模型和 condition 物件組成任務。應沿 task 的成功條件讀到 backend，而不是隻看任務名稱或示範檔。

版本與身份

README 明示action mode曾有破壞性變更；本輪固定公開commit，不能混用其他版本的動作約定。

領域
居家整理與清潔、通用物件與機動作業
環境
CoppeliaSim/PyRep 任務場景與模型；任務 class 數、variation 數和獨立環境數不能直接等同。
任務
Task class 繫結場景物件與 condition。open_drawer 包含 top/middle/bottom 三個 variation，並以 JointCondition 門檻0.15檢查絕對關節位移。
題數與資料
示範將多視角 RGB、depth、mask 分檔，並把影像從 observation 移除後儲存低維資料；載入時需閉合影像與狀態引用。
評估方式
各 task 註冊具體 condition。ConditionSet 可累積有序條件或做同時 AND；OrConditions 做 OR。這些狀態／過程語義要一起保留。

怎麼接入我們的benchmark

可重用

task ID、variation、場景模型、語言描述、示範與 condition 程式。

需要轉換

task、variation、初態、感測及 action mode 分開存；evaluator 指向具體條件程式。原生variation可作繫結變化，不自動當新增共同任務。

仍需補齊

完整模型／示範資產閉合、跨來源語義對齊及統一協定下的執行驗證。
