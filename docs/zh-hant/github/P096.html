ALFRED: A Benchmark for Interpreting Grounded Instructions for Everyday Tasks

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

ALFRED把家務型別、具體場景／物件／軌跡和語言repeat分開；成功取決於終態條件，與每步API成功、reward和示範長度加權分數不同。

版本與身份

主程式同時保留原論文與後續model links；不把所有外部model repo當新benchmark。ALFWorld是同系環境的不同介面，需顯式重用關係。

領域
居家整理與清潔、餐飲與烹飪
環境
AI2-THOR室內場景與物件狀態；原生目錄tuple包含scene_num，具體軌跡還需原始初態與版本。現行README仍指THOR2.1.0資料／檔案。
任務
評測器分7種家務型別：直接放置、清潔後放置、加熱後放置、冷卻後放置、放兩物、持物照燈、透過可移容器放置。物件／場景／語言repeat是下層條件，不與7種直接混算。
題數與資料
traj task_id/task_type、pddl_params、plan.high_pddl/low_actions、turk_annotations.anns[repeat_idx].task_desc；模型輸出離散action與互動mask。原生trial名稱不等於本庫policy重跑trial。
評估方式
EvalTask從視覺和語言rollout，STOP／max_steps／max_fails可終止，再取get_goal_satisfied與條件滿足數。例：照燈要求持有目標且燈可見並開啟。GC全域性累加條件分母，PLW按原示範low_actions長度加權，非導航圖最短距離SPL。t=0的除法及被exception跳過的題需adapter明確處理。

怎麼接入我們的benchmark

可重用

7種native task類別、PDDL引數、初態／低層操作與終態條件、language repeats。

需要轉換

原task_id/scene/repeat_idx拆為source instance與case鍵，留示範／語言父子關係；原生SR/GC/PLW分開記錄，失敗和未產出題也入分母清單。

仍需補齊

完整THOR初態重播、資產版本、split與合法模型資訊、missing/error題處理和原生/共同協定對照。
