P069 · robosuite

robosuite: A Modular Simulation Framework and Benchmark for Robot Learning

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

robosuite 提供可配置任務與狀態判定；論文的 SAC 圖表來自另一個 v1.0 benchmark 倉庫。已核讀 Lift、示範序列化及 return 統計鏈，不能把現行 v1.5 環境直接當原實驗版本。

版本與身份

主程式固定5ce6643f3092639d08f7b0f90ed1c6a84f50552c；SAC固定b229f7442f3590dd0e0cad21dc6ae52f410a34bc，依賴rlkit b7f97b2463df1c5a1ecd2d293cfcc7a4971dd0ab。SAC requirements 只寫robosuite>=1.0.1，卻使用mujoco-py/Gym舊API。notebook第89–100行把Wipe與Door都寫成NutAssemblyRound；Door示例variant為2000 epochs，論文／檔案為500。載入variant後，亂數初始化仍取CLI args.seed，不能只相信JSON seed。

對應 arXiv:2009.12293v3（2025-01-18），題名與作者以固定論文首頁為準；雖收錄年份為2020，本 PDF 明述 v1.5。PDF 第15頁直接連到 robosuite-benchmark；主倉庫 README 指回同一論文。

領域
居家整理與清潔、裝配與生產作業、通用物件與機動作業
環境
MuJoCo 的 robot＋arena＋objects 組合。已讀 Lift 使用0.8×0.8公尺桌面，桌高0.8公尺；cube 的 xy 初態在桌面原點附近各±0.03公尺抽樣。模型數、任務數與初始化 case 數分開。
任務
論文九個標準環境；實驗細化到 PickPlaceCan、NutAssemblyRound 等子型，雙臂設定另存。Lift 的具體 checker 只要求 cube 中心 z 大於桌面 z＋0.04公尺；不額外要求持續抓握或停留。其餘八個 checker 未逐一核讀。
題數與資料
原生 observation 是具名感測 dict；Lift 有 cube_pos、公尺制相對位置與 xyzw cube_quat，感測率跟 control_freq。HDF5 data/demo_N 存 states、actions 與 model_file XML；data attrs 存 env、env_info、repository_version、date/time。寫入前刪掉最後一筆 state 以對齊 actions，只收成功示範；此格式本身不含 RGB。20 Hz 是已讀基線設定，動作維度／縮放須保留各 controller 設定。
評估方式
基線鏈為 train→experiment→MdpPathCollector→CustomBatchRLAlgorithm._log_stats→get_custom_generic_path_information→eval_util。Returns 是每回合 reward 總和，ExplReturns 截至 exploration horizon；統計函式的 reward_scale 引數沒有執行除法，縮放在環境端。例示 run 每epoch收2500步、每回合500步，通常為5回合；論文另對5個訓練 seeds 報均值與標準差。現行 base.done 是 horizon 條件且 info 為空，不能當 task success。

怎麼接入我們的benchmark

可重用

任務 class、版本化 controller/env 設定、初態抽樣、HDF5 模型／狀態與具體 checker，以及原生 return 統計。

需要轉換

source 儲存論文v3與兩倉庫commit；environment 儲存robot/arena；task 儲存子型；case 儲存seed、初態、horizon/control_freq；evaluator 分列二元checker、shaped reward、episode return。模型XML與資產引用需閉合。

仍需補齊

原實驗所用 robosuite 精確commit仍未鎖定；尚需其餘任務checker、控制器動作約定及資產／重播驗證，不能宣稱已重現原圖。
