P235 · TransFusion

Summarize the Past to Predict the Future: Natural Language Descriptions of Context Boost Multimodal Object Interaction Anticipation

返回逐篇總表核心內容已核讀 方法／綜述參考原作 ↗

核讀快照 2026-10-11。已讀範圍限所列片段；本輪未執行上游程式。

作者頁直接連 algvr/transfusion，已核 Ego4D v1/v2 reader、語言摘要輸入及實際 Top-5 STA mAP。此來源是離線下一次人類物件互動預測；外部摘要、SlowFast TTC 替換與跨 GPU 合併都是結果協定的一部分。論文 EK100 路徑在現行入口尚未閉合。

版本與身份

固定 55d3a4eca3325dc65f5f0391cc27105ba110c00f。論文方法、作者專頁 CVPR 2024 release、Ego4D v1/v2 與 EK100 pseudo-label 實驗各留版本關係；同名 LiDAR TransFusion 不屬本篇。僅核上述核心來源，未執行上游、下載完整影片／模型／摘要套件。

精確題名與 Pasca、Gavryushin 等八位作者相符；清單 2023 是 arXiv 初稿，快取為 arXiv:2301.09209v4（2024-03-10）。PDF p.1 連作者專頁，專頁 HTML 52–117 行顯示相同題名、作者、CVPR 2024 與 Code→algvr/transfusion。專頁／現行 repo 支援兩版 Ego4D，不能把這個版本直接當 v4 文中全部 EK100 實驗的完整 release。

領域
方法／綜述參考，未另作來源用途歸納。
環境
Ego4D 人類第一人稱日常場景，包含廚房、園藝、維修等；論文另以 EPIC-KITCHENS-100 廚房影片驗證。輸入是 prediction frame 與其過去的語言化情境，沒有 robot state/action 或 simulator。
任務
每個 prediction uid 可有多個將互動的物件，預測 box、noun、verb、time_to_contact、score。v1 固定 mapping 有 87 nouns／74 verbs，v2 為 128／81；這些是詞彙類別，不是新增任務數。Noun、Noun-Verb、Noun-TTC、Overall 為不同匹配限制的指標，另有 noun-only／verb-only 消融。
題數與資料
fho_sta_{train,val,test_unannotated}.json 以 annotations、noun_categories、verb_categories、info.video_metadata 組成；每筆 uid、video_id(v1)/video_uid(v2)、frame、clip_id、clip_uid、clip_frame、objects[{box,verb_category_id,noun_category_id,time_to_contact}]。框為原影像 xyxy 畫素，TTC 為秒；det_sec=frame/fps，fps 讀各影片 metadata，不能一律硬設 30。reader 轉 Bboxes/all_nouns/all_verbs/det_diff，objects_to_entries 只留最後物件 TTC，再對所有物件複製，接軌應保留原始每物件 TTC 並驗證此假設。LMDB 模式可縮至高 480，jpg 模式不先縮框。noun ID 0 移至末類以讓 0 作背景，輸出再還原；v1/v2 對 nut/tape 等字串處理不同。設定 subset=0 實際使用原始 orig_split；另排除 5 個 UID、有框過濾與讀圖失敗跳下一筆，故完整 case 分母須由版本化可讀 uid manifest 計算，不能直接沿用論文的 64,798 統計。test 中 ball/take 與固定框為 loader placeholder，不能當 GT。語言 JSON 用 prediction uid 索引，v1 將 object_lang/action_lang 直接串接，v2 加分號；目前 current 策略消費預先生成摘要。
評估方式
EgoNAOTrainer 的 train/val 均建 STAMeanAveragePrecision(top_k=5)，先將預測與 GT 框轉整數。每圖按 confidence 遞減、以最大有效 IoU 一對一配對；IoU 使用畫素端點 +1 面積，實作 boxes>0.5，abs(TTC error)<=0.25 秒。論文 p.5 寫 IoU>=0.5、TTC<0.25，邊界不可混寫。Top-5 實作對每種配對條件豁免該圖最高分的 (5-1)×GT物件數個 FP；不是隻計五類。剩餘預測依 class/confidence 合併，recall=累積TP/該類GT物件數，precision=TP/(TP+FP)，取單調 precision envelope 的 VOC 積分；count_all_classes=False，對有 GT 的類別作宏平均×100，joint 指標按 noun 平均。trainer 輸出 results[uid]=至多5個{box,noun_category_id,verb_category_id,time_to_contact,score}，所以線上 raw-pred 指標與匯出檔重評有額外截斷差異。DDP 本地 AP 後同步不等於合併資料再計 AP；README 要合併 JSON 用 EGO4D/forecasting 正式指令碼。TTC loss 在兩設定均為 0，README 指論文結果使用外部 SlowFast TTC；這次沒有把本地 scorer 充當已核正式 server 結果。

怎麼接入我們的benchmark

可重用

版本化 category mapping、原始 annotation→case 欄位、語言 uid lookup、STA 配對與 AP 聚合，以及 submission JSON 外形。

需要轉換

source 記 paper/repo/Ego4D revision；domain/environment 指人類影片及該筆場景；task 保留下一次互動預測；case key=(dataset_version,split,uid)，frame 與 clip_frame 各留參照系，boxes 記 xyxy/原圖尺寸，objects 與 TTC 逐筆保留。label 同時存原 category ID 與背景重編號；context 記生成模型、輸入最大 frame/time、摘要資產 SHA、GT／預測模式。evaluator 區分本地／匯出／正式 server、Top-5 FP 預算、noun macro AP、TTC來源及 DDP 合併策略。

仍需補齊

需固定外部 context、Ego4D 標註與 SlowFast TTC revision；目前 loader 只按 uid 取字串，無法證明摘要只使用過去影格，w_leak=False 也不是此證明。核對多物件 TTC 被壓成一值、5 筆輸出截斷與實際可讀 case 分母。adapt_ttc_values.py 使用 argparse 的 description 引數、連字號 positional 名稱卻以底線取值，且 test_keys 未定義，不能視為可直接執行的 TTC 整合器；README 所述 evaluate_wandb_jsons.py 不在固定 tree。EK100 論文採 UniDet 產生 pseudo boxes 並依影片分割，現行 get_annotations_df 只接受 Ego4D，須找對應 release／處理過的 manifest 才能宣稱重現。
