EPIC Fields: Marrying 3D Geometry and Video Understanding

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

EPIC Fields分成重建/讀取工具與NVS、UDOS評測；epic-fields本身只是網頁倉庫，不能當作評測程式。

版本與身份

評測README明示2024-02-10標註更新，並給前版commit；原始arXiv與新版不能混用。

領域
居家整理與清潔、餐飲與烹飪
環境
相機與點雲是影片觀測幾何；video-scene與原廚房一對多，不能每影片都新增可操作環境。
任務
NVS、動態/半靜態分割、VISOR衍生VOS是不同資訊/世界模型評測端點。
題數與資料
JSON的camera採COLMAP/OpenCV內參，images為qw-first quaternion加translation的world-to-camera，points含XYZRGB。評測另需EPIC100影格、mask、split與模型cache。
評估方式
NVS先逐影片平均PSNR再跨影片平均，前景/背景僅在適用within-action列出。UDOS依有效mask畫素算AP、排除無有效標籤影格，motion型別分報。

怎麼接入我們的benchmark

可重用

video/frame ID、相機轉換、原生NVS/UDOS split與評分。

需要轉換

明記W2C、qw順序與軸方向；轉NeRF時儲存反轉/翻軸。兩種case的可見輸入、mask與聚合分母分開。

仍需補齊
