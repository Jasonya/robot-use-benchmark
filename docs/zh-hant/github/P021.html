P021 · Ego-ExoLearn

EgoExoLearn: A Dataset for Bridging Asynchronous Ego- and Exo-centric View of Procedural Activities in Real World

返回逐篇總表核心內容已核讀 benchmark／資料／評測主來源原作 ↗ 用途與原生規模依據

核讀快照 2026-10-10。已讀範圍限所列片段；本輪未執行上游程式。

EgoExoLearn 的核心是不同時間、不同視角的人類示範跟隨。已核讀標註、跨視角 association 的選項評分和 skill assessment 的成對排序，兩者不是同一種成功率。

版本與身份

annotations README 開頭仍說只有 train/val，結尾與 root 更新已提供 test GT；標準化應鎖定實際檔案，不直接採信舊段落。VQA 與 full-size videos 為後續更新，不能併稱首發版本。

領域
餐飲與烹飪、實驗室操作
環境
資料列 kitchen／lab，用於日常協助與實驗室程式；scene 是粗場景用途，video_uid 才是影片 ID。ego/exo 是非同步示範關係，不可當同步多相機標定資料。
任務
跨視角 association、動作分割／anticipation／planning、參考示範的 skill assessment／captioning；2024-08 又加入 VQA。能力題型與程式活動類別分開。
題數與資料
fine CSV 保留 video_uid、annotation_uid、subset、view、scene、start/end_sec、人工 narration_en；hand/no-hand prompt 文字是 GPT 改寫。skill list 每列 better/worse 影片，NPZ arr_0 提供特徵，use_exo 時依 action 從 exo 檔案隨機選一參考。association loader 回 query、options、answer、q_type、uid。
評估方式
association 對 query/options 特徵相似度 argmax，按 Ego→Exo／Exo→Ego 分組 accuracy；skill train.py 的 accuracy 是 better 分數嚴格大於 worse 的配對比例，平手不算對。RankingAttentionLoss 為訓練 loss，不能拿它代替評測 accuracy。

怎麼接入我們的benchmark

可重用

原生標註／改寫來源、跨視角配對、better/worse 排序與兩種核心評分。

需要轉換

保留 demo_reference 邊及不同 video 時間線；同一影片多問答／配對透過 uid 共用，不能重算成新環境。case 儲存配對順序、選項、exo reference 與抽樣 seed；人工與生成字幕 provenance 分開。

仍需補齊

尚未取得影片／gaze／特徵或執行。完整 segmentation/planning/captioning 與新增 VQA evaluator 尚未核讀；若比較參考示範版本，需鎖定具體 exo reference，不能每次隨機抽而不留紀錄。
